# 해외사업장 순투자·장기대여금·환산차이·순투자위험회피
## 최종 통합 보고서

> **통합 방침**
> 원본 4개 문서는 서로 다른 두 개의 숫자 사례(1,300→1,400 / 1,000→1,200)를 사용하고 있어 대조 시 혼란이 발생합니다.
> 본 보고서는 **1,000 → 1,200 사례 하나**로 전 구간(별도 → 개별 → 환산 → 연결 → 헤지 → 재분류)을 관통시키고, 원본에 없던 **제3통화 케이스, 세무 접점, 판단(지정 아님) 논점**을 보강했습니다.

# Part 0. 30초 요약 — 딱 이 다섯 문장

> **①** 모회사의 외화대여금 환율차이는 **모회사 별도재무제표에서 발생**하고, 해외사업장 환산차이는 **연결 환산과정에서 발생**한다. 둘은 **발생 원천이 다르다.**

> **②** 대여금이 순투자의 일부여도 **별도재무제표에서는 여전히 당기손익(P/L)**이다. 순투자의 일부라는 이유로 별도부터 OCI가 되는 것이 아니다.

> **③** 연결에서 내부 대여금·차입금 **원금은 제거**하지만, 그 화폐성 항목에서 발생한 **환율차이는 제거되지 않는다**(IAS 21.45).

> **④** 그 환율차이가 **연결 P/L에 남는지, 연결 OCI로 가는지**를 가르는 유일한 스위치가 **IAS 21.15 순투자 요건 충족 여부**다.

> **⑤** 내부 대여금은 순투자의 **구성항목(노출)**은 될 수 있어도, 연결재무제표에서 순투자위험회피의 **위험회피수단은 될 수 없다**(IFRS 9.6.2.3 외부 당사자 요건).

# Part 2. 이 주제가 헷갈리는 진짜 이유 — 4개 층위(Layer) 분리

이 주제의 모든 혼란은 **성격이 다른 4개의 회계 사건을 하나로 뭉쳐서 보기 때문**에 발생합니다.
아래 4층을 분리하는 순간 문제의 90%가 해결됩니다.

```text
┌──────────────────────────────────────────────────────────────┐
│ Layer 1 · 외화거래의 재측정 (IAS 21.20~28)                    │
│   각 기업이 "자기 기능통화"로 외화 화폐성 항목을 기말 재측정    │
│   → 발생 장소: 그 기업의 별도/개별재무제표                     │
│   → 원칙: P/L                                                 │
├──────────────────────────────────────────────────────────────┤
│ Layer 2 · 해외사업장 재무제표의 표시통화 환산 (IAS 21.39~41)   │
│   자회사 기능통화 FS → 그룹 표시통화로 환산                    │
│   → 발생 장소: 연결(환산) 절차                                 │
│   → 원칙: OCI (FCTR)                                          │
├──────────────────────────────────────────────────────────────┤
│ Layer 3 · 순투자의 일부인 화폐성 항목 (IAS 21.15, 32, 33, 45)  │
│   Layer 1에서 이미 P/L로 잡힌 환율차이의                       │
│   "연결에서의 표시 성격"을 바꾸는 재분류 레이어                 │
│   → 발생 장소: 연결조정                                        │
│   → 원칙: P/L → OCI                                           │
├──────────────────────────────────────────────────────────────┤
│ Layer 4 · 순투자위험회피 (IFRS 9.6.5.13 + IFRIC 16)           │
│   외부 금융상품 손익을 OCI에 넣는 완전히 별개의 절차           │
│   → 발생 장소: 위험회피회계 적용                               │
│   → 원칙: 유효부분 OCI / 비유효부분 P/L                        │
└──────────────────────────────────────────────────────────────┘
```

## 2.1 층위별 "가장 흔한 오해" 대응표

| Layer | 흔한 오해 | 정정 |
|---|---|---|
| 1 | "USD 100 대여금이니까 장부에 100달러로 기록" | 모회사 기능통화가 KRW이면 장부는 **KRW로 기록**하고, USD 100은 외화 보조원장의 **명목금액**으로 추적 |
| 1 | "모회사 환율이익 +10을 자회사 환율손실 -10이 상쇄" | 자회사 기능통화가 USD이고 차입금도 USD면 **자회사 개별 FS에는 환율손익이 없다** |
| 2 | "FCTR = 기말 순자산 × 환율변동" | 자산·부채는 기말환율, 손익은 거래일(평균)환율, 자본거래는 거래일환율. **단순 곱셈이 아니다** |
| 2 | "자회사 차입금 USD 100을 환산하니 별도 FCTR이 생긴다" | 내부대여로 현금 +100 / 차입금 +100 → 그 거래만으로 **자회사 순자산 변동 = 0** |
| 3 | "순투자의 일부니까 모회사 별도부터 OCI" | **별도는 P/L**. OCI는 연결에서 |
| 3 | "순투자의 일부인 대여금은 연결에서 상계하지 않는다" | **원금은 제거한다**. 제거되지 않는 것은 환율차이 |
| 3 | "우리는 그 대여금을 순투자로 지정했다" | 지정이 아니라 **사실관계 판단**. 지정이라는 표현은 위험회피회계 용어와 혼동을 유발 |
| 4 | "내부대여금이 순투자의 일부이므로 위험회피수단이다" | 순투자의 일부 = **위험회피대상(노출) 측**. 수단은 **외부계약**이어야 함 |
| 4 | "위험회피수단 환율손익 전액이 OCI" | **유효부분만** OCI |
| 4 | "헤지수단을 상환했으니 누적 OCI를 P/L로" | 우산을 접은 것이지 **건물을 판 것이 아니다** |

# Part 3. 통합 숫자 사례 (Master Case) — 이 하나로 끝까지

## 3.1 전제

```text
한국 모회사 A            미국 종속기업 B
기능통화 KRW    ──100%──▶ 기능통화 USD
연결 표시통화 KRW
```

| 항목 | 내용 |
|---|---|
| 2026.1.1 환율 | USD 1 = KRW 1,000 |
| 2026.12.31 환율 | USD 1 = KRW 1,200 (USD 강세 +200원) |
| A → B 지분출자 | USD 100 (2026.1.1) |
| A → B 장기대여 | USD 100 (2026.1.1, 계약통화 USD) |
| B의 기중 활동 | 영업·손익·배당·추가자본거래 **없음**, 받은 자금 USD 200 전액 현금 보유 |

> [!note] 단순화 고지
> B의 기중 손익·배당·증자를 0으로 둔 것은 **교육 목적의 단순화**입니다.
> 실제 FCTR 산정에서는 기초 순자산(전기말환율), 당기손익(평균/거래일환율), 배당·증자(거래일환율), 취득 시 공정가치조정·영업권까지 함께 환산해야 합니다.

## 3.2 B의 USD 재무상태 (기초 = 기말, 변동 없음)

```text
[미국 종속기업 B / 기능통화 USD]

자산   현금            USD 200
부채   A에 대한 차입금  USD 100
자본   자본금          USD 100
──────────────────────────────
       순자산          USD 100
```

## 3.3 Step 1 — 모회사 A의 별도재무제표 (Layer 1)

**최초 인식 (환율 1,000)**

```text
Dr 종속기업투자주식   100,000      ← 비화폐성 항목, 이후 환산 대상 아님
   Cr 현금                       100,000

Dr 대여금             100,000      ← 화폐성 항목, 외화 명목금액 USD 100 추적
   Cr 현금                       100,000
```

**기말 재측정 (환율 1,200)**

```text
대여금  USD 100 × 1,000 = 100,000
      → USD 100 × 1,200 = 120,000

Dr 대여금              20,000
   Cr 외화환산이익      20,000   → P/L
```

> [!important] 여기가 첫 번째 분기점
> **Case A(일반대여금)든 Case B(순투자의 일부)든 이 분개는 완전히 동일합니다.**
> IAS 21.32 전단이 순투자의 일부인 화폐성 항목도 별도재무제표에서는 P/L로 인식하도록 하기 때문입니다.

## 3.4 Step 2 — 자회사 B의 개별재무제표

B의 기능통화 = USD, 차입금 통화 = USD → **동일통화**

```text
차입금 USD 100 → USD 100  (변동 없음)
KRW/USD 환율변동으로 B의 개별 FS에 환율손익 = 0
```

따라서 모회사의 +20,000을 상쇄하는 자회사 -20,000은 **존재하지 않습니다.**
이것이 "연결에서 환율차이가 남는" 근본 이유입니다.

## 3.5 Step 3 — B의 재무제표 환산 (Layer 2)

| 항목 | USD | 적용환율 | KRW |
|---|---:|---:|---:|
| 자산(현금) | 200 | 1,200 (기말) | 240,000 |
| 부채(차입금) | (100) | 1,200 (기말) | (120,000) |
| **순자산 환산액** | **100** | 1,200 | **120,000** |
| 자본금 | 100 | 1,000 (거래일) | 100,000 |
| **환산차이(FCTR)** | | | **+20,000** |

```text
해외사업장 B 자체의 환산차이 = +20,000 → OCI   (IAS 21.39(c), 41)
```

> [!warning] 반드시 구분
> 이 **+20,000**과 Step 1의 **+20,000**은 **금액만 같고 완전히 다른 사건**입니다.
> - Step 1 : 모회사가 보유한 USD 화폐성 자산의 재측정 (IAS 21.28)
> - Step 3 : 자회사 순자산 USD 100의 표시통화 환산 (IAS 21.39(c))

## 3.6 Step 4 — 연결 제거

```text
Dr 자본금(B)          100,000
   Cr 종속기업투자주식        100,000   ← 투자·자본 상계

Dr 내부차입금(B)      120,000
   Cr 내부대여금(A)          120,000   ← 내부 채권·채무 제거
```

**여기서 IAS 21.45의 핵심 원리:**

> 내부 화폐성 채권·채무의 **원금**은 제거된다.
> 그러나 서로 다른 기능통화 사이에서 발생한 **환율변동의 결과까지 제거할 수는 없다.**

즉 Step 1의 +20,000은 원금 제거에도 불구하고 연결에 **반드시 어딘가에 표시**되어야 합니다.
어디에 표시되는가 — 그것이 Case A와 Case B의 유일한 차이입니다.

## 3.7 Case A — 일반 대여금 (IAS 21.15 요건 미충족)

**사실관계 예시**: 만기 1년, 실제 회수계획 존재, 가까운 미래 상환 예정, 정상적 원리금 회수 이력

```text
[1] 모회사 별도  : 외화환산이익 +20,000 → P/L
[2] 자회사 환산  : 환산차이     +20,000 → OCI
[3] 연결 제거    : 대여금 120,000 ↔ 차입금 120,000
[4] 환율차이     : +20,000은 연결 P/L에 그대로 잔존   (IAS 21.45 전단)

───────── 당기 효과 ─────────
연결 P/L   +20,000
연결 OCI   +20,000
합계       +40,000
```

## 3.8 Case B — 순투자의 일부인 장기대여금 (IAS 21.15 요건 충족)

**사실관계 예시**: 가까운 미래 결제계획 없음, 결제 가능성 낮음, 반복적 만기연장, 실질적 장기 투자자금

```text
[1] 모회사 별도  : 외화환산이익 +20,000 → P/L
[2] 자회사 환산  : 환산차이     +20,000 → OCI
[3] 연결 제거    : 대여금 120,000 ↔ 차입금 120,000
[4] 연결조정(IAS 21.32 후단)

    Dr 외화환산이익(P/L)      20,000
       Cr OCI / 외화환산누계액       20,000

───────── 당기 효과 ─────────
연결 P/L        0
연결 OCI   +40,000
합계       +40,000
```

## 3.9 Case A vs Case B 한눈에

| 구분 | Case A 일반대여금 | Case B 순투자의 일부 |
|---|---:|---:|
| 대여금 법적 성격 | 대여금 | **대여금** (자본으로 전환되지 않음) |
| 자회사 측 계정 | 차입금 | 차입금 |
| 모회사 별도 환율차이 | +20,000 P/L | **+20,000 P/L (동일)** |
| 자회사 개별 환율손익 | 0 | 0 |
| 자회사 자체 환산차이 | +20,000 OCI | +20,000 OCI |
| 내부 원금 제거 | 제거 | 제거 |
| 환율차이도 제거되는가 | **아니오** | **아니오** |
| 대여금 환율차이의 연결 표시 | **P/L** | **OCI / FCTR** |
| **최종 연결 P/L** | **+20,000** | **0** |
| **최종 연결 OCI** | **+20,000** | **+40,000** |
| **총 자본 증가** | **+40,000** | **+40,000** |
| 기준서 | IAS 21.45 전단 | IAS 21.15·32·45 후단 |

> [!important] 이 표의 마지막 행이 전부입니다
> **경제적 총효과 40,000은 두 Case가 동일합니다.**
> 달라지는 것은 오직 **그 40,000을 P/L과 OCI 사이에 어떻게 나누는가**뿐입니다.
> 순투자 판단은 "이익을 만드는" 문제가 아니라 **"이익의 표시 위치를 바꾸는"** 문제입니다.

## 3.10 검산 3종 — Case B의 OCI 40,000은 이중계상이 아니다

이 부분이 실무자가 가장 불안해하는 지점이므로 세 가지 방법으로 검산합니다.

**검산 ① — 경제적 USD 노출 관점**

```text
지분자금             USD 100
순투자의 일부인 대여금 USD 100
────────────────────────────
장기 USD 노출        USD 200

USD 200 × KRW 200 = KRW 40,000  ✔ 일치
```

**검산 ② — 연결재무상태표에 실제로 남는 외화자산 관점**

```text
연결에서 내부 대여금·차입금은 제거됨
그러나 B가 보유한 외부 USD 현금 200은 연결자산에 그대로 존재

기초: USD 200 × 1,000 = 200,000
기말: USD 200 × 1,200 = 240,000
                       ────────
                        +40,000  ✔ 일치
```

**검산 ③ — 발생원천 분해**

| 발생원천 | 기준서 | 당기 OCI |
|---|---|---:|
| 해외사업장 B 자체 재무제표 환산 | IAS 21.39(c) | +20,000 |
| 순투자의 일부인 화폐성 항목 환율차이 | IAS 21.32 | +20,000 |
| **합계** | | **+40,000** ✔ |

> 세 검산이 모두 40,000으로 수렴합니다. **이중계상이 아니라, 서로 다른 두 개의 USD 노출(지분 100 + 대여 100)의 합**입니다.

## 3.11 Step 5 — Layer 4 추가: 외부 USD 차입금으로 순투자위험회피

이제 A가 외부 은행에서 **USD 80**을 차입하고, 이를 미국 순투자에 대한 위험회피수단으로 지정했다고 가정합니다.

```text
외부 USD 차입금 USD 80
기초: 80 × 1,000 = 80,000
기말: 80 × 1,200 = 96,000
                  ────────
              환차손 -16,000
```

**위험회피회계 미적용 시**

```text
연결 P/L  -16,000  (외화환산손실)
연결 OCI  +40,000
```

**위험회피회계 적용 시 (지정금액 USD 80, hedge ratio 1:1, 완전유효 가정)**

| 항목 | 누적 변동 | 처리 |
|---|---:|---|
| 위험회피대상(순투자 중 USD 80 지정분) | +16,000 | (대상 자체는 별도 인식 없음) |
| 위험회피수단(외부 USD 차입금) | -16,000 | **유효부분 → OCI** |
| 비유효부분 | 0 | P/L |

```text
연결 OCI 구성
  자회사 자체 환산차이        +20,000
  순투자 화폐성 항목 환율차이  +20,000
  위험회피수단 유효부분        -16,000
  ──────────────────────────────────
  순 OCI                       +24,000

연결 P/L  0
```

## 3.12 유효/비유효 구분 — Under-hedge vs Over-hedge

순투자위험회피는 현금흐름위험회피와 유사하게 회계처리하며, 실무상 **lower-of 방식**으로 유효부분을 산정합니다.

> 3.11은 **대상 USD 80 : 수단 USD 80**(완전유효)을 가정했습니다. 아래는 **지정금액을 USD 100으로 늘린 경우**의 두 시나리오입니다.

**Case Under-hedge (지정 대상 USD 100, 수단 USD 80)**

```text
위험회피대상 누적변동   +20,000
위험회피수단 누적손익   -16,000

유효부분   -16,000 → OCI
비유효부분        0 → P/L
```

> ❌ `20,000 - 16,000 = 4,000`을 비효과로 P/L에 넣는 것이 아닙니다.
> 그 4,000은 **헤지되지 않고 남은 순투자 위험(unhedged exposure)**일 뿐입니다.

**Case Over-hedge (지정 대상 USD 100, 수단 USD 120)**

```text
위험회피대상 누적변동   +20,000
위험회피수단 누적손익   -24,000

유효부분   -20,000 → OCI
비유효부분  -4,000 → P/L
```

> [!caution] 확인 필요
> IFRS 9은 순투자위험회피를 "현금흐름위험회피와 유사하게 처리"하도록 규정(6.5.13)하며, lower-of 산식은 6.5.11(a)의 현금흐름위험회피 규정에 직접 명시되어 있습니다.
> 순투자위험회피에 대한 세부 측정방법은 **회계정책으로 문서화**해 두는 것이 안전합니다. (해석상 다툼 가능 영역은 아니나, 문서화 미비는 감사지적 사유가 됩니다.)

# Part 4. FCTR 해부 — 3대 유입경로와 Roll-forward

## 4.1 개념도

```text
                    해외사업장 관련 외화환산 OCI (FCTR)
                                │
          ┌─────────────────────┼─────────────────────┐
          │                     │                     │
          ▼                     ▼                     ▼
   [A] 해외사업장          [B] 순투자의 일부인      [C] 순투자위험회피
       재무제표 환산차이        화폐성 항목 환율차이      수단의 유효부분
          │                     │                     │
    IAS 21.39(c), 41       IAS 21.32, 33, 45      IFRS 9.6.5.13
          │                     │                     │
    발생: 연결 환산절차      발생: 별도 P/L        발생: 외부 금융상품 손익
          │                  → 연결조정으로 OCI       │
          │                     │                     │
          └─────────────────────┼─────────────────────┘
                                ▼
                          연결 OCI 누적 (FCTR)
```

> **핵심 명제: 같은 OCI 바구니에 들어간다고 해서 발생 원인까지 같은 것은 아니다.**

## 4.2 3대 유입경로 비교표

| 구분 | [A] 해외사업장 환산차이 | [B] 순투자 화폐성 항목 | [C] 위험회피수단 유효부분 |
|---|---|---|---|
| 기준서 | IAS 21.39(c), 41 | IAS 21.32~33, 45 | IFRS 9.6.5.13 |
| 출발점 | 자회사 기능통화 FS 전체 | 특정 화폐성 항목 1건 | 외부 금융상품 1건 |
| 최초 발생 위치 | 연결 환산절차 | 보유기업의 별도/개별 FS | 보유기업의 별도 FS |
| 별도 P/L 발생 | 없음 | **있음** (이후 연결조정) | **있음** (이후 OCI 대체) |
| 요건 | 기능통화·표시통화 상이 | IAS 21.15 판단 | IFRS 9.6.4.1 지정·문서화·효과성 |
| 효과성 평가 | 불필요 | 불필요 | **필수** |
| 비유효부분 개념 | 없음 | 없음 | **있음 → P/L** |
| 재분류 시점 | 해외사업장 처분 | 해외사업장 처분 | 해외사업장 처분 |
| 본 사례 금액 | +20,000 | +20,000 | -16,000 |

## 4.3 감사·결산용 FCTR Roll-forward 양식 (그대로 사용 가능)

| 구분 | 기초 | 당기 OCI | 재분류(P/L) | NCI 재귀속 | 기말 | 근거 |
|---|---:|---:|---:|---:|---:|---|
| A. 해외사업장 자체 환산차이 | X | +20,000 | - | - | X+20,000 | IAS 21.39(c) |
| B. 순투자 화폐성 항목 환율차이 | Y | +20,000 | - | - | Y+20,000 | IAS 21.32 |
| C. 순투자위험회피 유효부분 | Z | (16,000) | - | - | Z-16,000 | IFRS 9.6.5.13 |
| **합계** | X+Y+Z | **+24,000** | - | - | | |

> [!important] 실무 권고
> 다수 기업이 FCTR을 **단일 reserve 잔액 하나**로만 관리합니다.
> 그러나 처분·부분처분·헤지중단 시점에 **원천별 분해가 불가능하면 재분류 금액을 산정할 수 없습니다.**
> 위 3분류 roll-forward는 **해외사업장별(entity별)**로 작성해야 합니다.

# Part 5. 판단 ① — 이 대여금이 순투자의 일부인가? (IAS 21.15)

## 5.1 요건

IAS 21.15는 다음 요건을 제시합니다.

> 해외사업장에 대한 채권·채무 중 **결제가 가까운 미래(foreseeable future)에 계획되어 있지 않고, 발생 가능성도 낮은** 화폐성 항목은 실질적으로 해외사업장 순투자의 일부이다.

**명시적 제외**: **매출채권·매입채무(trade receivables/payables)는 제외**됩니다.

**IAS 21.15A**: 해당 화폐성 항목을 보유한 기업은 **모회사가 아니라 그룹 내 어느 종속기업이어도 무방**합니다.
→ 즉 `싱가포르 법인 → 미국 법인` 대여금도 순투자의 일부가 될 수 있습니다.

## 5.2 판단 체크리스트 (사실관계 수집표)

| # | 확인사항 | 순투자↑ 신호 | 일반대여금↑ 신호 | 증빙 |
|---:|---|---|---|---|
| 1 | 계약상 만기 | 만기 없음/초장기 | 1~3년 명확 | 대여계약서 |
| 2 | 만기 연장 이력 | 반복적 자동연장 | 연장 없음 | 변경계약서 |
| 3 | 과거 상환 실적 | 원금 상환 이력 없음 | 정기 분할상환 | 입출금 내역 |
| 4 | 이자 지급 | 무이자/이자 자본화 | 정상 이자 수취 | 이자 정산내역 |
| 5 | 자금 용도 | 설비투자·초기 결손 보전 | 일시적 운전자금 | 이사회 승인자료 |
| 6 | 차입자의 상환능력 | 자체 현금창출로 상환 불가 | 상환 가능 | 자회사 자금계획 |
| 7 | 자금계획상 상환 반영 | 미반영 | 반영 | 그룹 자금계획서 |
| 8 | 항목 성격 | 대여금/장기채권 | 매출채권·매입채무 | 계정분류 |
| 9 | 경영진 의도 문서 | "장기 투자자금" 명시 | 회수 예정 명시 | 경영진 memo |

> [!caution] 감사상 핵심 논점
> **"가까운 미래(foreseeable future)"는 기준서에 정의되어 있지 않습니다.** (해석상 다툼 가능)
> 실무상 12개월 초과를 기준으로 접근하는 사례가 많으나 기계적 기준은 아니며, **의도(intention)와 가능성(likelihood)을 모두** 입증해야 합니다.
> 특히 **"결제 계획이 없다"만으로는 부족하고 "결제 가능성도 낮다"는 별도 근거**가 필요합니다.

## 5.3 표현 교정 — "지정"이 아니라 "판단"

| ❌ 회사가 자주 쓰는 표현 | ✅ 정확한 표현 |
|---|---|
| "이 대여금을 순투자로 **지정**했습니다" | "이 대여금이 IAS 21.15 요건을 충족하는지 **판단**한 결과 순투자의 일부에 해당합니다" |

이 표현 차이가 중요한 이유:
- "지정(designation)"은 **IFRS 9 위험회피회계의 용어**입니다.
- 회사가 "순투자로 지정"이라고 말하는 순간, 감사인은 **위험회피지정과 혼동하고 있는지** 반드시 확인해야 합니다.
- 실제로 원본 검토건에서 발생한 오류의 출발점이 바로 이 용어 혼동입니다.

## 5.4 심화 — 대여금의 **표시통화**에 따라 환율차이 발생 장소가 달라진다 (IAS 21.33)

원본 4개 문서는 모두 "대여금 통화 = 자회사 기능통화(USD)" 케이스만 다루고 있습니다.
실무에서는 나머지 두 케이스도 자주 등장하므로 정리합니다.

| 케이스 | 대여금 표시통화 | 환율차이가 **발생하는 재무제표** | 연결에서의 처리 |
|---|---|---|---|
| ① (본 사례) | USD = **B의 기능통화** | **A의 별도 FS** (A에게 USD는 외화) | OCI |
| ② | KRW = **A의 기능통화** | **B의 개별 FS** (B에게 KRW는 외화) | OCI |
| ③ | EUR = **제3통화** | **A의 별도 FS + B의 개별 FS 양쪽** | **양쪽 모두 OCI** |

> **실무 시사점**
> 케이스 ②에서는 모회사 별도 FS에 환율손익이 없고, 대신 **자회사 개별 FS에 환율손익이 발생**합니다.
> 이때 "모회사 장부에 환율차이가 없으니 순투자 논점이 없다"고 판단하면 오류입니다.
> 케이스 ③에서는 **양쪽에서 각각 발생한 환율차이를 모두** 연결 OCI로 대체해야 하므로 조정 누락 위험이 가장 큽니다.

## 5.5 순투자 판단이 **변경**되는 경우 (확인 필요 / 해석상 다툼 가능)

| 상황 | 처리 방향 | 확실성 |
|---|---|---|
| 일반대여금 → 순투자의 일부 (상환계획 철회 등) | 변경 시점부터 **전진적** 적용 | 일반적 실무 |
| 순투자의 일부 → 일반대여금 (상환 확정 등) | 변경 시점부터 전진적 적용 | 일반적 실무 |
| 변경 전까지 OCI에 누적된 금액의 처리 | **기준서에 명시 규정 없음** → 처분 전까지 자본에 잔존시키는 견해가 우세하나 **해석상 다툼 가능** | ⚠️ |

→ 회계정책으로 사전에 확정하고 일관 적용할 것을 권고합니다.

# Part 6. 판단 ② — 위험회피회계 (가장 중요한 오류 지점)

## 6.1 반드시 구분할 3개 개념

> **① 순투자의 일부인 화폐성 항목** → 위험회피**대상 측 노출을 구성**
> **② 순투자위험회피의 위험회피대상(Hedged item)** → 순투자에서 발생하는 적격 외화위험
> **③ 순투자위험회피의 위험회피수단(Hedging instrument)** → **외부계약 금융상품**

## 6.2 내부 대여금은 왜 위험회피수단이 될 수 없는가

**(1) 형식 요건 — 결정적 사유**

IFRS 9.6.2.3은 위험회피수단을 **보고기업 외부 당사자와의 계약**으로 한정합니다.
연결재무제표에서 보고기업 = **연결실체 전체**이므로,

```text
한국 모회사 A ──── 내부 대여금 ────▶ 미국 종속기업 B
```

은 연결실체 **내부** 계약입니다. → **원칙적으로 부적격**

**(2) 경제적 관계 — 방향이 반대가 아니라 같다**

| 항목 | USD 강세 시 KRW 기준 효과 |
|---|---|
| 미국 자회사 순자산 (위험회피대상) | **+** 증가 |
| 모회사의 USD 대여금 | **+** 증가 |
| 외부 USD 차입금 (적격 수단) | **-** 감소(손실) |

내부 USD 대여금은 순투자 노출과 **같은 방향**으로 움직입니다.
→ 상쇄하는 수단이 아니라 **노출을 키우는 항목**입니다.

**(3) IFRIC 16 AG14~15 — 오히려 순투자 금액에 영향을 준다**

내부 화폐성 항목이 순투자의 일부이면, 그 **방향에 따라 지정가능한 순투자 금액 자체가 증감**합니다.
→ 동일 항목을 "노출 조정 항목"이자 "그 노출을 헤지하는 수단"으로 이중 취급하는 것은 논리적으로 성립하지 않습니다.

## 6.3 "IFRS 9은 순투자의 일부인 화폐성 항목의 위험회피도 포함한다"는 문언의 의미

이 문언은 다음을 의미합니다.

> ✅ 순투자의 일부인 화폐성 항목이 **위험회피대상(hedged item)에 포함될 수 있다**

다음을 의미하지 **않습니다.**

> ❌ 동일한 그룹 내부 화폐성 항목을 **위험회피수단으로 사용할 수 있다**

## 6.4 적격 위험회피수단의 범위

| 수단 | 적격 여부 | 비고 |
|---|---|---|
| 외부 은행 USD 차입금 | ✅ | 비파생 금융부채의 외화위험 구성요소 (IFRS 9.6.2.2) |
| 외부 USD 선도환 | ✅ | |
| 외부 통화스왑 | ✅ | |
| 외부 발행 USD 사채 | ✅ | |
| **그룹 내부 대여금** | ❌ | **IFRS 9.6.2.3 외부 당사자 요건 위반** |
| 그룹 내부 파생상품 | ❌ | 연결에서 제거됨 |

**보유 주체는 유연합니다 (IFRIC 16.14~15)**:

```text
싱가포르 종속기업 C ──── USD Forward ────▶ 외부 은행
                                            │
                        일정 요건 충족 시    │
                     그룹의 미국 사업장 B에 대한
                       순투자위험회피에 사용 가능
```

> **정리: 그룹 내 어느 회사가 보유하는지는 유연하다. 그러나 거래상대방은 반드시 그룹 외부여야 한다.**
> (2009년 개정으로 피위험회피 해외사업장 자체가 수단을 보유하는 것도 배제되지 않는 것으로 이해되나 — **확인 필요**)

## 6.5 지정가능 금액의 한도 (IFRIC 16.11) — 흔한 과대지정

> 위험회피대상으로 지정할 수 있는 금액은 **연결재무제표상 해외사업장 순자산 장부금액을 초과할 수 없습니다.**

본 사례에서 "총 USD 노출 200"이라고 해서 **자동으로 USD 200 전액을 지정할 수 있는 것이 아닙니다.**

지정 전 반드시 확인:
1. 연결재무제표상 해당 해외사업장의 순자산 장부금액 (영업권 포함 여부 포함)
2. 순투자의 일부인 내부 화폐성 항목의 **방향**(수취/지급)에 따른 순투자 금액 증감
3. 상위 모회사 단계에서 이미 지정된 위험회피관계 존부
4. **동일 순자산·동일 위험의 중복 지정 여부**

> [!caution] 사실관계에 따라 달라짐
> "OCI 노출이 USD 200이므로 USD 200 전액을 hedged item으로 지정할 수 있다"는 결론으로 바로 연결하면 안 됩니다.
> **OCI 회계처리와 hedge designation 가능 금액은 완전히 별개의 검토 단계**입니다.

## 6.6 적격 외화위험의 범위 (IFRIC 16.10, 13)

| 구분 | 적격 여부 |
|---|---|
| 해외사업장 기능통화 ↔ **모기업(직접·중간·최상위) 기능통화** 간 위험 | ✅ 적격 |
| 단순히 **표시통화**가 다르다는 이유로 발생하는 위험 | ❌ **부적격** |

→ 표시통화 환산위험만을 근거로 지정한 헤지관계가 있다면 **적격성 재검토 대상**입니다.

## 6.7 위험회피회계 적용요건 (IFRS 9.6.4.1) — 체크리스트

**지정·문서화 (개시 시점에 완비되어야 함, 사후 작성 불가)**

- [ ] 위험관리 목적 및 전략
- [ ] 위험회피대상 (해외사업장 및 지정금액 명시)
- [ ] 위험회피수단 (계약상대방·외부 여부 명시)
- [ ] 위험회피할 위험 (통화쌍 명시 — 기능통화 간 위험인지)
- [ ] Hedge ratio 및 그 근거
- [ ] 효과성 평가 방법 및 주기
- [ ] 예상되는 비효과의 원천

**효과성 요건**

- [ ] 위험회피대상과 수단 사이에 경제적 관계 존재 (**방향이 반대인지 반드시 확인**)
- [ ] 신용위험의 영향이 가치변동을 지배하지 않을 것
- [ ] 실제 위험관리에 사용하는 수량 기준의 hedge ratio 사용

## 6.8 통화별 Exposure Matrix (감사인 작성 권장)

말로 설명받지 말고 아래 표를 채우게 하면 부적격 지정이 즉시 드러납니다.

| 항목 | 보유주체 | 거래상대방 | 보유주체 기능통화 | 계약통화 | KRW/USD ↑ 시 | 연결 제거 | 역할 |
|---|---|---|---|---|---|---|---|
| 미국 자회사 순자산 | 연결실체 | - | USD | USD | **+** | N/A | Hedged item |
| A → B 대여금 | A | **B(내부)** | KRW | USD | **+** | 원금 제거 / 환율차이 존속 | **순투자 구성항목** |
| 외부 USD 차입금 | A | 외부은행 | KRW | USD | **-** | 제거 안 됨 | **Hedging instrument** |
| USD Forward | C | 외부은행 | SGD | USD | **-** | 제거 안 됨 | Hedging instrument |

이 표 하나로 즉시 확인되는 것:
1. 대상과 수단이 실제로 **반대 방향**인가
2. **내부/외부** 계약인가
3. 동일 위험이 **이중 지정**되어 있는가
4. 순투자 구성항목이 노출을 **증가**시키는가 감소시키는가

## 6.9 "분개 결과가 같으니 문제없다"는 반론에 대한 답

회사가 내부대여금을 위험회피수단이라고 **잘못 부르고 있어도**, 그 대여금이 실제로 순투자의 일부라면 IAS 21.32에 따라 어차피 OCI가 나옵니다.
→ **특정 기간의 수치 차이가 0인 경우가 실제로 존재합니다.**

그러나 다음은 여전히 오류 또는 통제 결함입니다.

| 영역 | 결함 유형 |
|---|---|
| 위험회피수단 적격성 판단 | 회계처리 근거 오류 |
| Hedge designation 문서 | 부적격 지정 |
| 효과성 측정·비효과 인식 | 미수행 |
| IFRS 7 / K-IFRS 1107 위험회피 공시 | **부적절한 공시** (실제 헤지관계가 없는데 있다고 공시) |
| FCTR roll-forward 원천 구분 | 처분 시 재분류 금액 산정 불가 |
| 내부통제 | 회계정책 수립·검토 통제 미비 |

> **감사 결론 문구 예시**
> "회사가 해당 대여금 자체를 연결재무제표상 순투자위험회피의 위험회피수단으로 지정한 경우, K-IFRS 제1109호 문단 6.2.3이 위험회피수단을 보고기업 외부 당사자와의 계약으로 한정하고 있음을 고려할 때 해당 지정은 적격하지 않은 것으로 판단된다. 다만 해당 대여금이 K-IFRS 제1021호 문단 15의 요건을 충족하는 순투자의 일부라면 관련 환율차이는 연결재무제표에서 OCI로 인식되므로, 회사의 현재 OCI 인식 결과가 위험회피회계 적용에 따른 것인지 순투자의 일부인 화폐성 항목에 대한 환율차이 처리에 따른 것인지 구분하여 회계처리 근거를 재정리할 필요가 있다."

# Part 7. 판단 ③ — 종료·상환·처분과 재분류(Recycling)

## 7.1 세 가지 사건을 반드시 구분

| 사건 | 위험회피회계 | 누적 OCI 즉시 재분류 |
|---|---|---|
| ① **외부 위험회피수단**의 만기·상환·종료 | 장래에 대해 중단 (IFRS 9.6.5.6) | **아니오** |
| ② **순투자의 일부인 내부대여금**의 상환 | 해당 없음 | **사실관계에 따라 달라짐 (⚠️ 해석상 다툼 가능)** |
| ③ **해외사업장 자체**의 처분·부분처분 | 종료 | **예** (IAS 21.48~48D) |

## 7.2 ① 외부 위험회피수단 상환 — "우산을 접은 것"

```text
[위험회피수단]              [위험회피대상]
외부 USD 차입금 상환   vs   미국 자회사 계속 영업·계속 보유
      ↓                            ↓
위험회피관계 종료            해외사업장 처분 아님
      ↓
장래에 대해서만 위험회피회계 중단
누적 유효부분은 자본에 잔존
```

> **비유**: 미국에 건물을 보유하고 우산(외부차입금)을 쓰고 있다가 우산을 접었다.
> **우산을 접은 것은 건물을 판 것이 아니다.**
> 따라서 누적 OCI를 P/L로 실현시킬 사건이 발생하지 않았습니다.

IFRS 9.6.5.14는 순투자위험회피수단의 누적 유효부분을 **IAS 21의 처분·부분처분 규정에 따라** 재분류하도록 연결하고 있습니다.

## 7.3 ② 순투자의 일부인 내부대여금 상환 — 해석상 다툼 가능

```text
상환 전: A의 B 지분율 100% / 대여금 USD 100
상환 후: A의 B 지분율 100% / 대여금 USD 0

→ 지분율(ownership interest) : 100% → 100% (변동 없음)
→ 경제적 투자금액 절대규모   : 감소
```

IAS 21.48D의 "**ownership interest 감소**"를 어떻게 읽을 것인가에 대해 두 견해가 존재합니다.

| 견해 | 내용 | 결과 |
|---|---|---|
| 견해 1 (비례적 관점) | **지분율 감소**만 부분처분 | 대여금 상환 → 재분류 **없음** |
| 견해 2 (절대금액 관점) | 투자금 **절대금액 감소**도 부분처분 | 대여금 상환 → 관련 FCTR **재분류** |

> [!caution] 해석상 다툼 가능 (⚠️ 최신 확인 필요)
> 과거 IFRS 해석위원회는 해외투자금 상환 시 외화환산누계액 재분류 여부에 대해 **실무 다양성이 존재함을 확인**하였으나, 당시 적시에 합의에 도달하기 어렵다고 판단하여 기준서 개정 안건으로 진행하지 않았습니다.
> **따라서 대여금 상환 사실만으로 FCTR을 기계적으로 전액 또는 비례 재분류해서는 안 됩니다.**
> 최근 IASB 논의 진행 여부는 별도 확인이 필요합니다.

**검토해야 할 사실관계**

- [ ] 상환의 법적 형태 (상환 / 출자전환 / 감자 / 배당)
- [ ] 지분율 변동 여부
- [ ] 지배력 변동 여부
- [ ] 상환된 항목이 순투자의 어느 구성요소였는지
- [ ] 상환 재원 (자체 영업현금 / 신규 외부차입 / 모회사 재출자)
- [ ] 회사가 과거 유사 거래에 적용해 온 회계정책
- [ ] 회계정책의 일관성
- [ ] 관련 누적 FCTR의 원천별 구성

> **권고**: 회계정책을 사전에 명문화하고 일관 적용할 것. 감사인은 **정책의 존재와 일관성**을 우선 확인.

## 7.4 ③ 해외사업장 처분·부분처분

| 상황 | 처리 |
|---|---|
| 해외사업장 **전체 처분** / **지배력 상실** | 관련 누적 환산차이 **전액을 P/L로 재분류** (처분손익 인식 시점) |
| 종속기업 부분처분, **지배력 유지** | 누적 환산차이의 **비례금액을 비지배지분에 재귀속** (P/L 재분류 아님) |
| 관계기업·공동기업 지분 일부 처분 (유의적 영향력 유지) | 비례금액을 P/L로 재분류 |

> ❌ "부분처분이면 무조건 비례금액 P/L 재분류" → **오류**
> ✅ **지배력 상실 여부가 갈림길**입니다.

동시에 순투자위험회피 관련 누적 유효부분도 IFRS 9.6.5.14에 따라 함께 재분류합니다.
→ 이때 **Part 4.3의 원천별 roll-forward가 없으면 금액 산정이 불가능**합니다.

# Part 9. 감사·검토 실무

## 9.1 판단 순서 (Decision Flow)

```text
① 모회사 기능통화 확인
        ↓
② 해외사업장 기능통화 확인
        ↓
③ 대여금 계약통화 확인  ← Part 5.4 (제3통화 여부)
        ↓
④ 환율차이가 어느 FS에서 발생하는지 확정
        ↓
⑤ IAS 21.15 순투자 요건 판단  ← Part 5.2 체크리스트
        │
   ┌────┴────┐
  NO         YES
   │          │
   ▼          ▼
연결 P/L   연결 OCI (IAS 21.32 조정)
   │          │
   └────┬─────┘
        ↓
⑥ 순투자위험회피 적용 여부 확인
        ↓
⑦ Hedged item 확인 (지정금액 ≤ 연결상 순자산? IFRIC 16.11)
        ↓
⑧ Hedging instrument 확인
        │
   [연결실체 내부 계약인가?]
        │
    YES ─▶ 연결재무제표상 부적격 → 회계처리 근거 재정리
        │
        NO
        ↓
⑨ 지정·문서화·경제적 관계·Hedge ratio 검토
        ↓
⑩ 유효부분(OCI) / 비유효부분(P/L) 측정
        ↓
⑪ 위험회피수단 종료 여부 → 장래에 대해 중단
        ↓
⑫ 해외사업장 처분·부분처분 여부 판단
        ↓
⑬ 원천별 FCTR roll-forward 기준 재분류
```

## 9.2 요청자료 리스트 (그대로 회사에 송부 가능)

### A. 대여금 관련
- 대여계약서 원본 및 전체 변경계약서
- 최초 대여일 / 금액 / 계약통화 / 만기 / 금리 / 상환조건
- 대여자·차입자 및 **양 당사자의 기능통화 판단 memo**
- 과거 원리금 상환 내역
- 만기 연장 이력 (연장 사유 포함)
- 향후 상환계획 및 그룹 자금계획서
- 이사회·경영진 승인자료

### B. 순투자 판단 관련
- IAS 21.15 적용 검토 memo
- "가까운 미래 결제계획 없음"의 근거자료
- "결제 가능성 낮음"의 **별도** 근거자료
- 해외사업장별 기능통화 판단 memo
- 별도 FS와 연결 FS 간 환율손익 조정내역
- 연결조정분개 상세 (IAS 21.32 대체분개)

### C. 위험회피회계 관련
- **Hedge designation 문서 원본** (개시일 확인)
- Hedged item / Hedging instrument / Hedged risk 기재내용
- **위험회피수단의 거래상대방 및 외부거래 입증자료**
- Hedge ratio 및 산정근거
- 위험관리 목적·전략 문서
- 효과성 평가자료 및 비효과 산식
- IFRS 7 / K-IFRS 1107 공시 초안

### D. FCTR 관련
- **해외사업장별 FCTR roll-forward (원천 3분류)**
- 환산에 사용한 기말환율·평균환율·거래일환율 근거
- NCI 배분내역
- 처분·상환 시 재분류 산식 및 회계정책

## 9.3 재무제표 표시·공시 유의사항

| 항목 | 유의사항 |
|---|---|
| 별도 FS | 대여금 환율차이는 P/L. **연결 OCI와 혼동한 표시 금지** |
| 연결 FS | 자본변동표에서 외화환산차이 항목이 **3개 원천의 합계**임을 이해하고 작성 |
| 주석 | 순투자의 일부인 화폐성 항목의 **존재·금액·판단근거** 공시 검토 |
| 주석 | 위험회피회계 적용 시 IFRS 7상 **위험회피 유형별 공시** (미적용인데 공시하면 부적절 공시) |
| 현금흐름표 | 내부대여금 원금은 연결 제거, 환율차이는 비현금항목 조정 |

# Part 10. 부록 — 세무 접점 (한국 세법)

> 원본 4개 문서는 전적으로 K-IFRS 관점입니다. 실무상 반드시 함께 검토되는 세무 논점을 보강합니다.
> ⚠️ **아래 내용은 방향성 정리이며, 개별 적용 시 최신 조문·예규 확인이 필요합니다.**

## 10.1 법인세 신고는 **별도재무제표** 기준

가장 중요한 출발점입니다.

```text
연결재무제표의 OCI 대체
        ↓
법인세 과세소득과 무관 (연결납세 적용 여부와도 별개 논점)
        ↓
법인세는 각 법인의 별도재무제표 기준
```

→ **Case A든 Case B든 모회사 별도 FS의 외화환산이익 +20,000은 동일**하므로,
   **순투자 판단이 모회사 법인세 과세소득 자체를 바꾸지는 않습니다.** (구조상 결론)

## 10.2 외화 화폐성 자산·부채의 세무상 평가 (확인 필요)

- 금융회사 등이 아닌 내국법인이 보유하는 화폐성 외화자산·부채는 **① 취득일 환율 유지 방법**과 **② 사업연도 종료일 환율 평가 방법** 중 **관할세무서장에게 신고한 방법**에 따라 평가하는 것으로 이해됩니다. (법인세법 시행령 §76 관련 — **조문 및 최신 개정 확인 필요**)
- 신고한 방법은 일정 기간 계속 적용 의무가 있는 것으로 이해됩니다. — **확인 필요**

**실무 시사점**

| 상황 | 결과 |
|---|---|
| ① 취득일 환율 방법 신고 | 회계상 외화환산이익 20,000 → **익금불산입 (△유보)**, 실제 회수 시 정산 |
| ② 기말 환율 방법 신고 | 회계 = 세무 → 세무조정 없음 |
| 신고 없음 | 법정 기본방법 적용 → **회계와 불일치 가능** |

→ **순투자 판단(IFRS)과 외화평가방법 신고(세법)는 완전히 별개**입니다.
→ 그러나 **대여금 자체가 순투자의 일부라는 사실이 세무상 대여금 성격까지 바꾸지는 않습니다.** 세법상으로는 여전히 **대여금**입니다.

## 10.3 함께 검토해야 할 세무 논점

| 논점 | 내용 | 리스크 |
|---|---|---|
| **부당행위계산부인** | 무이자·저리 대여 시 인정이자 익금산입 (법인세법 §52, 시행령 §88·§89) | 순투자로 보아 무이자 처리한 경우 **가장 큰 리스크** |
| **국제조세 이전가격** | 국외특수관계인 대여금의 정상이자율 (국조법) | 이자율 산정근거 문서화 |
| **과소자본세제** | 국외지배주주 차입금 관련 (국조법) — 방향 반대 케이스 주의 | 자회사 측 손금부인 |
| **대손금 손금산입** | 순투자 성격 대여금의 대손 인정 여부 | 실질 출자로 재구성될 위험 |
| **출자전환 시** | 대여금 → 자본 전환 시 채무면제이익·의제배당 검토 | 사실관계에 따라 달라짐 |
| **이연법인세 (IAS 12.39)** | 종속기업 투자 관련 일시적차이는 ① 소멸시점 통제 가능 ② 예측가능한 미래에 소멸하지 않을 가능성 높음 → 이연법인세부채 **인식 예외** | 순투자 판단과 정합성 확인 |

> [!caution] 핵심 세무 리스크
> **"가까운 미래에 결제할 계획이 없다"는 IFRS상 순투자 판단 근거가, 세무상으로는 "무이자·장기 방치된 국외특수관계자 대여금"으로 읽힐 수 있습니다.**
> 회계 memo와 세무 포지션이 **서로 모순되는 사실관계를 주장하고 있지 않은지** 반드시 교차 확인해야 합니다.
> → 실무상 이 교차 검토가 누락되는 경우가 매우 많습니다.

# Part 12. 고객 설명용 쉬운 표현

## 12.1 3문장 버전

> "미국 자회사에 빌려준 돈은 **법적으로는 여전히 대여금**입니다.
> 다만 사실상 돌려받을 계획이 없는 장기자금이라면, 회계에서는 '빌려준 돈'이라기보다 **'미국 사업에 심어둔 돈'**에 가깝게 봅니다.
> 그래서 **환율이 오르내릴 때 생기는 손익을 손익계산서가 아니라 자본에 쌓아뒀다가, 나중에 미국 사업을 실제로 팔 때 한꺼번에 손익으로 인식**합니다."

## 12.2 비유 3종

| 개념 | 비유 |
|---|---|
| 순투자의 일부인 대여금 | "지갑에서 잠깐 빌려준 돈이 아니라, **미국 사업에 이미 심어둔 씨앗**" |
| P/L → OCI 이동 | "이익이 사라지는 게 아니라, **손익계산서 방에서 자본 창고로 자리를 옮기는 것**" |

| 내부대여금이 수단이 될 수 없는 이유 | "**내 왼손과 오른손이 계약해도 보험이 되지 않습니다.** 보험은 밖에 있는 회사와 들어야 합니다" |

```text
■ 무엇이 문제인가
  미국 자회사 장기대여금 USD 100의 환율차이를
  손익(P/L)으로 볼지, 자본(OCI)으로 볼지

■ 회사 손익에 미치는 영향 (환율 +200원 가정)
  일반대여금으로 보면   → 당기순이익 +20,000
  순투자로 보면         → 당기순이익 0, 자본 +20,000
  ※ 총 자본 증가액은 40,000으로 동일

■ 판단 기준
  "가까운 미래에 갚을 계획도, 갚을 가능성도 낮은가?"
  → 회사의 의도가 아니라 객관적 증빙으로 입증

■ 반드시 확인할 것
  ① 그 대여금을 '위험회피수단'이라 부르고 있지 않은가 (부적격)
  ② 무이자 대여라면 세무상 인정이자 리스크는 검토했는가
  ③ FCTR을 원천별로 나눠서 관리하고 있는가
```

## 13.2 도입부 (초안)

> 결산 때마다 반복되는 질문이 있습니다.
>
> "해외 자회사에 빌려준 달러 대여금, 환율 올랐으니 환차익 잡으면 되는 거 아닌가요?"
>
> 별도재무제표만 보면 맞습니다. 그런데 연결재무제표를 열면 그 환차익이 **손익계산서에서 사라져 있습니다.** 자본 항목 어딘가에 들어가 있죠.
>
> 회계 오류일까요? 아닙니다. 그리고 여기서 실무자가 가장 많이 하는 세 가지 실수가 시작됩니다.
>
> 첫째, **"순투자니까 별도재무제표부터 OCI"**라고 처리하는 것.
> 둘째, **"연결에서 대여금을 상계하지 않는다"**고 설명하는 것.
> 셋째, 가장 위험한 실수 — **그 대여금을 "위험회피수단"이라고 부르는 것.**
>
> 오늘은 이 셋을 숫자 하나로 정리하겠습니다.

```text
5. 체크리스트 (Part 5.2 축약본)

6. 결론
```

## 13.4 결론 문단 (초안)

> 정리하면 이렇습니다.
>
> 해외 자회사 대여금의 환차익은 **없어지는 게 아니라 자리를 옮깁니다.** 그리고 그 자리를 정하는 것은 회사의 선택이 아니라 **"정말 돌려받을 계획이 있는가"라는 사실관계**입니다.
>
> 여기에 하나만 더 기억하시면 됩니다. **내 오른손이 왼손에게 빌려준 돈은 보험이 될 수 없습니다.** 순투자 위험을 헤지하려면 반드시 **그룹 밖의 은행이나 금융기관과의 계약**이 있어야 합니다.
>
> 그리고 마지막으로, 회계에서 "돌려받을 계획이 없다"고 써둔 문서는 세무조사에서 **"왜 무이자로 방치했는가"**라는 질문으로 돌아올 수 있습니다. 회계와 세무를 따로 검토하면 안 되는 이유입니다.

# Part 15. 최종 요약 — 반드시 기억할 8문장

> **①** 모회사 USD 대여금의 환율차이는 **모회사 별도재무제표**에서 발생하고, 해외사업장 환산차이는 **연결 환산절차**에서 발생한다. 발생 원천이 다르다.

> **②** 자회사의 기능통화와 차입금 통화가 모두 USD이면, KRW/USD 변동만으로 **자회사 개별 FS에는 환율손익이 없다.** 따라서 자동 상쇄되지 않는다.

> **③** 순투자의 일부여도 **별도재무제표에서는 P/L**이다. OCI는 연결에서 발생한다.

> **④** 연결에서 내부 대여금·차입금 **원금은 제거**하지만 **환율차이는 제거되지 않는다** (IAS 21.45).

> **⑤** 일반대여금이면 그 환율차이는 **연결 P/L**, 순투자의 일부이면 **연결 OCI**다. 총 경제적 효과는 동일하고 **표시 위치만** 달라진다.

> **⑥** 외화환산 자본항목에는 **① 해외사업장 환산차이 ② 순투자 화폐성 항목 환율차이 ③ 순투자위험회피 유효부분**이라는 **서로 다른 3개 원천**이 누적된다. 반드시 분해 관리해야 한다.

> **⑦** 순투자의 일부인 내부대여금은 **노출을 구성하는 항목**이지 **위험회피수단이 아니다.** 연결에서 위험회피수단은 **외부 당사자와의 계약**이어야 한다 (IFRS 9.6.2.3).

> **⑧** 위험회피수단의 상환·만기와 해외사업장의 처분은 **서로 다른 사건**이다. 수단이 사라졌다는 이유만으로 누적 OCI를 P/L로 재분류하지 않는다.

# 최종 한 문장

> **해외사업장 자체의 환산차이와 모회사 장기대여금의 환율차이는 처음부터 서로 다른 곳에서 발생하지만, 그 대여금이 IAS 21.15상 순투자의 일부라면 후자의 환율차이도 모회사와 해외사업장을 함께 포함하는 재무제표에서 OCI로 인식되어 같은 외화환산 자본항목에 누적된다. 다만 그 내부대여금이 순투자위험회피의 위험회피수단이 되는 것은 아니며, 적격 위험회피수단은 반드시 연결실체 외부와의 계약이어야 한다.**
