## 2. 부당행위계산부인의 유형과 금액요건(§52, 시행령 §88)

행위 당시의 특수관계로 판단하고, 비특수관계인을 거친 거래도 포함한다.

| 유형(시행령 §88①) | 점검 |
| --- | --- |
| 1호: 자산 고가매입·고가 현물출자, 과대상각 | 매입가와 시가 차이, 관련 상각 |
| 2호: 무수익자산 매입·비용 부담 | 수익성과 비용 부담의 실질 |
| 3호: 자산 무상·저가양도·현물출자 | 양도가와 시가 차이(주식매수선택권 등 예외) |
| 6호: 금전 무상·저리대여, 자산·용역 무상·저가 제공 | 이자율·임대료·용역대가(2026.2.27. 장애인 표준사업장 용도 무상·저가 임대 제외 신설) |
| 7호: 고리차입, 고가로 자산·용역을 제공받음 | 차입이율·임차료·용역대가 |
| 4호·5호: 불량자산 차환·불량채권 양수, 출연금 대납 | 이익분여 여부 |
| 3호의2·8호·8호의2: 불공정 합병·증자·감자 등 자본거래 | 유형별 이익분여 계산 |

- **5%·3억 원(§88③)**: 1·3·6·7호와 이에 준하는 9호 거래에만 적용하고, 주권상장법인 주식에는 적용하지 않는다. 요건을 넘으면 시가와의 차액 전부를 익금에 넣는다. 기준 초과분만 조정하지 않는다.
- "5% 미만이면 안전", "3억 원 미만이면 적용 안 됨"은 틀린 표현이다. §28 지급이자 손금불산입에는 이 기준을 쓰지 않는다.
- 특수관계인 거래라는 사정만으로 부인되지 않는다. 유형과 조세부담의 부당한 감소를 함께 본다.

「법인세-부당행위계산부인 › 3. 시가와 인정이자율(시행령 §89, 시행규칙 §43)」 원문 전체 절
## 3. 시가와 인정이자율(시행령 §89, 시행규칙 §43)

| 순서 | 기준 |
| --- | --- |
| 우선 | 그 법인이 비특수관계 불특정다수와 계속 거래한 가격 또는 제3자 간 일반 거래가격 |
| 불분명 1순위 | 감정평가법인 감정가액(둘 이상이면 평균). **주식·가상자산은 제외** |
| 불분명 2순위 | 상증법 평가규정 준용 가액 |
| 자산 사용대가 | (시가 × 50% − 전세금·보증금) × 정기예금이자율 |
| 건설 등 용역 | 원가 + 비특수관계 유사용역의 수익률 |

- 내부 목표이익률을 시가 수익률로 바로 쓰지 않는다. 내부 목표마진으로 통상 수익률 15%를 인정하기 부족하다고 본 판결이 확정됐다(서울고법 2024누46042, 2026.3.26. → 대법원 2026두30878, 2026.8.13.). 다만 증여세 사건에서 시행령 §89를 쓴 판단이다.

| 금전대차 | 내용 |
| --- | --- |
| 원칙 | **가중평균차입이자율**(대여 시점 차입금 잔액의 이율 가중평균, 특수관계인 차입금 제외) |
| 당좌대출이자율 | 연 4.6%. 비특수관계인 차입금이 없는 경우 등 법정 사유에 적용 |
| 선택 | 신고 때 당좌대출이자율을 고르면 그 사업연도와 이후 2개 사업연도에 적용 |
| 장기대여 | 대여일·갱신일부터 사업연도 말까지 5년을 넘으면 별도 규정 |
| 변동금리 | 금리 변동 때 종전 차입금을 갚고 새로 빌린 것으로 계산 |

"인정이자율은 항상 4.6%"라고 쓰지 않는다.

## 4. 인정이자와 업무무관 가지급금 지급이자

| 구분 | 인정이자 | 지급이자 손금불산입 |
| --- | --- | --- |
| 판단 | 시가 이자율보다 낮게 빌려줬는지 | 특수관계인에게 업무와 무관하게 빌려줬는지 |
| 효과 | 시가와의 차액 익금산입 | 법정 산식에 따른 이자 손금불산입 |
| 관계 | 업무관련 대여라도 저리면 별도 검토 | 적정 이자를 받아도 업무무관이면 별도 검토 |
| 근거 | §52, 시행령 §88·§89 | §28①4호 나목, 시행령 §53 |

- **손금불산입액 = 지급이자 × 업무무관자산·가지급금 적수 ÷ 총차입금 적수**(분자는 총차입금 한도). 부동산은 장부잔액이 아니라 취득가액(시가초과액 포함)으로 넣는다.
- 특수관계인 매출채권·미수금의 회수 지연도 대상이다. 정당한 사유 없이 매매대금 회수를 미루면 지급이자 손금불산입과 인정이자 익금산입이 함께 적용된다(대법원 2007두5646, 2010.1.14.). 계정 이름을 미수금으로 두거나 이자를 받는 것만으로 해결되지 않는다.
- 사업연도 중 차입금을 다 갚은 뒤 잉여자금을 빌려줬어도 그 사업연도 지급이자로 적용한다(서면-2019-법인-0699, 2020.8.31.). 업무관련성은 대여 시점으로 판단한다(서면-2021-법규법인-7996, 2023.2.7.).
- 같은 사람의 가지급금과 가수금은 원칙적으로 상계하되, 각각 상환기간·이자율 약정이 있어 상계할 수 없으면 하지 않는다(시행규칙 §28).
- 다른 지급이자 부인과의 순서: 채권자 불분명 사채이자 → 지급받는 자 불분명 채권 이자 → 건설자금이자 → 업무무관자산 이자(시행령 §55).
- 직원 급료 가불금·경조사비·학자금·중소기업 직원 주택자금 등은 예외다(시행규칙 §44). 비지배주주 직원이 배우자 명의로 산 주택도 실제 거주 목적이면 주택자금 특례 대상이라는 사전답변이 있다(사전-2026-법규법인-0523, 2026.6.16.). 미지급 배당·상여 관련 소득세를 법인이 대신 낸 가지급금 특례는 2026.3.20. 계산식·한도·기간이 정비됐다 `[원문 확인 필요]`. → [[가지급금]]

「법인세-부당행위계산부인 › 5. 업무무관부동산(§27, 시행령 §49, 시행규칙 §26)」 원문 전체 절
## 5. 업무무관부동산(§27, 시행령 §49, 시행규칙 §26)

| 부동산 | 유예기간 |
| --- | --- |
| 건축물·시설물 신축용 토지 | 취득일부터 5년 |
| 승인된 공장건설계획기간이 5년을 넘는 공장용 부지 | 그 계획기간 |
| 부동산매매업 주업 법인(겸영 시 당해·직전 2개 사업연도 매출 50% 초과)의 매매용부동산 | 5년 |
| 그 밖의 부동산 | 2년 |

- 업무는 법령상 업무 또는 사업연도 말 등기부 목적사업이고, 인허가 사업은 인허가를 받아야 한다. 착공하면 직접 사용으로 보지만 정당한 사유 없는 공사 중단 기간은 뺀다.
- **나대지 임대는 원칙적으로 직접 사용이 아니다.** 임대 중 법인이나 동의받은 임차인이 착공하면 착공일부터 직접 사용이다.

| 상황 | 업무무관 기간 |
| --- | --- |
| 유예기간 뒤에도 미사용 보유 | 미사용 기간 중 유예기간과 겹치는 기간 제외 |
| 취득 후 계속 미사용하다 양도 | 원칙적으로 **취득일부터 양도일까지** |
| 유예기간 중 미사용 상태로 양도 | 원칙적으로 취득일부터 양도일까지 |
| 매매업 주업 법인의 매매용부동산을 유예기간 안에 양도 | 직접 사용으로 봄 |
| 수용·협의매수, 일정 산업단지 토지 양도 | 유예기간과 겹치는 기간 제외 |

- 유예기간은 언제나 보장되는 비용 인정기간이 아니다. 팔기 전에 취득일부터의 사용 이력을 다시 판정한다.
- 법령상 사용금지·제한은 해제일부터 유예기간을 다시 세고, 건축허가·착공 제한은 제한기간을 더하는 등 예외마다 계산이 다르다. 사업성을 높이려 계획을 바꾸고 추가 토지 확보가 늦어진 것은 부득이한 사유가 아니다(조심2025서4169, 2026.4.28.).

기준일: 2026-10-29(한국). 기준일까지 공포되어 해당 거래일에 적용되는 법령·부칙을 우선하고, 미공포 정부안·의원안·보도는 별도 표시해 주세요. 예정 거래에는 현재 공포된 법에 따른 조건부 결론만 제시해 주세요.
되묻지 말고, 누락 사실은 통상적인 가정을 명시한 뒤 답해 주세요. 가정에 따라 결론이 바뀌는 핵심 조건은 최대 2개 분기로 표시하고, 특정 사실을 만들어 확정하지 마세요. 확인 못 한 근거·계산은 '확인 불가'로 적고 확인된 범위까지 바로 답해 주세요.
이 질문은 일반 세법 검토 또는 가상 사례입니다. 세법상 과세요건·산식·신고절차만 검토해 주세요. 회계·외부감사·감사인 독립성 판단, 민사상 유효성 판단과 금융상품 추천은 요청하지 않습니다.
답은 쟁점별 결론·근거 → 계산 또는 판정표 → 필요한 증빙·신고기한 순서로 간결하게(목표 1,200~1,800자, 중요한 산식·단서는 생략하지 않음) 써 주세요. 근거는 법령명·조/항/호·적용일, 예규·판례는 문서/사건번호·일자·공식 원문 링크로 표시하고 핵심 1~3건만 골라 주세요. 직접 판단과 유사사례·추론을 구별하고 반대 근거가 실제 확인되면 함께 적어 주세요. 원문을 못 본 문서를 확정 근거로 쓰거나 존재하지 않는 번호를 만들지 마세요. 판례를 인용하면 확인한 후속 심급과 확정 여부만 표시하고, 원문 인용은 필요한 짧은 문구로 제한해 주세요.

## 답변

[W31] 금액요건의 경계값, 용역 시가 산식, 인정이자 예외의 필수 전제를 수정해야 합니다.

요청 기준일은 2026-10-29이나 현재는 2026-10-28입니다. 따라서 내일 추가 공포 여부는 확인 불가이며, 확보한 조문 기준으로 아래 절만 판정했습니다. 개정 부칙을 확보하지 못한 항목은 거래별 최초 적용시기를 확정하지 않았습니다.
