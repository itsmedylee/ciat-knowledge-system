## 질문

법인세 이월결손금 공제(15년, 중소기업 외 공제한도 80%), 결손금 소급공제 요건, 감가상각 시부인(내용연수 신고·변경, 즉시상각 의제, 감가상각 의제), 중소기업 기준과 중소기업 특례(접대비 한도, 최저한세 등)의 판정을 실무용으로 정리해 주세요. 실무자가 놓치기 쉬운 함정, 최근 3년 개정 사항, 주요 예규·심판례·판례(납세자 유리·불리)를 근거 조문·문서번호·날짜와 함께 정리해 주세요.

# 법인세 이월결손금·감가상각·중소기업 판정 관련 세무검토

## 검토의견 요약

**실무상 우선 점검할 사항은 ‘결손금 발생연도별 공제기간’, ‘소급공제 신청기한’, ‘상각부인액의 자동추인’, ‘세법상 중소기업 판정’입니다.** 특히 상각부인액은 결손이라는 이유로 추인을 미루었다가 흑자연도에 임의로 공제할 수 없습니다.(법인세법 제13조, 법인세법 제72조, 법인세법 시행령 제32조, 조심2026부0061, 2026.04.02)

아래는 **법인세 신고·세무조정용 보강안**입니다. 재무보고 목적의 회계기준 적용, 분개 및 공시는 다루지 않습니다. 최근 개정은 현행 조문의 개정 이력이 확인된 범위에서 정리하였으며, **부칙 원문을 확보하지 못한 개정의 최초 적용연도·경과조치는 확정하지 않았습니다.**

| 구분 | 핵심 판정 | 놓치기 쉬운 사항 |
| --- | --- | --- |
| 이월결손금 | 원칙적으로 15년, 일반법인 소득의 80%, 중소기업 등 100% 한도 | 과거 발생분까지 모두 15년은 아님. 신고·결정·경정 등에 포함된 결손금이어야 함.(법인세법 제13조, 법인세법 집행기준 13-10-1) |
| 소급공제 | 중소기업의 직전 사업연도 법인세 환급 | 당기·전기 모두 기한 내 신고하고, 당기 신고기한까지 별도 신청해야 함.(법인세법 제72조, 법인세법 시행령 제110조) |
| 감가상각 | 계상액을 개별 자산별 상각범위액과 비교 | 상각부인액과 시인부족액은 이월 취급이 다름.(법인세법 제23조, 법인세법 시행령 제26조, 법인세법 시행령 제32조) |
| 즉시상각 의제 | 취득비·자본적 지출을 비용 처리한 경우 감가상각 시부인 적용 | 명칭과 달리 언제나 전액 손금 인정되는 제도가 아님.(법인세법 제23조, 법인세법 시행령 제31조) |
| 감가상각 의제 | 법인세 면제·감면을 받은 경우 상각범위액까지 손금산입 의무 | 결손금이나 상각비를 장래로 남기려는 임의 조정과 구분해야 함.(법인세법 제23조, 법인세법 시행령 제30조) |
| 중소기업 | 규모·자산·독립성·업종·제외법인 요건을 함께 검토 | 중소기업기본법상 판정이나 유예를 세법에 그대로 적용하지 않음.(조세특례제한법 시행령 제2조, 대법원2013두10458, 2015.04.23) |

## 검토의견

### 가. (질의1) 이월결손금과 결손금 소급공제

#### 1) 이월결손금 공제

**법인세법 제13조**는 이월결손금, 비과세소득, 소득공제액을 순서대로 공제하도록 하고, 이월결손금은 신고·결정·경정 또는 수정신고한 과세표준에 포함된 금액으로 제한합니다.(법인세법 제13조)

| 판정 항목 | 실무 적용 |
| --- | --- |
| 공제기간 | 각 사업연도 개시일 전 15년 이내에 개시한 사업연도에서 발생한 결손금. 집행기준은 2019.12.31. 이전 개시 사업연도 발생분을 10년으로 구분합니다.(법인세법 제13조, 법인세법 집행기준 13-10-1) |
| 일반법인 한도 | 각 사업연도 소득의 80%.(법인세법 제13조) |
| 중소기업 등 한도 | 중소기업 및 시행령에 열거된 법인은 100%. 중소기업이 아니더라도 회생계획 이행법인 등 예외에 해당할 수 있습니다.(법인세법 제13조, 법인세법 시행령 제10조) |
| 공제 순서 | 먼저 발생한 사업연도의 결손금부터 공제합니다.(법인세법 시행령 제10조) |
| 중복공제 방지 | 소급공제받은 결손금, 일정한 자산수증이익·채무면제이익으로 충당된 결손금 등은 공제된 것으로 봅니다.(법인세법 시행령 제10조) |

본 사안의 경우 실무노트의 “15년·80%”는 위의 발생연도·확정요건·예외한도를 함께 붙여야 정확합니다. 따라서 **발생연도별 잔액과 공제기간을 구분하고, 당기 법인의 중소기업 등 해당 여부에 따라 공제한도를 판정**하는 방식이 타당합니다.(법인세법 제13조, 법인세법 시행령 제10조, 법인세법 집행기준 13-10-1)

**함정:** 결손금 감액경정을 단순히 “당장 납부세액이 없는 조정”으로 취급하면 안 됩니다. 대법원 2017두63788은 일정한 결손금 감액경정을 항고소송 대상 처분으로 인정하면서, 그 단계에서 다투지 않으면 이후 연도에 종전 감액경정의 오류를 주장하는 데 제한이 있음을 밝혔습니다. 이는 판결 소개이며, 구체적인 소송 수행에 관한 자문은 포함하지 않습니다.(대법원2017두63788, 2020.07.09)

#### 2) 소급공제 요건과 환급한도

**법인세법 제72조 및 시행령 제110조**에 따른 기본 요건은 다음과 같습니다.(법인세법 제72조, 법인세법 시행령 제110조)

| 요건 | 확인 내용 |
| --- | --- |
| 대상 | 중소기업에 해당하는 내국법인에 결손금 발생 |
| 전기·당기 신고 | 결손 발생 사업연도와 직전 사업연도 모두 법정 신고기한 내 과세표준·세액 신고 |
| 신청 | 결손 발생 사업연도의 신고기한까지 소급공제법인세액환급신청서 제출 |
| 환급 계산 | 전기 산출세액에서 전기 과세표준에 소급공제 결손금을 반영하여 전기 세율로 재계산한 세액 차감 |
| 환급한도 | 전기 산출세액에서 전기 공제·감면세액을 차감한 금액. 토지등 양도소득에 대한 법인세 제외 |
| 사후관리 | 결손금 감소, 전기 세액 변경, 중소기업 오판정 등에 따른 환급액 조정·징수 |

위 표의 요건과 계산은 법인세법 제72조 및 시행령 제110조에 근거합니다.(법인세법 제72조, 법인세법 시행령 제110조)

본 사안의 경우 **법인세 신고와 소급공제 신청은 별개의 확인사항**으로 관리해야 합니다. 따라서 “신고는 했으므로 나중에 경정청구하면 된다”는 처리는 피해야 합니다. 대법원 2001두10721 및 현행 집행기준은 기한 내 신청을 하지 않은 소급공제를 경정청구로 새로 신청하는 것을 인정하지 않습니다.(대법원2001두10721, 2003.07.25, 법인세법 제72조, 법인세법 집행기준 72-110-1)

다만, 납세자에게 유리한 최근 해석으로 **기획재정부 법인세제과-615, 2025.12.08.**은 이미 소급공제받은 중소기업이 이를 적용하지 않은 것으로 수정신고하고, 이후 사업연도에 이월결손금 공제를 받을 수 있다고 회신하였습니다. 이는 신청기한을 놓친 소급공제를 새로 허용한 해석과는 다릅니다.(기획재정부 법인세제과-615, 2025.12.08)

#### 3) 소결

따라서 이월공제와 소급공제는 **공제기간·당기 한도·전기 환급가능세액·기한 내 신청 여부를 분리하여 판단**해야 하며, 소급공제한 금액을 이월결손금에서 다시 공제해서는 안 됩니다.(법인세법 제13조, 법인세법 제72조, 법인세법 시행령 제10조, 법인세법 시행령 제110조)

### 나. (질의2) 감가상각 시부인

#### 1) 상각범위액과 상각부인액

**법인세법 제23조**는 손비로 계상한 감가상각비 중 상각범위액 이내 금액을 손금으로 인정하고, 초과액을 손금불산입하도록 규정합니다. 상각범위액은 개별 감가상각자산별로 계산합니다.(법인세법 제23조, 법인세법 시행령 제26조)

| 구분 | 세무상 처리 |
| --- | --- |
| 당기 계상액이 범위액 초과 | 초과액 손금불산입, 이후 사업연도 추인 대상 |
| 과거 상각부인액 존재 + 당기 시인부족액 발생 | 시인부족액 한도로 손금산입 |
| 당기 감가상각비 미계상 + 과거 상각부인액 존재 | 상각범위액 한도로 과거 부인액 손금산입 |
| 시인부족액 자체 | 이후 사업연도의 상각부인액에 충당 불가 |
| 자산 양도 | 해당 자산의 상각부인액을 양도 사업연도 손금산입 |

위 처리는 법인세법 제23조 제5항 및 시행령 제32조에 따른 것입니다.(법인세법 제23조, 법인세법 시행령 제32조)

본 사안의 경우 **‘아직 손금으로 공제하지 않았으니 상각부인액이 계속 남는다’고 판단하면 위험**합니다. 조심2026부0061은 결손 등을 이유로 추인을 누락했더라도 해당 연도에 추인했어야 할 금액을 반영하여 이후 연도 상각범위액을 계산해야 한다고 결정하였습니다. 따라서 부인액 추인을 흑자연도로 임의 이연할 수 없다고 판단됩니다.(조심2026부0061, 2026.04.02)

#### 2) 내용연수 신고와 변경

| 항목 | 요건·기한 |
| --- | --- |
| 최초 내용연수 선택 | 일반 대상자산은 기준내용연수에 25%를 가감한 법정 범위 안에서 선택 |
| 신고기한 | 영업 개시 또는 기준내용연수가 다른 자산의 신규 취득·새 업종 개시일이 속하는 사업연도의 법인세 신고기한 |
| 미신고 | 기준내용연수 적용 |
| 계속 적용 | 신고내용연수 또는 기준내용연수를 이후 사업연도에도 계속 적용 |
| 특례·변경 | 부식·마모, 가동률 변화, 기술개발 등 법정 사유와 관할 지방국세청장 승인 필요 |
| 변경 범위 | 원칙적으로 기준내용연수 ±50%, 시행령 제29조 제1항 제5·6호는 ±25% |
| 신청기한 | 최초 승인 관련 기준일부터 3개월 또는 변경내용연수 적용 최초 사업연도 종료일까지 |
| 재변경 | 변경내용연수 최초 적용 사업연도 종료일부터 3년 경과 필요 |

위 내용은 시행령 제28조·제29조에 근거하며, 실제 자산별 내용연수 범위와 상각률은 시행규칙 제15조가 정한 별표를 적용해야 합니다.(법인세법 시행령 제28조, 법인세법 시행령 제29조, 법인세법 시행규칙 제15조)

본 사안의 경우 **내용연수 최초 신고, 내용연수 변경승인, 상각방법 변경승인을 서로 구분**해야 합니다. 상각방법 변경은 별도의 법정 사유와 세무서장 승인이 필요하고, 승인 없이 변경하면 변경 전 방법으로 상각범위액을 계산합니다. 따라서 단순한 신고서 제출만으로 기존 상각방법·내용연수가 모두 바뀐다고 보아서는 안 됩니다.(법인세법 시행령 제27조, 법인세법 시행령 제28조, 법인세법 시행령 제29조)

최근 회신인 **서면-2024-법규법인-4867, 2025.11.27.**은 사업연도 중 건물 용도변경으로 기준내용연수가 달라진 경우, 변경승인일이 속하는 사업연도 신고부터 변경된 기준내용연수에 따라 연 단위로 계산한다고 보았습니다.(서면-2024-법규법인-4867, 2025.11.27)

#### 3) 즉시상각 의제와 감가상각 의제

**두 제도는 효과가 다릅니다.** 즉시상각 의제는 일정한 비용계상액을 감가상각비로 보아 시부인하는 것이고, 감가상각 의제는 면제·감면 사업연도에 법정 상각비를 손금산입하도록 하는 것입니다.(법인세법 제23조, 법인세법 시행령 제30조, 법인세법 시행령 제31조)

| 구분 | 적용 및 함정 |
| --- | --- |
| 취득비·자본적 지출 비용계상 | 감가상각비로 보아 상각범위액 적용. **전액 손금 인정이 아님**.(법인세법 제23조) |
| 소액 수선비 예외 | 손비계상한 수선비가 개별 자산별 600만원 **미만**, 전기말 자산가액의 5% **미달**, 또는 3년 미만 주기 수선 중 하나에 해당하면 자본적 지출에서 제외.(법인세법 시행령 제31조) |
| 소액자산 | 거래단위별 취득가액 100만원 **이하**이고 사용 사업연도에 손비계상한 경우. 고유업무상 대량 보유자산·사업 개시 또는 확장 취득자산은 제외.(법인세법 시행령 제31조) |
| 별도 열거자산 | 공구·가구·개인용 컴퓨터 등은 시행령 제31조 제6항의 별도 규정 확인. 소액자산 일반규정만으로 판정하지 않음.(법인세법 시행령 제31조) |
| 손상차손 | 시행령상 요건에 해당하면 감가상각비로 보아 시부인. 감액액 전부가 자동으로 당기 손금이 되는 것은 아님.(법인세법 시행령 제31조) |
| 면제·감면 | 개별 자산 감가상각비가 상각범위액이 되도록 손금산입. 시행령 제30조 단서에 따른 법인은 별도 규정 적용.(법인세법 시행령 제30조) |
| 추계결정·경정 | 감가상각비를 손금산입한 것으로 봄.(법인세법 시행령 제30조) |

추가로, 사업연도 중 취득자산의 상각은 **취득일이 아니라 사업에 사용한 날부터** 월할 계산하며, 건설 중인 자산·사업에 사용하지 않는 자산은 제외하되 유휴설비는 해당 제외규정의 예외입니다.(법인세법 시행령 제24조, 법인세법 시행령 제26조)

#### 4) 소결

따라서 감가상각 검토는 **① 자산별 상각범위액, ② 당기 부인액, ③ 과거 부인액 추인, ④ 즉시상각·감가상각 의제**를 순차적으로 점검하는 방식이 타당합니다. 특히 결손연도에도 과거 부인액의 추인을 빠뜨리지 않아야 합니다.(법인세법 제23조, 법인세법 시행령 제26조, 법인세법 시행령 제30조, 법인세법 시행령 제31조, 법인세법 시행령 제32조, 조심2026부0061, 2026.04.02)

### 다. (질의3) 중소기업 기준과 특례 판정

#### 1) 세법상 중소기업 판정 순서

**조세특례제한법 시행령 제2조**는 다음 요건을 모두 충족하도록 규정합니다.(조세특례제한법 시행령 제2조)

1. 주업종·규모: 둘 이상 사업은 사업수입금액이 큰 사업을 주된 사업으로 보고, 업종별 매출액 기준을 적용합니다.(조세특례제한법 시행령 제2조)
2. 당기 매출액: 세법상 매출액은 해당 과세연도 매출액이며, 창업·분할·합병은 정해진 연환산 규정을 적용합니다.(조세특례제한법 시행령 제2조, 조세특례제한법 시행규칙 제2조)
3. 자산: 자산총액이 5천억원 이상이면 원칙적으로 중소기업으로 보지 않습니다.(조세특례제한법 시행령 제2조)
4. 독립성: 공시대상기업집단 해당 여부 및 중소기업기본법 시행령을 인용한 실질적 독립성 요건을 확인합니다. 관계기업 판단 기준은 과세연도 종료일입니다.(조세특례제한법 시행령 제2조, 조세특례제한법 시행규칙 제2조)
5. 제외 업종·법인: 부동산 임대업·소비성서비스업을 주업으로 하는 기업과 법인세법 시행령 제42조 제2항의 요건을 모두 충족하는 내국법인은 제외합니다.(조세특례제한법 시행령 제2조)

본 사안의 경우 중소기업 확인 여부만으로 세제 적용을 끝내서는 안 됩니다. 대법원 2013두10458은 세법상 중소기업 및 유예 여부를 조세특례제한법령에 따라 판단해야 한다고 보았습니다. 따라서 **세법상 판정을 먼저 하고, 개별 감면·공제의 추가 요건을 별도로 검토**하는 것이 타당합니다.(대법원2013두10458, 2015.04.23, 조세특례제한법 시행령 제2조)

**확인 한계:** 현행 중소기업기본법 시행령 별표 1 원문을 확보하지 못하였습니다. 따라서 업종별 매출액 한도를 이 노트에서 확정표로 제시하지 않습니다. 확보된 집행기준에는 현행 조문과 다른 유예기간 등 과거 내용도 포함되어 있어, 이를 최신 업종별 기준표로 그대로 전재하지 않았습니다.(조세특례제한법 집행기준 6-2-1, 조세특례제한법 시행령 제2조)

#### 2) 유예기간

| 유형 | 현행 조문상 취급 |
| --- | --- |
| 규모 확대·자산기준 초과·관계기업 매출액 기준 초과 등 | 최초 사유 발생 과세연도와 다음 5개 과세연도 |
| 법정 시점에 유가증권시장·코스닥시장 상장요건 충족 | 다음 7개 과세연도 |
| 기준 법령 개정으로 중소기업에서 제외 | 사유 발생 과세연도와 다음 3개 과세연도 |
| 중소기업 외 기업·유예기업과 합병, 일정 독립성 위반, 창업 초기 규모 초과 | 법정 유예배제 여부 확인 |

위 유예기간 및 배제사유는 조세특례제한법 시행령 제2조 제2항·제5항에 따릅니다. **기존 유예기업에 확대기간이 적용되는지는 해당 개정 부칙을 추가 확인해야 합니다.**(조세특례제한법 시행령 제2조)

또한 **서면-2025-법인-1669, 2025.10.17.**은 과거 유예를 적용받은 후 규모 축소로 다시 중소기업이 되었다가 관계기업 매출 합산으로 기준을 재초과한 사실관계에서 유예기간의 재적용을 부인했습니다. 따라서 규모가 줄었다가 다시 커졌다는 사정만으로 유예기간이 새로 시작된다고 판단해서는 안 됩니다.(서면-2025-법인-1669, 2025.10.17)

#### 3) 기업업무추진비와 최저한세

**기업업무추진비**

| 항목 | 한도 |
| --- | --- |
| 기본한도 | 일반법인 1,200만원, 중소기업 3,600만원 × 사업연도 개월 수 ÷ 12 |
| 수입금액 100억원 이하 | 0.3% |
| 100억원 초과 500억원 이하 | 3,000만원 + 100억원 초과액 × 0.2% |
| 500억원 초과 | 1억1,000만원 + 500억원 초과액 × 0.03% |
| 특수관계인 거래 수입금액 | 해당 산출액의 10% |
| 법정 부동산임대업 등 해당법인 | 기본한도와 수입금액별 한도 합계의 50% |

위 한도는 법인세법 제25조에 근거합니다. 한도 계산 전 적격증빙 미비로 손금불산입되는 금액을 구분해야 합니다.(법인세법 제25조)

특히 시행령 제42조 제2항은 지배주주등 지분 50% 초과, 부동산임대업 주업 또는 일정 수동소득 비중 50% 이상, 상시근로자 5명 미만의 요건을 **모두** 충족하는 법인을 규정합니다. 이 법인은 중소기업 제외 여부와 기업업무추진비 50% 제한을 함께 확인해야 합니다.(법인세법 시행령 제42조, 조세특례제한법 시행령 제2조, 법인세법 제25조)

**최저한세**

| 구분 | 세율 |
| --- | --- |
| 중소기업 | 7% |
| 법정 유예 종료 후 최초 중소기업 졸업: 최초 3년 이내 종료 과세연도 | 8% |
| 그 다음 2년 이내 종료 과세연도 | 9% |
| 일반법인 과세표준 100억원 이하 부분 | 10% |

위 세율은 조세특례제한법 제132조에 따르며, 졸업 완화세율의 출발점은 시행령 제126조에 따른 유예 종료 여부와 연결됩니다.(조세특례제한법 제132조, 조세특례제한법 시행령 제126조)

본 사안의 경우 **중소기업이라는 이유로 모든 감면·공제를 최저한세 적용대상에서 제외해서는 안 됩니다.** 제132조의 대상 목록과 예외를 구분해야 하며, 예컨대 중소기업의 제10조 세액공제는 같은 조 제1항 제3호의 열거대상에서 제외되어 있습니다. 따라서 공제·감면별로 적용 여부를 판정해야 합니다.(조세특례제한법 제132조)

#### 4) 소결

따라서 중소기업 판정 결과는 이월결손금 한도, 소급공제, 기업업무추진비 기본한도 및 최저한세에 연결하되, **각 제도의 별도 제한을 다시 확인**해야 합니다. 특히 유예기간 확대와 졸업 후 최저한세 완화기간을 같은 기간으로 혼동하지 않아야 합니다.(법인세법 제13조, 법인세법 제72조, 법인세법 제25조, 조세특례제한법 제132조, 조세특례제한법 시행령 제126조)
