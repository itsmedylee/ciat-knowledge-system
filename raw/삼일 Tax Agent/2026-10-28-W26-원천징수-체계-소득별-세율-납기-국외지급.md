「원천징수-체계 › 2. 소득별 원천징수세율(거주자)」 원문 전체 절
## 2. 소득별 원천징수세율(거주자)

| 소득 | 국세 원천징수 | 지방소득세 포함 | 주의 |
| --- | --- | --- | --- |
| 상용근로소득 | 매월 간이세액표 | 간이세액표 세액 + 10% | 연말정산·퇴직 때 정산. 월급에 기본세율(6~45%)을 바로 곱하지 않는다 |
| 일용근로소득 | (일급여 − 15만 원) × 6% × 45% | + 10% | 15만 원은 1일 근로소득공제, 산출세액의 55% 세액공제 |
| 원천징수대상 사업소득 | 지급액의 3% | **3.3%** | 시행령 §184의 용역에 한정. 프로스포츠구단과 계약한 외국인 직업운동가는 국세 20%(2024.12.31. 개정) |
| 기타소득(일시적 강연료·원고료 등) | 기타소득금액의 20% | 필요경비 60%면 지급액 대비 **8.8%** | 실제 필요경비가 60%를 넘으면 초과분도 넣는 단서(2026.2.27. 시행령 §87 개정) |
| 이자소득 | 14% | 15.4% | 비영업대금 이익 25%(27.5%), 등록 온라인투자연계금융업자를 통한 이자는 14% |
| 배당소득 | 14% | 15.4% | 출자공동사업자 배당 25%(27.5%) |
| 퇴직소득 | 퇴직소득 산출세액 | + 10% | 근속연수·환산 구조. 단일세율을 곱하지 않는다. → [[퇴직소득-과세체계]] |

- **소득 구분이 먼저다.** 강연료라는 이름만으로 기타소득을 고르지 않는다. 독립된 자격으로 계속·반복 제공하는 용역의 대가는 사업소득이고, 일시성은 활동 기간·횟수·태양·상대방으로 판단한다(사전-2017-법령해석소득-0356, 2017.6.21.).
- **기타소득 과세최저한**: 건별 기타소득금액 5만 원 이하면 과세하지 않는다(필요경비 60%면 지급액 12만5천 원). 그래도 원고료·일시적 인적용역은 지급명세서 제출면제에서 빠진다(시행규칙 §97).
- **일용근로 소액부징수**: 일용급여를 월별로 한꺼번에 주면 매일의 세액이 아니라 **월별 원천징수세액 합계**로 소액부징수(1천 원 미만)를 판단한다. 주휴수당은 지난 1주의 소정근로일에, 공휴일 유급휴일수당은 그달 실제근로일에 배분한다(서면-2025-법규소득-4683, 2026.6.17.).

「원천징수-체계 › 3. 납부기한과 반기별 납부(§128, 시행령 §186)」 원문 전체 절
## 3. 납부기한과 반기별 납부(§128, 시행령 §186)

원칙은 징수일이 속한 달의 다음 달 10일이다.

| 반기납부 | 요건·기한 |
| --- | --- |
| 인원 | 직전 연도 상시고용인원 **20명 이하**(매월 말일 인원 평균). 신규 사업자는 신청일이 속한 반기 인원 |
| 제외 | 금융·보험업 제외, 종교단체는 별도 포함 |
| 신청 | 적용받으려는 반기의 직전 월 1일~말일 |
| 승인 | 신청일이 속한 반기의 다음 달 말일까지 통지, 없으면 승인 간주 |
| 납부 | 징수일이 속한 반기 마지막 달의 다음 달 10일. 지방소득세도 같이 반기납부 가능 |
| 반기납부에서도 빠지는 것 | 법인세법 소득처분 상여·배당·기타소득, 국조법상 일정 배당처분, §156의5 원천징수세액 |

반기납부는 **세액 납부기한 특례**일 뿐이다. 일용근로 지급명세서와 사업·인적용역 기타소득 간이지급명세서의 월별 제출은 그대로다. 반기납부 승인대장과 월별 제출대장을 따로 관리한다. 제출기한·제출 간주·가산세 상세는 [[지급명세서-제출의무와-가산세]]에서 다룬다.

「원천징수-체계 › 4. 원천징수 불이행 가산세(국기법 §47의5)」 원문 전체 절
## 4. 원천징수 불이행 가산세(국기법 §47의5)

- 미납·과소납부세액의 3% + 일수에 따른 이자 상당액(일 0.022%, 국기령 §27의4)이 기본이다.
- 현행 조문에는 고지 전 합계 10% 한도 외에 지정납부기한 경과 후 월별 가산(월 0.67%), 독촉비용, 전체 50% 한도가 함께 있다. "원천징수 가산세는 최대 10%"라고 단정하지 않는다.
- 2025.12.23.·2026.2.27. 개정의 고지 후 계산 체계는 부칙상 적용 시점이 확인되지 않았다 `[원문 확인 필요]`. 과거 체납분에 일괄 적용하지 않는다. → [[기한후신고와-가산세-감면]]
- **세액 미납 가산세와 소득자료 미제출 가산세는 별개**다. 세금만 내거나 명세서만 내서 다른 의무가 대체되지 않는다.

「원천징수-체계 › 5. 비거주자·외국법인 지급」 원문 전체 절
## 5. 비거주자·외국법인 지급

### 5-1. 국내법상 기본세율(국세)

| 국내원천소득 | 세율 |
| --- | --- |
| 이자 | 20%(국가·지자체·내국법인 발행 채권 이자 14%) |
| 배당 | 20% |
| 선박 등 임대·사업 | 2%(조약상 과세 사업소득 제외 규정 주의) |
| 인적용역 | 20%(일정 국외 제공 용역으로 조약상 국내 발생 소득이면 3%) |
| 사용료 | 20% |
| 일반 기타소득 | 20%(열거 예외 있음) |
| 부동산·유가증권 양도 | 지급액 10%, 취득가액 등이 확인되면 지급액 10%와 양도차익 20% 중 적은 금액 |

- 지방소득세는 국내법상 원천세의 10%를 특별징수한다. 조약 제한세율에 지방소득세가 포함되는지는 상대국 조약을 보고 정한다.
- 국외 계좌로 줘도 지급자가 국내에 주소·본점·사업장이 있으면 국내 지급으로 본다. 송금 장소만으로 원천징수를 빼지 않는다.

### 5-2. 제한세율 적용 절차(§156의6, 법인세법 §98의6)

1. 소득 구분과 **실질귀속자**를 확인한다(신청은 실질귀속자가 한다).
2. 지급 전에 제한세율 적용신청서를 받는다. 국외투자기구를 거치면 실질귀속자 명세·국외투자기구 신고서도 본다.
3. 서류가 없거나 실질귀속자를 알 수 없으면 국내법 세율로 원천징수한다.
4. 내용 변동이 없으면 제출일부터 3년 안 재제출을 생략할 수 있다. 자료는 납부기한 다음 날부터 5년 보관한다.
5. 제한세율을 못 받았으면 원천징수된 달의 다음 달 11일부터 5년 안에 경정청구할 수 있다.

- 2025.12.23. 개정으로 원천징수의무자가 받은 신청서 등을 **지급연도의 다음 연도 2월 말일까지 세무서에 제출**하는 의무가 생겼다. 최초 적용 지급분은 부칙 확인 전이다 `[원문 확인 필요]`.
- **비과세·면제 신청은 제한세율 신청과 별개**이고, 국내원천 사업소득은 그 대상이 아니다(§156의2, 법인세법 §98의4).
- 국외 지급분 지급명세서는 비거주자 다음 연도 2월 말일(근로·퇴직은 3월 10일), 외국법인 2월 말일이다(§164의2, 법인세법 §120의2).

### 5-3. 판례·심판례

| 구분 | 번호 | 요지 |
| --- | --- | --- |
| 유리 | 서울고법 2019누37242(2019.12.20.) → 대법원 2020두31620(2020.4.29. 심리불속행) | 성실히 조사해 확보한 자료로도 다른 실질귀속자를 알 수 없었던 사정 인정, 납세자 승소 확정. 현행 신청서 절차를 면제하는 판결은 아니다 |
| 유리 | 조심2022서5547(2023.5.31.) | 고객이 거주자라며 서류를 낸 주식거래에서 금융기관에 과도한 확인의무를 요구하기 어렵다고 보아 원천징수·지급명세서 가산세 취소 |
| 불리 | 대법원 2013두23317(2016.11.9.) | 거래구조·이사 겸직·보고관계로 실제 이자소득 귀속자를 알 수 있었던 사안에서 정당한 사유 부정 |

결론을 가르는 것은 **거래 당시 확보한 자료로 실질귀속자를 알 수 있었는지**다.

기준일: 2026-10-29(한국). 기준일까지 공포되어 해당 거래일에 적용되는 법령·부칙을 우선하고, 미공포 정부안·의원안·보도는 별도 표시해 주세요. 예정 거래에는 현재 공포된 법에 따른 조건부 결론만 제시해 주세요.
되묻지 말고, 누락 사실은 통상적인 가정을 명시한 뒤 답해 주세요. 가정에 따라 결론이 바뀌는 핵심 조건은 최대 2개 분기로 표시하고, 특정 사실을 만들어 확정하지 마세요. 확인 못 한 근거·계산은 '확인 불가'로 적고 확인된 범위까지 바로 답해 주세요.
이 질문은 일반 세법 검토 또는 가상 사례입니다. 세법상 과세요건·산식·신고절차만 검토해 주세요. 회계·외부감사·감사인 독립성 판단, 민사상 유효성 판단과 금융상품 추천은 요청하지 않습니다.
답은 쟁점별 결론·근거 → 계산 또는 판정표 → 필요한 증빙·신고기한 순서로 간결하게(목표 1,200~1,800자, 중요한 산식·단서는 생략하지 않음) 써 주세요. 근거는 법령명·조/항/호·적용일, 예규·판례는 문서/사건번호·일자·공식 원문 링크로 표시하고 핵심 1~3건만 골라 주세요. 직접 판단과 유사사례·추론을 구별하고 반대 근거가 실제 확인되면 함께 적어 주세요. 원문을 못 본 문서를 확정 근거로 쓰거나 존재하지 않는 번호를 만들지 마세요. 판례를 인용하면 확인한 후속 심급과 확정 여부만 표시하고, 원문 인용은 필요한 짧은 문구로 제한해 주세요.
