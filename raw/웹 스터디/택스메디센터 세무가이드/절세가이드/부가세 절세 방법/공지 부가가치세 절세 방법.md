# 공지 부가가치세 절세 방법

![86b7e0e98dab5.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/86b7e0e98dab5.jpg)

사업할 때 알아두면 좋은 부가가치세 절세 방법을 알려드려요 💁🏻‍♀️

**💡 국세청 홈택스에 사업용 신용카드 등록하기 💳**

사업할 때 가장 익숙해져야 하는 곳이 국세청이에요.

사업용 카드를 홈택스에 등록해두면 사용 내역에 대해 증빙을 따로 챙길 필요가 없어요.

부가가치세, 종합소득세 신고가 편해지고 세금을 줄일 수 있는 가장 쉬운 방법이죠 😊

🚩**법인**의 경우, **법인 명의의 카드가 자동 등록**됩니다.

[홈택스에 카드 등록하는 방법](http://guide.taxmedicenter.com/25/?idx=6080966&bmode=view)

**💡 적격증빙은 필수!**

사업과 관련된 모든 비용에 대해서는 반드시 적격증빙을 받아야 해요.

적격증빙은 계산서, 세금계산서, 카드 영수증, 현금영수증을 말해요.

특히 **현금 결제 또는 계좌이체**로 지출하실 때는 거래 상대방에게서 **현금영수증이나 세금계산서**를 꼭 받으세요!

**💡 공과금도 매입세액 공제가 가능해요!**

전기요금, 통신비, 가스요금 등에도 부가가치세가 포함되어 있어요.

**사업자 명의로 등록해서 전자세금계산서**를 받으면 부가가치세 매입세액 공제를 받을 수 있답니다 😎

**💡 음식점업을 하고 있다면 의제매입세액공제에 주목!**

의제매입세액공제란 면세 농축수산물 및 임산물 등을 원재료로  하는 제품 및 가공품을 판매할 경우, 일정 비율의 금액을 매입세액으로 보아 공제해주는 거예요.

**간이과세자는 의제매입세액공제가 불가**하다는 점에 유의하세요! (2021년 7월 이후 공급받는 분부터 적용)

|  |  |
| --- | --- |
| **공제 조건** | 부가가치세 과세사업자 |
| 면세농산물 등을 구입 |
| 면세농산물 등을 원재료로 하여 제조, 가공한 재화  또는 창출한 용역의 공급 |
| 제조, 가공한 재화 또는 창출한 용역의 공급이 **과세** 대상 |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😀

**💡 직원 복리후생비 및 사업용 차량 관련 비용은 공제 가능!**

직원 식비, 커피값 등 식음료 비용 및 유니폼, 면장갑 등 피복비는 복리후생비로 보아 부가가치세 매입세액 공제가 가능해요 🙆🏻‍♀️  
단, 지급한 급여에 대해 원천세 등 신고를 해야 해요.

사업용으로 차량을 구매한 경우에도 공제가 가능해요.

**매입세액 공제 대상 차량**은 아래 표를 참고해주세요.

|  |  |
| --- | --- |
| **영업용 차량** | **비영업용 차량** |
| 상관없이 공제 가능 | 1,000cc 이하 경차, 9인승 이상 승합차  밴, 화물차, 125cc 이하 이륜차만 공제 가능 |

**💡 매출누락에 유의!**

매출을 누락하면 가산세가 부과될 수 있어요 😥

국세청은 과세 정보를 누적해서 관리하다가 세무조사를 할 때 한꺼번에 추징하는 것이 기본 방침이에요.

정확한 매출은 아래 사이트에서 확인하실 수 있어요.

|  |  |
| --- | --- |
| **매출 구분** | **확인 가능한 곳** |
| 신용카드 체크카드 | 여신금융협회 가맹점매출조회 사이트 각 카드단말기회사 사이트 |
| 전자세금계산서 전자계산서 현금영수증 | 국세청 현금영수증 사이트 |
| 전자상거래 | 인터넷결제대행사 사이트 오픈마켓 관리자 사이트 등 |
