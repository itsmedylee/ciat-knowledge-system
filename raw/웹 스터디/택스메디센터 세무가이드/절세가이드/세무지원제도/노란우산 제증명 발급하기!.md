# 노란우산 제증명 발급하기!

![b2bbd07fa3389.jpeg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/b2bbd07fa3389.jpeg)

1. 홈페이지 발급 

[노란우산 홈페이지](https://www.8899.or.kr/yuma/index.do)

노란우산 **가입증서, 부금납입 증명서, 청약서 부본**은 홈페이지에서 직접 발급이 가능해요. 

제증명 발급을 위해서는 간편로그인이 아닌 다른 수단으로 로그인 해야해요.

**[마이페이지]**에서 **[제증명발급]**메뉴를 눌러주세요.  
![3fa79f9fba80f.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/3fa79f9fba80f.png)

**[발급신청]**을 눌러주세요.

문서 확인 버튼은 문서 발급이 아닌 단순 확인이에요.

![f86103f1982e5.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/f86103f1982e5.png)

기초 자료 확인 후 신청정보에서 **발급할 서류를 선택**하고,**[증명서 발급 신청]**을 눌러주세요.

선택한 증명서는 **카카오 알림톡**으로 발급돼요. 

![b8d96426a01be.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/b8d96426a01be.png)

2. 홈페이지에서 발급 불가한 서류

위 서류 외 모든 서류는 **홈페이지에서 발급할 수 없어요.**

추가적인 서류가 필요하시다면 **노란우산 고객센터(1666-9988-1-0)**에서 **대표자 본인이 직접 통화**해서 발급해 주세요!(타인 대리 발급 불가함)
