# 희망리턴패키지 - 사업정리컨설팅 전직장려수당 신청 방법 (폐업 후 최대 100만 원 받아 가세요!)

![e606a45316119.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/e606a45316119.jpg)

**전직 장려 수당**은 제출 서류 구비 후 **온라인으로 신청**하시거나 **공단 지역 센터에 방문 접수**하시면 돼요 💁🏻‍♀️

**💡 전직장려수당 지원 대상은?**

폐업 신고 후 구직 활동을 하거나 취업해서 30일 이상 고용보험 가입한 사람에게 지원돼요.

**💡 전직장려수당은 어떻게 지급되나요?**

구직 활동 중 1차 수당(40만원)을 받고, 취업 및 근속 확인 후 2차 수당(60만원)을 받을 수 있어요.

단, 2차 수당 신청시 고용노동부 국민취업지원제도를 통해 “취업성공수당”을 이미 지원받았다면 중복 수령이 안돼요!

**💡 전직장려수당을 못 받는 경우도 있나요?**

|  |
| --- |
| <아래의 항목 중 1개 이상 해당할 경우 전직장려수당 지원 대상에서 제외 됩니다.>   * (제외업종) 희망리턴패키지 지원 제외 업종에 해당하는 자 * (미폐업자) 전직장려수당 신청 전 본인 명의의 모든 사업자등록을 폐업 신고하지 않은 것으로 확인된 경우 * (신청일 초과) 재취업 기초교육을 수료한 날로부터 14개월 이내 신청하지 못한 경우 * (취업일 초과) 재취업 기초교육을 수료한 날로부터 12개월 이내취업을 완료하지 못한 경우 * (기취업자) 재취업 기초교육 수료 전 취업자 * (취업성공수당 수혜자) 국민취업지원제도를 통해 취업성공수당을 이미 지원받은 이력이 있는 경우(2차 지급 불가) * (일용근로자) 고용보험이 일용근로내역서로 신고 되는 일용근로자 * (근로자가 아닌 자) 근로기준법에 의한 근로자가 아닌 자 |

**💡 폐업신고했지만 다른 사업자를 보유하고 있는데 지급 받을 수 있나요?**

아니요!

매출액 유무와 관계없이 기존사업장을 폐업하지 않은 것으로 확인된 경우, 미 폐업자로 판단돼 지원 제외 대상에 해당돼요.

그러나, 비영리법인 또는 비영리사업자의 경우는 다른 요건이 부합하다면 지급이 가능해요.

**💡 신청 서류는 어떤 것이 있나요?**

|  |
| --- |
| <공통 서류>   * 전직장려수당 신청서 및 동의서 * 폐업사실증명원 * 총사업자등록증명내역 사실증명원(전체 이력) * 신청자 본인 명의 통장 사본 |

|  |
| --- |
| <취업 전>   * 국민취업지원제도 사업참여확인서 * 고용보험 자격이력내역서(전체이력, 직종명(코드)포함) |

|  |
| --- |
| <취업 후>   * 표준근로계약서 * 고용보험 자격이력내역서 (직종명코드 기입, 전체 이력) |

자세한 내용은 아래 링크 및 **중소기업통합콜센터(☎ 1357)**를 통해서 확인하실 수 있어요!
