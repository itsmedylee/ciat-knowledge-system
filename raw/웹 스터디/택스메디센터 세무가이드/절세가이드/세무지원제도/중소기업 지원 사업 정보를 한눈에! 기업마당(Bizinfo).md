# 중소기업 지원 사업 정보를 한눈에! 기업마당(Bizinfo)

![89b96d791e7cd.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/89b96d791e7cd.png)

[기업마당 홈페이지 가기](https://www.bizinfo.go.kr/)

화면 상단의 **[정책정보]**메뉴를 누르면 지원 사업 공고조회 화면이 나와요.

왼쪽의 지원사업명 부분을 클릭하면 소관부처, 내용, 해시태그를 선택할 수 있고, 그에 맞는 검색어를 입력하면 해당하는 공고가 조회돼요.

대표적인 지원 제도는 세무가이드의 세무지원제도 카테고리를 참고해주세요.

[세무지원제도 카테고리 바로 가기](https://guide.taxmedicenter.com/22)

**지원금**을 받으셨다면 **소득세 신고를 할 때 연소득금액에 합산**해야 해요.

신고 시 내용이 누락되지 않도록 세무대리인에게 **지원 사업명, 사업 기간, 지원금 총액**이 기재된 **선정 확인서**를 꼭 보내주세요!

각 지원금 공고 세부사항에 기재된 관할 기관에 문의하시면 더 자세한 내용을 확인하실 수 있어요 😃
