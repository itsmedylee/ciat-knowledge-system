# 자영업자의 퇴직금, 노란우산공제에 대해 알아봐요.

![68e44603cedc1.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/68e44603cedc1.png)

**노란우산공제**는 중소기업중앙회에서 운영하는 제도예요.

폐업 등의 사유가 발생할 경우를 대비해 **목돈 마련**을 할 수 있고 **소득공제**까지 가능해서 흔히 **자영업자의 퇴직금**이라고도 불려요.

노란우산공제는 **개인사업자 또는 법인의 대표자**가 가입할 수 있어요 😀

**💡 노란우산공제 특징은?**

|  |
| --- |
| * 법에 의한 압류, 양도, 담보 제공 금지 * 종합소득세 신고 시 소득공제 * 대출 가능 * 상해 보험금 지급 |

**💡 소기업·소상공인은 어떤 기준으로 판단하나요?**

|  |  |
| --- | --- |
| **업종** | **3년 평균 매출액** |
| 제조업(의료용 물질·의약품 등 15개) 전기·가스·수도사업 | 120억 이하 |
| 제조업(펄프·종이·종이제품 등 9개) 광업, 건설업, 운수업 농업, 임업, 어업, 금융·보험업 | 80억 이하 |
| 출판·영상·정보서비스 도·소매업 | 50억 이하 |
| 전문·과학·기술서비스, 사업서비스 하수·폐기물처리업, 예술·스포츠·여가서비스 부동산임대업 | 30억 이하 |
| 보건, 사회복지서비스 개인서비스업, 교육서비스업, 숙박·음식점업 | 10억 이하 |

**💡 공제부금 납부 방법은?**

|  |
| --- |
| * 매월 납부 또는 분기별 납부 * 5만 원부터 100만 원까지 1만 원 단위 * 가입자 명의 지정 예금 계좌에서 자동이체 |

**💡 노란우산공제 가입 방법이 궁금해요.**

은행 또는 홈페이지에서 가입하실 수 있어요.

[홈페이지 바로 가기](https://www.8899.or.kr/)

**💡 노란우산공제 납입금은 어떤 경우에 지급받을 수 있나요?**

|  |
| --- |
| * 폐업 또는 사망, 법인사업자의 해산 * 법인 대표자의 질병·부상으로 인한 퇴임 * 만 60세 이상 도달 + 10년 이상 불입 시 * 개인 사정에 따른 해약 청구 시 등 |

자세한 내용은 중소기업중앙회(국번 없이 ☎️ 1666-9988)로 문의해주세요.
