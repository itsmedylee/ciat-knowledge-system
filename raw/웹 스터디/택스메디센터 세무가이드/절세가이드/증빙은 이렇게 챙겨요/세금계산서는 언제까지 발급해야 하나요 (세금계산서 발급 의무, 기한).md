# 세금계산서는 언제까지 발급해야 하나요? (세금계산서 발급 의무, 기한)

![9670e24e8a3c0.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/9670e24e8a3c0.jpg)

💡 **세금계산서란?**

**사업자 간 거래가 있을 때 주고 받는 증빙**으로서 세법에서 인정해주는 대표적인 **적격 증빙**이에요.

* **세금계산서**는 부가가치세 **과세** 거래에 대해 발급하고
* **계산서**는 부가가치세 **면세** 거래에 대해 발급해요.

과세인지 면세인지에 따라 발급되는 종류가 다를 뿐, 발급 방법이나 시기 등은 모두 동일해요 🙆🏻‍♀️

🚨 **주의!**

특정 사업자는 종이세금계산서가 아닌 **전자세금계산서**를 발급해야 해요.

발급 의무 기준은 아래 표를 참고해주세요 💁🏻‍♀️

|  |  |  |
| --- | --- | --- |
| 구분 | **전자****세금계산서** | **종이****세금계산서** |
| 발급 의무 | 모든 법인 직전년도 공급가액 1억 원 이상인 개인사업자 (과세·면세 합계액 기준) | 직전년도 공급가액 2억 원 미만인 개인사업자 (과세·면세 합계액 기준) |
| 발급 시기 | **거래 월 다음 달 10일까지** | |
| 혜택 및 특징 | 보관 의무 없음 합계표 개별 작성 의무 면제 전자세금계산서 발급 세액공제 | 종이로 보관 필요 |
| 가산세 | 미발급 : 공급가액 x 2% 지연발급 : 공급가액 x 1% 종이로 발급 시 : 공급가액 x 1% | 미발급 : 공급가액 x 2% 지연발급 : 공급가액 x 1% |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃

💡 **직전년도 공급가액 합계액 1억 원 미만인 개인 사업자는...**

전자세금계산서로 발행하면 전자세금계산서의 혜택을 누릴 수 있어요.

종이세금계산서로 발급하더라도 종이 발급에 대한 가산세는 없어요.

💡 **세금계산서 지연발급의 기준은?**

원래대로라면 세금계산서는 거래가 발생한 다음달 10일까지 발급해야 하죠.

지연발급은 다음달 10일까지는 발급하지 않았지만

**상반기 거래분에 대해서는 7월 25일까지**

**하반기 거래분에 대해서는 다음해 1월 25일까지** 발급한 경우를 말해요.

예를 들어, 4월 거래분에 대해 5월 25일에 세금계산서를 발급한다면?

**공급자(매출자)**에게는 지연발급가산세(1%)가 부과되고

**공급받은 자(매입자)**는 매입세액공제는 받을 수 있지만 지연수취가산세(0.5%)가 부과돼요.

💡 **세금계산서 미발급의 기준은?**

지연발급 기준이 되는 기한까지도 세금계산서를 발급하지 않은 경우에 해당해요.

예를 들어, 4월 거래분에 대해 7월 30일에 세금계산서를 발급한다면?

매출자에게는 미발급 가산세(2%)가 부과되고, 매입자는 매입세액공제를 받을 수 없어요 😱

세금계산서를 제때 발급하고 수취해야 하는 이유, 아시겠죠?
