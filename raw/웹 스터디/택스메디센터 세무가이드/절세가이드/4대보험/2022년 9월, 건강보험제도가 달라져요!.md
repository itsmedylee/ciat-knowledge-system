# 2022년 9월, 건강보험제도가 달라져요!

![614372869755a.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/614372869755a.jpg)

|  |
| --- |
| * 지역가입자 보험료 감소 * 직장가입자 피부양자 요건 강화 * 직장가입자 급여 외 소득에 대한 보험료 부과 기준 강화 |

**💡 지역가입자 보험료는 이렇게 달라져요.**

* **건강보험료 부과 대상 재산 축소**

2022년 9월 1일부터 건강보험료를 부과하는 재산에 대한 공제액이 5,000만 원으로 높아져요.

무주택 또는 1주택 세대는 실거주 목적의 주택 부채를 추가로 공제받을 수 있어서 **재산 보험료 부담이 낮아져요.**

자동차에 대한 건강보험료 부과 기준도 완화돼요.

* **건강보험료 산정 방식 간소화**

기존에는 지역가입자 소득을 97등급으로 나누어 점수당 금액을 곱하는 방식으로 보험료를 구했어요.

그러나 2022년 9월 1일부터는 **직장가입자와 동일하게 소득에 보험료율을 곱하는 방식**으로 바뀌어요.

그 밖에도 최저 보험료를 직장가입자와 동일하게 책정하고, 공적연금소득 및 일시근로소득 평가율이 기존 30%에서 50%로 달라져요.

|  |  |  |
| --- | --- | --- |
| **지역가입자** | **기존** | **2022년 9월 1일 이후** |
| 재산 공제액 증가 (보험료 부과 대상 재산 감소) | 재산 공제 500~1,350만 원 (구간별 차등 적용) | 일괄 5,000만 원 공제 |
| 자동차 보험료 부과 기준 완화 | 1,600cc 이상 차량 또는 차량가액 4,000만 원 이상인 차량 | 차량가액 4,000만 원 이상인 차량 (감가상각 고려한 금액 기준) |
| 보험료 산정 방식 간소화 | 소득구간별 보험료율 차등 적용 (최대 약 20%) | 단일 보험료율 적용 (약 7%, 직장가입자와 동일) |
| 최저 보험료 일원화 | 월 14,650원 | 월 19,500원 |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃

**💡 직장가입자 보험료는 이렇게 달라져요.**

* **피부양자 요건이 강화돼요.**

기존에는 피부양자 연간 소득이 3,400만 원을 초과할 때 피부양자 자격이 박탈됐어요.

그러나 2022년 9월 1일 이후로는 **연간 소득이 2,000만 원을 초과하면** 피부양자 자격이 박탈돼요.

* **급여 외 소득에 대한 보험료 부과 기준이 강화돼요.**

기존에는 급여 외 소득이 연간 3,400만 원을 초과할 때 보험료를 부과했어요.

그러나 2022년 9월 1일부터는 임대소득, 사업소득, 이자·배당소득 등 **급여 외 소득이 연간 2,000만 원을 초과할 때** 보험료를 부과해요.

|  |  |  |
| --- | --- | --- |
| **직장가입자** | **기존** | **2022년 9월 1일 이후** |
| 피부양자 요건 강화 | 피부양자 연간 소득 3,400만 원 초과 시 자격 박탈 | 피부양자 연간 소득 2,000만 원 초과 시 자격 박탈 |
| 급여 외 소득에 대한 보험료 부과 기준 강화 | 연간 3,400만 원 초과 시 부과 | 연간 2,000만 원 공제 후 초과한 금액에 대해서만 부과 |
