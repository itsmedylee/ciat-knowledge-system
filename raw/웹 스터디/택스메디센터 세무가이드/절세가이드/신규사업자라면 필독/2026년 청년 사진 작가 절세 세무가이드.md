# 2026년 청년 사진 작가 절세 세무가이드

새내기 사장님, 아래 **5가지** 챙기고 세금 걱정 없이 셔터만 누르세요!

> **청년 창업 감면의 마법✨**

청년 창업자는 5년간 소득세를 감면해줍니다.

* 지역이 중요해요

|  |  |
| --- | --- |
| **지역** | **감면율** |
| 비수도권, 수도권의 인구감소지역 | 100% |
| 수도권과밀억제권역과 인구감소지역이 아닌 수도권 | 75% |
| 수도권과밀억제권역 | 50% |

 

* 청년 :  만 15세~34세
* 업종 : 업종에 따라 창업 감면 여부가 달라질 수 있으므로 사업자등록 전 상담을 받아보세요.

> **현금영수증 의무발행업종?💸**

인물사진촬영업은 **현금영수증 의무발행** 업종입니다.

따라서

* 고객이 요청하거나
* 건당 10만원 이상 매출에 대해서는 현금영수증을 **무조건** 발급해야 합니다.

현금영수증 의무발행업종은 현금영수증 가맹점가입까지해야 창업감면이 가능하니 꼭 챙겨야겠죠?

> **일반 vs 간이, 그것이 문제로다! 🧐**

간이과세자는 일반과세자보다 유리하다고 알려져있죠.

하지만 초기 장비구입액이 많다면, 환급이 가능한 일반과세자가 더 유리할지도 몰라요.

>  **등록 전 산 장비, 포기하지 마세요! ✅**

사업자등록 전에 샀더라도 증빙이 있다면, 비용 처리 가능하답니다. 챙겨주세요.
