# 현금영수증 가맹점 가입 의무란?

![4ee6d58a9e2b0.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/4ee6d58a9e2b0.jpg)

**현금영수증 가맹점 가입 의무**는 업종이나 수입금액에 따라 달라져요.

가맹점에 가입하셨다면 발급받은 **가맹점 스티커를 소비자가 잘 볼 수 있는 곳에** 붙여주셔야 해요.

[나도 현금영수증 가맹점 가입 대상일까?](http://guide.taxmedicenter.com/32/?idx=9433945&bmode=view)

**💡 현금영수증 가맹점 가입 대상은?**

|  |
| --- |
| * 소비자 상대 업종 사업자 중 직전 과세기간 수입금액 2,400만 원 이상인 개인사업자 * 소비자 상대 업종을 영위하는 법인사업자 * 의사·약사 등 의료 보건 용역 제공 사업자 * 변호사 등 부가가치세 간이과세 배제 전문직 사업자 * 현금영수증 의무 발행 업종 사업자 |

소비자 상대 업종은 글 아래의 **첨부 파일**에서 확인하실 수 있어요.

**💡 언제까지 가입해야 하나요?**

|  |  |  |
| --- | --- | --- |
| **구분** | | **가입 기한** |
| **법인** | | 개업일 등이 속하는 달의 말일부터 3개월 이내 |
| **개인** | **소비자 상대 업종** | 수입금액이 2,400만 원 이상이 되는 해의 다음해 3월 31일까지 |
| **현금영수증 의무 발행 업종** | 사업 개시일, 업종 정정일 등 요건 해당일로부터 60일 이내 |

**💡 가맹점 미가입 시 불이익이 있나요?**

미가입 기간 소비자 상대 업종 **수입금액의 1%가 가산세**로 부과돼요.

(2019년 이후에는 세금계산서 발급분을 제외한 수입금액을 기준으로 가산세 부과)
