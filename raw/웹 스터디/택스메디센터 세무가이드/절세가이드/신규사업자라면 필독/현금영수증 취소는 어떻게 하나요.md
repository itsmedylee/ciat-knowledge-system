# 현금영수증 취소는 어떻게 하나요?

[현금영수증 발급을 깜박했다면?](http://guide.taxmedicenter.com/32/?idx=9045235&bmode=view)

|  |
| --- |
| <현금영수증 취소 방법>  1. 홈택스에서 현금영수증 취소하기   * 홈택스 발급분만 취소 가능 * 최근 36개월 동안의 거래만 조회 가능   2. ARS로 현금영수증 취소하기  3. 카드 단말기로 현금영수증 취소하기 |

**💡 홈택스에서 현금영수증 취소하기**

[홈택스 바로 가기](https://www.hometax.go.kr/)

홈택스 로그인 후 **[계산서·영수증·카드] - [현금영수증(가맹점)] - [발급] - [현금영수증 취소 발급]** 메뉴를 클릭해주세요.

![8840f060a2c78.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/8840f060a2c78.png)

**조회 기간을 설정하고 [조회하기]**를 누르면 해당 기간에 발급한 현금영수증 목록이 나와요.

아래 이미지와 같이 **취소하려는 건을 선택**하면 거래 정보를 등록하는 화면이 뜨는데, **총 거래 금액을 입력**하고 **취소 사유를 선택**후 **[취소 발급]**을 누르시면 돼요.

총 거래 금액을 입력하면 공급가액과 부가세는 자동으로 입력돼요 🙂

![4479bebb3c08f.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/4479bebb3c08f.png)

**💡 ARS로 현금영수증 취소하기**

**국번 없이 ☎️ 126** 으로 전화하신 후 ARS 안내 음성에 따라

**1번 홈택스 - 1번 현금영수증 - 1번 한국어 안내 - 4번 가맹점 현금영수증 발급 서비스**순서로 숫자를 눌러주세요.

안내 음성이 나오면 **사업자 번호와 ARS 비밀번호를 입력**해주세요.

\*ARS 비밀번호를 처음 설정하신다면 **사업자 대표 휴대전화번호 #** 을 눌러 인증번호를 받으신 후, **인증번호 #** 을 누르면 비밀번호를 설정하실 수 있어요.

**봉사료 유무, 거래 취소 사유를 선택**하고 **거래 일자 및 금액**을 누르시면 돼요.

**💡 카드단말기로 현금영수증 취소하기**

현금영수증을 카드단말기로 발급하셨다면 카드단말기의 **현금영수증 취소 기능**으로 빠르게 취소하실 수 있어요 🙂

**💡 금융결제원 홈페이지에서 취소하기**

과거 1년 동안 발급한 현금영수증은 금융결제원에 회원 가입해서 조회 및 취소 요청이 가능해요.

아래 링크의 방법을 참고해주세요 😊

[금융결제원 현금영수증 취소 방법](https://www.kftcvan.or.kr/guide/service/cashReceipt.do?tab=03)
