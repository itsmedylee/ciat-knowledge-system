# 세금 낼 돈이 없는데... 부가세 신고 안 하면 안 될까요?

![620dab0178604.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/620dab0178604.jpg)

**💡 세금 낼 여유가 없는데... 신고 안 하면 안 돼요?**

**안 돼요 ❌**

신고를 아예 안 하는 것과 납부 기한만 지키지 못하는 것은 완전히 달라요. 

납부 기한을 연장하는 방법도 있으니, 당장 납부하기 어렵더라도 신고는 꼭 해주세요 😥

[세금도 분납할 수 있어요!](https://guide.taxmedicenter.com/27/?idx=6892731&bmode=view)

**💡 납부 기한이 지났어요!**

아래 방법으로 납부하실 수 있어요.

[홈택스에서 납부 기한 지난 세금 내기](https://guide.taxmedicenter.com/32/?idx=7007447&bmode=view)

**💡 신고 안 하면 불이익이 있나요?**

* **매입세액 공제 불가**

매입세액을 공제받으려면 부가가치세 신고를 할 때 공제 관련 서류를 제출해야 해요.

부가가치세 신고를 하지 않으면 공제 관련 서류도 제출할 수 없기 때문에 매입세액 공제를 받지 못해요.

* **가산세**

**매출처별세금계산서합계표 미제출 가산세** : 매출액 x 0.5%

**매입처별세금계산서합계표 미제출 가산세** : 매입액 x 0.5%

**무신고 가산세** : 납부세액 x 20%(부정 무신고 시 40%)

**납부지연 가산세** : 미납세액 x (2.2/10,000) x 미납일수
