# 다주택자인 자녀? 무주택 손자? 누구에게 상속·증여가 유리할까!

오늘은 **어머니의 아파트 1채**를 기준으로  
자녀가 상속받는 것과 손자에게 증여하는 것 중 

어떤 게 세금 측면에서 유리한지 비교해볼게요!

> **상황🏠**

* 어머니는 아파트를 제외한 다른 재산은 없음
* 과거 10년 동안 어머니께서 증여한 재산 없음
* 아버지께서는 먼저 돌아가심
* 자녀는 현재 다주택자
* 손자는 무주택자, 성인

> **자녀의 고민💬**

제가 어머니 주택을 상속 받으면 취득세가 중과될까봐 걱정이에요

차라리 손자에게 미리 증여하는 게 나을까요?

> **상속 vs 증여, 세금으로 따져볼게요.📊**

1. 상속 받는 경우

* 상속세 : 최소 공제 5억원
* 취득세 : 3.16% (취득세 중과 없음)

2. 증여 받는 경우

* 증여세 : 최소 공제 5천만원
* 취득세 : 3.8%

3. 아파트 가액이 5억원일 때

구체적인 금액을 통해서 확인해보겠습니다. 

|  |  |  |
| --- | --- | --- |
| 구분 | 상속 | 증여 |
| 상속세 또는 증여세 | 0 원 | 1억 400만원 |
| 취득세 | 1,580만원 | 1,900만원 |
| 합계 | 1,580만원 | 1억 2,300만원 |

👉상속이 증여보다 유리합니다.
