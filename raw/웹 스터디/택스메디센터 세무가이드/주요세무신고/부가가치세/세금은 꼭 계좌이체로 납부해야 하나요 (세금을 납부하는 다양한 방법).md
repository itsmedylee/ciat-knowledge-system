# 세금은 꼭 계좌이체로 납부해야 하나요? (세금을 납부하는 다양한 방법)

**💡 현금으로 세금 납부하기**

납부서를 가지고 있다면 은행이나 우체국에서 **현금으로 납부**하실 수 있어요.

또는 납부서에 기재된 **국세 전용 가상계좌로 계좌이체**하실 수도 있어요.

**💡 카드로 세금 납부하기**

**은행이나 우체국 CD·ATM**을 사용해서 **카드로 납부**하실 수 있어요.

또는 **홈택스**나 **손택스**로 **카드****납부**하거나, **세무서의 무인 수납 창구**에서도 **카드로 납부**하실 수 있어요.

**💡 현금 납부와 카드 납부 중 뭐가 유리한가요?**

|  |  |  |
| --- | --- | --- |
|  | **현금 납부** | **카드 납부** |
| 장점 | 별도의 수수료 없음 | 납부불성실가산세 줄일 수 있음 |
| 단점 | 당장 자금이 있어야 납부 가능 | 카드 결제 수수료 발생 (0.5~0.8%) 할부 수수료 발생 (약 10% 이상) |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃

카드로 납부하면 카드 결제 수수료가 발생해요. 할부 결제라면 할부 수수료가 추가로 발생해요.

그러나 신용카드로 결제한다면 미납일수에 따라 늘어나는 납부불성실가산세를 조금이나마 줄일 수 있어요.

또한 당장 현금이 없더라도 신용카드 결제가 승인되면 **국세완납증명서를 발급**받을 수 있어요.

반면 현금으로 납부하면 별도의 수수료가 없는 대신 당장 수중에 있는 금액만큼만 납부할 수 있어요.
