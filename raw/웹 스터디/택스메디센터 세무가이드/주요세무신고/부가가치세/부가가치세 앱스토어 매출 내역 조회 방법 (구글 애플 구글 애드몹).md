# 부가가치세 앱스토어 매출 내역 조회 방법 (구글/애플/구글 애드몹)

|  |
| --- |
| * 구글플레이 매출 조회 * 애플 앱스토어 매출 조회 * 구글 애드몹(Google AdMob) 매출 확인 |

###### **💡 구글 매출 내역 조회하는 방법**

###### [구글플레이 접속하기](https://play.google.com/intl/ko/console/about/?utm_source=google&utm_medium=cpc&utm_campaign=Console2020-Branded&utm_term=%EA%B5%AC%EA%B8%80%20%ED%94%8C%EB%A0%88%EC%9D%B4%20%EC%BD%98%EC%86%94%7Ce&utm_content=480049911998&gclid=CjwKCAjwqvyFBhB7EiwAER786eW0RM43goboJqrZYq4sLqTuyS63bmXBQ8THgK649_Xterc4OJHz3BoCr48QAvD_BwE)

구글플레이 관리자 **로그인 - [보고서] - [보고서 다운로드] - [재무]**를 클릭해주세요.

매출 확인 후 **엑셀 파일 다운로드**하시면 돼요.

![39b5cf6258783.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/39b5cf6258783.png)

구글 매출은 하나의 상품에 대해 3행(Google fee / Charge /  Tax)으로 이루어져 있어요.

|  |
| --- |
| * Google fee 구글이 과금하는 수수료 (판매 금액의 30%) * Charge 소비자가 결제한 금액 (개발자가 받는 수익금 = Charge - Google fee) * Tax Google fee 계산에서 제외되어 국내 거주 개발자는 부가가치세(10%)로 납부하셔야 하는 금액 |

**구글 매출 내역에는 아래 필수 항목이 반드시 포함되도록 선택하여 다운로드해주세요!**

![370c35af745d5.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/370c35af745d5.png)

![b0dc3913a01cc.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/b0dc3913a01cc.png)

###### **💡 애플 앱스토어 매출 내역 조회하는 방법**

###### [앱스토어 접속하기](https://itunesconnect.apple.com/login)

###### 아이튠즈 관리자 로그인 후 **[지불 및 재무 보고서]**를 확인해주세요.

![866a8749fc390.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/866a8749fc390.png)

**해당 기간을 선택**하고 화폐 단위를 **원화**로 변경한 후 **[보고서 생성(Create reports)]**을 클릭해주세요.

![d981049f8d2ff.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/d981049f8d2ff.png)

![58a307a0a39e5.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/58a307a0a39e5.png)

![d5e3d24bb1fc5.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/d5e3d24bb1fc5.png)

다운로드한 파일은 **압축한 상태(zip 파일)**로 보내주세요.

앱스토어 사이트에서는 은행 계좌에 입금하는 통화 기준으로 조회돼요.

따라서 외화로 입금된 경우 원화로 조회되지 않을 수도 있어요.

관련 문제가 발생하면 앱스토어 고객센터를 통해 정확한 답변을 얻으실 수 있어요.

###### **💡 구글 애드몹(Google AdMob) 매출 확인하는 방법**

애드몹 매출은 모두 해외 매출로서 영세율 적용이 가능해요.

따로 자료나 보고서를 받으실 필요 없이, 애드몹으로 입금되는 **은행에 외화입금증명서를 요청**하시면 돼요!
