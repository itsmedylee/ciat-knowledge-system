# 결제대행 사이트 매출은 어떻게 조회하나요? (토스페이먼츠, (주)다날, 크티)

**💡 토스페이먼츠**

토스페이먼츠 계정으로 상점관리자 페이지에 로그인 후 **[내 상점]**을 눌러주세요.

**[결제 조회]**메뉴 중 **[부가세 신고 자료]**를 선택하면 매출 자료를 조회할 수 있고, 조회 결과는 카드 결제건, 현금영수증 발행분, 계좌이체 결제건, 포인트 결제건 등이 구분되어 나와요.

필요에 따라 분기별, 반기별 혹은 1년 단위로 **조회 기간을 설정**하고, **엑셀 다운로드**해서 보내주시면 돼요.

|  |
| --- |
| 조회 기간 예시  7월 부가세 신고 시 : 1월~6월 조회  1월 부가세 신고 시 : 전년도 7월~12월 조회 |

메뉴 화면 등 보다 자세한 내용은 아래 링크에서도 보실 수 있어요.

[토스 부가가치세 자료 조회 방법](https://blog.tossbusiness.com/articles/how-to-vat)

**💡 (주)다날**

다날 파트너센터에 로그인 후 **[정산/세금] - [부가세 신고 자료 조회]** 메뉴에서 확인할 수 있어요.

마찬가지로 **기간 설정** 후 조회하고 **엑셀 다운로드**해서 보내주시면 돼요.

[다날 파트너센터 바로 가기](https://partner.danalpay.com/account/login)

**💡 크티 (CTEE)**

크티 플레이스 로그인 후 프로필 이미지를 누르면 하위 메뉴가 나와요.

여기서 **[내 플레이스 관리] - [정산]** 메뉴로 들어가면 자료를 조회할 수 있어요.
