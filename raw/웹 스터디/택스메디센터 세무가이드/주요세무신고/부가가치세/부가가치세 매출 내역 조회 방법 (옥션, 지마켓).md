# 부가가치세 매출 내역 조회 방법 (옥션, 지마켓)

💡**옥션 매출(지마켓 매출) 조회하는 방법** [ESM 판매자 페이지 가기](https://www.esmplus.com/Member/SignIn/LogOn)

**1. ESM 판매자 페이지에 로그인해주세요.**

![abfb58298b84f.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/abfb58298b84f.png)

**2. 왼쪽 [정산 관리] - [부가가치세 신고 내역]을 눌러주세요.**

![8f16ee3dab28d.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/8f16ee3dab28d.png)

**3. 기간을 설정하고 [조회]를 눌러주세요.**

- 법인사업자 : 1월~3월 / 4월~6월 / 7월~9월 / 10월~12월

- 일반과세자 : 1월~6월 / 7월~12월

- 간이과세자 : 1월~12월

![762b4d97910a0.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/762b4d97910a0.png)

**4. 매출 내역이 조회되면 오른쪽 엑셀다운을 클릭해서 파일을 저장해주세요.**

결제 수단과 금액이 잘 나오도록 **조회 결과 화면을 캡처**해서 보내주셔도 돼요.

기간 설정 부분 바로 위의 **[G마켓]** 탭을 누르면 같은 방법으로 G마켓 매출도 조회하실 수 있어요.

![6421d6945efc2.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/6421d6945efc2.png)

캡처 또는 다운로드하신 매출 자료는 한경세무회계로 꼭 보내주세요🙋🏻‍♀️
