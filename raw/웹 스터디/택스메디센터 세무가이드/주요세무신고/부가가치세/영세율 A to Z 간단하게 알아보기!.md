# 영세율 A to Z 간단하게 알아보기!

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃

|  |
| --- |
| 1. 영세율이란?  2. 영세율 적용 대상은?  3. 영세율 세금계산서 발급 대상은?  4. 구매확인서란?  5. 구매확인서 발급 기한에 따라 달라지는 세금계산서 발급 방법 |

**💡 영세율이란?**

0% 세율을 적용해서 부가가치세 부담을 완전히 덜어주는 제도예요.

부가가치세 신고를 통해 매입세액을 환급받을 수 있어요.

|  |  |  |
| --- | --- | --- |
| 과세사업자 | 일반과세자 | 영세율 적용 ⭕ |
| 간이과세자 | 영세율 적용 ⭕ \*간이과세자이므로 환급은 불가 |
| 면세사업자 | | 영세율 적용 ❌ \*면세 포기 시 영세율 적용 가능 |

**💡 영세율 적용 대상은?**

**① 재화의 수출** : 직수출, 내국신용장/구매확인서에 의한 공급 등

**② 국외에서 공급하는 용역** : 해외 건설 용역 등

**③ 선박 또는 항공기에 의한 외국항행용역의 공급**

**④ 외화를 획득하기 위한 재화 또는 용역의 공급** : 국내 거래이지만 국내사업장이 없는 비거주자 또는 외국법인에게 공급하며, 그 대금을 외국환은행에서 원화로 받는 등의 방법으로 외화획득이 가능한 거래 등

**⑤ 조세특례제한법상 영세율 적용대상 재화나 용역** : 방산업체가 공급하는 방산물자 등

**💡 영세율 세금계산서 발급 대상은?**

|  |  |
| --- | --- |
| 영세율 세금계산서 ⭕ | 내국신용장·구매확인서에 의한 공급, 수출재화임가공용역 |
| 영세율 세금계산서 ❌ | 직수출, 국외에서 공급하는 용역, 외국항행용역의 공급 |

**💡 구매확인서란?**

최종 수출을 하기 위해 구매했음을 증명해주는 서류예요.

물건을 공급하는 자는 구매확인서를 근거로 해서 영세율 세금계산서를 발행하면 돼요.

**💡 구매확인서 발급 기한에 따라 달라지는 세금계산서 발급 방법**

① 재화나 용역을 공급하고 **다음달 10일까지 구매확인서**를 발급한 경우

→ **영세율** 세금계산서 발행 (작성일자 = 공급일자)

② 상반기 공급분은 7월 25일까지, 하반기 공급분은 다음해 1월 25일까지 구매확인서를 발급한 경우

→ 일반 세금계산서 발행 - 구매확인서 발급 - 영세율 세금계산서로 수정 발행

③ 상반기 공급분은 7월 25일까지, 하반기 공급분은 다음해 1월 25일까지 **구매확인서를 발급하지 않은 경우**

→ 영세율이 인정되지 않으므로 **수정세금계산서 발행**❌
