# 부가가치세 매출 내역 조회 방법 (큐텐/Qoo10)

**💡 큐텐(Qoo10) 매출 내역 조회하는 방법**

[큐텐 판매자 페이지 가기](https://qsm.qoo10.jp/GMKT.INC.Gsm.Web/login.aspx)

큐텐 판매자 페이지에 로그인 후 **[정산관리] - [판매정산내역]** 메뉴로 들어가주세요.

홈페이지가 외국어로 나온다면 왼쪽 위에서 언어를 한국어로 설정해주세요.

검색 조건은 **구매자 결제일**로 설정하고, **조회 기간**과 **결제 통화** 종류를 선택하신 뒤 **[검색]**을 눌러주시면 합계 내역이 나와요.

이 화면을 금액과 항목이 잘 보이게 캡처해서 저장해주세요.

* 개인사업자 간이과세자는 1월 1일~12월 31일
* 개인사업자 일반과세자는 1월 1일~6월 30일 또는 7월 1일~12월 31일

![618715b2691a5.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/618715b2691a5.png)

정산 대금 옆의 **[상세조회]**를 누르면 아래에 정산 예정/완료 내역이 나와요.

조회 내역 오른쪽의 **[Excel]** 버튼을 눌러 **엑셀 파일을 저장**해주세요.

![a1e6106cb67ff.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/a1e6106cb67ff.png)

큐텐에서 큐익스프레스를 이용하신다면 배송 자료도 조회하실 수 있어요.

**[배송/취소/미수취] - [집하센터 배송]** 메뉴로 들어가주세요.

상단에서 **[영세율 증빙(한국발 해외배송)]** 탭을 누르고, 주문 국가와 조회할 분기를 선택해주세요.

오른쪽 **[조회]**를 눌러 아래에 내역이 나오면 **[Excel]** 버튼을 눌러 파일을 저장해주세요.

조회할 분기는 판매 내역 조회 기간과 동일하게 설정해주시면 돼요.

![7d15d1811d708.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/7d15d1811d708.png)

위 화면에서 분기 선택란 위의 **[해외배송 증빙]**을 클릭하면 해외배송 소포 수령증을 저장하실 수 있어요.

여기까지 하시면 큐텐 부가세 자료 준비는 끝! 🙆🏻‍♀️
