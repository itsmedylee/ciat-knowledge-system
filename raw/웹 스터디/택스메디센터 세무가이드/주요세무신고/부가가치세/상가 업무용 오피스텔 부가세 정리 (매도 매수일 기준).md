# 상가/ 업무용 오피스텔 : 부가세 정리 (매도/매수일 기준)

상가, 업무용 오피스텔을 **임대사업자 등록**하여 임대하다가 매도하는 경우 부가세에 대해 알아보겠습니다.

아래 내용은 **매도자**와 **매수자** 모두 **일반사업자**임을 가정하였습니다.

|  |  |  |
| --- | --- | --- |
| 구분 | 매도자 | 매수자 |
| 일반적인 경우 | ① 건물분 부가세 신고 및 납부 잔금일에 폐업 | ② 건물분 부가세 지급 일반임대사업자등록하여 건물분 부가세 환급 |
| 사업의 포괄양수도 | ③ 건물분 부가세 발생X, 잔금일에 폐업 | ④ 매도인과 동일한 업종으로 사업자등록 |

① 일반적인 경우 - 매도자

* **건물분 부가세 신고 및 납부** : 건물가액의 10%에 해당하는 부가세만큼 세금계산서도 발행하고, 신고도 하여야 합니다.
* **폐업** : 해당 상가/오피스텔을 양도함으로써 임대업이 종료되므로 잔금일에 폐업하고, 관련 신고를 진행하여야 합니다.

② 일반적인 경우 - 매수자

* **건물분 부가세 지급** : 건물가액의 10%에 해당하는 부가세를 매도자에게 지급하여야 합니다.
* **환급** : 임대업을 등록하거나 자기 사업에 사용하는 경우 부가세를 환급받을 수 있습니다.

③ 사업의 포괄양수도 - 매도자

* **부가세 문제 X** : 매도자와 매수자가 사업 관련한 권리와 의무를 포괄적으로 양수도한다면 부가세 문제가 발생하지않습니다.
* **폐업** : 해당 상가/오피스텔을 양도함으로써 임대업이 종료되므로 잔금일에 폐업하고, 관련 신고를 진행하여야 합니다.

④  사업의 포괄양수도 - 매수자

* **사업자등록** : 매도자와 동일한 업종으로 사업자등록을 하고, 사업을 영위하여야 합니다.

위 내용은 매도자와 매수자 모두 일반사업자일 때의 내용입니다.

면세사업자인 경우에는 위 내용이 적용되지 않을 수 있으니 전문가와 상의 후 진행하시길 바랍니다.
