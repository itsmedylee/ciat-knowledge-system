# 홈택스 수정세금계산서 발급 예시 - 공급가액을 수정할 때

공급가액을 착각해서 세금계산서를 잘못 발행했을 때, 홈택스에서 수정세금계산서 발급하는 방법을 알려드릴게요.

[홈택스 바로 가기](https://hometax.go.kr/)

홈택스 로그인 후 **[계산서·영수증·카드] - [전자(세금)계산서 발급] - [전자(세금)계산서 수정발급]** 메뉴로 들어가주세요.

승인번호로 조회하셔도 되고, **[세금계산서 조회하기]** 버튼을 눌러서 조회하실 수도 있어요.

![43a7d26e6411e.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/43a7d26e6411e.png)

![4b3cb8a03273f.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/4b3cb8a03273f.png)

작성일자 등을 설정하고 **[조회하기]**를 누르면 해당되는 전자세금계산서 목록이 나와요.

그중에서 수정하시려는 세금계산서를 선택하고 **[수정세금계산서발급]**을 눌러주세요.

![6c320711ddc37.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/6c320711ddc37.png)

해당하는 수정 발급 사유를 확인하고 **[발급하기]**를 눌러주세요.

지금은 공급가액 수정을 예로 들었기 때문에 **기재사항 착오 정정 등**을 선택했어요.

수정세금계산서를 발급할 때는 오른쪽 안내를 보시고 **부가가치세 수정 신고가 필요한 경우인지** 꼭 확인해주세요.

![5753a740b655e.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/5753a740b655e.png)

화면을 아래로 내려서 **당초에 잘못 기재했던 부분을 올바르게 수정**해주세요.

공급가액을 수정할 때는 금액이 기재된 칸 옆의 **[계산]**을 누르면 아래와 같은 창이 떠요.

합계 칸에 **부가가치세를 포함한 금액**을 입력하고 다시 한번 **[계산]**을 누르면 공급가액과 세액이 자동으로 구분되니, 금액이 맞는지 보신 후 **[확인]**을 눌러주세요.

화면 아래 **[발급하기]**를 누르면 수정세금계산서를 발급하실 수 있어요 🙂
