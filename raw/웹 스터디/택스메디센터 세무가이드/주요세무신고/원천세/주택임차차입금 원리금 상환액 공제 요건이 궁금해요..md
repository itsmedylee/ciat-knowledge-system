# 주택임차차입금 원리금 상환액 공제 요건이 궁금해요.

주택임차차입금 원리금 상환액 공제를 받으려면 기본적으로 아래의 요건을 만족해야 해요.

|  |
| --- |
| * 근로소득이 있는 거주자일 것 * 공제를 받으려는 해 12월 31일 기준 무주택 세대주일 것 * 국민주택규모 이하의 주택일 것 (주거용 오피스텔 포함) |

세대주가 주택 관련 소득공제를 받지 않았다면 세대원이 공제를 받는 것도 가능해요.

국민주택규모 이하란 주거전용면적 85㎡ 이하를 말해요.

이때 수도권을 제외한 도시 지역이 아닌 읍·면 지역은 100㎡ 이하를 기준으로 해요.

**💡 얼마까지 공제받을 수 있나요?**

공제 금액은 **원리금 상환액의 40%**이고 **연간 400만 원 한도**로 공제받을 수 있어요.

연간 한도는 주택마련저축 납입액 공제 금액과 합산한 금액을 말해요.

주택임차자금을 누구에게서 빌렸느냐에 따라서도 특정 요건을 만족해야 공제를 받을 수 있어요.

* **은행 등 대출기관에서 빌린 경우**

임대차계약서상 입주일과 등본상 전입일 중 빠른 날로부터 **전후 3개월 이내**에 빌린 돈이어야 해요.

빌린 돈은 **대출기관에서 임대인 계좌로 직접 입금**되어야 해요.

* **대부업 등을 경영하지 않는 거주자에게서 빌린 경우**

임대차계약서상 입주일과 등본상 전입일 중 빠른 날로부터 **전후 1개월 이내**에 빌린 돈이어야 해요.

총급여액이 5,000만 원 이하여야 하고, 연 이자율이 2.9%보다 낮지 않아야 해요.

[소득세법시행규칙 제57조 (주택임차자금 차입금의 이자율)](https://www.law.go.kr/%EB%B2%95%EB%A0%B9/%EC%86%8C%EB%93%9D%EC%84%B8%EB%B2%95%EC%8B%9C%ED%96%89%EA%B7%9C%EC%B9%99/(20220101,00848,20210316)/%EC%A0%9C57%EC%A1%B0)

🚨 신용대출 등을 통해 빌린 돈은 소득공제 대상 차입금이 아닙니다.
