# 장기주택저당차입금 이자 상환액 공제 요건이 궁금해요.

![b8e3a4d61703f.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/b8e3a4d61703f.jpg)

장기주택저당차입금 이자 상환액 공제를 받으려면 아래의 요건을 모두 만족해야 해요.

|  |
| --- |
| * 근로소득이 있는 거주자 * 12월 31일 기준 무주택 또는 1주택 세대주 * 취득 당시 주택 기준시가 5억 원 이하  <세법개정으로 2024.1.1.이후 취득하는 분부터 5억원 → 6억원으로 상향> * 해당 주택에 저당권 설정하고 금융회사 또는 주택도시기금으로부터 차입했을 것 * 주택소유권이전등기 또는 보존등기일로부터 **3개월 이내에 차입**했을 것 * 장기주택저당차입금의 채무자가 저당권 설정된 해당 주택의 소유자일 것 * 차입금 상환 기간이 15년 또는 10년 이상일 것 |

세대주가 주택 관련 공제를 받지 않는다면 실제 거주하는 세대원이 공제를 받을 수 있어요.

공제를 신청할 때는 아래의 서류를 준비해주세요.

* 주택자금 상환 등 증명서
* 장기주택저당차입금 이자 상환 증명서
* 주민등록등본
* 주택 가격을 확인할 수 있는 서류

**🚨 유의사항**

주택 명의자와 차입금 명의자가 각각 근로자와 배우자로 상이하다면 공제받을 수 없어요.

주택이 근로자 단독 또는 공동 명의이고 차입금이 공동 명의일 때는 **근로자 채무 부담 부분에 해당하는 이자 상환액**을 공제받을 수 있어요.

[소득세법 제52조](https://www.law.go.kr/%EB%B2%95%EB%A0%B9/%EC%86%8C%EB%93%9D%EC%84%B8%EB%B2%95/(20220218,18425,20210817)/%EC%A0%9C52%EC%A1%B0)
