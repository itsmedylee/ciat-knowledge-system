# 프리랜서 사업소득 3.3% 어떻게 신고하나요? (사업주 입장)

![96eaf7bba96d0.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/96eaf7bba96d0.jpg)

프리랜서를 어쩌다 한번 고용할 때 인건비 신고 방법을 몰라서 난처해하시는 분이 많아요.

오늘은 **프리랜서에게 인건비를 지급할 때 소득세 계산하는 방법, 사업소득 원천세 신고하는 방법**을 간단히 알려드릴게요.

**💡 사업소득 3.3% 세금은 어떻게 계산하나요?**

계약 당시의 세전 금액을 기준으로 소득세 3%, 지방소득세는 소득세의 10%를 원천징수하시면 되고, 이때 원 단위는 절사해요.

예를 들어, 사업소득 세전 금액을 100만 원으로 계약하셨다면 세금 및 실제 지급액은 아래와 같아요.

**소득세**는 세후 금액(실제 지급액)이 아니라 **세전 금액을 기준으로 계산**한다는 것을 꼭 기억하세요!

|  |
| --- |
| 소득세 : 100만 원 x 3% = 3만 원  지방소득세 : 3만 원 x 10% = 3천 원  프리랜서에게 실제 지급할 금액 : 100만 원 - 소득세 3만 원 - 지방소득세 3천 원 = 96만 7천 원 |

**💡 사업주인 제가 신고해야 할 세금은 어떤 게 있나요?**

|  |
| --- |
| * **원천세 신고 및 납부** - 소득 지급일의 다음달 10일까지 * **사업소득 간이지급명세서 제출** - 소득 지급일의 다음달 말일까지 * **거주자의사업소득 지급명세서 제출** - 소득 지급 후 다음해 3월 10일까지 |

소득세는 홈택스 **[신고/납부] - [세금신고] - [원천세]** 메뉴에서 신고하실 수 있고, 지방소득세는 위택스에서 신고 및 납부하실 수 있어요.
