# 직원 급여는 근로소득과 사업소득 중 어느 쪽으로 신고하는 게 유리한가요?

![ae31cf2de31d8.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/ae31cf2de31d8.jpg)

인건비는 원칙적으로 **근로자의 실제 근무 형태에 따라 소득을 구분해서 신고**해야 해요.

|  |
| --- |
| 4대보험 가입하는 근로자(정직원)의 급여 → **근로소득**  프리랜서 등 세금을 3.3% 떼고 지급하는 경우 → **사업소득** |

직원의 급여를 근로소득으로 신고할 경우와 사업소득으로 신고할 경우의 특징은 아래 표를 참고해주세요.

|  |  |  |
| --- | --- | --- |
|  | **근로소득으로 신고 시** | **사업소득으로 신고 시** |
| **소득세 원천징수** | 소득 구간별 **간이세액표에 따라 소득세 발생** | 사업소득 총액에서 소득세 및 지방소득세 약 3.3% 발생 (소득세는 사업소득의 3%, 지방소득세는 소득세의 10%) |
| **사회보험료(4대보험)** | **사업주**가 근로자의 국민연금, 건강보험료, 고용보험료 **일부** 및 산재보험료 **전액**을 부담함 | **근로자**가 자신의 국민연금, 건강보험료를 **전액** 부담함 |
| **소득 신고** | 회사에서 근로자의 전년도 소득을 파악하여 **매년 2월경 연말정산** → 사업소득 등 연말정산 시 합산하지 않은 다른 소득이 있을 경우 **근로자가 추가로 5월에 종합소득세 신고** | 근로자가 자신의 전년도 소득을 합산해 **매년 5월에 종합소득세 신고** |
| **지원금** | 두루누리 지원금 등 **사회보험료 혜택 있음** 그 외 **고용 관련 각종 세액공제 가능** |  |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃
