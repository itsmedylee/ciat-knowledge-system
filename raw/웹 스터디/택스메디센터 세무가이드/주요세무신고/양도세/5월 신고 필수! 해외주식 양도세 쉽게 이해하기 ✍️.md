# 5월 신고 필수! 해외주식 양도세 쉽게 이해하기 ✍️

**🌟 해외주식 양도세 신고는 언제 해야 하나요?**

해외주식의 양도세는 다음 해 5월 1일부터 31일까지 신고합니다. 예를 들어, 2024년에 해외주식을 매도했다면 2025년 5월에 신고하시면 됩니다. 

**1️⃣ 해외에서 납부한 세금? 국내 양도세에서 차감 가능!**

혹시 해외에서 세금을 이미 납부하셨나요? 그렇다면 다행입니다!  
외국납부세액 공제(해외에서 낸 세금을 국내 세금에서 빼주는 제도)를 활용하면 해당 금액을 국내 양도세에서 차감할 수 있어요.   
 단, 세금 납부 증빙자료를 꼼꼼히 준비해야 합니다. 

**2️⃣ 국내주식 양도손익과 통산 가능**

국내 주식에서 손실이 발생했다면, 이를 해외주식 양도소득과 합산(통산)하여 세금을 줄일 수 있어요.  
예를 들어:

|  |  |
| --- | --- |
| 구분 | 수익 / 손실 (예시) |
| 해외주식 수익 | + 500만원 |
| 국내주식 손실 | - 300만원 |
| 합산 결과 | + 200만원 |

👉 이렇게 통산한 결과로 더 낮은 금액에 대해 양도세를 내게 됩니다. 👍

**3️⃣ 기본공제 250만 원 활용!**

양도소득세 기본공제라고 들어보셨나요?  
이는 양도소득이 발생한 경우, 250만 원까지 비과세하는 제도입니다.  
하지만 기본공제는 1번만 적용된다는 점 기억하세요! 해외주식과 국내주식을 합산 신고하더라도 총 공제금액은 250만 원입니다.

**4️⃣ 신고가 어렵다면? 전문가 도움 받으세요! 🤔**

처음이라면 양도세 신고가 복잡하게 느껴질 수 있습니다.  
🔍 정확한 계산부터 효과적인 세금 절감 방법까지 제대로 준비하고 싶다면, 세무사와 상담하는 것도 좋은 방법이에요.
