# 토지와 건물을 함께 양도하여 구분이 불분명한 경우 어떻게 산정하나요?

💡 토지와 건물을 함께 양도하여 전체 실지거래가액은 확인이 되나 자산별로 구분이 불분명한 경우\*에는 취득 또는 양도 당시의 시가를 순차적으로 적용한 가액으로 안분계산합니다.

1. 감정가액

2. 기준시가  [조회하기](https://www.hometax.go.kr/websquare/websquare.wq?w2xPath=/ui/pp/index_pp.xml&tmIdx=17&tm2lIdx=1701000000&tm3lIdx=)

3. 장부가액

4. 취득시가

\*납세자가 구분하여 신고한 가액이 기준시가에 따른 안분가액과 30% 이상 차이가 나는 경우는

토지와 건물 등의 가액 구분이 불분명한 경우로 봅니다.

**💡 사례**

* 취득 시 : 실지거래가액 6억원, 토지 기준시가 2억원, 건물 기준시가 1억원
* 양도 시 : 실지거래가액 10억원, 토지 기준시가 3억원, 건물 기준시가 2억원

|  |  |  |
| --- | --- | --- |
|  | 토지 | 건물 |
| 양도가액 | 10억 × 3억/(3억+2억) | 10억 × 2억/(3억+2억) |
| 취득가액 | 6억 × 2억/(2억+1억) | 6억 × 2억/(2억+1억) |
