# 상생임대주택 요건 충족한 이후에도 임대료 5%를 준수해야 하나요?

> 주택 취득 당시 조정대상지역에 위치하였다면, 2년 거주까지 하여야 1주택 비과세를 받을 수 있습니다.

[1주택 비과세 요건 확인하기](https://guide.taxmedicenter.com/37/?idx=24550762&bmode=view)

> 그런데 계속 임대 중이어서 2년 이상 거주를 하기 힘든 경우, 상생임대주택을 통해서 2년 거주하지 않더라도 1주택 비과세를 받을 수 있습니다.   [상생임대주택 Q&A 바로 가기](https://guide.taxmedicenter.com/37/?bmode=view&idx=19524856&back_url=&t=board&page=1)

|  |
| --- |
| **상생임대주택 요건**    * 직전임대차계약의 임대 기간이 1년 6개월 이상일 것 * 상생임대차계약의 임대 기간이 2년 이상일 것 * 상생임대차계약을 2021.12.20 ~ 2024.12.31 내에 체결하고 임대할 것 * 직전 임대차계약에서 임대료 증가율 5% 이내로 상생임대차계약을 체결할 것 |

> **직전임대차계약, 상생임대차계약 요건을 모두 충족한 이후, 다음에 체결하는 임대차계약도 계약기간 및 5%를 준수해야할까요?**

그렇지 않습니다. 이후에는 상생임대주택 요건을 계속 준수하지 않아도 괜찮습니다. 

해당 주택 양도 시 직전임대차계약서와 상생임대차계약서를 첨부하여 상생임대주택 특례적용신고서를 제출하시면 됩니다.
