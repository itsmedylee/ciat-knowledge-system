# 공동사업자의 사업자등록(정정) 시 필요 서류에는 어떤 것이 있을까요?

**공동사업자 사업자 등록** 또는 **공동사업자 사업자 등록 정정**에 필요한 서류를 알려드릴게요 💁🏻‍♀️

|  |
| --- |
| * **공동사업약정서** 인적사항, 손익 분배 비율을 명시하고 동업자의 인감을 날인한 것 * **대표자 전원의 인감증명서** 동업자가 함께 세무서에 방문할 때는 인감증명서 제외 * **대표자 전원의 신분증** * **임대차 계약서** 공동사업자 전원의 이름으로 계약된 것 * **기존 사업자등록증** (사업자 등록 정정인 경우) |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃

대표 공동사업자란 **공동사업자 중 선임된 사람**을 말하고, 선임된 대표자가 없을 때는 **손익 분배 비율이 가장 큰 사람**을 말해요.

손익 분배 비율이 같을 때는 사업장 소재지 관할 세무서장이 결정하게 돼요.
