# 근로 기간에만 공제되는 항목은? (연말정산, 종합소득세)

![cc50cdb422e32.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/cc50cdb422e32.jpg)

연말정산 또는 종합소득세 신고를 준비하실 때 많이 헷갈려하시는 것 중 하나가 바로 **근로 제공 기간에 따른 공제 여부**예요.

근로 기간을 따져봐야 하는 대표적인 항목과 그렇지 않은 항목을 정리해봤어요 ☺️

**✅ 1년 치 금액을 모두 반영해도 되는 항목**

|  |
| --- |
| * 연금보험료 (국민연금 등 공적연금 근로자 부담금) * 개인연금저축 납입액 * 퇴직연금·연금저축 납입액 * 소기업·소상공인 공제부금 납입액 * 투자조합출자 등 투자 금액 * 기부금 |

**✅ 근로 기간을 따져야 하는 항목**

입사한 달부터 퇴사한 달까지, 실제 근로 기간을 따져서 반영해야 하는 항목이에요.

[중도입퇴사자 근로 기간 설정하기](http://guide.taxmedicenter.com/30/?idx=9358691&bmode=view)

|  |
| --- |
| * 주택자금공제 주택 임차 차입금 원리금 상환액 장기 주택 저당 차입금 이자 상환액 * 신용카드 등 사용금액 * 보장성보험료 * 의료비 * 교육비 * 주택청약종합저축 납입액 * 월세 납입액 |

**💡 휴직 기간도 제외해야 하나요?**

재직 중 잠시 휴직하는 기간은 근로 제공 기간으로 봐요.

그러나 퇴사 후 재취업할 때처럼 이직을 위한 공백기는 근로 기간으로 보지 않으니 제외해주세요.

**🚨 주의사항**

위 내용은 **근로 제공 기간**이라는 기준만으로 판단한 것이므로 **세부 공제 요건은 소득자 본인이 확인**하셔야 해요.

[공제 여부 체크리스트](https://call.nts.go.kr/call/cm/cntnts/cntntsView.do?mi=2764&cntntsId=7042#)
