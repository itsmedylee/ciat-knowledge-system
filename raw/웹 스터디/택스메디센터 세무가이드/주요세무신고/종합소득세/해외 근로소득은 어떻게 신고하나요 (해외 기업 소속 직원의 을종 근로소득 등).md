# 해외 근로소득은 어떻게 신고하나요? (해외 기업 소속 직원의 을종 근로소득 등)

![5516a89170e1e.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/5516a89170e1e.jpg)

**💡 외국 기업 소속 근로자의 소득은 세금 신고를 어떻게 하나요?**

근로자가 외국 기업에 소속되어 급여를 받을 때는 세금 신고를 어떻게 해야 할까요?

우선 근로자가 거주자인지 비거주자인지에 따라 달라져요.

|  |  |
| --- | --- |
| **거주자** | 국내소득, 국외소득 모두 한국에서 세금 신고 필요 |
| **비거주자** | 한국에서 발생한 소득만 한국에서 세금 신고 필요 |

[거주자, 비거주자 판단 기준은?](https://guide.taxmedicenter.com/32/?idx=11766400&bmode=view)

거주자일 경우 국내에서 발생한 소득은 물론이고 국외에서 발생한 소득까지 모두 한국에서 세금 신고 및 납부를 해요.

해외 기업 등에 소속되어 원천징수를 하지 않은 근로소득이 발생했다면 **을종 근로소득**으로서 한국에 신고하게 돼요.

현지에서도 세금 신고를 한다면 두 개 이상의 국가에 세금을 중복해서 내는 일이 없도록 외국납부세액 공제를 적용해서 세금을 정산하는 과정을 거쳐요.

을종 근로소득을 한국에서 신고할 때는 납세조합을 통해 진행하는 방법도 있지만, 모든 근로자가 납세조합에 가입하지는 않기 때문에 **세무대리인을 통해 종합소득세 신고 기간인 5월에 신고 및 납부**하는 경우가 많아요.

**💡 을종 근로소득은 꼭 신고해야 하나요?**

다른 소득과 마찬가지로 을종 근로소득도 제때 신고 및 납부하지 않으면 무신고 가산세, 납부 불성실 가산세가 부과돼요.
