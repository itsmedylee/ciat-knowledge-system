# 소득공제 자료는 이렇게 준비하세요!

국세청 홈택스에 **공동인증서 로그인** 후 왼쪽 상단**[**나의**홈택스]**를 눌러주세요.

**[**나의**소득·연말정산] - [연말정산 소득·세액공제 자료 조회]**를 눌러주세요.

![74d4ad40727e4.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/74d4ad40727e4.png)

부양가족의 자료를 함께 받을 때는 자료 제공 동의가 필요해요.

**[장려금·연말정산·기부금] - [연말정산간소화] - [부양가족 자료제공동의 신청/조회/취소]**를 눌러주세요.

![32a457f2a1f2a.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/32a457f2a1f2a.png)

**[부양가족 자료제공 동의 신청/조회/취소]**아래의 **[신청하기]** 버튼을 눌러주세요.  
**[본인인증 신청]**또는**[미성년자녀 신청]** 중 해당 탭을 클릭해주세요.

본인 인증 신청은 자료 제공자(부양가족) 명의의 공동인증서(구 공인인증서), 신용카드, 아이핀, 휴대전화가 있으면 가능해요.

미성년 자녀 신청은 조회하는 부모의 공동인증서로 신청할 수 있어요.

본인인증수단이 없다면 온라인 신청, 팩스 신청, 세무서 방문 신청을 하실 수 있어요.

![5767882010172.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/5767882010172.png)

연말정산 간소화 자료 조회 화면으로 돌아와서 자료를 받아주세요.

귀속년도와 해당 월을 선택하고 건강보험부터 기부금까지 각 항목을 클릭해서 금액이 나오는지 확인해주세요.

모두 확인하셨다면 **[내려받기]** 버튼을 눌러주세요.

이때 **정규직 근로자로 근무했던 월만 체크**하셔야 한다는 점에 주의하세요!

예를 들어 8월부터 12월까지 근로소득이 있었다면 8월~12월만 체크해주세요.

![1259677d1c399.png](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/1259677d1c399.png)

**[소득·세액 공제 자료 내려받기]** 창 하단의**[PDF로 내려받기]**를 클릭해주세요.

저장하신 후 **파일명 수정하지 말고** 제출해주세요!
