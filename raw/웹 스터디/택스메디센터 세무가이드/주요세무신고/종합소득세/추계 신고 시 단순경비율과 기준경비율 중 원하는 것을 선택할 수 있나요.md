# 추계 신고 시 단순경비율과 기준경비율 중 원하는 것을 선택할 수 있나요?

![a03244f007249.png](https://cdn.imweb.me/upload/S201701195880299bc5f37/a03244f007249.png)

**💡 단순경비율과 기준경비율 중 원하는 것을 선택할 수 있나요?**

종합소득세 신고 안내문에서 확인할 수 있는 **기장 의무와 추계 신고 시 적용 경비율**에 따라 선택지가 달라져요.

관련 내용은 아래 표를 참고해주세요 😊

|  |  |  |
| --- | --- | --- |
| **기장 의무** | **추계 시 적용 경비율** | **신고 옵션** |
| **간편장부대상자** | 단순경비율 | 단순경비율, 기준경비율, 장부 신고 중  선택 가능 |
| 기준경비율 | 기준경비율, 장부 신고 중 선택 가능 단순경비율로 신고 불가 |
| **복식부기의무자** | 기준경비율, **복식** 장부 신고 중 선택 가능 단순경비율로 신고 불가 |

* **간편장부대상자**

간편장부대상자가 **복식장부**를 작성해서 신고한다면 **기장세액공제**를 받아서 세금을 줄일 수 있어요.

장부를 작성하지 않고 **추계신고**를 한다면 **무기장 가산세**가 부과돼요. 단, 소규모 사업자라면 가산세가 부과되지 않아요.

* **복식부기의무자**

복식부기의무자가 **간편장부**를 작성해서 신고한다면 **무기장 가산세**가 부과돼요.

장부를 작성하지 않고 **추계신고**를 한다면 무신고로 간주하여 감면 혜택을 받을 수 없고, **무신고 가산세와 무기장 가산세 중 큰 금액이 가산세로 부과**돼요.
