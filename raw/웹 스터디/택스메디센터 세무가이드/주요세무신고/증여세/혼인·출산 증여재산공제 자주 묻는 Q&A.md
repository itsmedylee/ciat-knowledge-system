# 혼인·출산 증여재산공제 자주 묻는 Q&A

요건 및 공제액 확인하기  👉[혼인출산 증여 공제가 무엇인가요?](https://guide.taxmedicenter.com/22/?idx=19316408&bmode=view)

**1. 아이를 낳을 때마다 1억원씩 공제받을 수 있나요?**

|  |
| --- |
| 🙅‍♀️ 첫째를 출산한 거주자가 이미 1억원을 공제받았다면, 둘째를 출산하더라도 추가로 1억원을 공제 받을 수 없습니다. 다만, 첫째 출산 시 6천만원만 공제받았다면, 둘째 출산 시 4천만원까지 공제 받을 수 있습니다. |

**2. 비거주자인 자녀도 혼인출산 증여 공제가 가능한가요?**

|  |
| --- |
| 🙅‍♀️ 국내 거주자만 공제 가능합니다. |

**3. 2022년 혼인 신고한 자도 공제 받을 수 있나요?**

|  |
| --- |
| 2022년 혼인 신고 후 아직 2년이 경과하지 않았고, 2024.1.1. 이후 증여를 받게 되면 적용 가능합니다. 예를 들어 2022.10.10. 혼인 신고한 자가 2024.1.1. ~ 2024.10.10. 사이에 직계존속으로부터 증여를 받게 되면 혼인·출산 증여재산공제 적용이 가능합니다. |

**4. 결혼할 때 1억원 공제를 받았는데, 아이 출산 후 1억원을 추가로 받을 수 있나요?**

|  |
| --- |
| 🙅‍♀️ 혼인·출산 공제는 모두 합하여 1억원까지 공제 가능합니다. 혼인 시 1억원의 공제를 받았다면, 아이 출산 시 1억원을 추가로 받을 수 없습니다. 다만, 요건이 충족되어 혼인 시 6천만원을 공제 받았다면, 출산 시 4천만원까지 공제 받을 수 있습니다. |
