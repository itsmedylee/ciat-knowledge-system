# 자녀에게 상가 증여? 부가세와 이월과세를 잊지 마세요!

**📌 상가를 자녀에게 증여할 때 부가세 알아보기**

* **부담부증여란 무엇인가요?** 부담부증여는 증여받는 사람이 일정한 부채나 부담을 함께 떠안는 증여를 뜻합니다. 예를 들어 상가를 자녀에게 물려주면서 해당 상가에 대한 임대업(세입자에게 월세 받기)을 그대로 지속하도록 넘기는 것을 의미합니다. (참고: 증여에는 단순증여와 부담부증여 두 가지가 있습니다. 부담부증여는 세금 계산식에도 차이가 있답니다!)

* 부동산 증여는 단순히 "주고 끝나는 일"이 아닙니다! 특히 자녀에게 상가를 물려줄 때, 부가세를 검토해야 합니다.

자, 여기서 중요한 점은 받을 상가 건물을 자녀가 어떤 용도로 활용하느냐인데요. ✅ 정리해볼까요?

|  |  |
| --- | --- |
| 자녀의 상가 활용 | 세금계산서 발행 여부 |
| 임대업(부모님의 임대업 승계) | ❌ 발행하지 않아도 됩니다 |
| 다른 업종 영위(예: 음식점, 도소매업 등) | ✅ 발행해야 합니다 |

 

👉 결론: 자녀가 기존 임대업을 "승계"하면 건물분 부가세에 대한 세금계산서를 발행하지 않아도 되지만, 새로운 업종을 시작할 경우 세금계산서를 발행해야 합니다!

---

**📌 이월과세란, 그리고 주의 포인트는?**

이월과세는 증여 후 부동산 양도로 발생하는 양도소득세 문제를 다룬 규정입니다.

 특히, 자녀에게 부동산을 증여한 뒤 10년 내에 해당 부동산을 자녀가 처분하면 이 규정이 적용됩니다.

**양도세 계산 방법:**

1️⃣ 증여받은 시점의 취득가액 기준 양도세 계산 : 이 방법은 증여받을 당시 금액을 기준으로 양도세를 계산합니다.

2️⃣ 부모님의 취득가액 기준으로 계산하는 양도세 : 즉, 자녀가 받은 부동산의 원래 부모님의 취득가액으로 양도세를 계산합니다.

👉 여기서 둘 중 더 큰 금액을 선택하여 세금을 납부해야 해요! 왜냐면 국가는 증여 후 단기적으로 "차익 실현"을 통해 세금을 줄이는 것을 방지하려 하기 때문이죠.

**💡 예제 상황으로 쉽게 이해하기**

✅ 사례: 부모님이 2005년에 1억원에 매입한 빌딩을 2025년, 자녀에게 증여했어요. 동시에, 자녀는 2027년에 이 부동산을 3억원에 매각합니다.

 증여 당시(2025년)의 평가금액은 2억원이었고, 2027년에 3억원에 팔렸습니다.

|  |  |
| --- | --- |
| 양도세 계산 방법 | 결론 |
| 1️⃣증여가액 2억 기준 양도세 계산 | 이월과세 적용 →  둘 중 더 큰 양도세로 납부 |
| 2️⃣부모님 취득가액 1억 기준 양도세 계산 |

✨ 이러한 혜택을 놓치지 않기 위해, 전문가와 충분히 상담한 후 증여 및 매각을 진행하세요.
