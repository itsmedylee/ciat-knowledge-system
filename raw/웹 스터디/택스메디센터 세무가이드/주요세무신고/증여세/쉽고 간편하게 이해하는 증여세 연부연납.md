# 쉽고 간편하게 이해하는 증여세 연부연납

**🤔 증여세 연부연납, 그것이 무엇인가요?**

고액의 증여세를 한꺼번에 내기 부담스럽다면 연부연납 제도를 활용할 수 있어요! 

간단히 말해, 증여세를 최대 5년간 나눠서 납부할 수 있는 제도입니다. 😃

**📈 증여세 연부연납의 이자율은?**

연부연납을 신청하면 일정한 이자가 붙습니다. 2026년 기준, 연부연납 이자율은 연 3.1%입니다. 

연부연납 신청 전에 이자 포함 총 납부 금액을 미리 계산해보는 것이 좋아요.

**📊 담보 제공 필수**

연부연납을 신청하려면 반드시 담보를 제공해야 합니다. 

|  |  |  |
| --- | --- | --- |
| 구분 | 부동산 담보 제공 | 납세보증보험 가입 |
| 의미 | 본인 또는 타인 명의 부동산을 담보로 제공 | 납세보증보험에 가입하여 세금을 납부할 수 있도록 보증 |
| 비용 | 담보 설정에 따른 등기 비용 타인명의 부동산인 경우 국민주택채권 매입비용 | 보증보험료 |
| 장점 | 부대비용 적음 | \* 부동산 처분 자유로움 \* 임차인 구하는 데 제약이 없음 \* 세무서 승인 불필요 |
| 단점 | \* 부동산 처분에 제약이 생김 \* 등기부등본 상 담보 설정으로 인해 임차인을 구하기 어려울 수 있음 \* 세무서 승인이 필요 | 부대비용 큼 |
| 특이사항 | 건물인 경우 화재보험 가입 필수 | 개별 상황에 따라 납세보증보험 가입이 어려울 수 있음 |

**💡 증여세 연부연납은 이렇게 진행됩니다!**

1. 신청 요건 확인 : 증여세 납부세액이 2천만원을 초과할 것

2. 연부연납 신청 & 담보 제공 : 세무서에 증여세 신고서와 함께 연부연납 신청서, 납세담보 제공서 제출

3. 세무서 승인

4. 매년 분할 납부

**💵 납부 방법**

1. 증여세 신고하는 첫 해는 직접 납부

2. 그 다음해부터는 세무서에서 고지서 발송. 납부기한 내 고지서 발송이 누락된 경우 세무서에 직접 연락하여 고지서 요청
