# 자녀가 창업할 예정인데, 증여세 없이 현금을 증여할 방법이 없을까요?

다음 특례를 이용할 경우에는 현금 5억원까지는 자녀에게 증여할 때 납부할 세금이 없습니다. 

<창업자금에 대한 증여세 과세특례>

|  |  |  |
| --- | --- | --- |
| 구분 | 내용 | |
| 대상 | 60세 이상의 부모가 18세 이상의 자녀(거주자)에게 창업할 목적으로 창업 자금을 증여하는 경우 | |
| 요건 | 1. 창업중소기업 세액감면 해당 업종을 창업할 것 2. 양도소득세 과세대상이 아닌 재산을 증여할 것 (예. 현금) 3. 증여받은 날로부터 2년 이내에 창업할 것 4. 실질적인 창업에 해당할 것 5. 증여받은 날부터 4년이 되는 날까지 창업자금을 모두 해당 목적에 사용할 것 | |
| 내용 | 5억원까지는 납부할 증여세X 5억원 초과하는 금액에 대해서는 10%의 증여세 납부 | |
| 추징 | 사유 | 금액 |
| ① 2년 이내에 창업하지 않은 경우 | 창업자금 전액 |
| ② 창업자금으로 대상이 아닌 업종을 영위하는 경우 | 타업종에 쓰인 금액 |
| ③ 증여받은 날부터 4년이 되는 날까지 창업 목적에 사용하지 않은 경우 | 창업 목적에 사용되지 아니한 금액 |
| ④ 증여받은 날부터 10년 이내에 창업자금을 타용도로 사용한 경우 | 타용도로 사용된 창업자금 |
| ⑤ 창업 후 10년 이내에 수증자가 사망하거나 사업을 휴·폐업하는 경우 | 창업자금과 이로 인한 가치 증가분 |
| ⑥ 증여받은 창업자금이 50억원을 초과하는 경우      & 5년 이내에 근로자수가 감소한 경우 | 50억원을 초과하는 창업자금 |

**⭐주의사항⭐**

1. 법에 나열된 업종에 대해서만 적용 가능하므로 업종 확인이 필요합니다. [업종 확인하기(클릭)](https://guide.taxmedicenter.com/22/?idx=11971185&bmode=view)

2. 토지, 건물은 양도소득세가 과세되는 재산으로 증여세 특례를 받을 수 없습니다.  [양도소득세 과세대상 자산 확인하기(클릭)](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2308&cntntsId=7707)

     증여하고자하는 재산이 증여세 특례를 받을 수 있는지 확인해야 합니다.

3. 실질적인 창업으로 보지 않는 대표적인 예시는 다음과 같습니다.

    ①  사업의 양수 등을 통하여 종전의 사업을 승계하는 경우

    ②  개인 사업을 법인으로 전환하여 새로운 법인을 설립한 경우 

    ③  폐업 후 동일한 종류의 사업을 다시 개시한 경우 

    ④  다른 업종을 추가하는 등 새로운 사업을 최초로 개시하는 것으로 보기 곤란한 경우 

4.  창업자금을 다음에 사용하여야 창업 목적에 사용하였다고 인정받을 수 있습니다.

    ①  토지와 감가상각자산의 취득자금

    ② 사업장의 임차보증금(전세금 포함) 및 임차료 지급액

    ☞ 대출금 상환, 재고자산 구입비용은 창업 목적에 사용한 것으로 보지 않습니다.😭

5. 한도 : 창업자금이 50억원을 초과하는 경우에는 50억까지만 과세특례를 적용합니다.(창업을 통하여 10명 이상 신규 고용하는 경우 : 100억원 한도)

6. 중복지원 배제 : 창업자금에 대한 과세특례를 적용 받으면 가업의 승계에 대한 증여세 과세특례는 적용하지 않습니다. 

7. 사후관리 : 4년간 창업자금에 대한 사용내역서를 세무서에 제출하여야 합니다.
