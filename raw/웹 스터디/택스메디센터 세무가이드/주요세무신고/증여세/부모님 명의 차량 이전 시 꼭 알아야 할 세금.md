# 부모님 명의 차량 이전 시 꼭 알아야 할 세금

안녕하세요! 오늘은 차량을 가족간 명의 이전할 때 발생하는 세금에 대해 쉽게 알려드릴게요.

> **차량 이전 시 발생하는 세금**

부모님 차량을 자녀 명의로 이전하면 크게 두 가지 세금이 발생해요.

* **취득세** : 차량 취득에 따라 구청에 납부하는 세금
* **증여세** : 부모님이 자녀에게 차량을 무상으로 넘겨주는 '증여'에 해당

> **증여세는 어떻게 신고하나요?**

**1. 신고 방법 :** 홈택스로 전자 신고하기

**2. 신고납부기한 :** 증여일이 속하는 달의 말일로부터 3개월 이내

예를 들어 7월 증여 → 10월 31일까지 증여세 신고납부

**3. 증여 공제 :** 차량 가액이 증여 공제액을 초과하는 경우 증여세가 발생합니다.

|  |  |
| --- | --- |
| 차량을 받는 사람 | 증여 공제 (10년간 합산) |
| 배우자 | 6억원 |
| 자녀 | 5천만원 |
| 형제자매, 사위, 며느리 | 1천만원 |
