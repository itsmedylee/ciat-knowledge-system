# 법인 수익으로 주식 투자를 할 경우, 법인세 부담은?

![b1095b2682267.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/b1095b2682267.jpg)

법인이 영업 활동을 통해 번 돈을 주식 투자에 써서 수익이 발생하면 어떤 세금을 내야 할까요?

투자 수익이 동일하다고 가정할 때, 개인보다 법인이 유리할까요?

**💡 법인 투자 수익에 따른 법인세율은?**

법인 수익이 연간 2억 원 이하라면 9%, 2억 원 초과 200억 원 이하라면 19%의 세율을 적용해요.

개인일 경우 2023년부터는 수익이 2,000만 원 이상일 때 20%, 3억 원 초과분에 대해서는 25%의 세율을 적용한다고 하니 수익이 2억 원 이하라면 개인보다 법인이 유리하겠죠.

**💡 그럼 주식 수익이 2억 원일 때 세금은 얼마나 내야 하나요?**

|  |  |
| --- | --- |
| **개인** | **법인** |
| (2억 - 2,000만 원\*) x 20% 세율  → **3,600만 원 부담**  \*기본 공제 2,000만 원 | 2억 x 9% 세율  → **1,800만 원 부담** |

**🚨 유의사항**

그렇다고 해서 법인 투자가 무조건 유리한 것은 아니에요.

법인 투자 수익은 법인의 것으로 보기 때문에 개인이 가져가서 쓰려면 배당을 받아야 하는데, 이 과정에서 **배당소득세**(15.4%)를 내야 하거든요.

위 경우처럼 법인에 2억 원의 수익이 발생했을 때 개인에게 배당하는 과정을 보자면 아래와 같아요.

|  |  |
| --- | --- |
| 법인 수익 2억 원  - **법인세 1,800만 원 (세율 9%)**   ---   = 1억 8,200만 원 (잔여 수익) | 1억 8,200만 원 (전액 개인에게 배당 시)  → **배당소득세 2,802만 원** (세율 15.4%) |

타소득 등 다른 조건을 배제하고 단순하게 계산한 내용임을 감안해주세요 🙂
