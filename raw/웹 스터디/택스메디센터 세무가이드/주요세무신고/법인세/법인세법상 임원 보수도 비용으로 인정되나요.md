# 법인세법상 임원 보수도 비용으로 인정되나요?

![a824991b973f8.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/a824991b973f8.jpg)

**💡 임원이란?**

법인세법상 임원은 직책이나 등기 여부에 관계없이 직무의 실질 내용에 따라 판단해요.

[법인세법시행령 제40조](https://www.law.go.kr/%EB%B2%95%EB%A0%B9/%EB%B2%95%EC%9D%B8%EC%84%B8%EB%B2%95%EC%8B%9C%ED%96%89%EB%A0%B9/(20220414,32418,20220215)/%EC%A0%9C40%EC%A1%B0)

**💡 임원 보수도 비용으로 인정되나요?**

임원이 실제로 직무를 수행한 경우에 한해 임원 보수가 비용으로 인정돼요.

**💡 임원 보수 종류에 따라서 비용으로 인정되지 않을 수도 있나요?**

임원 보수는 무한정 비용으로 인정되지 않고, 보수를 지급한 목적에 따라서도 비용으로 인정되지 않을 수 있어요.

자세한 내용은 아래 표의 내용을 참고해주세요.

|  |  |  |  |
| --- | --- | --- | --- |
|  | **지배주주인 임원 및****해당 임원의 특수관계인** | **비상근 임원** | **그 외 임원** |
| **급여** | 정당한 사유 없이 동일 직위 임원(지배주주 외)의 보수를 초과해 지급할 경우 → 초과분 비용 인정 불가 | 특수관계이며 법인의 세금을 부당하게 줄이려는 목적으로 지급할 경우 → 비용 인정 불가 | 전액 비용 인정 |
| **상여** | 아래 상여와 동일 기준 적용 |
| ① 지급 규정 없을 경우 ② 이익처분에 의해 지급된 경우 ③ 정관, 주주총회, 사원총회, 이사회결의로 결정된 금액을 초과한 금액 → 비용 인정 불가 | | |
| **퇴직급여** | ① 임원이 현실적으로 퇴직할 경우 지급하는 부분에 한해서 ② 법인세법상 한도 내 금액만 비용으로 인정 1순위 : 정관상 금액 (불특정다수를 대상으로 할 것) 2순위 : 1년간 총급여 x 1/10 x 근속연수 | | |

모바일에서는 표를 좌우로 스크롤하실 수 있어요 😃

참고로 지배주주란 지분율 1% 이상인 주주 및 해당 주주와 특수관계인의 소유 주식 합계가 해당 법인 주주 중 가장 많은 경우를 말해요.

임원은 고용증대세액공제, 사회보험료세액공제 대상이 아니에요.
