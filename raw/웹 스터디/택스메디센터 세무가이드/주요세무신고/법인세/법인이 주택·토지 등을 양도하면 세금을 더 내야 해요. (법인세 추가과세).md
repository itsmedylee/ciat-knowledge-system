# 법인이 주택·토지 등을 양도하면 세금을 더 내야 해요. (법인세 추가과세)

법인이 부동산 등을 양도할 경우 법인세를 추가로 내야 한다는 사실 아셨나요?

투자 목적으로 취득했다가 양도하는 과정에서 차익을 남겼더라도 추가과세까지 고려하면 이익이 크게 줄어들거나 오히려 손해일 수도 있어요 😅

**법인세 추가과세**는 영리법인과 비영리법인 모두 해당되는 내용이니 주택 등을 양도할 계획이 있다면 꼭 확인해주세요!

![61c8578765162.jpg](https://cdn.imweb.me/upload/S20210317a96d22bffcce0/61c8578765162.jpg)

**💡 어떤 자산을 양도할 때 법인세가 추가로 과세되나요?**

법인이 **비사업용 토지, 주택(주택에 딸린 부수 토지 포함) 등**을 양도해서 차익을 얻는다면 법인세가 추가로 과세돼요.

과거에는 주택 및 별장 등 **부동산** 양도에 대해서 세금을 부과했지만, 이제는 분양권이나 조합원 입주권 등 **주택을 취득하기 위한 권리**에 대해서도 과세한다는 점에 유의하세요.

|  |  |  |
| --- | --- | --- |
| **양도 시기** | **과세 기준** | **세율** |
| 2014년~2015년 | **중소기업 과세하지 않음** | 10% |
| 2016년~2020년 | 모든 법인 과세 |
| 2021년~ | **분양권, 입주권 등도 주택으로 보아 과세** | 비사업용 토지 10% 주택 20% **미등기 토지 또는 주택 40%** |

💡 **양도차익 계산 방법이 궁금해요.**

법인세 추가과세 대상 자산의 양도차익은 아래와 같이 구해요.

|  |
| --- |
| 양도차익 = 실제 양도가액 - 양도 시점의 장부가액  (장부가액 = 취득가액 - 감가상각누계액) |

법인세 추가과세 관련 내용은 아래 링크의 법령 및 국세청 안내를 통해서도 확인할 수 있어요 🙂

💡 **법인이 임대 등록한 주택도 과세 대상인가요?**

과거에는 법인이 임대 사업자 등록을 하고 임대 주택과 관련해서 일정 조건을 만족하면 해당 자산으로 얻은 양도소득에 대해 법인세 추가과세를 하지 않도록 하는 규정이 있었어요.

그러나 세법이 개정되면서 법인이 **2020년 6월 18일 이후에 장기 임대 등록하는 주택**도 추가과세 대상에 해당해요. (일부 제외)

|  |  |
| --- | --- |
| **임대 등록 시기** | **양도소득 추가과세 여부** |
| ~2018년 3월 31일 | 추가과세 제외 |
| 2018년 4월 1일 ~2020년 6월 17일 | 단기임대주택은 추가과세 해당 장기임대주택은 추가과세 제외 |
| 2020년 6월 18일~ | 추가과세 해당 단, 장기건설임대주택은 추가과세 제외 |
