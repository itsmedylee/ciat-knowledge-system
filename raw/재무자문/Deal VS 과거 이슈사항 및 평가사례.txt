[Issue 1] 할인율(WACC, Ke, Kd)
For Internal Distribution Only
▶가중평균자본비용(WACC)산출시검토이슈
WACC = Kex S/(S+B) + Kd x (1-T) x B/(S+B)
Ke = 자기자본비용
Kd = 타인자본비용(차입금의부채비용)
T = 법인세율
S = 자기자본총액(비지배지분이고려된시가총액)
B = 이자부담부채총액
검토해야될
내용
목표자본구조는평가대상회사의자본구조가아니며, 일반적으로산업평균또는대용기업평균치를
사용(시장참여자관점)
타인자본비용의경우평가대상회사의신용등급이반영된차입이자율인지검토
Ke, Kd 간 동일한화폐가정으로적용된할인율인지검토

[Issue 1] 할인율(WACC, Ke, Kd)(계속)
For Internal Distribution Only
▶자기자본비용(Ke)산출시검토이슈
Ke =  Rf + {E(Rm) – Rf} x β + α
Rf = 무위험이자율
E(Rm) = 시장기대수익율
β = 회사의체계적위험
α = 개별위험가산율(Specific Risk Premium)
검토해야될
내용
통상적으로무위험이자율(Rf)는Bloomberg상 조회되는평가대상회사가속한국가의10년국고채
수익율적용
시장위험프리미엄{E(Rm)-Rf} : 일반적으로 Bloomberg에서 조회한 data 사용
→통상적으로는평가기준일로부터과거1년시장위험프리미엄평균값사용
→2020년에 COVID-19의 영향으로시장위험프리미엄이과거대비높게상승하게됨
→이에따라Big4에서는조정시장위험프리미엄(과거2개년~ 10개년평균값)을적용검토중

개별위험가산율(α, Size Premium, Company Specific Risk Premium) 에 대한 적절한
근거를적용하였는지검토필요

[Issue 1] 할인율(WACC, Ke, Kd)(계속)
For Internal Distribution Only
▶자기자본비용(Ke)산출시검토이슈(계속)
βu = βL/{1+(1-T) x B/S}
βL: 대용기업의자기자본베타
T : 대용기업에 적용되는 법인세율
S : 대용회사 비지배지분포함시가총액
B : 대용회사이자부부채총액
검토해야될
내용
대용기업은평가대상회사와유사한기업으로선정되었는지검토및평가인에게질의필요
외부평가인이
평가대상회사가속한산업지수(ex) KRX 반도체)에속한 ‘모든’ 회사를유사
기업으로
선정했던이슈
→같은산업지수내회사들이라도평가대상회사와유사한영업활동을갖는지에대한검토필요
1차로선정된유사기업중특정event로인하여당기평가시outlier로제외하여야할기업들은
없는지검토및평가인에게질의
베타(β)의 경우일반적으로Bloomberg에서조회된조정베타(Adjusted Beta, 2/3 x Raw
Beta + 1/3 x 1)
베타(β) 표본 추출 기간/주기: 통상적으로2년주간, 5년주간, 5년월간적용

▶자기자본비용(Ke)산출시검토이슈(계속)
βL = βU x {1+(B/S) x (1-T)}
βL: 평가대상기업의자기자본베타
T : 평가대상기업의 법인세율
B/S : 목표자본구조
검토해야될
내용
목표자본구조는평가기준일시점평가대상회사의자본구조가아니며, 일반적으로산업평균
또는대용기업평균치등을사용
최근평가대상기업에게적용되었던법인세율검토필요. 만약영업이익(법인세전이익)이
200억이하일경우세율은22%(20% + 지방소득세(20%x10%))로 고려되어야함
