# raw/ — 원본 소스 (불변)

여기에 원본 자료를 넣는다. 기사, 문서, 마크다운, PDF 등.

- 이 폴더는 **진실의 원천**이다. LLM은 읽기만 하고 **절대 수정하지 않는다**.
- 새 자료를 넣은 뒤 LLM에게 "정리해줘" / "이거 수집해줘"라고 하면 위키에 통합된다.
- 팁: Obsidian Web Clipper로 웹 기사를 마크다운으로 저장하면 편리하다.

## 넣는 방법
1. 파일을 이 폴더에 복사/저장.
2. LLM에게 파일명을 알려주며 수집 요청.

## 폴더 구조

- `유튜브 스터디/` — YouTube transcript 컬렉션의 공통 컨테이너
  - `세무법인다솔 유튜브 스터디/`
  - `로뎀세무법인 유튜브 스터디/`
  - `세금전문회계사 김희연 유튜브 스터디/`
- 그 밖의 원본은 자료 성격별 컬렉션 폴더에 둔다.

YouTube 신규 채널은 `raw/` 루트에 병렬로 만들지 않고 `유튜브 스터디/<채널 컬렉션>/`에 추가한다.
