# 상생임대주택 특례 실무 체크리스트

- 문서 기준일: **2026-08-14**
- 공식자료 재확인일: **2026-08-15**
- 핵심 근거: 「소득세법」 제89조·제95조, 「소득세법 시행령」 제154조·제155조의3·제159조의4, 「소득세법 시행규칙」 제74조의3, 「국세기본법」 제14조
- 용도: 고객 초도상담, 자료요청, 요건별 검토, 신고 전 최종점검

> **중요:** 이 문서는 상담용 검토도구다. 실제 판정은 양도일 현재 법령, 시행령 부칙·적용례, 예규 원문, 계약 전체와 계좌흐름을 다시 확인한 후 확정한다. 특히 2026년 세제개편안은 법률·시행령으로 공포되기 전까지 현행법이 아니다.

## 1. 제도 한 줄 요약과 핵심 구조

### 한 줄 요약

> **내가 산 집을 먼저 정상적으로 1년 6개월 이상 임대하고, 다음 계약에서 임대료를 5% 이하로 올려 2년 이상 실제 임대하면, 나중에 그 집을 세법상 1세대1주택으로 양도할 때 일정한 거주기간 제한을 면제해 주는 제도다.**

상생임대주택 특례는 집을 자동으로 비과세해 주는 제도가 아니다. 현행 「소득세법 시행령」 제155조의3은 요건을 모두 갖춘 상생임대주택에 대해 제154조제1항, 제155조제20항제1호 및 제159조의4를 적용할 때 **거주기간의 제한을 받지 않도록** 한다. 따라서 1세대1주택, 보유기간, 고가주택 과세, 양도일 현재 주택 수 등 나머지 요건은 따로 충족해야 한다. [소득세법 시행령 제155조의3](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1028332727)

### 핵심 구조

```text
주택 취득
  ↓
취득 후 소유자가 임차인과 체결한 직전임대차계약
  ↓ 실제 임대 1년 6개월 이상
직전 대비 임대료 증가율 5% 이하의 상생임대차계약
  ↓ 2021.12.20.~2026.12.31. 체결 + 계약금 증빙 + 임대 개시
상생계약에 따른 실제 임대 2년 이상
  ↓
양도일 현재 1세대1주택 또는 세법상 1세대1주택 간주
  ↓
비과세·장기보유특별공제 적용 시 해당 거주기간 제한 면제
  ↓
신고서와 직전·상생 임대차계약서 제출
```

### 특례가 해주는 것과 해주지 않는 것

| 구분 | 내용 |
|---|---|
| 해주는 것 | 제154조제1항 등의 2년 거주 제한과 제159조의4의 표2 진입을 위한 거주기간 제한을 면제 |
| 해주지 않는 것 | 자동 비과세, 2년 보유요건 면제, 다주택 상태 자동 해소, 고가주택 과세 제외, 실제 거주기간 공제율 자동 생성 |

## 2. 체크리스트 항목별 성격

| 성격 | 뜻 | NO일 때 처리 |
|---|---|---|
| **필수요건** | 상생임대주택 자체의 법정 자격 | 원칙적으로 특례 불가. 다만 법정 합산·간주 예외가 있는지 확인 |
| **기본 비과세요건** | 상생임대 특례 밖에서 별도로 필요한 요건 | 상생임대에 성공해도 비과세가 안 될 수 있음 |
| **실익판단** | 특례가 실제로 세금을 줄이는지 판단 | 특례 탈락이 아니라 필요성·절세액이 작아질 수 있음 |
| **계산방법** | 5% 또는 기간을 올바르게 계산하는 방법 | 다시 계산한 결과에 따라 필수요건 판정 |
| **절차** | 신고서와 증빙 제출 | 미이행 즉시 탈락으로 단정하지 말고 사후적용·경정청구 검토 |
| **리스크** | 형식과 실제가 달라 과세관청이 문제 삼을 가능성 | 계약의 실질을 입증하거나 특례 부인 위험 반영 |
| **개정안·모니터링** | 아직 현행법이 아닌 정부안 또는 미확인 정보 | 법령 공포 전 현행요건으로 사용하지 않음 |

판정표에는 다음 세 가지 결과를 사용한다.

- **충족:** 자료와 사실관계로 요건을 확인함
- **미충족:** 반대 사실이 확인되어 원칙적으로 특례 적용 불가
- **추가확인:** 자료가 없거나 예외·해석 검토가 필요한 상태

## 3. 0~7단계 상세 체크리스트

### 0단계 - 선결 및 실익 판단

#### 0-1. 양도할 때 세법상 주택인가?

- 성격: **필수요건**
- 초등학생 설명: **“파는 물건이 정말 집이 맞아?”**
- YES: 다음 단계로 간다.
- NO: 상생임대주택 특례를 적용할 수 없다.
- 확인자료: 건축물대장, 등기사항증명서, 실제 사용현황, 전입·공과금 자료, 용도변경일
- 주의: 공부상 명칭만 보지 말고 양도 시점의 실제 사용용도를 함께 확인한다.

#### 0-2. 원래 2년 거주요건이 생기는 주택인가?

- 성격: **실익판단**
- 초등학생 설명: **“이 쿠폰이 없으면 원래 이 집에 2년 살아야 했어?”**
- YES: 상생임대 특례의 비과세 실익이 크다.
- NO: 상생임대 특례가 자동 탈락하는 것은 아니다. 다만 비과세 측 실익은 작을 수 있고, 고가주택 장기보유특별공제 실익은 별도로 본다.
- 현행 판단의 중심: **취득 당시에 조정대상지역에 있었는지**를 본다. [소득세법 시행령 제154조제1항](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027269363)
- 경과규정: 2017.8.2. 이전 취득주택, 2017.8.2. 이전 매매계약과 계약금 지급이 확인되는 일정한 무주택 세대 등은 종전 규정 적용 여부를 별도로 확인한다.
- **수정 문구:** `2017.8.3. 이후 취득 + 취득 당시 조정대상지역`은 간편한 역사적 요약일 뿐, 상생임대 자체의 필수요건으로 쓰면 안 된다.

#### 0-3. 양도가액이 12억원을 초과하는가?

- 성격: **실익판단**
- 초등학생 설명: **“1주택이어도 비싼 부분에는 세금이 남는 집이야?”**
- YES: 고가주택 과세부분이 생길 수 있으므로 장기보유특별공제 계산이 중요하다.
- NO: 다른 1세대1주택 비과세요건을 모두 갖추면 전액 비과세 가능성이 있어 장특공제의 실익이 없을 수 있다.
- 근거: 12억원 초과 고가주택은 제89조제1항제3호의 전면 비과세 대상에서 제외된다. [소득세법 제89조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031132269)

### 1단계 - 세대·주택 요건: 양도시점

#### A-1. 양도일 현재 1세대1주택인가?

- 성격: **핵심 필수요건**
- 초등학생 설명: **“집을 파는 날 세법이 우리 세대를 1주택자로 봐 줘?”**
- YES: 다음 단계로 간다.
- NO: 원칙적으로 상생임대 특례를 적용할 수 없다.
- 확인자료: 본인·배우자·세대원 주택, 분양권, 조합원입주권, 공동소유, 해외주택, 사실상 주택 현황

#### A-2. 실제 2주택 이상이어도 1세대1주택으로 보는 특례가 있는가?

- 성격: **A-1의 간주·예외 판단**
- 초등학생 설명: **“집이 두 채처럼 보여도 세법이 특별히 한 채로 계산해 줘?”**
- YES: 일시적 2주택, 상속, 혼인, 동거봉양 등 해당 규정의 세부기한까지 충족하면 A-1을 살릴 수 있다.
- NO: 실제 다주택 상태라면 A-1 미충족 가능성이 크다.
- 주의: 제155조, 제155조의2, 제156조의2, 제156조의3 및 그 밖의 법령에 따른 간주를 타임라인으로 검토한다.

#### A-3. 지금 파는 집이 바로 상생임대한 그 집인가?

- 성격: **필수요건**
- 초등학생 설명: **“쿠폰을 만든 집과 지금 파는 집이 같은 집이야?”**
- YES: 다음 단계로 간다.
- NO: 다른 집의 상생임대 실적으로 현재 양도주택의 거주요건을 면제받을 수 없다.

#### A-4. 2년 이상 보유 등 나머지 비과세요건을 충족하는가?

- 성격: **기본 비과세요건**
- 초등학생 설명: **“거주 말고 다른 숙제도 다 했어?”**
- YES: 다음 단계로 간다.
- NO: 상생임대를 잘했어도 비과세가 안 될 수 있다. 다만 제154조의 보유기간 제한 예외가 있는지 별도 확인한다.
- 핵심: 상생임대는 주로 **거주기간 제한**을 면제하며 보유기간 제한을 일반적으로 면제하지 않는다.

### 2단계 - 직전임대차계약 요건

#### B-1. 주택을 취득한 후 체결된 계약인가?

- 성격: **필수요건**
- 초등학생 설명: **“내가 집주인이 된 다음에 맺은 계약이야?”**
- YES: 직전임대차계약 후보가 된다.
- NO: 원칙적으로 직전임대차계약으로 사용할 수 없다.
- 확인자료: 취득일, 잔금일, 등기일, 계약 체결일, 임대개시일

#### B-2. 취득으로 승계한 원계약 자체가 아닌가?

- 성격: **필수요건**
- 초등학생 설명: **“전 집주인의 계약을 그냥 물려받은 것 말고, 내가 집주인이 된 뒤 생긴 계약이야?”**
- YES: 다음 단계로 간다.
- NO: 승계한 원계약 자체는 직전임대차계약에서 제외된다.
- 단, **세입자가 있는 집을 샀다는 이유만으로 영구 탈락하는 것은 아니다.** 취득 후 갱신·재갱신 계약이 각각 요건을 갖추면 직전계약과 상생계약으로 볼 수 있다는 국세청 해석이 있다. [서면-2024-법규재산-1914](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=200000000000010094)

#### B-3. 승계 후 적격한 후속 계약이 따로 있는가?

- 성격: **승계주택 구제항목**
- 초등학생 설명: **“물려받은 계약 뒤에 진짜 새 계약이나 갱신계약이 있었어?”**
- YES: 그 후속 계약부터 직전임대차계약 후보로 검토한다.
- NO: 적격 직전임대차계약이 없어 특례 적용이 어렵다.
- 확인자료: 승계 원계약부터 양도일까지 계약서·갱신합의·묵시적 갱신 내역 전체

#### B-4. 직전계약으로 실제 1년 6개월 이상 임대했는가?

- 성격: **핵심 필수요건**
- 초등학생 설명: **“첫 번째 적격 계약으로 세입자가 실제 18개월 이상 살았어?”**
- YES: 통과한다.
- NO: 원칙적으로 미충족이다.
- 계산: 월력에 따라 계산하고 1개월 미만은 1개월로 본다. 계약서상 기간이 아니라 실제 임대기간을 확인한다. [소득세법 시행령 제155조의3제2호·제3항](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1028332727)

#### B-5. 여러 단기계약의 기간을 합산하고 있는가?

- 성격: **법정 합산·해석항목**
- 초등학생 설명: **“짧은 계약 여러 개를 그냥 더한 거야, 아니면 법이 허용한 이어달리기야?”**
- NO: 한 적격 계약만으로 18개월을 충족하면 일반 검토로 간다.
- YES: **무조건 탈락도, 무조건 합산도 아니다.** 아래를 나누어 본다.
  1. 동일 임차인과 갱신·연장된 계약인지
  2. 임차인의 사정으로 새 임차인과 계약한 것인지
  3. 새 계약의 보증금 또는 임대료가 종전보다 증가하지 않았는지
- 현행법은 임차인의 사정으로 새 계약을 체결하고 시행규칙상 임대료 불인상 요건을 충족하면 기간을 합산할 수 있다. [시행령 제155조의3제4항](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1028332727), [시행규칙 제74조의3](https://law.go.kr/lsLinkCommonInfo.do?lspttninfSeq=174207)
- 결론: 법정·해석상 합산 근거가 없으면 미충족 위험이 크다.

#### B-6. 단순 조건변경을 별개의 새 계약이라고 주장하는 것은 아닌가?

- 성격: **리스크·해석항목**
- 초등학생 설명: **“원래 계약의 숫자만 조금 고친 건데 새 계약이라고 이름만 바꾼 것은 아니야?”**
- YES, 별개의 갱신·신규계약 실체가 분명함: 다음 단계로 간다.
- NO, 단순 변경에 불과함: 직전계약 특정이 잘못될 수 있으므로 계약 경위와 예규를 추가 검토한다.
- 확인자료: 계약 만료, 갱신 협의, 신규 계약금, 전월세신고, 확정일자, 당사자 의사

### 3단계 - 상생임대차계약 요건

#### C-1. 직전계약보다 보증금·임대료를 5% 이하로 올렸는가?

- 성격: **핵심 필수요건**
- 초등학생 설명: **“두 번째 계약의 집세를 5% 넘게 올리지 않았어?”**
- YES: 통과한다.
- NO: 원칙적으로 상생임대차계약이 아니다.
- 예시: 전세 5억원 → 5억2천만원은 4%로 통과, 5억3천만원은 6%로 미충족.

#### C-2. 전세와 월세가 바뀌었다면 법정 전환기준으로 다시 계산했는가?

- 성격: **C-1의 계산방법**
- 초등학생 설명: **“전세와 월세를 같은 자로 바꿔서 비교했어?”**
- YES: 환산 후 증가율이 5% 이하이면 C-1을 충족한다.
- NO: 단순 보증금 차이만으로 판단하지 말고 다시 계산한다.
- 현행 연결규정: 제155조의3제2항 → 민간임대주택법 제44조제4항 → 같은 법 시행규칙 제18조 → 주택임대차보호법 제7조의2. [민간임대주택법 시행규칙 제18조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=150799)
- 전월세전환율 상한:

```text
r = min(연 10%, 해당 시점 한국은행 기준금리 + 연 2%p)
```

- 환산보증금의 간편식:

```text
환산보증금 = 보증금 + (월세 × 12 ÷ r)
증가율 = (상생계약 환산보증금 - 직전계약 환산보증금)
         ÷ 직전계약 환산보증금 × 100
```

- 적용시점의 기준금리와 계약·전환일을 원문 기준으로 확인한다. [주택임대차보호법 제7조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?ancYnChk=&chrClsCd=&lsJoLnkSeq=1031475575)

#### C-3. 관리비·시설사용료·별도금으로 사실상 임대료를 더 받은 적이 없는가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“월세라는 이름만 피해서 다른 이름으로 돈을 더 받은 것은 아니야?”**
- YES, 우회수취 없음: 정상 관리비 근거를 보관하고 다음 단계로 간다.
- NO, 사실상 임대료를 별도 수취: 5% 초과로 재구성되거나 계약 실체가 부인될 위험이 있다.
- 확인자료: 관리비 산정표, 공용비용 영수증, 특약, 실제 계좌 입금내역

#### C-4. 상생계약 체결일이 2021.12.20.~2026.12.31. 안에 있는가?

- 성격: **핵심 필수요건·현행법**
- 초등학생 설명: **“법이 정한 기간 안에 두 번째 계약을 했어?”**
- YES: 통과한다.
- NO: 현행법상 상생임대차계약으로 인정받기 어렵다.
- 주의: 계약서 날짜만이 아니라 계약 체결 및 계약금 지급의 실제 시점을 확인한다.

#### C-5. 계약금을 지급받은 사실이 증빙서류로 확인되는가?

- 성격: **법문상 요건**
- 초등학생 설명: **“계약한 날 진짜 계약금이 오간 증거가 있어?”**
- YES: 가장 안전하다.
- NO: 상당한 위험이 있다. 다만 묵시적 갱신 등 별도 계약금이 없는 특수사례는 계약형태와 관련 예규를 검토하고, 사후에 가짜 증빙을 만들면 안 된다.
- 확인자료: 계좌이체, 영수증, 계약일 전후 계좌흐름, 중개대상물 확인자료

#### C-6. 상생계약에 따라 실제 임대를 시작했는가?

- 성격: **필수요건**
- 초등학생 설명: **“계약서만 쓴 게 아니라 실제로 집을 빌려줬어?”**
- YES: 다음 단계로 간다.
- NO: 상생임대요건을 충족하지 못한다.
- 확인자료: 인도일, 전입일, 보증금 잔금, 월세 수령, 전기·수도·가스 사용내역

#### C-7. 상생계약에 따라 실제 2년 이상 임대했는가?

- 성격: **핵심 필수요건**
- 초등학생 설명: **“두 번째 계약으로 실제 임대한 시간이 24개월 이상이야?”**
- YES: 통과한다.
- NO: 원칙적으로 미충족이다. 다만 임차인 사정으로 새 계약을 체결하고 임대료 불인상 등 제155조의3제4항 요건을 갖추면 합산 가능성을 검토한다.
- 주의: 계약서에 2년이라고 적힌 것보다 실제 퇴거·보증금 반환·공실·자가사용·멸실일이 중요하다.
- **멸실 없음은 독립된 법정요건이 아니다.** 멸실 때문에 실제 2년 임대를 채우지 못하면 C-7을 충족하지 못하는 구조다.

### 4단계 - 신고 및 서류 절차

#### D-1. 양도소득세 신고기한까지 특례적용신고서를 제출했는가?

- 성격: **절차**
- 초등학생 설명: **“혜택을 받겠다는 신청서를 제때 냈어?”**
- YES: 정상적이고 가장 안전하다.
- NO: 시행령 문언상 미이행이지만 **즉시·무조건 탈락으로 단정하지 않는다.** 실체요건 충족이 확인되면 특례 적용이 가능하다는 국세청 과세기준자문이 있으므로 수정신고·경정청구 등 사후구제를 검토한다. [기준-2025-법규재산-0020](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=200000000000012419)
- 원칙적 제출서식: 별지 제83호의4 `상생임대주택에 대한 특례적용신고서`

#### D-2. 직전임대차계약서와 상생임대차계약서를 첨부했는가?

- 성격: **절차**
- 초등학생 설명: **“첫 계약과 두 번째 계약의 증거를 같이 냈어?”**
- YES: 정상적이고 가장 안전하다.
- NO: 절차상 보완대상이다. 실체요건이 객관적으로 확인되면 즉시 탈락으로 단정하지 말고 계약서·계좌내역·전월세신고 등으로 보완한다.
- 주의: 묵시적 갱신처럼 계약서가 별도로 없는 경우에는 갱신 사실과 조건을 다른 객관자료로 입증하고 관련 해석을 검토한다.

> 실무 원칙: 국세청 해석이 사후적용 가능성을 인정하더라도 처음부터 기한 내 신고·첨부를 하는 것이 가장 안전하다. 사후구제는 정상 신고를 대신하는 운영방식이 아니다.

### 5단계 - 2026년 세제개편안 및 입법 모니터링

#### 먼저 결론

2026.8.14. 현재 시행 중인 제155조의3에는 **상생임대차계약 종료 후 1년 이내 양도**나 **2027.12.31.까지 양도** 같은 처분기한이 적혀 있지 않다. 현행 실체요건은 제155조의3제1항의 5%·계약기간·계약금·임대개시, 직전 1년 6개월, 상생 2년 등이다. [현행 제155조의3 원문](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1028332727)

재정경제부는 2026.8.3. 세제개편안을 발표했으나 정부안은 공포 법령이 아니다. 공식 공개페이지에서는 부동산 세제와 장기보유특별공제 개편 방향·단계적 시행을 안내하고 있다. [재정경제부 2026년 세제개편안](https://www.mofe.go.kr/2026/taxlaw.do), [발표 보도자료 페이지](https://www.mofe.go.kr/nw/nes/detailNesDtaView.do?menuNo=4010100&searchBbsId1=MOSFBBS_000000000028&searchNttId1=MOSF_000000000078809)

#### E-1. 양도일이 최종 개정법령의 적용대상인가?

- 성격: **개정안·모니터링**
- 초등학생 설명: **“집을 팔 때 새 규칙이 이미 시작됐어?”**
- YES: 최종 공포된 조문, 부칙, 시행일, 적용례에 따라 다시 판정한다.
- NO: 양도일 현재 현행법으로 판정한다.
- **수정:** 기존 체크리스트의 `2026.10.1. 이후 양도분`은 이 문서에서 확보한 공식 근거로 확정하지 못했으므로 사용하지 않는다. `양도일이 최종 개정법령의 적용대상 양도분인지`로 바꾼다.

#### E-2. 기존 대화의 “2026.12.31. 이전 종료 → 2027.12.31.까지 양도” 수치

- 성격: **미확인 경보**
- 초등학생 설명: **“전에 들은 마감일이 진짜 법으로 확정됐어?”**
- YES, 최종 공포문과 부칙에서 확인됨: 그때 비로소 법적 양도기한으로 사용한다.
- NO 또는 확인 전: 고객에게 확정기한으로 안내하지 않고 현행요건과 분리한다.

#### E-3. 기존 대화의 “2027.1.1. 이후 종료 → 종료 후 1년 이내, 최대 2029.12.31.” 수치

- 성격: **미확인 경보**
- 초등학생 설명: **“계약이 끝난 뒤 1년이라는 규칙이 정말 공포됐어?”**
- YES, 최종 공포문과 부칙에서 확인됨: 종료일과 양도일을 일 단위로 관리한다.
- NO 또는 확인 전: 현행법 요건으로 쓰지 않는다.

#### 개편안 실무 메모

- 공식 2026년 세제개편안은 장기보유특별공제를 보유 중심에서 거주 중심으로 바꾸고 양도세 개편을 유예·단계 시행하는 방향도 제시한다.
- 따라서 2028년 이후 양도예정 사건은 상생임대 양도기한뿐 아니라 **제95조 표2 구조 자체의 최종 개정 여부**도 다시 확인한다.
- 정부안, 입법예고안, 국회 통과안, 공포 법령은 서로 다를 수 있다.

### 6단계 - 장기보유특별공제 표2 실익

#### F-1. 상생임대 특례로 표2의 2년 거주 진입요건을 해결할 수 있는가?

- 성격: **세금 실익**
- 초등학생 설명: **“실제로 2년 살지 않았다는 이유만으로 표2 입구에서 막히는 것을 풀 수 있어?”**
- YES: 상생임대요건을 충족하면 제159조의4 적용 시 거주기간 제한을 면제받아 표2 적용 가능성을 확보한다.
- NO: 실제 2년 거주 등 제159조의4 요건을 별도로 충족해야 한다.
- 주의: 표2 적용 가능성은 양도일 현재 1세대1주택, 3년 이상 보유 등 다른 요건까지 갖춘다는 전제다. [소득세법 시행령 제159조의4](https://law.go.kr/LSW/lsLinkCommonInfo.do?lspttninfSeq=191899)

#### F-2. 상생임대를 하면 자동으로 80% 공제되는가?

- 성격: **계산·핵심 수정사항**
- 초등학생 설명: **“상생임대 쿠폰 하나만 있으면 가장 큰 할인 80%를 바로 받아?”**
- YES라는 뜻으로 이해하면: **틀렸다.**
- 정확한 답: 현행 표2는 **보유기간별 공제 최대 40% + 실제 거주기간별 공제 최대 40% = 합계 최대 80%** 구조다. [소득세법 제95조제2항 표2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033141655)
- 상생임대의 효과: 실제 2년 거주가 없다는 이유로 표2 자체를 쓰지 못하게 하는 제한을 면제한다.
- 상생임대가 하지 않는 것: 실제 거주기간을 10년으로 만들어 주거나 거주공제 40%를 자동 부여하지 않는다.

##### 현행 표2 간단 계산

| 구분 | 공제율 | 최대 |
|---|---:|---:|
| 보유기간 | 원칙적으로 연 4% | 10년 이상 40% |
| 실제 거주기간 | 원칙적으로 연 4% | 10년 이상 40% |
| 합계 | 두 공제율의 합 | 최대 80% |

예를 들어 10년 보유, 실제 거주 0년, 상생임대요건 충족이라면 표2 진입 가능성은 확보되지만 **실제 거주기간에 따른 40%가 자동으로 생기지는 않는다.** 보유기간 공제와 실제 거주기간 공제를 나누어 계산해야 한다.

### 7단계 - 실질과세 리스크

「국세기본법」 제14조는 거래의 이름보다 실제 내용을 보고 과세하도록 한다. 둘 이상의 행위나 제3자를 이용해 세법상 혜택을 부당하게 받으려는 경우 경제적 실질에 따라 재구성될 수 있다. [국세기본법 제14조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029615893)

#### G-1. 계약일 소급작성 정황이 없는가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“나중에 계약서를 옛날 날짜로 다시 만든 것은 아니야?”**
- YES, 정황 없음: 계약금·신고일·확정일자가 서로 맞으면 방어력이 높다.
- NO, 소급작성 정황 있음: C-4·C-5와 계약 실체가 부인될 위험이 매우 크다.
- 방어자료: 계약금 이체, 중개사 자료, 확정일자, 전월세신고, 문자·이메일

#### G-2. 임대료 5%를 관리비·별도금으로 우회하지 않았는가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“집세를 다른 이름으로 몰래 더 받은 것은 아니야?”**
- YES, 우회 없음: 정상 관리비의 실제 비용 근거를 보관한다.
- NO, 우회 있음: 사실상 임대료로 합산되어 5%를 넘을 위험이 있다.
- 방어자료: 관리비 정산서, 공과금, 특약, 계좌내역

#### G-3. 임차인이 실제로 거주했는가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“계약서 속 사람만 있는 게 아니라 진짜 세입자가 살았어?”**
- YES: 전입·공과금·보증금·월세 흐름이 일치하면 방어력이 높다.
- NO: 형식적 임대차로 보아 특례가 부인될 위험이 있다.
- 방어자료: 전입·전출, 전기·수도·가스, 보증금, 월세, 임차인 생활근거

#### G-4. 계약금이 가장거래가 아닌가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“집주인이 돈을 빌려주고 바로 계약금으로 돌려받은 가짜 거래는 아니야?”**
- YES, 정상 계약금: 임차인의 독립 자금과 보유기간을 확인한다.
- NO, 순환·즉시반환: 계약금 증빙과 계약 실체가 부인될 위험이 크다.
- 방어자료: 계약금 전후 계좌 전체, 자금원천, 반환시점

#### G-5. 임대기간이 계약서와 실제로 일치하는가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“종이에 2년이라고 썼지만 실제로는 일찍 나간 것은 아니야?”**
- YES: 실제 인도·퇴거·보증금 반환일이 기간요건과 맞으면 통과 가능성이 높다.
- NO: 18개월 또는 24개월 요건을 다시 계산한다. 법정 합산 예외가 없으면 미충족 위험이 크다.
- 방어자료: 퇴거합의, 보증금 반환, 새 임차인 계약, 공실기간, 공과금

#### G-6. 하나의 계약을 서류상 두 계약으로 쪼갠 것이 아닌가?

- 성격: **실질과세 리스크**
- 초등학생 설명: **“처음부터 한 번에 하기로 한 계약을 혜택 때문에 두 장으로 나눈 것은 아니야?”**
- YES, 실제로 두 번의 독립된 계약·갱신이 있었음: 계약 경위가 자료와 일치하면 방어 가능하다.
- NO, 사후 분할에 불과함: 직전·상생계약의 독립 실체가 부인될 위험이 크다.
- 방어자료: 각 계약 협상, 만료·갱신 통지, 계약금, 중개자료, 신고자료

## 7. 실제 고객상담 Workflow

### Step 1. 상담 목표를 먼저 정한다

- 12억원 이하 전면 비과세가 목표인지
- 12억원 초과 고가주택의 과세부분과 장특공제 절감이 목표인지
- 아직 계약 전이라 구조 설계가 필요한지, 이미 양도해 경정청구가 필요한지 구분한다.

### Step 2. 주택과 세대 현황을 확정한다

- 양도대상이 세법상 주택인지 확인한다.
- 양도일 기준 본인·배우자·세대원의 모든 주택·권리를 펼친다.
- 일시적 2주택 등 1세대1주택 간주 가능성을 검토한다.

### Step 3. 임대차 타임라인을 한 장으로 만든다

| 순번 | 계약 성격 | 계약일 | 임대개시 | 실제 종료 | 보증금 | 월세 | 임차인 | 계약금 증빙 |
|---:|---|---|---|---|---:|---:|---|---|
| 1 | 취득 당시 승계 원계약 |  |  |  |  |  |  |  |
| 2 | 취득 후 계약·갱신 |  |  |  |  |  |  |  |
| 3 | 상생계약 후보 |  |  |  |  |  |  |  |
| 4 | 중도퇴거 후 대체계약 |  |  |  |  |  |  |  |

### Step 4. 적격 직전임대차계약을 먼저 특정한다

- 승계 원계약을 제외한다.
- 취득 후 계약·갱신 중 어느 계약을 직전계약으로 볼지 정한다.
- 실제 18개월과 법정 합산 예외를 계산한다.

> 직전계약을 잘못 잡으면 5% 계산의 기준금액도 모두 틀어진다.

### Step 5. 상생계약과 5%를 계산한다

- 전세↔월세 전환이 없으면 계약금액을 직접 비교한다.
- 전환이 있으면 계약일별 기준금리와 법정 전환율로 환산표를 만든다.
- 관리비·별도금까지 실제 수취내역을 검토한다.

### Step 6. 실제 임대기간과 계약 실체를 검증한다

- 직전 18개월, 상생 24개월을 월력으로 계산한다.
- 중도퇴거 시 새 계약 합산요건을 확인한다.
- 계약금, 보증금, 월세, 전입, 공과금, 보증금 반환 흐름을 맞춘다.

### Step 7. 양도일의 기본 비과세요건을 검토한다

- 세법상 1세대1주택 또는 간주 여부
- 2년 보유 등 기본요건
- 12억원 초과 고가주택 여부
- 양도주택과 상생운영주택의 동일성

### Step 8. 세금 실익을 숫자로 비교한다

최소 세 가지 시나리오를 계산한다.

1. 상생임대 특례 적용
2. 상생임대 특례 미적용
3. 양도시점 변경 또는 다른 주택 선처분

고가주택이면 표2의 보유공제와 **실제 거주공제**를 따로 계산한다.

### Step 9. 개정법령 체크포인트를 건다

- 계약 체결 직전
- 상생임대 2년 충족일
- 매매계약 체결 직전
- 잔금·양도 직전
- 신고 직전

각 시점마다 국가법령정보센터의 현행조문과 부칙, 재정경제부 발표, 국세청 해석을 다시 확인한다.

### Step 10. 신고 패키지를 완성한다

- 상생임대주택 특례적용신고서
- 직전·상생 임대차계약서
- 18개월·24개월 계산표
- 5% 환산계산표
- 계약금·보증금·월세 계좌자료
- 전입·공과금·퇴거·보증금 반환자료
- 양도일 1세대1주택 검토표
- 미제출 사건이면 경정청구서와 실체요건 입증자료

## 최종 검토 메모

- [ ] 예규 사건번호와 회신 원문을 실제 사실관계에 맞게 재대조했다.
- [ ] 양도일 현재 시행 중인 제155조의3과 부칙·적용례를 확인했다.
- [ ] 2026년 세제개편안이 최종 공포됐는지 확인했다.
- [ ] 상생임대 관련 별도 양도기한이 신설됐는지 확인했다.
- [ ] 제95조 표2의 구조와 시행시기를 다시 확인했다.
- [ ] 18개월·24개월 월력 계산표를 사건파일에 보관했다.
- [ ] 5% 환산계산표와 적용 기준금리 자료를 보관했다.
- [ ] 계약서 외 실제 계좌흐름·전입·공과금·보증금 반환자료를 확보했다.
