# 홈페이지·블로그 SEO와 GEO 성장 운영

> [!info] 개요
> 공식 홈페이지 [ciatpartners.com](https://ciatpartners.com/)과 [네이버 블로그 insightlens](https://blog.naver.com/insightlens)의 고객 확보 운영 기준이다. 2026-10-23 사용자 확인에 따라 **기장·신고 수임과 양도·상속·증여 상담**을 먼저 늘린다. 홈페이지 구현 위치는 `C:/dev/ciatpartners`다. 홈페이지 개선은 2026-10-24 운영 배포했고, 네이버 게시본 수정과 검색·상담 성과 측정은 후속 작업이다.

## 1. 목표와 우선 고객

사용자는 아직 확보한 업체가 없는 초기 단계라고 설명했다. 전체 업무를 성장시키되 우선순위는 ① 기장·신고 등 지속 수임, ② 양도·상속·증여 상담으로 정했다. 회계·재무 자문은 공개 안내를 유지하면서 첫 4주의 신규 콘텐츠 자원은 앞의 두 분야에 집중한다. 과거 실무 경험과 현재 사무소의 수임 현황은 구분한다. → [[Ideal-Customer-Profile]] · [[Service-Portfolio]]

**최종 성과는 신규 상담과 수임**이다. 방문자·검색 노출·AI 인용은 고객이 오는 경로를 이해하는 중간 지표로 사용한다. 기존 고객 수, 검색량, 현재 순위, 전환율을 추정해 채우지 않는다.

| 우선 분야 | 찾아올 사람의 상황 | 먼저 답할 질문 | 연결할 페이지 |
|---|---|---|---|
| 기장·신고 | 처음 세무대리를 맡기는 개인사업자·법인 | 무엇까지 맡길 수 있고 비용은 어떻게 정하나 | `/services/tax-compliance/` → `/pricing/` → 서비스별 문의 |
| 기장·신고 | 기존 세무사무소 변경 검토 | 인계 시점·자료·추가 비용은 어떻게 되나 | 기장 상세 → 사무소 변경 FAQ → 문의 |
| 양도·상속·증여 | 거래 전 판단 또는 신고가 필요한 개인·가족 | 내 사실관계에서 무엇을 검토해야 하나 | `/services/private-tax/` → 상담 기준 → 서비스별 문의 |

지역은 실제 소재지인 **경산**을 중심으로 대구·경북과 전국 비대면 업무를 안내한다. 주소가 없는 지역의 지점이나 실제 수임 사례를 만들어 지역 페이지를 늘리지 않는다.

## 2. 확인한 현재 상태와 남은 확인

확인일: **2026-10-23, 한국시간**. 공개 홈페이지는 HTTP GET과 초기 HTML로 점검했다.

| 항목 | 관찰 결과 | 다음 행동 |
|---|---|---|
| 검색 접근 기반 | 공개 사이트맵 10페이지, robots·본문 HTML·canonical·메타·기존 FAQ 및 안내 파일 검사 실패 0건 | 접근 기반을 유지하며 검색 의도에 맞는 내용을 보강 |
| 서비스 설명 | 기존 `/services/` 한 페이지에 4개 서비스의 앵커가 있음 | 업무별 상세 URL과 준비사항을 추가하고 기존 앵커 유지 |
| 업체·대표자 식별 | AccountingService·WebSite·대표자 식별자와 공식 블로그 연결이 이미 있음 | 새 서비스 페이지에서도 동일 사무소를 참조 |
| 블로그 연결 | 홈페이지가 RSS 최신 글을 네이버 원문으로 연결 | 서비스 상세에서 관련 글, 블로그 목록에서 관련 서비스로 연결 |

| 검색 성과 | Search Console·서치어드바이저·블로그 통계 계정은 미열람 | 최근 28일 기준선과 색인 상태 확보 필요 |
| 문의 성과 | 접수·상담·수임 집계 미확보 | 아래 최소 측정표로 집계 시작 |

## 3. 홈페이지에서 실행할 구조

2026-10-23 로컬 코드에 다음을 구현했다. 운영 반영 상태는 배포 후 별도로 기록한다.

1. 홈 검색 제목에 경산·대구와 우선 업무를 표시하고, 설명에 대표 공인회계사·실제 업무·비대면 상담을 명시한다.
2. **기장·신고 / 상속·증여·양도 / 세무자문 / 회계·재무 자문** 상세 페이지를 만든다. 각 페이지는 대상 상황, 업무, 첫 문의 준비사항, 진행 순서, 기존 FAQ, 비용·문의 연결을 갖춘다.
3. 홈·업무 분야·블로그에서 상세 페이지를 연결한다. 상세 페이지는 관련 네이버 글과 서비스가 선택된 문의 양식으로 연결한다.
4. 각 상세 페이지의 고유 제목·설명·canonical·Service·BreadcrumbList, 사이트맵과 공개 안내 파일의 링크를 일치시킨다.
5. 가격과 운영 정책은 기존 홈페이지의 공통 데이터에서 재사용한다. 새 가격·실적·처리기한 보장을 만들지 않는다.

초기에는 위의 두 우선 분야에서 **문의자가 무엇을 묻는지**를 모아 상세 페이지의 설명을 보완한다. 지역명만 다른 복제 페이지나 제목만 다른 짧은 글을 양산하지 않는다.

## 4. 검색어와 콘텐츠의 연결

다음은 **운영 가설**이다. 검색량·경쟁도·상위 노출 가능성을 실측한 목록이 아니다. 실제 노출 검색어와 상담 질문을 보고 우선순위를 조정한다.

| 검색 상황·예상 표현 | 담당 채널 | 담을 내용 | 상담 연결 |
|---|---|---|---|
| 경산 기장, 경산 회계사, 대구 기장대리 | 홈페이지 기장 상세 | 소재지·업무 범위·담당자·준비사항 | 기장 문의 |
| 개인사업자 기장료, 법인 기장료, 세무조정료 별도 | 홈페이지 비용 + 블로그 설명 | 포함·별도 업무, 비용 산정 기준, 질문 예시 | 현재 비용 페이지 |
| 세무사 변경, 세무사무소 변경 자료 | 블로그 + 기존 FAQ | 인계 준비, 이전·새 담당자의 업무 시점 확인 | 기장 상세 |
| 경산 양도세 상담, 상속세 상담, 증여세 상담 | 홈페이지 재산제세 상세 | 검토 범위·예약·자료·상담과 신고 구분 | 재산제세 문의 |
| 상생임대주택 체결기한·양도기한 | 기존 블로그 | 기존 [[상생임대주택-블로그]]의 근거 상태를 확인해 최신화 | 재산제세 상세 |

한 검색 질문을 맡는 대표 페이지를 정하고 비슷한 새 글보다 기존 글의 보완을 먼저 검토한다. 네이버와 홈페이지에는 각각 다른 독자 과제를 맡긴다. 홈페이지는 서비스·공식 비용·상담 안내, 블로그는 구체적인 질문·사례·판단 과정을 담당한다.

## 5. 블로그 작성·수정 때 쓰는 기준

새 글의 법령·판례 내용은 정본 topics와 공식 원문을 확인한다. 작성·검증·윤문·게시 순서는 기존 `OneDrive - 씨앗세무회계/초안/README.md`를 따른다. 이 운영 문서는 게시 전 검토를 대체하지 않는다.

- **제목:** 핵심 제도나 고객 상황을 앞에 둔다. 해결할 질문을 하나로 좁힌다. 해시태그 수나 키워드 반복 횟수를 순위 공식으로 사용하지 않는다.
- **첫 문단:** 질문에 대한 짧은 답과 적용 전제를 함께 쓴다. 예외가 중요한 내용은 요약에서도 예외를 생략하지 않는다.
- **본문:** 누구의 어떤 거래인지 → 확인할 날짜·계약·증빙 → 판단이 갈리는 지점 → 다음 행동 순서로 설명한다. 표·이미지의 핵심 정보는 독자가 읽을 수 있는 본문 텍스트에도 남긴다.
- **근거:** 법령명·조문, 사건·회신 번호, 시행일과 검토 기준일을 식별할 수 있게 쓴다. 미확인 사항은 검색 노출을 위해 단정문으로 바꾸지 않는다.
- **신뢰:** 실제 작성자와 전문자격을 블로그 프로필·소개에서 확인할 수 있게 한다. 새 후기·고객 실적·성공률을 만들지 않는다.
- **관련 글:** 독자가 다음에 궁금해할 기존 글 1~2개를 연결한다. 모든 글에 같은 링크를 길게 붙이지 않는다.
- **상담 안내:** 주제에 맞는 서비스 상세와 현재 비용 안내를 연결한다. 법리 설명과 사무소 안내를 구분한다.
- **갱신:** 개정·정정이 있으면 변경 내용을 함께 적는다. 실제 검토 없이 기준일만 최신으로 바꾸지 않는다.

기장 글은 [기존 홈페이지 FAQ](https://ciatpartners.com/faq/)와 실제 비용 기준으로 쓴다. 양도·상속·증여 글의 법리와 요건은 [[양도소득세-1세대1주택-비과세]] · [[상속세-과세체계와-전략]] · [[증여세-과세체계]] 등 정본을 확인하고 필요한 원문 검증을 거친다. 현재 미수임 단계에서는 실제 고객 사례 대신 명시적으로 가상 사례를 사용한다.

## 7. GEO에 적용할 기준

GEO는 생성형 검색 답변에서 정확한 출처로 발견·인용되도록 돕는 작업으로 정의한다. **짧게 답하되, 전제·예외·근거가 함께 있는 콘텐츠**를 만드는 것은 이 사무소의 편집 전략이다. 특정 문장 길이나 FAQ 개수가 AI 인용을 높인다고 검증된 공식으로 취급하지 않는다.

공식 문서에서 확인한 사실은 다음과 같다.

- Google의 AI 검색은 기존 SEO 기반을 사용한다. 별도의 AI 텍스트 파일이나 전용 구조화데이터가 필수는 아니다. 따라서 기존 `llms.txt`를 유지하되 추가 파일 제작보다 본문·내부 링크·정확한 정보를 우선한다. [Google AI 검색 안내](https://developers.google.com/search/docs/appearance/ai-features)
- ChatGPT 검색용 OAI-SearchBot과 학습용 GPTBot의 설정은 독립적이다. 현재 공개 사이트의 wildcard 허용을 확인했으며, 검색 노출을 위해 학습 허용 정책을 새로 바꾸지 않았다. 실제 검색 봇의 방화벽 통과와 색인은 별도 확인 대상이다. [OpenAI 크롤러 공식 안내](https://developers.openai.com/api/docs/bots)
- 네이버는 고유한 제목·설명, 본문 접근, 사이트맵과 연관 채널 안내를 권장한다. 홈페이지용 서치어드바이저 설정과 네이버 블로그 통계는 구분해 확인한다. [네이버 검색 최적화 기본 안내](https://searchadvisor.naver.com/guide/seo-basic-intro)

## 8. 측정표와 의사결정

현재 수치를 아직 확보하지 못한 항목은 **미측정**, 접근하지 못한 계정은 **미확인**으로 둔다. 검색 결과 한 번이나 `site:` 검색만으로 전체 색인과 순위를 확정하지 않는다.

| 지표 | 가져올 곳·집계 기준 | 현재 기준선 | 판단에 쓰는 방법 |
|---|---|---|---|
| Google 노출·클릭·검색어·대상 URL | Search Console 최근 28일. 브랜드 포함/미포함 구분 | 미측정 | 실제 노출되는 질문에 맞춰 제목·본문 보완 |
| 네이버 홈페이지 노출·클릭 | 서치어드바이저 | 미측정 | 홈페이지 수집·노출 점검 |
| 네이버 블로그 유입 검색어·조회 글 | 블로그 통계 | 미측정 | 읽히는 주제와 문의 주제 비교 |
| 상세 페이지 색인 상태 | 각 검색 도구의 URL 검사 | 미확인 | 미색인 원인을 먼저 확인 |
| 문의·본상담·수임 건수 | 승인된 업무시스템에서 주간 집계 | 미측정 | 기장·재산제세를 나눠 고객 확보 성과 확인 |
| AI 출처 인용 | 아래 고정 질문을 검색 가능한 환경에서 수동 실행 | 미측정 | 실제 클릭 가능한 자사 출처 URL과 사실 정확성 기록 |

첫 문의 양식에 추적 코드를 새로 수집하는 기능은 넣지 않았다. 먼저 상담 중 **‘어떤 검색어나 글을 보고 오셨나요?’**를 확인하고 합계만 기록한다. 위키에는 고객 식별정보나 원본 문의 내용을 저장하지 않는다.

AI 확인 질문은 브랜드와 비브랜드를 나눈다.

1. ‘씨앗세무회계 기장료와 기장 업무 범위는?’
2. ‘씨앗세무회계에서 양도·상속·증여 상담을 받으려면?’
3. ‘경산에서 개인사업자 기장대리를 알아볼 때 무엇을 비교해야 하나?’
4. ‘양도세 상담 전에 어떤 자료를 준비해야 하나?’

엔진, 날짜, 검색 활성화 여부, 질문 원문, 출처 URL과 인용 오류를 함께 적는다. 브랜드 질문 인용은 비브랜드 신규 고객 노출과 구분한다. 같은 조건에서도 답변이 달라질 수 있으므로 단일 실행을 노출률로 표현하지 않는다.

**D+14**에는 수집·색인과 초기 문의를 확인하고, **D+30 이후**에는 집계 지연을 고려해 같은 길이의 변경 전후 기간을 비교한다. 변화가 이 작업 때문이라고 단정하지 않고 계절·신고기간·신규 발행의 영향도 함께 본다.
