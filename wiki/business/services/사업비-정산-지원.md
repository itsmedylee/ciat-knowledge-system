# 사업비 정산 지원

> [!info] 개요
> 씨앗세무회계의 사업비 정산 서비스 범위와 수임 기준을 정하는 내부 초안이다. 등록 공인회계사 개인사무소로 수행하며, 회계법인 또는 등록 감사반 자격으로 수행하는 서비스로 표시하지 않는다. 법령·기관별 근거와 판정은 [개인 공인회계사 사업비 정산 자격 보고서](<../../../reports/개인 공인회계사 사업비 정산 자격.md>)를 참조한다. 기준일은 2026-10-24이다.

## 제공할 서비스

지원사업 수행자가 집행자료를 정리하고 정산을 준비하도록 돕는다. 공고·협약·지침을 먼저 확인하여 **사업자 측 정산 준비 지원**과 **기관에 제출하는 정산·검증 용역** 중 어떤 업무를 맡을지 계약 전에 정한다. 등록 공인회계사의 회계 계산·정리 등 일반 직무가 기본 근거이며, 제출용 보고서 자격은 사업별 요건을 별도로 확인한다. [공인회계사법 제2·7조](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=258791)

| 업무 | 기본 산출물 | 계약에서 확인할 점 |
|---|---|---|
| 집행자료·증빙 점검 | 집행내역과 증빙 대사표, 누락·불일치 목록 | 대상 기간·자료 종류·점검 범위 |
| 정산자료 작성 지원 | 사업자가 검토·제출할 정산자료 초안, 집행명세서 정리 | 최종 작성·제출 책임과 제출 주체 |
| 집행기준 사전 검토 | 협약·지침 대비 확인사항과 보완자료 목록 | 불인정 여부의 최종 결정 주체, 판단이 필요한 쟁점 |
| 보완 요청 대응 지원 | 요청 항목별 회계자료와 사실관계 설명자료 | 회계자료 준비 범위·회차·마감 |
| 개별 기관이 개인 CPA를 인정하는 정산용역 | 해당 사업이 정한 보고서·확인서 | 허용 자격, 지정·선정 절차, 서식·서명·발급 명의 |

마지막 행은 **조건부 서비스**다. 기관명이나 ‘정산’이라는 업무명만으로 수임 가능을 확정하지 않는다. 법정 검증·감사가 필요한 사업의 자료 준비 지원을 맡는 경우에도, 그 지원 결과물은 법정 검증·감사보고서를 대체하지 않는다. [국고보조금법 제27조](https://law.go.kr/LSW/lsInfoP.do?lsId=000729), [지방보조금법 제17조](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=291237)

### 부가세 집행 기준 (2026-10-25 추가)

집행기준 사전 검토에서 가장 자주 걸리는 쟁점은 부가세다. 원칙은 "공제·환급받을 수 있는 부가세는 사업비가 아니다"이며, 일반과세자는 공급가액만 집행하고 면세·간이·겸영 사업자는 사업별 지침과 전문기관 확인이 필요하다. 판단 기준의 정본은 [[부가가치세-매입세액-공제와-불공제]]의 「정부지원사업비와 매입세액」 절이다. 정산 소명을 위해 세금계산서·지급증빙과 해당 기간 부가세 신고서(매입처별 세금계산서합계표)를 함께 보관하도록 안내한다. ([[정부지원사업 부가세 사업비로 집행할 수 있는 경우와 없는 경우-소스요약]])

## 법정 검증과 별도로 정할 범위

> [!warning] 주의
> 공인회계사 개인 등록과 외부감사법상 감사인 자격은 다르다. 외부감사법상 감사인은 회계법인 또는 한국공인회계사회에 등록한 감사반이다. 씨앗 개인사무소 명의로 그 자격이 필요한 법정 검증·감사보고서를 발급하는 서비스는 포함하지 않는다. [외부감사법 제2조제7호·제9조](https://www.law.go.kr/lsInfoP.do?lsiSeq=270309)

수임 초기에 확인할 기본 기준은 다음과 같다. 아래 금액은 **총사업비나 수임료 기준이 아니다.** 세부 예외·중복검증 조정·기관별 요건은 근거 보고서에서 확인한다.

| 구분 | 기본 적용 전제 | 수임 판단 |
|---|---|---|
| 국고 정산보고서 법정 검증 | 해당 보조사업·간접보조사업의 보조금·간접보조금 총액 **1억원 이상**이 원칙. 보조사업자 등이 지방자치단체인 경우 제외, 공기업·준정부기관 등 고시 특례 가능 | 법정 감사인에 의한 검증 별도 |
| 지방 정산보고서 법정 검증 | 해당 지방보조사업의 지방보조금 총액 **3억원 이상**. 지방자치단체인 사업자 제외, 국고법상 해당 내용의 검증을 이미 받은 경우 등 예외 | 법정 감사인에 의한 검증 별도 |
| 특정사업자 재무제표 회계감사 | 같은 회계연도 중 교부받은 보조금 등의 총액 **10억원 이상**인 국고·지방 특정사업자가 기본 대상. 각 법의 산정 범위·생략·대체 예외 확인 | 법정 감사인에 의한 감사 별도 |

근거: [국고보조금법 제27·27조의2](https://law.go.kr/LSW/lsInfoP.do?lsId=000729), [국고 시행령 제12조의2](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=288975), [지방보조금법 제17·18조](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=291237). 위 기준 미만이어도 개별 사업이 회계법인·지정기관 등 별도 자격을 요구할 수 있다. 국가연구개발비·민간위탁금 등 다른 자금에 이 표를 그대로 적용하지 않는다.

기관이 자체 정산용역에서 개인 CPA를 허용하는 경우와 위 법정 검증은 구분한다. **입찰 참가 허용은 개인사무소 명의의 법정 보고서 발급 자격, 현재 모집 중이라는 사실, 우리 사무소의 지정·실적을 뜻하지 않는다.** 기관별 판정과 확인 공고는 [근거 보고서](<../../../reports/개인 공인회계사 사업비 정산 자격.md>)에서 관리한다.

## 독립성과 겸업 경계

집행자료 작성·장부 작성 지원과 같은 대상에 대한 독립적 검증·감사를 동시에 묶어 약속하지 않는다. 공인회계사법 제21조와 국고 정산검증지침 제5·6조, 지방보조금 관리기준 제22조에는 관계자 독립성과 이해상충 업무 제한이 있다. 기관 승인 예외가 있는 지침도 있지만, 승인으로 다른 법령상 자격·직무제한까지 해소되는 것은 아니므로 규정별로 확인한다. [공인회계사법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=258791), [국고 검증지침](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000248440), [지방 관리기준](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000284062)

별도 감사인 또는 기관 지정 정산기관이 관여하는 경우, 계약상 역할·결과물·질의 창구를 먼저 정한다. 외부 기관의 심사·승인·사업비 전액 인정 결과를 보장하지 않는다. ‘소명 지원’은 회계자료·사실관계 설명자료 준비로 정의하며 행정심판·소송의 법률대리까지 포함하는 표현으로 사용하지 않는다.

## 기본 수임 검토 체크리스트

- [ ] 공고·협약·집행지침의 명칭·버전·적용 연도를 확인한다.
- [ ] 자금의 성격을 국고보조금·지방보조금·연구개발비·민간위탁금 등으로 구분한다.
- [ ] 주무부처·전담/관리기관·실제 제출처와 계약상대방을 확인한다.
- [ ] 의뢰 업무가 사업자 측 자료 준비인지, 기관 제출용 정산용역인지, 법정 검증·감사인지 구분한다.
- [ ] 필요한 자격의 정확한 문구와 정의 조항, 지정·선정·입찰 절차를 확인한다.
- [ ] 개인 CPA 허용이 기관 자체 용역에 한정되는지, 별도 법정 검증이 필요한지 확인한다.
- [ ] 보조금 산정 단위·금액·회계연도와 적용 예외를 확인한다.
- [ ] 기존 기장·자료작성·감사 관계와 이해상충·독립성을 검토한다.
- [ ] 적용 서식, 발급·서명 명의, 제출 주체와 기한을 확인한다.
- [ ] 자료량·정리 상태·검토 기간·보완 회차를 확인하고 범위·보수·추가 업무를 계약서에 적는다.
- [ ] 필요한 기관 확인은 업무 범위와 해당 조항을 특정해 문서로 남긴다.
- [ ] 의뢰인의 원본 장부·증빙·식별정보는 승인된 업무시스템에서 관리하고 이 위키에 저장하지 않는다.

## 홈페이지 연결과 운영 상태

사용자 제공 타 사무소 페이지의 설명 항목을 참고해 정산 개념·유형, 비목별 자료, 집행 단계 자문과 개인카드·사업기간·이자·예산 변경 FAQ를 새 문안으로 보강했다. 전용률·이자·부가세·제재를 일률적으로 설명하지 않고 적용 기준과 승인 예외를 구분한다. 구체적인 반영·법령 대조 기록은 홈페이지 저장소의 `docs/PROJECT-COST-SETTLEMENT-2026-10-24.md`에서 관리한다.

2026-10-24 후속 요청에 따라 개인 CPA·개인사무소 허용 근거를 전면에 배치했다. 제주다양성영화·경기도 문화의 날·KISA·NIA·NST·한국연구재단·KOICA의 추가 공고를 확인했고, 법인 한정·허용 미확인 기관 목록은 공개 페이지에서 제외했다. 공고상 조직형태 허용과 인력·소재지·지정 조건은 계속 구분한다. 후속 근거는 [개인 회계사 정산 허용 추가 사례](<../../../reports/개인 회계사 정산 허용 추가 사례.md>)에서 관리한다.

홈페이지 서비스 경로는 **`/services/project-cost-settlement/`**로 구현했다. 표시 명칭은 **‘사업비 정산 지원’**이며, 내용은 위 범위에서 고객에게 필요한 설명으로 줄였다. 2026-10-24 로컬 미리보기·빌드·타입·문법 검사와 공개 페이지 15개 SEO 검사, 문의 QA 63건을 통과했다. 이 작업에서는 커밋·운영 배포하지 않았다. 기관별 실제 수임 요건은 별도로 확인하며, 이 내부 문서의 `draft` 상태가 기관 지정·보고서 발급 자격을 의미하지 않는다.
