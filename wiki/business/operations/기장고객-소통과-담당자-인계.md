# 기장고객 소통과 담당자 인계

> [!info] 개요
> 대표의 상담·기존 대화가 직원의 자료 수집·신고 준비로 이어지도록 하는 운영 초안이다. 실제 담당 배정·응답 시간·도구는 대표가 확정한다.

## 인계 순서

1. 고객에게 직원이 도울 업무와 소통 경로를 알리고 업무방 개설·합류에 대한 동의를 확인한다.
2. 고객 창구·자료 수집·장부 작성·세무 판단·최종 검토·부재 시 대체 담당을 정한다.
3. 기존 상담 자료·최종 결정·수정 이력·현재 신고의 대상 기간·개별 납기·미해결 질문을 인계한다.
4. 직원은 기존 자료를 확인하고 누락 목록·다음 안내 시점을 고객에게 알린다. 단순 초대만으로 인계를 끝내지 않는다.
5. 전문 판단이 필요한 질문은 검토 담당자에게 연결하고 회신 내용을 같은 업무 기록에 남긴다.

## 업무시스템 기록 틀

| 항목 | 내용 |
|---|---|
| 고객번호·업무 | 세목·협업 업무, 대상 기간 |
| 요청·변경 | 접수일, 최초 요청, 최종 수정 내용 |
| 담당 | 처리 담당·검토자·대체 담당 |
| 현재 상태 | 확인 중 / 고객 자료 대기 / 외부 회신 대기 / 검토 중 / 완료 / 보류 |
| 다음 조치 | 연락일, 요청 자료, 처리 기한 |
| 근거·결과 | 최종 파일 보관 위치, 반영 업무, 안내일·고객 확인 |

이 표는 양식 구조다. 실제 고객별 행과 개인정보는 위키에 채우지 않는다.

## 소통 기준

- 전달 경로(문자·메일·개인 대화·업무방)를 기록한다. 기한 있는 자료는 수신 확인까지 남긴다.
- 통화 후에는 실제 합의한 적용 월·최종 요청·다음 담당을 적는다. 통화 요청만 있는 기록에서 통화 내용을 추정하지 않는다.
- 수정본은 이전본과 함께 보관하고 최종 적용본을 표시한다. 자료 상태는 [[증빙수취-자료요청-체크리스트]]를 따른다.
- 고객의 장기 부재는 업무에 필요한 기간·대체 연락 계획만 기록한다. 업무와 무관한 사적 사정은 위키에 남기지 않는다.
- 기본 범위 밖의 일은 범위와 견적을 먼저 안내한다 → [[세무기장-서비스범위와-보수]].

## 대표 확인 항목

응답 시간·미회신 재연락·납부 미확인 후속 연락·대체 담당자·자료 보관 권한과 사용 도구를 정한다. 이 초안을 이미 확정된 사무소 운영 방침으로 표시하지 않는다.
