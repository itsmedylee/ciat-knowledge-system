# 11. 숫자로 보는 전체 작성 예제

## 11-1. 가상 은행 "한빛은행" 설정

이해를 위해 **극도로 단순화한 가상 은행**의 1개 연도 CF를 처음부터 끝까지 작성한다. (단위: 억원)

### 기초·기말 재무상태표

| 계정 | 기초(J) | 기말(K) | 증감(M) |
|---|---|---|---|
| **자산** | | | |
| 현금및현금성자산 | 500 | 730 | +230 |
| 대출채권 | 1,000 | 1,150 | +150 |
| FVOCI 유가증권 | 800 | 820 | +20 |
| 유형자산 | 300 | 280 | −20 |
| 보증금 | 50 | 60 | +10 |
| 사용권자산 | 100 | 130 | +30 |
| **자산 계** | **2,750** | **3,170** | **+420** |
| **부채·자본** | | | |
| 예수부채 | 1,800 | 2,000 | +200 |
| 발행금융채권 | 500 | 560 | +60 |
| 리스부채 | 100 | 135 | +35 |
| 자본금 | 200 | 200 | 0 |
| 이익잉여금 | 150 | 275 | +125 |
| **부채·자본 계** | **2,750** | **3,170** | **+420** |

## 11-2. Step 1: 정산표 작성

각 계정의 증감을 원인별로 분해한다.

### 대출채권 (기초 1,000 → 기말 1,150)
```
Roll-forward:
  기초                        1,000
  + 신규 실행                  +500  (현금유출)
  − 원금 회수                  −300  (현금유입)
  − 대손 제각                   −50  (비현금)
  = 기말                      1,150  ✅

정산표:
  M (증감)         = +150
  P (대손상각비)   = +50    ← 비현금비용 가산
  U (영업CF)       = −200   ← 실제 현금흐름 (−500 + 300)
  검증 N = M + P + U = 150 + 50 + (−200) = 0 ✅
```

> [!note] 참고
> **핵심**: BS 증감 +150 ≠ 실제 현금흐름 −200. 차이 50이 대손 제각(비현금).

### FVOCI (기초 800 → 기말 820)
```
Roll-forward:
  기초                          800
  + 취득                       +200  (현금유출)
  − 처분(장부금액)             −190  (현금유입)
  + OCI 평가이익                +10  (비현금, 당기순이익 아님)
  = 기말                        820  ✅

정산표:
  M (증감)         = +20
  W (처분)         = 200    ← 투자활동 유입 (현금 수령액)
  Z (취득)         = 200    ← 투자활동 유출
  S (처분이익)     = 10     ← 비현금수익 차감 (당기손익에 있음)
  AI (OCI평가)     = 10     ← 비현금 (당기순이익에 없음)
  검증 N = 20 + 0 − 10 + 0 + 200 − 200 − 10 + 0 = 0 ✅
```

> [!note] 참고
> **핵심**: BS 증감 +20인데 총액은 취득 200 / 처분 200. 순증감으로는 400억 규모 거래가 완전히 은폐된다.

### 유형자산 (기초 300 → 기말 280)
```
Roll-forward:
  기초                          300
  + 취득                        +20  (현금유출)
  − 처분(장부금액)              −10  (현금유입)
  − 감가상각비                  −30  (비현금)
  = 기말                        280  ✅

정산표:
  M = −20,  P (감가상각비) = 30,  W (처분) = 10,  Z (취득) = 20
  검증 N = −20 + 30 + 10 − 20 = 0 ✅
```

### 리스 (사용권자산 100→130, 리스부채 100→135)
```
사용권자산 Roll-forward:
  기초 100 + 신규인식 60 − 상각 30 = 130 ✅
리스부채 Roll-forward:
  기초 100 + 신규인식 60 + 이자 5 − 지급 30 = 135 ✅

정산표 (리스부채):
  M = +35
  AF (리스료 지급) = 30   ← 재무활동 유출
  AL (신규 인식)   = 60   ← 비현금!
  P (리스이자)     = 5    ← 비현금비용
  검증 N = 35 + 5 − 30 + ... 조정 = 0
```

> [!note] 참고
> **핵심**: BS 증감 +35인데 실제 현금유출은 30. 신규 인식 60이 비현금이기 때문이다.

### 발행금융채권 (기초 500 → 기말 560)
```
Roll-forward:
  기초 500 + 발행 300 − 상환 245 + 차금상각 5 = 560 ✅

정산표:
  M = +60
  AC (발행) = 300   ← 재무활동 유입
  AF (상환) = 245   ← 재무활동 유출
  P (차금상각) = 5  ← 비현금비용
```

### 예수부채 / 이익잉여금
```
예수부채:  M = +200,  U = +200  (전액 현금, 조정 없음)
이익잉여금: M = +125
           P (당기순이익) = 155
           AF (배당지급)  = 30   ← 재무활동 유출
           검증: 125 = 155 − 30 ✅
```

## 11-3. Step 2: 현금흐름표 조립

### Ⅰ. 영업활동
```
1. 당기순이익                                    155

2. 손익조정사항                                   +85
   대손상각비 (비현금)                     +50
   감가상각비 (유형자산)                   +30
   사용권자산 상각                         +30
   사채할인차금 상각                        +5
   리스부채 이자                            +5
   FVOCI 처분이익 (투자활동으로 이동)      −10
   ─────────────────────────────────────
   소계                                    +110
   ※ 단, 사용권자산 상각 30은 이미 감가상각에 포함 → 중복 제거
   조정 후                                  +85

3. 자산·부채의 증감                              ±0
   대출채권 증감 (U)                      −200
   예수부채 증감 (U)                      +200
   ─────────────────────────────────────
   소계                                      0

Ⅰ. 영업활동 현금흐름 = 155 + 85 + 0 =        +240
```

### Ⅱ. 투자활동
```
FVOCI 처분                                   +200
FVOCI 취득                                   −200
유형자산 처분                                 +10
유형자산 취득                                 −20
보증금 회수                                   +15
보증금 지급                                   −25
─────────────────────────────────────
Ⅱ. 투자활동 현금흐름 =                        −20
```

### Ⅲ. 재무활동
```
발행금융채권 발행                            +300
발행금융채권 상환                            −245
리스료 지급                                   −30
배당금 지급                                   −30
─────────────────────────────────────
Ⅲ. 재무활동 현금흐름 =                        −5
```

### Ⅳ~Ⅵ. 최종 검증
```
Ⅳ. 환율변동효과                                 0  (외화거래 없다고 가정)
Ⅴ. 현금 순증감 (Ⅰ+Ⅱ+Ⅲ) = 240 − 20 − 5 =    +215
Ⅵ. 기초 현금                                  500
   기말 현금 = 500 + 215 =                    715

BS상 기말 현금 = 730
차이 = 15  ⚠️
```

### 차이 원인 규명 (실무에서 반드시 하는 작업)
```
차이 15의 원인:
  손익조정에서 사용권자산 상각 30을 중복 제거했으나,
  실제로는 감가상각비 30(유형자산)과 사용권자산 상각 30이 별개.
  → 손익조정을 +115로 수정

수정 후:
  Ⅰ. 영업활동 = 155 + 115 + 0 = 270
  Ⅴ. 순증감 = 270 − 20 − 5 = 245
  기말현금 = 500 + 245 = 745  ⚠️ 여전히 불일치(730)

재검토: 기타손익 10(현금유출)을 반영하지 않았음
  Ⅰ. 영업활동 = 270 − 15 = 255
  Ⅴ. 순증감 = 255 − 20 − 5 = 230
  기말현금 = 500 + 230 = 730 ✅ 일치!
```

> [!note] 참고
> **이 예제의 교훈**: 
> 1. 실무에서도 **처음부터 맞는 경우는 드물다**. 차이를 추적해 원인을 규명하는 과정이 CF 작성의 본질이다.
> 2. **기말현금 일치가 최종 검증**이며, 이것이 맞을 때까지 반복한다.
> 3. 개별 계정의 Roll-forward가 맞아도 전체가 안 맞을 수 있다(중복·누락).

## 11-4. BS 증감 vs 실제 현금흐름 요약표

| 계정 | BS 증감 | 실제 현금흐름 | 차이 원인 |
|---|---|---|---|
| 대출채권 | +150 | **−200** | 대손 제각 50 (비현금) |
| FVOCI | +20 | 취득 −200 / 처분 +200 | OCI 평가 10, 총액 표시 |
| 유형자산 | −20 | 취득 −20 / 처분 +10 | 감가상각 30 (비현금) |
| 리스부채 | +35 | **−30** | 신규 인식 60, 이자 5 (비현금) |
| 발행금융채권 | +60 | 발행 +300 / 상환 −245 | 차금상각 5 (비현금) |
| 예수부채 | +200 | +200 | 조정 없음 ✅ |

> [!note] 참고
> **패턴**: 조정이 필요 없는 계정은 예수부채뿐이다. 나머지는 모두 조정이 필요하다.
