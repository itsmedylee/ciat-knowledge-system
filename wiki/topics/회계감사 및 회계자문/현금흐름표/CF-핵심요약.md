# 15. 핵심 요약

## 15-1. 한 문장 요약

> [!note] 참고
> **현금흐름표 작성이란, 모든 BS 계정의 잔액 변화를 ①현금거래 ②비현금손익 ③비현금대체로 남김없이 분해하여, 그 결과 계산된 기말현금이 원장과 일치함을 증명하는 작업이다.**

## 15-2. 반드시 기억할 10가지

| # | 원칙 |
|---|---|
| 1 | **BS 증감 ≠ 현금흐름.** 부호까지 반대인 경우가 실제로 존재한다 (대출채권: +7.8조 vs −6.3조) |
| 2 | **최종 검증은 기말현금 = 원장.** 이것이 맞으면 큰 틀에서 검증된 것이고, 틀리면 반드시 원인을 찾아야 한다 |
| 3 | **간접법은 당기순이익에서 출발한다.** 당기순이익에 없는 항목(OCI)은 조정 대상이 아니다 |
| 4 | **은행은 영업활동 범위가 넓다.** 대출·예금·트레이딩은 본업이므로 영업활동 |
| 5 | **투자·재무활동은 총액표시.** 순증감으로는 실제 거래 규모가 은폐된다 (FVOCI: 순증감 −2,922억 vs 총액 21조) |
| 6 | **BS만으로 알 수 없는 정보는 M시트/Key-in으로.** 총액, 비현금 대체가 대표적 |
| 7 | **비현금거래는 AI/AL 짝으로 기록하여 상쇄.** 순효과 0이 되도록 설계 |
| 8 | **환율효과는 현금흐름이 아니다.** 별도 표시하되 순증감 계산에서 제외 |
| 9 | **단수조정 셀은 필수 장치다.** 함부로 삭제하면 정합성이 깨진다 |
| 10 | **검증은 계정별(N열) → 소계별 → 최종(기말현금) 3층으로.** 오류를 계정 단위로 특정할 수 있다 |

## 15-3. 정산표 없이 원장만으로 CF를 재구성하는 절차

```
1. BS 전 계정을 세로로 나열, 기초·기말·증감 산출

2. 각 계정마다 질문한다:
   "이 잔액 변화의 원인은 무엇인가?"
   → 현금거래 / 비현금손익 / 비현금대체로 분해

3. 총액표시가 필요한 계정(투자·재무)은 원장 상세를 조사
   → 취득/처분, 증가/감소 총액 파악

4. 비현금손익을 PL에서 골라내 손익조정에 반영
   → 단, OCI 항목은 제외 (당기순이익에 없음)

5. 비현금대체를 식별하여 상쇄 처리 + 주석 공시

6. 계정별 검증: 증감 = 원인의 합

7. 활동별 집계

8. 최종 검증: 기초현금 + 3활동 + 환율효과 = 기말현금(원장)
   → 불일치 시 2~7 반복
```

## 15-4. 가장 흔한 오류 Top 5

| 순위 | 오류 | 결과 |
|---|---|---|
| 1 | **신규 리스 인식을 현금거래로 처리** | 투자·재무활동 동시 과대 |
| 2 | **FVOCI 평가손익(OCI)을 손익조정에 포함** | 이중조정, 기말현금 불일치 |
| 3 | **대손 제각액 복원 누락** | 영업활동 현금흐름 왜곡 |
| 4 | **투자·재무활동을 순액으로 표시** | 실제 거래 규모 은폐 |
| 5 | **환율효과를 영업활동에 포함** | 실현되지 않은 현금 계상 |
