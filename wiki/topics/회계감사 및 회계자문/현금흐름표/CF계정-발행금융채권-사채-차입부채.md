# 10. 발행금융채권 / 사채 / 차입부채

> ## 📌 요약 박스
> - **CF 분류**: **재무활동**. 발행금융채권·사채는 증가/감소 **총액표시**, 차입부채는 순증가/순감소 **순액표시**
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (총액표시 + 할인발행차금 상각 조정 필요)
> - **핵심 조정항목**: ① 할인·할증발행차금 상각(P336 = 645억) ② 외화채권 환율변동 ③ 발행/상환 총액 파악
> - **가장 흔한 실수**: 할인발행차금 상각으로 부채 장부금액이 늘어난 것을 "추가 발행"으로 오인하는 것

---

## A. 계정의 경제적 실질
은행의 **시장성 자금조달** 수단. 예수부채(고객 예금)와 달리 이것은 명백한 **차입**이다.

| 구분 | 예수부채 | 발행금융채권·사채 |
|---|---|---|
| 성격 | 상품 판매 (수신) | 자금 조달 |
| CF 분류 | **영업활동** | **재무활동** |

### B. 회계처리
```
① 발행 (현금)
   (차) 현금          980     (대) 발행금융채권     824
       사채할인발행차금  20
② 할인차금 상각 (비현금)
   (차) 이자비용        5      (대) 사채할인발행차금   5
③ 상환 (현금)
   (차) 발행금융채권    824    (대) 현금          824
```

### C~D. 거래 성격
- **현금**: 발행(유입), 상환(유출)
- **비현금**: **할인·할증발행차금 상각**, 외화채권 환율변동

### E. BS 증감 사용 가능성
**불가능** ❌: 총액표시 + 차금상각 조정

### F. Bridge
```
기초 발행금융채권 (장부금액)
+ 발행 현금유입액                ← 재무활동 유입 (AC열)
- 상환 현금유출액                ← 재무활동 유출 (AF열)
+ 할인발행차금 상각              ← 비현금 (이자비용 인식)
± 환율변동 (외화채권)            ← 비현금
= 기말 발행금융채권 (장부금액)
```

### G. 분류
**재무활동**: 증가/감소 총액표시
파일: `공시용 CF` 50~51행 `(5) 사채의 증가 6,359,322 / (6) 사채의 감소 -8,301,696` `[파일 확인]`

### H. 현재 정산표에서의 처리 `[파일 확인]`

전체표 매핑:
```
D774 발행금융채권의 증가 = 정산자료!AC331    6,359,322,185,108
D814 발행금융채권의 감소 = 정산자료!AF331    8,301,696,064,220
D771 차입부채의 순증가   = 정산자료!AC303      994,908,748,361
D812 차입부채의 순감소   = 정산자료!AF303    1,139,453,322,266
```

**Key-in 항목 2건** `[파일 확인]`:
```
AI332 = 48,766,421          [발행금융채권(상환)]
P336  = 64,610,415,352      [발행금융채권할인할증발행차금(-)]
```

> [!note] 참고
> **P336의 의미**: 할인발행차금 상각액 645억을 **비현금비용으로 가산**한다. 이는 이자비용으로 인식되지만 현금 유출이 없으므로 손익조정에서 되돌린다. 이 조정이 없으면 영업활동 현금흐름이 645억 과소 표시된다. `[논리 추론]`

### I. 검토 시 주의사항
1. **총액 vs 순액**: 발행금융채권은 총액(증가/감소 각각)으로, 차입부채는 순액("순증가/순감소")으로 처리했다. 이 차이의 근거를 확인해야 한다 `[확인 필요]`.
2. **할인발행차금 상각 누락**: 가장 흔한 오류. 사채 장부금액은 상각으로 계속 증가하는데 이를 "추가 발행"으로 오인하면 안 된다.
3. **외화채권 환율변동**: 외화 발행채권의 원화 장부금액 변동을 상환이나 발행으로 오인하지 않는다.
4. 원천: `사채_M` 시트(6회 참조) `[파일 확인]`
