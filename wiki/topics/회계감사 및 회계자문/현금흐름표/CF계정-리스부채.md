# 09. 리스부채 / 사용권자산

> ## 📌 요약 박스
> - **CF 분류**: **재무활동** — 리스부채의 상환(원금분). 이자 부분은 정책에 따라 영업 또는 재무활동
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (BS −228억 vs 실제 현금유출 1,442억, 약 6배)
> - **핵심 조정항목**: ① 신규 리스 인식(비현금, 주석 공시) ② 리스부채 이자 ③ 리스료 지급(현금, 재무활동 유출)
> - **가장 흔한 실수**: 신규 리스 인식을 현금거래로 처리 — 투자·재무활동을 동시에 부풀림(전체 Top 5 오류 1위)

---

## A. 계정의 경제적 실질
K-IFRS 제1116호 도입으로 대부분의 리스가 자산·부채로 인식된다. 은행은 영업점 임차가 많아 리스 규모가 크다.

### B. 회계처리
```
① 리스 개시 (비현금!)
   (차) 사용권자산      824    (대) 리스부채       824   ← 현금 이동 없음
② 리스료 지급 (현금)
   (차) 리스부채        80     (대) 현금          100
       이자비용         20
③ 감가상각 (비현금)
   (차) 감가상각비     200     (대) 사용권자산     200
```

### C~D. 거래 성격
- **현금**: 리스료 지급만
- **비현금**: **리스 개시 시 자산·부채 동시 인식**(가장 중요), 감가상각, 리스부채 이자, 리스 조건 변경

### E. BS 증감 사용 가능성
**불가능** ❌

**WHY**: 리스 개시는 현금이 전혀 안 움직이는데 자산·부채가 동시에 크게 증가한다. BS 증감을 현금흐름으로 보면 **존재하지 않는 현금흐름을 만들어낸다**.

### F. Bridge
```
기초 리스부채
+ 신규 리스 인식액              ← 비현금 (주석 공시 대상)
+ 리스부채 이자비용             ← 비현금 (또는 이자지급으로 별도)
- 리스료 지급액 (현금)          ← 재무활동 유출
± 리스 조건 변경                ← 비현금
± 환율변동 (외화 리스)          ← 비현금
= 기말 리스부채
```

### G. 분류
**재무활동** — 리스부채의 상환
파일: 전체표 `D821 리스부채의 감소 = 정산자료!AF393` = 144,249,737,720 `[파일 확인]`

> [!note] 참고
> **WHY 재무활동인가**: 리스는 경제적 실질이 **자산을 담보로 한 차입**이다. 따라서 원금 상환분은 재무활동으로 분류한다. 이자 부분은 정책에 따라 영업 또는 재무활동. `[일반 원칙]`

### H. 현재 정산표에서의 처리 `[파일 확인]`

정산자료 393행(리스부채):

| 열 | 금액 | 의미 |
|---|---|---|
| J (기초) | 571,539,820,494 | |
| K (기말) | 548,708,808,522 | |
| M (증감) | **−22,831,011,972** | BS 증감 |
| **AF (상환)** | **144,249,737,720** | **재무활동 유출** |
| AI | −2,357,876,585 | 비현금 |
| **AL** | **119,060,849,162** | **신규 리스 인식 (비현금)** |

하위 명세 `[파일 확인]`:
```
394행: AI = 1,027,450,599,  AL = 81,769,028,900   ← Key-in
395행: AL = 37,291,820,263
396행: AI = -3,385,327,184
```

**원천 시트 확인** — `리스부채지급내역_M` `[파일 확인]`:
```
"리스의 총 현금유출"  개별(별도) = 144,249,737,720
                      개별(연결) = 150,083,031,480.43
리스관련 지급금액(2026년.2Q) = 145,087,922,743
```
→ 정산자료 AF393(144,249,737,720)과 M시트의 별도 기준 총현금유출이 **정확히 일치**한다 ✅

> [!note] 참고
> **극적인 관찰**: BS 증감은 −228억에 불과하지만 실제 현금 유출(리스료 지급)은 **1,442억**이다. 차이 약 1,214억은 **신규 리스 인식(AL, 비현금)** 때문이다. BS 증감만 쓰면 리스 현금유출이 약 1/6로 과소 표시된다. `[파일 확인]`

### I. 검토 시 주의사항
1. **신규 리스 인식은 비현금거래 주석 공시 대상**이다. `[일반 원칙]` (K-IFRS 1007호 문단 43)
2. **리스료 총액 vs 원금분**: CF에 표시할 금액이 총 지급액인지 원금 상환분인지 정책 확인. 파일은 총현금유출(144,249,737,720)을 사용 `[파일 확인]`.
3. **소액·단기리스**: 인식 면제 대상은 영업활동 비용으로 처리. M시트에 `임차관리비는 리스관련 대상이 아님`, `해외점포 소액리스료 처리계정` 등 주석이 있다 `[파일 확인]`.
4. **연결과 별도의 차이**: M시트에 별도(144,249,737,720)와 연결(150,083,031,480) 두 숫자가 병기되어 있다 `[파일 확인]`. 본 파일은 **별도** 기준이므로 별도 숫자를 사용해야 한다.

## 🔁 Roll-forward 공식 (원본 10장) ★

★ = BS 증감과 현금흐름 괴리가 특히 큰 계정

```
기초 리스부채
+ 신규 리스 인식                       ← 비현금! (주석 공시)
+ 리스부채 이자                        ← 비현금
- 리스료 지급 (현금유출, 재무활동)
± 리스 조건 변경                       ← 비현금
± 환율변동                             ← 비현금
= 기말 리스부채
```

## ⚠️ BS증감 ≠ CF 사례 (원본 5장, 유형 3 — 비현금 인식이 개입)

| 계정 | BS 증감 | 실제 현금유출 | 차이 |
|---|---|---|---|
| **리스부채** | −22,831,011,972 | **144,249,737,720** | 신규리스 인식 AL 119,060,849,162 |

> [!note] 참고
> **교훈**: 리스 개시는 현금이 0인데 부채가 늘어난다. BS 증감을 쓰면 현금유출이 약 1/6로 과소 표시된다. `[파일 확인]`

## ✅ 검토 체크리스트 (원본 14장 — 리스)

- [ ] **신규 리스 인식을 비현금으로 처리했는가** (가장 흔한 오류)
- [ ] 신규 리스 인식을 주석에 공시했는가
- [ ] 리스료 지급액이 M시트와 일치하는가
- [ ] 소액·단기리스 면제분을 구분했는가

## 🔷 리스 자체의 회계처리는 별도 정본으로

이 카드는 **리스가 현금흐름표에 어떻게 나타나는가**만 다룬다. 그 앞단 — 계약대장 설계, 사용권자산 4구성요소 분해, 임차보증금 현재가치평가(선급리스료 전환), 월별 결산분개 9종, 개시·갱신·해지 분개, 만기구조 주석(COUNTA 버킷팅), 롤포워드 3중 tie-out, 연결 내부리스 제거 — 은 **[[리스회계-K-IFRS1116]]** 이 담당한다.

CF 관점에서 그 문서로부터 반드시 가져올 3가지:

| 논점 | 내용 |
|---|---|
| **리스부채 총액 계상 구조** | 리스부채(미할인 총액) + 현재가치할인차금(차감계정) 방식이면, **임차료 지급 분개가 전액 리스부채 차감**이 된다. 이 구조를 모르면 정산표에서 상환액을 잘못 집계한다 |
| ⚠️ **미할인 vs 할인** | **만기구조 주석 총계 ≠ BS 리스부채 장부금액.** 차액 = 현재가치할인차금 잔액. 둘을 대사하려다 헤매는 것이 가장 흔한 실수 |
| **사용권자산 취득 = 0이 정상** | 신규 리스는 현금 이동이 없으므로 투자활동에 나타나지 않는다. 0이 아니면 그 자체가 이상신호 |

> [!warning] 주의
> ⚠️ `[K-IFRS 1116.6]` **단기리스·소액리스 면제분**과 **변동리스료**는 리스부채가 아니므로 **재무활동이 아니라 영업활동 유출**이다. 3분류 혼동 주의.
> 리스 해지 시 사용권자산 장부금액과 리스부채 잔액의 **차액은 당기손익**(1116.46) → 조정사항에서 제거 대상.
