# 8. 환율변동효과

## 8-1. 왜 별도 표시하는가 `[일반 원칙]`

K-IFRS 제1007호 문단 28:
> 외화로 표시된 현금및현금성자산의 환율변동효과는 **영업·투자·재무활동 현금흐름과 구분하여 별도로 표시**한다.

**WHY**: 환율이 변해서 외화현금의 원화 환산액이 커진 것은 **현금이 들어온 것이 아니다**. 달러 100은 그대로 100인데 원화 표시만 커졌을 뿐이다. 이를 영업활동 등에 포함하면 실제로 벌지 않은 현금을 벌었다고 표시하게 된다.

**동시에 무시할 수도 없다**: 기초현금 + 3대 활동 = 기말현금이 성립하지 않기 때문이다. 그 차이가 바로 환율효과다. 그래서 **별도 라인으로 표시하되 순증감 계산(I+II+III)에서는 제외**하는 독특한 구조를 갖는다.

## 8-2. 파일에서의 환율효과 산출 `[파일 확인]`

```
전체표 D848  외화표시 현금및현금성자산에 대한 환율변동효과
             = −정산자료!P8 + 정산자료!S8 + 정산자료!AI8
             = 364,097,508,327
```

구성 요소:

| 항목 | 값 | 의미 |
|---|---|---|
| 정산자료 P8 | 145,009,132,774 | 현금성자산 관련 비현금비용 |
| 정산자료 S8 | 436,994,207,084.84 | 현금성자산 관련 비현금수익 |
| 정산자료 AI8 | 72,112,434,017 | 현금성자산 해외사업환산차대 |

AI8의 하위 구성 `[파일 확인]`:
```
AI9  현금                    0
AI10 외국통화               70,151,668
AI11 사용가능원화예치금     251,383,107
AI12 사용가능외화예치금  71,790,899,243   ← 대부분
AI13 사용가능역외외화예치금       0
AI14 외국통화                    0
```
각각 `=SUMIF(M해외사업환산차대!A:A, 계정코드, M해외사업환산차대!T:T)` 형태로 산출된다.

> **관찰**: 환율효과의 대부분(718억)이 **사용가능외화예치금**에서 나온다. 외화예치금 잔액이 기초 5.5조 → 기말 10.1조로 급증한 것과 관련이 있다 `[논리 추론]`.

## 8-3. 환율효과와 환산차대의 구분 — 가장 헷갈리는 지점

두 개념이 자주 혼동된다. 명확히 구분하자. `[일반 원칙]`

| 구분 | 외화환산손익 | 해외사업환산차대 |
|---|---|---|
| **대상** | 개별 외화 자산·부채 | **해외사업장(지점) 전체** |
| **귀속** | **당기손익 (PL)** | **기타포괄손익 (OCI, 자본)** |
| **CF 처리** | 손익조정에서 제거 | **당기순이익에 없으므로 조정 대상 아님** |
| **파일 위치** | 공시용 CF 17행 `(12) 외화환산손익 154,628` | M해외사업환산차대 시트 |

> **핵심**: 간접법은 **당기순이익**에서 출발한다. 따라서 당기순이익에 있는 외화환산손익은 제거하지만, 당기순이익에 없는 해외사업환산차대는 **제거 대상이 아니다**. 제거하면 오히려 이중조정이 되어 기말현금이 어긋난다.

이 원리가 [[CF계정-파생상품|파생상품 카드]]에서 본 파생상품 환산차대 처리(전체표 D349 = S189 − U187)의 근거다.

## 8-4. 환율효과 검증 방법 `[논리 추론]`

```
검증식: 기초현금 + 영업CF + 투자CF + 재무CF + 환율효과 = 기말현금(원장)

파일에서:
  D850 기초현금        18,696,558,273,378
  D849 순증감           4,493,300,539,052  (= E5+E716+E764+D848)
  D851 기말현금        23,189,858,812,430
  D853 원장 기말현금   23,189,858,812,430
  D852 검증                          True  ✅
```

환율효과가 정확히 산출되었는지는 **이 최종 등식으로만 검증 가능**하다. 환율효과 자체를 독립적으로 검증하기는 어렵기 때문에, 다른 모든 항목이 정확하다는 전제 하에 잔차로 확인하는 구조다.

> **주의** `[논리 추론]`: 이 구조의 약점은 **다른 곳의 오류가 환율효과로 흡수될 수 있다**는 점이다. 환율효과 금액이 전기 대비 비정상적으로 크거나 작다면, 다른 계정의 오류가 숨어 있을 가능성을 의심해야 한다.

## 🔷 8-5. 환율효과를 "차액"이 아니라 "설명 가능한 값"으로 만드는 기법

> 출처: [[현금흐름표_정산표_학습레포트-소스요약]] (금융지주 연결 FY25 1Q)

§8-4에서 지적한 약점 — **다른 곳의 오류가 환율효과로 흡수될 수 있다** — 에 대한 실무 해법이다.

### 논리

1. **PL의 외화환산손익**은 조정사항으로 제거한다.
2. 그러나 **BS 계정별로 배분한 외화환산 조정액의 총합**과 **PL 총액**은 다르다.
3. 그 차이가 곧 **현금및현금성자산 자체의 환율변동효과**다.
4. `[K-IFRS 1007.28]` 외화표시 현금및현금성자산의 환율변동효과는 영업·투자·재무와 **구분하여 별도 표시**한다.

### 구현 — 논리 등식으로 증명

```text
E424 (조정사항 '외화환산손익')     = 외화환산손실 − 외화환산이익 = −4,180,028,087
H424 (계정별 배분 외화환산 총합)   = +4,579,310,869
H425 = H424 − E424                 =  8,759,338,956
I417 = 조정사항 총액 차이           =  8,759,338,956

H426 = (H425 = I417) → TRUE        ← ★ 논리검증
F491 (환율변동효과)                 =  8,759,338,956.77
```

> 💡 **학습 포인트**: 환율변동효과를 "그냥 차액"으로 밀어 넣는 파일이 많다. 이 파일은 **`H425 = I417`이라는 논리 등식으로 그 차액이 설명 가능함을 증명**한다. 자작성 시 반드시 모방할 기법이다.
> ⚠️ 단, 같은 수식 안에 `−0.75`라는 **하드코딩 상수**가 박혀 있었다. 단수차이 조정용으로 보이나 **하드코딩된 plug는 반드시 코멘트로 근거를 남겨야** 한다. → [[CF-검증체계와-단수조정]] §4·§6
