# 02. 대출채권 — 은행 CF의 심장

> ## 📌 요약 박스
> - **CF 분류**: **영업활동** → 3. 자산·부채의 증감 → (3) 대출채권
> - **BS증감 그대로 사용 가능?**: **일부 조정 필요** ⚠️ (BS +7.8조 vs 실제 CF −6.3조, 부호까지 반대)
> - **핵심 조정항목**: ① 대손 제각(상각)액 복원 ② 대손충당금 증감 ③ 현재가치할인차금 상각·외화대출 환율변동
> - **가장 흔한 실수**: 대손상각(제각)액 누락 — 장부금액은 줄지만 현금은 안 나가므로 반드시 복원해야 함

---

## A. 계정의 경제적 실질

은행의 **주된 수익창출 자산**이다. 제조업의 매출채권과 형태는 비슷하지만 성격이 근본적으로 다르다.

| 구분 | 제조업 매출채권 | 은행 대출채권 |
|---|---|---|
| 발생 원인 | 매출의 부산물 (외상판매) | **그 자체가 상품** (여신 실행) |
| 수익 인식 | 매출액 인식 시점 | 기간 경과에 따른 **이자수익** |
| CF 분류 | 영업활동 (매출채권 증감) | **영업활동** (대출채권 증감) |
| 규모 | 총자산의 일부 | **총자산의 대부분** (파일: 350조 / 비중 압도적) |

> **WHY 영업활동인가**: 대출 실행은 은행의 주요 수익창출활동이다. 제조업이라면 "자금 대여 = 투자활동"이지만, 은행에게 대출은 재고자산을 파는 것과 같은 본업이다. `[일반 원칙]`

### B. 일반적인 회계처리

```
① 대출 실행 (현금거래)
   (차) 대출채권        824    (대) 현금          824

② 이자 수취 (현금거래)
   (차) 현금            50     (대) 이자수익       50

③ 미수이자 인식 (비현금)
   (차) 미수수익        10     (대) 이자수익       10

④ 대손충당금 설정 (비현금)
   (차) 대손상각비      30     (대) 대손충당금      30

⑤ 대손확정 상각 (비현금 — 총액 감소)
   (차) 대손충당금      20     (대) 대출채권       20

⑥ 원금 회수 (현금거래)
   (차) 현금          300     (대) 대출채권      300
```

### C. 현금이 움직이는 거래
- 대출 실행 (현금 유출)
- 원금 회수 (현금 유입)
- 이자 수취 (현금 유입)

### D. 비현금거래
- **대손충당금 설정/환입** (④)
- **대손확정 상각** (⑤) — 장부금액은 줄지만 현금은 안 움직임
- **현재가치할인차금 상각**
- **외화대출의 환율변동**
- **연체이자 자본화 / 재약정에 따른 계정 대체**

### E. BS 증감을 그대로 현금흐름으로 쓸 수 있는가?
**일부 조정 필요** ⚠️

이유: 대출채권 장부금액 변화에는 ①실제 현금 대출/회수 외에 ②대손상각 ③충당금 변동 ④환율변동 ⑤계정대체가 섞여 있다.

**예시로 보는 오류:**
```
기초 대출채권   824
당기 신규대출  +500 (현금유출)
당기 원금회수  -300 (현금유입)
대손상각      -50  (비현금)
기말 대출채권    948

BS 증감 =   948 -   824 = +150
→ 이걸 그대로 쓰면 "현금 150 유출"로 표시됨 ❌

실제 현금흐름 = -500 + 300 = -200 (현금 200 유출) ✅
차이 50 = 대손상각(비현금)
```
→ **조정 안 하면 현금흐름이 50만큼 과소 표시된다.**

### F. 필요한 현금흐름 조정 (Bridge)

```
기말 대출채권 (총액)
- 기초 대출채권 (총액)
= BS 증감
  + 대손상각(제각)액              ← 비현금 감소분 복원
  ± 대손충당금 증감                ← 비현금
  ± 현재가치할인차금 상각          ← 비현금
  ± 외화대출 환율변동효과          ← 비현금
  ± 계정대체 (정상↔부실 재분류)   ← 비현금
= 실제 대출 순현금흐름
```

### G. 현금흐름표 분류
**영업활동 → 3. 자산·부채의 증감 → (3) 대출채권**
파일 확인: `공시용 CF` 23행 `(3) 대출채권 -6,463,399` (백만원) `[파일 확인]`

### H. 현재 정산표에서의 처리 `[파일 확인]`

정산자료 99행(대출채권 소계) 실제 값:

| 열 | 금액 | 의미 |
|---|---|---|
| J (기초) | 342,909,833,753,741 | 전기말 잔액 |
| K (기말) | 350,772,615,234,045 | 당기말 잔액 |
| M (증감) | 7,862,781,480,304 | BS 증감 (+7.8조) |
| **P** (비현금비용) | 452,391,342,240 | 대손상각비 등 가산 |
| **S** (비현금수익) | 1,289,167,584,517 | 충당금환입·현할차상각 등 차감 |
| **U** (자산부채증감) | **-6,383,960,148,742** | **영업활동 현금흐름** |
| **AI** (비현금 차변) | 915,081,400,183 | 비현금 대체 |
| **AL** (비현금 대변) | 273,036,310,899 | 비현금 대체 |

**검증**: `M + P − S + U − AI + AL = 0`
```
7,862,781,480,304 + 452,391,342,240 − 1,289,167,584,517
+ (−6,383,960,148,742) −   915,081,400,183 + 273,036,310,899 ≈ 0 ✅
```

> **핵심 관찰**: BS 증감은 **+7.8조**인데 실제 영업 현금흐름(U열)은 **−6.3조**다. 부호까지 반대다! 이것이 "BS 증감 ≠ 현금흐름"의 가장 극적인 사례다. 차이 약 14조는 비현금 항목(P, S, AI, AL)으로 설명된다. `[파일 확인]`

### I. 검토 시 주의사항

1. **총액 기준인가 순액 기준인가**: 대출채권을 대손충당금 차감 후 순액으로 볼지, 총액으로 볼지에 따라 조정 내용이 달라진다. 파일은 총액 계정과 충당금 계정을 별도 행으로 분리하는 방식으로 보인다 `[논리 추론]`.
2. **대손상각(제각)액 누락**: 가장 흔한 오류. 제각은 장부금액을 줄이지만 현금이 안 나가므로 반드시 복원해야 한다.
3. **외화대출 환율효과**: 외화대출 비중이 크면 환율변동만으로 원화 장부금액이 크게 변한다. 이를 영업 현금흐름으로 오인하면 심각한 왜곡이 발생한다.
4. **미수이자와의 구분**: 이자수익 중 미수분은 대출채권이 아니라 미수수익 계정에서 관리되는지 확인.
5. **부실채권 매각**: 대량 매각 시 투자활동으로 볼 것인지 영업활동으로 볼 것인지 판단 필요. `[확인 필요]`

★ = BS 증감과 현금흐름 괴리가 특히 큰 계정

```
기초 대출채권(총액)
+ 신규 대출 실행 (현금유출)
- 원금 회수 (현금유입)
- 대손 제각(상각)                      ← 비현금
± 대손충당금 증감                      ← 비현금
+ 현재가치할인차금 상각                ← 비현금
± 외화대출 환율변동                    ← 비현금
± 정상↔부실 계정대체                   ← 비현금
= 기말 대출채권(총액)
```

## ⚠️ BS증감 ≠ CF 사례 (원본 5장, 유형 1 — 부호까지 뒤집히는 경우)

| 계정 | BS 증감(M) | 실제 CF(U) | 차이 원인 |
|---|---|---|---|
| **대출채권** | +7,862,781,480,304 | **−6,383,960,148,742** | 대손상각·충당금·현할차 |

> **교훈**: 부호가 반대인 경우가 실제로 존재한다. BS 증감을 그대로 쓰면 "현금이 들어왔다"와 "나갔다"가 뒤바뀐다. `[파일 확인]`
