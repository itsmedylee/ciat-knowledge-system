# 05. 유가증권 ② FVOCI (기타포괄손익-공정가치측정)

> ## 📌 요약 박스
> - **CF 분류**: **투자활동** — 취득/처분 **총액표시**
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (BS 순증감 −2,922억 vs 총액 21조 규모)
> - **핵심 조정항목**: ① 취득/처분 총액 파악(M시트) ② OCI 평가손익은 **손익조정 대상 아님** ③ 현할차 상각·손상·환율변동
> - **가장 흔한 실수**: OCI 평가손익을 손익조정에 넣는 것 — 당기순이익에 없는 것을 빼면 이중조정이 된다

---

## A. 계정의 경제적 실질
**장기 투자 및 유동성 관리 목적**으로 보유. 평가손익이 당기손익이 아닌 **기타포괄손익(OCI, 자본)**으로 간다는 점이 결정적 차이다.

### B. 일반적인 회계처리
```
① 취득 (현금)
   (차) FVOCI금융자산    824    (대) 현금          824
② 공정가치 평가 (비현금, OCI!)
   (차) FVOCI금융자산    50     (대) 기타포괄손익   50   ← 당기순이익 아님!
③ 처분 (현금)
   (차) 현금            907    (대) FVOCI금융자산   865
                                (대) 처분이익        50
```

### C~D. 현금거래 vs 비현금거래
- **현금**: 취득, 처분
- **비현금**: **공정가치 평가손익(OCI)**, 환율변동, 손상, 현재가치할인차금 상각

### E. BS 증감 사용 가능성
**불가능** ❌ — 반드시 총액 조정 필요

**WHY**: 두 가지 이유가 겹친다.
1. 투자활동은 **총액표시**가 원칙이므로 취득액과 처분액을 각각 파악해야 한다. BS 순증감으로는 총액을 알 수 없다.
2. 평가손익이 **OCI(자본)**로 가므로 당기순이익에 없다. 따라서 **손익조정 대상이 아니면서도** 장부금액은 변화시킨다.

> **핵심 함정**: FVPL 평가손익은 당기순이익에 있으므로 손익조정에서 제거해야 하지만, **FVOCI 평가손익은 당기순이익에 애초에 없으므로 제거 대상이 아니다.** 간접법은 당기순이익에서 출발하므로, 순이익에 없는 것을 빼면 오히려 틀린다. `[일반 원칙]`

### F. Bridge (Roll-forward)

```
기초 FVOCI 장부금액
+ 현금 취득액                    ← 투자활동 유출 (Z열)
- 현금 처분액 (장부금액 기준)     ← 투자활동 유입 (W열)
+ 공정가치 평가손익 (OCI)         ← 비현금 (당기순이익 아님)
+ 환율변동효과                    ← 비현금
+ 현재가치할인차금 상각            ← 비현금
- 손상차손                        ← 비현금
= 기말 FVOCI 장부금액
```

### G. 분류
**투자활동** — 취득/처분 총액표시
파일: `공시용 CF` 33~34행 `(3) 투자금융상품의 처분 16,319,572 / (4) 투자금융상품의 취득 -19,072,716` `[파일 확인]`

> **극적인 관찰**: BS 순증감은 −2,922억에 불과하지만, 실제 투자활동 현금흐름은 **처분 10.9조 / 취득 10.5조**로 총액이 21조에 달한다. 순증감만 보면 이 은행이 연간 21조 규모의 투자증권을 회전시킨다는 사실이 완전히 가려진다. `[파일 확인]`
>
> **이것이 총액표시를 요구하는 이유이자, M시트(유가_M)가 필요한 이유다.**

### I. 검토 시 주의사항
1. **총액 파악의 원천**: BS만으로는 절대 알 수 없다. `유가_M`, `FVOCI사모사채 취득처분_M` 시트가 이 정보를 제공한다 `[파일 확인]`.
2. **처분액 기준**: 처분 현금유입액인지 처분된 자산의 장부금액인지 구분. Roll-forward에는 장부금액, CF 표시에는 현금유입액.
3. **OCI 평가손익을 손익조정에 넣는 오류**: 당기순이익에 없는 것을 빼면 이중조정이 된다.
4. **재분류조정(recycling)**: 처분 시 OCI에 누적된 평가손익이 당기손익으로 재순환되는 경우, 이는 당기순이익에 포함되므로 조정 대상이 된다. `[확인 필요]` 파일의 `기타포괄손익_M` 시트에서 확인 필요.

## 🔁 Roll-forward 공식 (원본 10장) ★

★ = BS 증감과 현금흐름 괴리가 특히 큰 계정

```
기초 FVOCI
+ 취득 (현금유출, 투자활동 총액)
- 처분(장부금액) (현금유입, 투자활동 총액)
± 공정가치 평가손익 (OCI)              ← 비현금, 당기순이익에 없음 → 손익조정 대상 아님!
+ 현할차 상각                          ← 비현금 (당기손익)
- 손상차손                             ← 비현금 (당기손익)
± 환율변동                             ← 비현금
= 기말 FVOCI
```

## ⚠️ BS증감 ≠ CF 사례 (원본 5장, 유형 2 — 총액이 순액에 가려지는 경우)

| 계정 | BS 순증감 | 총액 (취득/처분) | 배율 |
|---|---|---|---|
| **FVOCI** | −292,203,591,344 | 처분 10.9조 / 취득 10.5조 | **약 73배** |

> **교훈**: 순증감만 보면 실제 거래 규모가 완전히 은폐된다. 투자·재무활동에 총액표시를 요구하는 이유다. `[파일 확인]`

## ✅ 검토 체크리스트 (원본 14장 — 유가증권 중 FVOCI 항목)

- [ ] **FVOCI 평가손익(OCI)을 손익조정에 넣지 않았는가** (넣으면 이중조정)
- [ ] FVOCI·AC 취득/처분을 총액으로 파악했는가
- [ ] 현재가치할인할증차금 상각을 조정했는가
- [ ] 처분 시 재분류조정(recycling) 처리가 맞는가
