# 1. 은행 현금흐름표 전체 구조

## 1-1. 왜 은행 현금흐름표는 어려운가

제조업 현금흐름표는 "영업(본업) + 투자(설비) + 재무(자금조달)"라는 직관이 통한다. 그런데 은행은 **돈 자체가 상품**이다. 대출을 내주는 것이 설비투자가 아니라 본업이고, 예금을 받는 것이 차입이 아니라 본업이다. 이 지점에서 일반적 직관이 무너진다.

여기서 은행 CF의 첫 번째 원칙이 나온다. `[일반 원칙]`

> [!note] 참고
> **금융회사의 영업활동 범위는 제조업보다 훨씬 넓다. 대출채권·예수부채·단기매매증권처럼 "제조업이라면 투자·재무활동일 것"이 은행에서는 영업활동이 된다.**

이유는 K-IFRS 제1007호가 활동 분류의 기준을 **"기업의 주요 수익창출활동인가"**에 두기 때문이다. 대출·예금은 은행의 주요 수익창출활동 그 자체이므로 영업활동이다.

## 1-2. 은행 CF 공시 양식의 3단 구조 `[파일 확인]`

제공 파일의 `공시용 CF` 시트를 보면 은행 표준 양식이 명확히 드러난다. (단위: 백만원)

```
Ⅰ. 영업활동으로부터의 현금흐름                     8,772,898
   1. 당기순이익                                  1,446,464
   2. 손익조정사항                                  741,894   ← 비현금손익 제거 (14개 항목)
   3. 자산·부채의 증감                             6,584,540   ← 영업용 자산·부채 순증감 (9개 항목)

Ⅱ. 투자활동으로부터의 현금흐름                    -2,739,609   ← 총액표시 (처분/취득 각각)
Ⅲ. 재무활동으로부터의 현금흐름                    -1,982,629   ← 총액표시 (증가/감소 각각)
Ⅳ. 외화표시 현금및현금성자산에 대한 환율변동효과       364,098   ← 별도 표시 (현금흐름 아님)
Ⅴ. 현금및현금성자산의 순증감 (I+II+III)            4,414,758
Ⅵ. 기초 현금및현금성자산                          18,695,922
   기말 현금및현금성자산                          23,110,680
```

이 구조에서 반드시 기억할 두 가지:

**(1) 영업활동의 3단 구조가 곧 간접법의 전부다**
```
당기순이익  →  ± 손익조정(비현금손익 제거)  →  ± 자산·부채 증감  =  영업활동 현금흐름
```
- **2단(손익조정)**: PL에 있지만 현금이 안 오간 손익을 걷어낸다 (감가상각비, 평가손익, 충당금전입 등)
- **3단(자산부채증감)**: BS 변화 중 영업 관련분을 반영한다 (대출채권·예수부채 증감 등)

**(2) Ⅳ 환율변동효과는 "현금흐름이 아니다"**
Ⅴ 순증감 계산식이 `(I + II + III)`로 **Ⅳ를 제외**하고 있다는 점에 주목하라. 환율효과는 현금이 오간 것이 아니라 기존 외화현금의 원화 환산액만 바뀐 것이므로, 3대 활동과 **구분 표시**한다. `[일반 원칙]` (K-IFRS 제1007호 문단 28)

## 1-3. 파일의 5개 레이어 구조 `[파일 확인]`

52개 시트가 구분자 시트(`▶▶▶`, `=>`)로 명확히 계층화되어 있다.

| 레이어              | 대표 시트                                                                                                      | 역할                                                    |
| ---------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **① 원천 데이터**     | `BSPL_2025.4Q`(전기말), `BSPL_2026.2Q`(당기말): 각 14,928행                                                       | 계정코드별 원장 잔액·손익. 모든 숫자의 뿌리                             |
| **② 수기작성(M) 보조** | `유형자산_M`, `유가_M`, `보증금_M`, `리스부채지급내역_M`, `사채_M`, `지분법_M`, `충당금변동표_M`, `M해외사업환산차대`, `M 38.재무활동(파생)` 등 20여 개 | **BS 증감만으로 알 수 없는 정보**(총액 취득/처분, 비현금 대체, 환산차대)를 별도 산출 |
| **③ 정산표(엔진)**    | **`정산자료`** (849행 × 50열)                                                                                    | 계정을 세로로 세우고 증감을 현금/비현금으로 분해하는 **핵심 워크시트**             |
| **④ 집계**         | `전체표`(864행) → `흐름자료_최종단수조정`(274행)                                                                          | CF 항목코드(CF10000~)로 재집계 → 백만단위 환산·단수조정                 |
| **⑤ 공시**         | `공시용 CF`(64행)                                                                                              | 은행 표준 양식 최종 산출물                                       |

**데이터 흐름**
```
BSPL_2025.4Q (전기말) ┐
BSPL_2026.2Q (당기말) ┼→ 정산자료 → 전체표 → 흐름자료_최종단수조정 → 공시용 CF
M시트 20여개 (보조)   ┘    (엔진)     (CF코드)     (백만단위·단수조정)      (공시)
```

정산자료의 외부 참조 빈도를 집계하면 이 구조가 그대로 확인된다. `[파일 확인]`

| 참조 대상 | 횟수 | 의미 |
|---|---|---|
| `BSPL_2026.2Q` | 438회 | 당기말 잔액·당기 손익 |
| `BSPL_2025.4Q` | 266회 | 전기말 잔액 |
| `M해외사업환산차대` | 187회 | 환산차대 (해외지점 환율효과) |
| `유형자산_M` | 45회 | 유형자산 총액 취득/처분 |
| `외화자산부채평가손익` | 44회 | 외화평가손익 |
| `영업보고서(통합)` | 36회 | 상세 손익 데이터 |
| `유가_M`, `기타포괄손익_M` | 각 16회 | 유가증권 취득/처분, OCI |

> [!note] 참고
> **학습 포인트**: M시트가 20여 개나 있는 이유가 곧 이 자료의 핵심 주제다. **BS 증감만으로는 현금흐름을 알 수 없는 계정이 그만큼 많다**는 뜻이다. 어느 계정에 M시트가 붙어 있는지를 보면, 그 계정이 "BS 증감 ≠ 현금흐름"인 계정임을 역으로 알 수 있다.
