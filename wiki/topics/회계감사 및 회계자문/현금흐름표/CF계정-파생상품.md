# 07. 파생상품 (매매목적 / 위험회피)

> ## 📌 요약 박스
> - **CF 분류**: **분리**. 매매목적→**영업활동**, 공정가치위험회피→**투자/재무활동**, 현금흐름위험회피→**재무활동**
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (평가손익 P 4.4조·S 5.4조가 BS 증감 3.1조보다 큼)
> - **핵심 조정항목**: ① 공정가치 평가손익 제거 ② 해외사업환산차대(OCI, 손익조정 대상 아님) ③ 3분류 정확성
> - **가장 흔한 실수**: 3분류(매매/공정가치위험회피/현금흐름위험회피)를 잘못 분류하거나, 환산차대(OCI)를 손익조정에 포함하는 것

---

## A. 계정의 경제적 실질

파생상품은 **보유 목적에 따라 완전히 다른 계정**으로 취급해야 한다.

| 유형 | 목적 | 평가손익 귀속 | CF 분류 |
|---|---|---|---|
| **매매목적** | 트레이딩 수익 | 당기손익 | **영업활동** |
| **공정가치위험회피** | 자산·부채 공정가치 변동 위험 회피 | 당기손익 (회피대상과 상계) | 회피대상 성격 따름 (**투자/재무**) |
| **현금흐름위험회피** | 미래 현금흐름 변동 위험 회피 | **OCI** (효과적 부분) | **재무활동** |

### B~D. 거래 성격
- **현금**: 계약 체결 시 프리미엄 수수, 결제(정산) 시 현금 수수
- **비현금**: **공정가치 평가손익**(대부분), 외화 파생의 환율변동/환산차대

### E. BS 증감 사용 가능성
**불가능** ❌: 평가손익이 압도적으로 크다

### F. Bridge
```
기초 파생상품자산(부채)
+ 신규 계약 프리미엄 (현금)
- 결제/청산 (현금)
+ 공정가치 평가손익                ← 비현금 (금액이 매우 큼)
+ 환율변동 / 해외사업환산차대       ← 비현금
= 기말 파생상품자산(부채)
```

### G. 분류 (3분류) `[파일 확인]`

### H. 현재 정산표에서의 처리 `[파일 확인]`

> [!note] 참고
> **관찰**: P와 S가 각각 4.4조, 5.4조로 **BS 증감(3.1조)보다도 크다**. 파생상품은 평가손익이 장부금액 변화를 압도하는 대표적 계정이다. BS 증감을 현금흐름으로 쓰면 완전히 틀린다. `[파일 확인]`

**공정가치위험회피 파생자산 (187행)**: 특별히 중요한 사례

| 열 | 금액 |
|---|---|
| M (증감) | −1,954,156,198 |
| P | 59,621,928,881 |
| S | 22,194,898,077 |
| **U** | **15,658,562** ← 해외사업환산차대 |
| W | 1,182,244,972 |
| AF | 36,655,119,578 |
| **AI** | **15,658,562** ← U와 동일 금액 |

하위 명세: `[파일 확인]`
```
188행 (거래)          S = 19,414,841,661
189행 (평가)          S =  2,780,056,416  ← BSPL 원장값 (환산차대 포함)
190행 (환산대차)      AI = 15,658,562, U = 15,658,562, N = 0
```

**190행의 구조가 정산표 설계의 정수(精髓)다.**
- AI(비현금 차변)로 환산차대 15,658,562이 들어옴
- U(자산부채증감)로 같은 금액이 나감
- N열 검증식에서 `+U − AI`이므로 **자동 상쇄되어 N190 = 0**
- 즉 **환산차대가 계정 내부에서 자기완결**된다

전체표 D349: `= 정산자료!S189 − 정산자료!U187` = 2,780,056,416 − 15,658,562 = **2,764,397,854** `[파일 확인]`

> [!note] 참고
> **WHY 환산차대를 빼는가**: 해외사업환산차대는 당기순이익이 아니라 **기타포괄손익(자본)** 항목이다. 간접법은 당기순이익에서 출발하므로, 당기순이익에 없는 환산차대는 **손익조정 대상이 아니다**. 따라서 비현금수익 차감액에서 제외해야 한다.
>
> 검증: 이 처리 상태에서 계산 기말현금이 원장과 정확히 일치(차이 0)한다 `[파일 확인]`. 반대로 환산차대를 빼지 않으면 기말현금이 15,658,562원 어긋난다.

### I. 검토 시 주의사항
1. **3분류 정확성**: 매매목적/공정가치위험회피/현금흐름위험회피 구분이 CF 분류를 결정한다.
2. **평가손익과 자산증감의 짝 맞추기**: 평가손익을 S열에서 빼면 U열(자산증감)에 대응이 있어야 한다. 짝이 없으면 기말현금이 어긋난다.
3. **환산차대의 OCI 성격**: 당기순이익에 없는 항목을 손익조정하면 이중조정이 된다.
4. **위험회피회계 중단**: 회계 중단 시 재분류가 발생하며 비현금 대체로 처리해야 한다. `[확인 필요]`
