# 04. 유가증권 ① FVPL (당기손익-공정가치측정)

> ## 📌 요약 박스
> - **CF 분류**: **영업활동** → 3. 자산·부채의 증감 → (1) 당기손익인식금융자산 (트레이딩 = 본업)
> - **BS증감 그대로 사용 가능?**: **일부 조정 필요** ⚠️ (BS +1.01조 vs 실제 CF −1.57조, 부호 반대)
> - **핵심 조정항목**: ① 공정가치 평가손익 제거 ② 외화증권 환율변동 ③ 현재가치할인차금 상각
> - **가장 흔한 실수**: 평가손익을 완전히 제거하지 못하는 것. 원화/외화/외국 증권별로 계정이 나뉘어 있어 누락되기 쉽다

---

## A. 계정의 경제적 실질
**단기 매매차익 목적**으로 보유하는 유가증권. 은행의 트레이딩 부서가 운용한다.

> [!note] 참고
> **WHY 영업활동인가**: 트레이딩은 은행의 주요 수익창출활동이다. 제조업이 여유자금을 주식에 투자하면 투자활동이지만, 은행의 트레이딩 데스크가 채권을 사고파는 것은 본업이다. `[일반 원칙]`

### B. 일반적인 회계처리
```
① 취득 (현금)
   (차) FVPL금융자산     824    (대) 현금          824
② 공정가치 평가 (비현금)
   (차) FVPL금융자산     50     (대) 평가이익       50
③ 처분 (현금)
   (차) 현금            907    (대) FVPL금융자산    865
                                (대) 처분이익        50
```

### C. 현금거래 / D. 비현금거래
- **현금**: 취득, 처분
- **비현금**: 공정가치 평가손익, 외화증권 환율변동, 현재가치할인차금 상각

### E. BS 증감 사용 가능성
**일부 조정 필요** ⚠️: 평가손익을 제거해야 한다.

### F. Bridge
```
기말 FVPL 장부금액
- 기초 FVPL 장부금액
= BS 증감
  - 공정가치 평가이익 (+평가손실)    ← 비현금 제거
  ± 외화증권 환율변동                ← 비현금
  ± 현재가치할인차금 상각            ← 비현금
= FVPL 순현금흐름 (영업활동)
```

### G. 분류
**영업활동 → 3. 자산·부채의 증감 → (1) 당기손익인식금융자산**
파일: `공시용 CF` 21행 `(1) 당기손익인식금융자산 -1,569,161` `[파일 확인]`

### H. 현재 정산표에서의 처리 `[파일 확인]`

정산자료 23행(FVPL 소계):

| 열 | 금액 |
|---|---|
| J (기초) | 18,507,716,325,617 |
| K (기말) | 19,521,209,530,465 |
| M (증감) | **+1,013,493,204,848** |
| P (비현금비용) | 1,258,461,354,242 (평가손 등) |
| S (비현금수익) | 693,759,379,993 (평가익 등) |
| **U (영업CF)** | **−1,569,161,223,121** |
| AI (비현금차변) | 9,033,955,976 |

> [!note] 참고
> **관찰**: BS 증감 +1.01조 → 실제 영업 현금흐름 −1.57조. 여기서도 부호가 반대다. 평가손익(P·S)이 큰 폭으로 개입하기 때문이다. `[파일 확인]`

별도로 `FVPL활동구분_M` 시트가 존재하여 FVPL 내에서도 활동 구분을 별도 관리하고 있다 `[파일 확인]`.

### I. 검토 시 주의사항
1. **평가손익의 완전 제거**: 평가손과 평가익을 모두 찾아 제거했는지. 원화/외화/외국 증권별로 계정이 나뉘어 있어 누락되기 쉽다.
2. **처분손익 처리**: 처분손익은 현금흐름에 이미 반영되어 있으므로 별도 조정 대상이 아니지만, 순이익에서 제거 후 총액으로 표시할지 판단 필요.
3. **FVPL vs FVOCI 분류 변경**: 재분류가 있었다면 비현금 대체로 처리해야 한다.

## 🔁 Roll-forward 공식 (원본 10장)

```
기초 FVPL
+ 취득 (현금유출)
- 처분(장부금액) (현금유입)
± 공정가치 평가손익                    ← 비현금 (당기손익!)
+ 현할차 상각                          ← 비현금
± 환율변동                             ← 비현금
= 기말 FVPL
```

## ⚠️ BS증감 ≠ CF 사례 (원본 5장, 유형 1: 부호까지 뒤집히는 경우)

|---|---|---|---|
| **FVPL** | +1,013,493,204,848 | **−1,569,161,223,121** | 공정가치 평가손익 |
