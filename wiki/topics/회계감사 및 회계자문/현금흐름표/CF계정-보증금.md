# 11. 보증금 (임차보증금)

> ## 📌 요약 박스
> - **CF 분류**: **투자활동** — 신규 지급/회수 총액표시
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (BS −195억 vs 총액 4,252억, 신규 임차와 계약 종료가 동시 발생)
> - **핵심 조정항목**: ① 신규 지급/회수 총액 파악(보증금_M) ② 현재가치할인차금 상각 ③ 대손충당금 설정(비현금)
> - **가장 흔한 실수**: 순증감만 표시해 총액(임차 계약 회전 규모)을 은폐, 또는 대손충당금(비현금)을 투자CF에서 미제거

---

## A. 계정의 경제적 실질
영업점 임차를 위해 임대인에게 맡긴 돈. 계약 종료 시 반환받으므로 **자산**이다.

### B~D. 거래 성격
- **현금**: 보증금 지급(증가), 보증금 회수(감소)
- **비현금**: 현재가치할인차금 상각, 대손충당금 설정, 리스 전환 시 대체

### E. BS 증감 사용 가능성
**불가능** ❌ — 총액표시 필요 (신규 임차와 계약 종료가 동시 발생)

### F. Bridge
```
기초 보증금
+ 신규 보증금 지급 (현금)        ← 투자활동 유출 (Z열)
- 보증금 회수 (현금)             ← 투자활동 유입 (W열)
+ 현재가치할인차금 상각          ← 비현금
- 대손충당금 설정                ← 비현금
= 기말 보증금
```

### G. 분류
**투자활동**
파일: `D733 보증금의 감소 = 정산자료!W210` (226,876,175,266), `D758 보증금의 증가 = 정산자료!Z210` (198,292,013,817) `[파일 확인]`

> **관찰**: BS 증감은 −195억이지만 실제로는 회수 2,269억 / 지급 1,983억으로 **총액 4,252억**이 오갔다. 영업점 임차 계약이 활발히 회전하고 있음이 총액표시로만 드러난다. `[파일 확인]`

### I. 검토 시 주의사항
1. **총액 원천**: `보증금_M` 시트가 신규/회수 총액을 제공 `[파일 확인]`
2. **대손충당금**: 미회수 보증금에 대한 충당금은 비현금
3. **투자 vs 영업 분류**: 보증금을 투자활동으로 볼지 영업활동(기타자산)으로 볼지는 실무상 견해차가 있다. 파일은 **투자활동**으로 처리 `[파일 확인]`. `[확인 필요]` 회사 정책 일관성 확인 권장.

## 🔁 Roll-forward 공식 (원본 10장 — 보증금)

```
기초 보증금
+ 신규 지급 (현금유출, 투자활동)
- 회수 (현금유입, 투자활동)
+ 현할차 상각                          ← 비현금
- 대손충당금 설정                      ← 비현금
= 기말 보증금
```

## ✅ 검토 체크리스트 (원본 14장)

14장에 보증금 전용 체크 항목은 없다. 위 I(검토 시 주의사항)와 투자활동 총액표시 원칙([[CF-활동분류-논리|활동분류논리 3-4]])이 실질적 체크포인트다:
- [ ] 신규 지급/회수를 총액으로 파악했는가(보증금_M 대사)
- [ ] 미회수 보증금 대손충당금(비현금)을 투자CF에서 제외했는가
- [ ] 투자활동 분류가 회사 정책·전기 공시와 일관되는가
