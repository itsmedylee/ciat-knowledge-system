# 6. 비현금거래 조정

## 6-1. 비현금거래란 무엇이며 왜 중요한가

**정의** `[일반 원칙]`: 현금및현금성자산의 유입·유출을 수반하지 않는 투자·재무활동 거래.

**왜 중요한가**: 두 가지 이유가 있다.
1. **CF에서 제외해야 한다** — 현금이 안 움직였으므로 현금흐름표 본문에 넣으면 허위 현금흐름이 된다.
2. **주석으로 공시해야 한다** — K-IFRS 제1007호 문단 43. 재무제표 이용자가 기업의 투자·재무활동 전모를 파악하려면 비현금거래 정보가 필요하다.

## 6-2. 정산표에서 비현금거래를 처리하는 메커니즘 `[파일 확인]`

정산자료는 **AI(차변) / AL(대변)** 두 열로 비현금거래를 처리한다.

**부호 정의** (4행): AI = 현금감소, AL = 현금증가
**검증식에서의 부호**: `N = ... − AI + AL`

이 설계의 우아함은 **비현금거래가 자동으로 상쇄**된다는 점이다. 한 거래를 AI와 AL에 짝으로 기록하면, 검증식에서 `−AI + AL = 0`이 되어 현금흐름에 영향을 주지 않는다.

**대표 사례: 공정가치위험회피 파생 환산차대 (190행)** `[파일 확인]`
```
AI190 = 15,658,562   (해외사업환산차대 유입)
U190  = 15,658,562   (자산부채증감으로 이관)
N190  = ... + U190 − AI190 = +15,658,562 − 15,658,562 = 0 ✅
```

> **학습 포인트**: 비현금거래는 "들어왔다가 나가는" 형태로 기록되어 순효과가 0이 된다. 이것이 정산표가 비현금거래를 다루는 표준 패턴이다.

## 6-3. 비현금거래 유형별 정리

| 유형 | 대표 사례 | 파일에서의 위치 | 주석 공시 |
|---|---|---|---|
| **신규 리스 인식** | 사용권자산 ↔ 리스부채 동시 인식 | AL393 = 119,060,849,162 | 필수 |
| **해외사업환산차대** | 해외지점 자산·부채 원화 환산 | AI (187회 참조, M해외사업환산차대) | 해당 없음 |
| **계정 대체** | 건설중자산 → 본계정, 정상 → 부실 | AI/AL 각 계정 | 중요시 공시 |
| **충당금 설정/환입** | 대손충당금, 복구충당부채 | P/S 열 | 해당 없음 |
| **현물 배당·출자전환** | 주식으로 배당, 채권의 주식 전환 | `[확인 필요]` | 필수 |
| **재측정요소** | 확정급여제도 OCI | AI203 = 108,093,399,458 | 해당 없음 |

## 6-4. 정산자료의 비현금거래 전용 검증 `[파일 확인]`

정산자료에는 비현금거래만 따로 검증하는 영역이 있다.

```
AH514  비현금거래 차변합계
AK514  비현금거래 대변합계
AH515  비현금거래검증
AK1    비현금거래 수기조정
AI2    비현금거래검증
```

> **설계 의도** `[논리 추론]`: 비현금거래는 차변 합계 = 대변 합계여야 한다(복식부기 원리). 이를 별도 검증하여, 한쪽만 기록하는 실수를 방지한다.

## 6-5. 비현금거래 조정을 빠뜨리면 어떻게 되는가

**사례 1: 신규 리스 인식을 조정 안 하면** `[논리 추론]`
```
신규 리스 1,190억 인식 (현금 0)
→ 사용권자산 +1,190억, 리스부채 +1,190억

조정 안 하면:
  사용권자산 증가 → "유형자산 취득 1,190억" (투자활동 유출) ❌ 허위
  리스부채 증가   → "차입 1,190억" (재무활동 유입) ❌ 허위

결과: 투자활동과 재무활동이 각각 1,190억씩 부풀려짐.
      순효과는 0이라 기말현금은 맞지만, 활동별 금액이 심각하게 왜곡됨.
```

**사례 2: 환산차대를 조정 안 하면** `[파일 확인]`
```
파생 환산차대 15,658,562원을 손익조정에 포함하면
→ 계산 기말현금이 원장보다 15,658,562원 어긋남
→ 최종 검증(D852) 실패
```

| # | 유형 | 성격 |

| 1 | **유효이자 상각** | FVOCI·AC 금융자산 상각 |
| 2 | **이연대출부대비용·수익 상각** | K-IFRS 1109 유효이자율 |
| 3 | **현재가치할인차금 상각** | 대출채권 |
| 4 | **사채할인발행차금 상각** | 사채 |
| 5 | **리스 개시·재평가** | 사용권자산 ↔ 리스부채 **쌍으로 발생** → [[리스회계-K-IFRS1116]] |
| 6 | **금융상품 재분류** | 당기손익→관계기업, 상각후원가→당기손익 등 (1109 사업모형 변경) |
| 7 | **출자전환** | 채권 → 주식 |
| 8 | **기타포괄평가손익** | FVOCI 평가 |
| 9 | ★ **미지급금 계상 취득** | **무형·유형자산 취득 중 미지급분** |
| 10 | **해외사업장환산** | 환산차이 → §6-3, [[CF-환율변동효과]] |
| 11 | **연결범위 변동** | 지배력 취득·상실 |

### ⚠️ 9번이 실무 최대 함정

```text
무형자산 취득 433.27억 중 미지급금 계상분을 투자활동 유출로 처리
  → 투자활동 현금흐름 433.27억 과대
  → 기타부채 증감 433.27억 과대
  → 검증란은 0. 발견 불가.
```

`[K-IFRS 1007.43]` 현금을 사용하지 않는 투자·재무활동 거래는 **CF에서 제외하되 주석에 공시**한다. 대표 사례: **리스에 의한 자산 취득, 미지급금 계상 유·무형자산 취득, 출자전환, 주식배당, 전환사채 전환.**

### 6-7. 차·대 합계 검증과 허용오차

비현금거래는 정의상 현금 이동이 없으므로 **차변 = 대변**이어야 한다. 합계가 0이 아니면 **어딘가에서 한쪽만 입력**했다는 뜻이다.

관측 파일에서는 차변 합계 +209,088,789,602.17 / 대변 합계 −209,088,789,601.34 로 **1원**이 남아 있었다.

> ⚠️ 반올림 잔차로 보이더라도 **허용오차 기준(예: ±10원)을 문서화**해 두어야 한다. 기준이 없으면 허용 단수인지 실오류인지 판별할 수 없다. → [[CF-검증체계와-단수조정]] §6-3

### 6-8. 비현금거래는 CF 오류의 조기경보 지표

plug 구조에서 비현금 처리 누락은 **전부 운전자본으로 흡수되어 검증에 걸리지 않는다.** 따라서 위 12유형 전수 점검이 사실상 유일한 방어선이다. → [[CF-검증체계와-단수조정]] §3
