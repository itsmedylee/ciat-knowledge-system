# 3. 영업·투자·재무활동 분류 논리

## 3-1. 분류의 근본 기준 `[일반 원칙]`

K-IFRS 제1007호의 분류 기준:

| 활동 | 정의 | 은행에서의 의미 |
|---|---|---|
| **영업활동** | 주요 수익창출활동 및 투자·재무활동이 아닌 활동 | 여신·수신·유가증권 매매 등 **본업 전체** |
| **투자활동** | 장기성 자산 및 현금성자산에 속하지 않는 투자자산의 취득·처분 | **투자 목적** 유가증권, 유형·무형자산, 지분법자산 |
| **재무활동** | 자본과 차입금의 크기·구성 변동 | 사채·차입금·배당 등 **자금조달** |

## 3-2. 왜 은행에서는 영업활동 범위가 넓어지는가

### 핵심 논리
> [!quote] 인용
> **"그 자산·부채가 은행의 수익창출 그 자체인가, 아니면 수익창출을 위한 수단인가"**

| 항목 | 제조업 | 은행 | 이유 |
|---|---|---|---|
| **대출채권** | (해당 없음) | **영업활동** | 이자수익 창출의 본체. 제조업의 매출채권에 해당 |
| **예수부채** | (해당 없음) | **영업활동** | 예금은 차입이 아니라 은행의 상품. 예대마진의 원천 |
| **단기매매증권(FVPL)** | 투자활동 | **영업활동** | 트레이딩 = 은행의 수익창출활동 |
| **투자증권(FVOCI/AC)** | 투자활동 | **투자활동** | 장기 보유·유동성 관리 목적 |
| **차입부채·사채** | 재무활동 | **재무활동** | 자금조달 수단 |
| **파생상품** | 상황별 | **분리** | 매매목적→영업, 위험회피→투자/재무 |

### 파일에서의 실제 분류 `[파일 확인]`

`공시용 CF` 3. 자산·부채의 증감(영업활동)에 포함된 항목:
```
(1) 당기손익인식금융자산  -1,569,161   ← FVPL: 영업활동
(2) 파생금융상품             99,981   ← 매매목적 파생: 영업활동
(3) 대출채권             -6,463,399   ← 영업활동
(5) 기타자산            -13,881,038
(7) 예수부채             12,306,433   ← 영업활동
(9) 기타부채             15,936,049
```

투자활동(Ⅱ)에 포함된 항목:
```
(3) 투자금융상품의 처분    16,319,572   ← FVOCI + AC: 투자활동
(4) 투자금융상품의 취득   -19,072,716
(5) 지분법적용자산의 처분      88,867
(7) 유형자산의 처분            9,967
```

→ **같은 "유가증권"인데 FVPL은 영업활동, FVOCI·AC는 투자활동**으로 갈린다. 이것이 은행 CF 분류의 핵심 분기점이다.

## 3-3. 파생상품의 3분류 — 가장 어려운 부분 `[파일 확인]`

파생상품은 **보유 목적에 따라 세 갈래**로 나뉜다. 이 파일이 정확히 그렇게 처리하고 있다.

| 파생 유형 | 정산자료 행 | 분류 | 근거 |
|---|---|---|---|
| **매매목적 파생** | 183~186 | **영업활동** (자산부채증감 U열) | 트레이딩 = 수익창출활동 |
| **공정가치위험회피 파생** | 187~191 | **투자활동**(W/Z) + **재무활동**(AF) | 회피대상 자산·부채의 성격을 따름 |
| **현금흐름위험회피 파생** | 192~195 | **재무활동** (AC/AF) | 주로 조달 관련 위험 회피 |

전체표에서의 실제 매핑: `[파일 확인]`
```
D598 매매목적파생상품자산의 감소(증가) = 정산자료!U184 + U183   → 영업활동
D732 공정가치위험회피파생자산 (순감소)  = 정산자료!W189          → 투자활동 유입
D808 공정가치위험회피파생자산 (순증가)  = 정산자료!AF187         → 재무활동 유출
D768 현금흐름위험회피파생자산 (순감소)  = 정산자료!AC192         → 재무활동 유입
```

> [!note] 참고
> **WHY**: 위험회피회계에서 파생상품은 그 자체가 목적이 아니라 **회피대상(hedged item)의 위험을 상쇄**하기 위한 수단이다. 따라서 회피대상이 투자자산이면 투자활동, 조달부채면 재무활동으로 분류하는 것이 경제적 실질에 부합한다. `[일반 원칙]`

계정별 상세는 [[CF계정-파생상품|파생상품 카드]] 참조.

## 3-4. 총액표시 원칙과 예외 `[일반 원칙]`

**원칙**: 투자·재무활동은 **총액**(취득과 처분을 각각) 표시한다.

**예외 (순액표시 허용)** — K-IFRS 제1007호 문단 22~24:
- 회전율이 높고 금액이 크며 만기가 짧은 항목
- **금융회사 특례**: 단기(만기 3개월 이내) 대여금·차입금, 예수금 등

파일에서의 적용: `[파일 확인]`
```
[총액표시]
D718 매도가능유가증권의 처분 = 정산자료!W50   10,906,675,194,034
D739 매도가능유가증권의 취득 = 정산자료!Z50   10,482,452,954,505

[순액표시]
D771 차입부채의 순증가 = 정산자료!AC303     994,908,748,361
D812 차입부채의 순감소 = 정산자료!AF303   1,139,453,322,266
```
→ 유가증권은 총액, 차입부채는 "순증가/순감소"로 순액 처리. `[논리 추론]` 차입부채는 회전이 빈번하여 순액표시 특례를 적용한 것으로 보인다.

## 🔷 3-5. 금융업 CF의 핵심 — 이자·배당·법인세 gross-up

> [!quote] 출처
> 출처: [[현금흐름표_정산표_학습레포트-소스요약]] (금융지주 연결 FY25 1Q)

### 구조

```text
1. 당기순이익
2. 조정사항
   └ 이자수익   − PL 이자수익 전액 차감      (예: −1,371,380백만)
   └ 이자비용   + PL 이자비용 전액 가산      (예:   765,221백만)
   └ 법인세비용 + PL 법인세 전액 가산
3. 영업활동 자산·부채의 변동
──────── 여기까지 = "영업에서 창출된 현금흐름" ────────
4. 이자수익의 수취   ← 실제 현금 (예: 1,352,462백만)
5. 배당금의 수취     ← 실제 현금
6. 이자비용의 지급   ← 실제 현금 (예:  −815,999백만)
7. 법인세의 납부     ← 실제 현금
```

### 개념적 요체

**발생주의 이자수익(PL)을 전액 제거한 뒤 → 현금기준 이자수취를 다시 넣는다.** 그 차액이 곧 미수이자 증감이다.

이자수취를 별도 라인으로 뽑지 않으면 미수수익 증감을 운전자본에 넣어야 하는데, **금융회사는 금액이 커서 정보가치가 떨어진다.**

### 기준 근거

| 기준 | 내용 |
|---|---|
| `[K-IFRS 1007.31]` | 이자·배당의 수취·지급은 **각각 별도 공시** |
| `[K-IFRS 1007.33]` | 금융회사의 이자수취·지급·배당수취는 통상 **영업활동** |
| `[K-IFRS 1007.35]` | 법인세 현금흐름은 별도 공시, 원칙적으로 영업활동 |
| `[K-IFRS 1007.21]` | 총액표시 원칙 (예외 22~24: 금융회사 회전율 높은 항목은 순액 가능) → §3-4 |

### ★ 실무 지침 — 연결에서 역산하지 마라

관측 파일은 이자수취·지급(R/S/T/U 열)을 **자회사 시트에서 직접 받아온다.** 연결 레벨에서 역산하지 않는다.

**이유**: 미수이자·미지급이자의 상각, 부실여신 이자 미인식, 이자와 원금의 혼합회수 등으로 **역산이 부정확**하다.

> [!note] 참고
> → **자회사 자료요청서(PBC)에 "현금기준 이자수취/지급"을 명시적으로 포함**해야 한다. (관측 파일에 `PBC>>` 구분시트가 존재하는 이유)

## 🔷 3-6. 계정 활동분류 기본표 (금융업)

| BS 계정 | 활동 | 비고 |
|---|---|---|
| 현금및현금성자산 | N/A | 현금 그 자체 |
| **3개월 초과 예치금** | **영업** | "예치금의 증감". BS "현금및예치금"에서 **반드시 분리** (1007.6~9) |
| 당기손익-공정가치 금융자산 | **영업** | ⚠️ 사업모형·보유목적에 따라 일부 투자 (1007.15~16) |
| 기타포괄손익-공정가치 금융자산 | **투자** | 취득·처분 총액 |
| 상각후원가 금융자산(유가증권) | **투자** | |
| 대출채권 및 수취채권 | **영업** | 은행 본업 |
| 관계기업투자주식 | **투자** | 지분법손익 제거, **배당은 배당수취 라인** |
| 유·무형자산, 투자부동산 | **투자** | |
| 사용권자산 | 투자(취득) / **비현금(개시)** | 통상 취득 **0이 정상** |

> [!warning] 주의
> ⚠️ **현금및현금성자산 정의가 첫 단추**: 금융업 BS의 "현금및예치금"에는 **3개월 초과 예치금이 섞여 있다.** 분리하지 않으면 이후 전부 어긋난다.
> ⚠️ 한국은행 지급준비예치금·사용제한 예치금을 현금성자산에 포함할지는 **회사별 정책 차이**가 있다. 사용제한 예금은 주석 별도 공시가 일반적(1007.48). `[확인 필요]`
