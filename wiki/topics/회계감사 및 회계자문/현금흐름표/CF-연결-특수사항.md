# 9. 연결 현금흐름표 특수사항

> [!warning] 주의
> ⚠️ **[2026-08-20 익명화]** 이 문서가 참조하는 실무 파일의 **실제 기업명은 제거**되었다. `A금융지주`·`은행A`·`은행B`는 치환된 가명이며 실재 법인명이 아니다. 셀 주소·금액·구조는 원본 관측값 그대로이므로 **개념 예시로만** 사용한다.


> [!note] 참고
> **본 파일은 별도재무제표 기준이다** `[파일 확인]`. 파일명이 `별도_EUC-0260`이고, 리스 M시트에 "개별(별도)"과 "개별(연결)"이 병기되어 있다. 따라서 본 장은 일반 원칙 중심으로 서술한다.

## 9-1. 연결 CF의 추가 고려사항 `[일반 원칙]`

| 항목 | 내용 | CF 영향 |
|---|---|---|
| **내부거래 제거** | 지배기업 ↔ 종속기업 간 대여·차입·배당 | 연결 CF에서 전액 제거 |
| **종속기업 취득** | 취득 대가 − 취득한 현금 = **순현금유출** | 투자활동, 순액 표시 |
| **종속기업 처분** | 처분 대가 − 처분된 현금 = **순현금유입** | 투자활동, 순액 표시 |
| **비지배지분** | 비지배주주 배당, 지분 추가취득/처분 | 재무활동 |
| **해외종속기업 환산** | 해외사업환산차대 발생 | OCI, CF 조정 대상 아님 |

## 9-3. 본지점 거래의 특수성 `[논리 추론]`

은행은 해외**지점**(별도 법인이 아님)을 다수 운영한다. 본지점 간 거래는:
- 법적으로는 **동일 법인 내부거래**
- 회계상 본점과 지점이 각각 장부를 유지
- **별도재무제표 작성 시 본지점 계정은 상계 소거**

`M해외사업환산차대` 시트의 `본지점자산 / 본지점부채` 항목(O1, O2행, 값 0)이 이 상계 결과를 보여준다 `[파일 확인]`.

**CF 영향**: 본지점 간 자금 이동은 현금흐름이 아니므로 전액 제거되어야 한다. 제거하지 않으면 영업/투자/재무활동이 모두 부풀려진다.

### 9-4. ★ 별도합산 ≠ 연결: `998:연결조정`을 별도 트랙으로 관리

원천 TB의 법인 열에 지주·은행·증권·캐피탈… 과 나란히 **`998:연결조정` 열**을 둔다. 연결조정을 자회사와 동등한 하나의 "가상 법인"으로 취급하는 것이다.

그 위에 **`상세분석` 시트**("계정별 별도-연결 차이원인 분석")를 얹는다.

```text
[지주 | 은행A | 은행B | 증권 | … | 펀드합계] → 별도합산(R)
                                              연결 CF 금액(S)
                                              차이(T) = S − R − F(998:연결조정)
                                              원인(U)  ← 담당자가 문장·금액으로 기입
                                              검증(V) = (U = T) → TRUE
```

> [!tip] 팁
> 💡 **이 구조가 핵심 학습 포인트다.** 차이를 "있다/없다"로 끝내지 않고, **"원인란에 적은 설명금액이 차이와 일치하는지"를 다시 TRUE/FALSE로 검증**한다. **미설명 차이를 0으로 만드는 강제장치**다.

실제 결론 메모 예시: *"원화매도가능금융자산매매익(계정코드 4041010102)과 관련된 998:연결조정분개 때문임"*. **분개까지 명시**(차) 원화기타포괄손익인식증권평가이익 / 대체이익잉여금 → (대) 매매익).

### 9-5. 구조화기업(펀드) 다수의 확장 가능 설계

```text
펀드CF (1,589행)   : 펀드별 CF정산표를 48행 블록으로 세로 반복, 목차 하이퍼링크
       │ SUMIFS(펀드CF!금액열, 계정과목, 구분)   ← 2개 키로 매칭
       ▼
펀드합계 (386행)   : 연결정산표와 동일 템플릿
       ▼
연결현금흐름정산표 : 1개 열로 참여
```

셀 직접참조가 아니라 **SUMIFS 기반**이므로 펀드가 늘어나도 블록만 추가하면 된다.

> [!warning] 주의
> ⚠️ **관측된 리스크**: 검증 합계식이 `=H12+H58+H106+…` 처럼 **34개 항을 손으로 나열**한 수식이었다. 펀드를 새로 편입할 때 **이 수식을 갱신하지 않으면 검증이 무력화된다**. → `SUMIF(…,"검증용",…)` 또는 헬퍼열 방식을 권한다. [[CF-검증체계와-단수조정]] §4

### 9-6. 지배력 변동·비지배지분

| 항목 | 처리 | 기준 |
|---|---|---|
| 종속기업 취득/처분 | **취득·처분대가에서 인수·처분한 현금을 차감한 순액**을 투자활동에 표시 | 1007.39 |
| **지배력을 유지하는** 지분율 변동 | **재무활동** (자본거래) | 1007.42A |
| 비지배지분 배당 지급 | 재무활동 | 1007.17 |
| 신종자본증권 분배금 | 재무활동 (자본거래) | |
| 신종자본증권 발행/상환 | 재무활동 (자본거래) | |

> [!tip] 팁
> 💡 **배울 습관**: 관측 파일에는 **타 금융지주의 표시 명칭 비교 메모**가 남아 있었다: KB "기타", 신한 "비지배지분의 증감", 우리 "비지배지분 배당금의 지급", 하나 "비지배지분의 순증감". **동종업 표시관행 벤치마킹을 파일 안에 남겨두면** 감리·심사 대응에 유용하다.

### 9-7. 지분법투자

```text
지분법손익      → 조정사항에서 전액 제거 (현금유입 아님)
지분법처분손익  → 조정사항에서 제거
관계기업 배당수취 → 실제 배당 수취액만 현금흐름으로 인식
```

> [!warning] 주의
> ⚠️ 배당수취를 **영업(1007.33) vs 투자** 중 어디로 분류할지는 **정책 선택**이다. 관측 파일은 영업으로 분류했다. **해석상 다툼이 있을 수 있는 영역이며, 연도 간 일관성을 유지하는 것이 관건이다.**

### 9-8. 연결 내부리스 제거

그룹 내부 리스는 연결 실체 입장에서 리스가 아니므로 사용권자산·리스부채·상각비·이자·리스료수익을 전부 제거한다. **내부 리스료 지급은 연결에서 사라지므로 재무활동 "리스부채의 상환"에서 제거**되어야 한다.

상세(계정코드 첫 자리 기반 차·대 자동판정, 이월이익잉여금 제거액의 의미)는 [[리스회계-K-IFRS1116]] §8에서 확인한다.
