# 08. 유형자산 / 무형자산 / 사용권자산

> ## 📌 요약 박스
> - **CF 분류**: **투자활동** — 취득/처분 **총액표시**
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (총액표시 + 감가상각·상각 조정 필요)
> - **핵심 조정항목**: ① 감가상각비·상각비 전액 가산 ② 취득/처분 총액 파악(M시트) ③ 건설중자산 대체(비현금)
> - **가장 흔한 실수**: 상각 조정 누락으로 투자 규모 왜곡(무형자산 BS −226억 vs 상각비 557억), 또는 건설중자산 대체를 취득으로 이중계상

---

## A. 계정의 경제적 실질
은행에서도 영업점 건물, 전산장비 등 유형자산이 필요하다. 다만 **총자산 대비 비중은 매우 작다**(파일: 유형자산 6.2조 / 대출채권 350조).

### B~D. 회계처리
```
① 취득 (현금)
   (차) 유형자산       824    (대) 현금          824
② 감가상각 (비현금)
   (차) 감가상각비     100    (대) 감가상각누계액  100
③ 처분 (현금)
   (차) 현금          950     (대) 유형자산      900
                              (대) 처분이익       50
④ 손상 (비현금)
   (차) 손상차손        50     (대) 손상차손누계액   50
```

### E. BS 증감 사용 가능성
**불가능** ❌ — 총액표시 + 감가상각 조정 필요

### F. Bridge (Roll-forward)
```
기초 유형자산 (순액)
+ 현금 취득액                    ← 투자활동 유출 (Z열)
- 처분 자산 장부금액              ← 투자활동 유입 (W열)
- 감가상각비                      ← 비현금 (손익조정 가산)
- 손상차손                        ← 비현금
± 계정 대체 (건설중자산 → 본계정) ← 비현금
± 환율변동 (해외지점 자산)         ← 비현금
= 기말 유형자산 (순액)
```

### G. 분류
**투자활동** — 취득/처분 총액표시
파일: `공시용 CF` 37~40행 `(7) 유형자산의 처분 9,967 / (8) 유형자산의 취득 -55,309 / (9) 무형자산의 처분 111 / (10) 무형자산의 취득 -9,309` `[파일 확인]`

### I. 검토 시 주의사항
1. **감가상각비 전액 포착**: 유형·무형·사용권자산의 상각비를 모두 손익조정에 가산했는가. 파일 `공시용 CF` 12행 `(7) 감가상각비 및 상각비 198,747` `[파일 확인]`
2. **처분손익 vs 처분가액**: CF에는 처분가액(현금유입), 손익조정에는 처분손익 제거.
3. **건설중인자산 대체**: 비현금 대체이므로 취득으로 잡으면 이중계상.
4. **총액 원천**: `유형자산_M`(45회 참조), `무형자산_M` 시트가 총액 정보를 제공 `[파일 확인]`.

## 🔁 Roll-forward 공식 (원본 10장 — 유형자산)

```
기초 유형자산(순액)
+ 취득 (현금유출, 투자활동)
- 처분(장부금액) (현금유입, 투자활동)
- 감가상각비                           ← 비현금
- 손상차손                             ← 비현금
± 건설중자산 대체                      ← 비현금
± 환율변동 (해외지점)                  ← 비현금
= 기말 유형자산(순액)
```

> [!note] 참고
> 사용권자산의 Roll-forward(신규 리스 인식·상각)는 [[CF계정-리스부채|리스부채 카드]] 참조.

## ⚠️ BS증감 ≠ CF 사례 (원본 5장, 유형 4 — 상각이 개입)

| 계정 | BS 증감 | 상각비 | 함의 |
|---|---|---|---|
| **무형자산** | −22,651,225,975 | P = 55,732,853,831 | 상각을 빼면 실제 취득 규모가 안 보임 |

## ✅ 검토 체크리스트 (원본 14장 — 유형·무형·사용권자산)

- [ ] 감가상각비·상각비를 전액 가산했는가
- [ ] 취득/처분을 총액으로 표시했는가
- [ ] 건설중자산 대체를 취득으로 이중계상하지 않았는가
- [ ] 처분손익과 처분가액을 구분했는가
