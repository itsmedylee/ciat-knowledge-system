# 06. 유가증권 ③ AC (상각후원가측정)

> ## 📌 요약 박스
> - **CF 분류**: **투자활동** — 취득/처분 **총액표시**
> - **BS증감 그대로 사용 가능?**: **불가능** ❌ (총액표시 + 상각 조정 필요)
> - **핵심 조정항목**: ① 취득/처분(만기상환) 총액 파악 ② 현재가치할인할증차금 상각 ③ 손상차손·환율변동
> - **가장 흔한 실수**: 현재가치할인할증차금 상각액(이자수익 인식이나 현금 유입 없음)을 비현금으로 제거하지 않음

---

## A. 계정의 경제적 실질
**만기까지 보유**하며 계약상 현금흐름(원리금)을 수취할 목적. 공정가치 평가를 하지 않고 **상각후원가**로 측정한다.

### B~D. 회계처리 및 거래 성격
```
① 취득 (현금)
   (차) AC금융자산      824    (대) 현금          824
② 현재가치할인차금 상각 (비현금)
   (차) AC금융자산      20     (대) 이자수익       20
③ 만기 상환 (현금)
   (차) 현금            841    (대) AC금융자산     841
```
- **현금**: 취득, 처분/만기상환
- **비현금**: **현재가치할인할증차금 상각**, 손상차손, 환율변동

### E. BS 증감 사용 가능성
**불가능** ❌ — 투자활동 총액표시 + 상각 조정 필요

### F. Bridge
```
기초 AC 장부금액
+ 현금 취득액                       ← 투자활동 유출 (Z열)
- 현금 처분/상환액 (장부금액)        ← 투자활동 유입 (W열)
+ 현재가치할인할증차금 상각          ← 비현금 (이자수익 인식)
+ 환율변동효과                      ← 비현금
- 손상차손                          ← 비현금
= 기말 AC 장부금액
```

### G. 분류
**투자활동** — 취득/처분 총액표시

### I. 검토 시 주의사항
1. **현재가치할인할증차금 상각액**은 이자수익으로 인식되지만 현금 유입이 없다. 반드시 비현금으로 제거.
2. **FVOCI vs AC 재분류**: 사업모형 변경에 따른 재분류는 비현금 대체.
3. 파일에서 D720(만기보유유가증권의 처분) = 정산자료!W77, D745(취득) = 정산자료!Z77로 매핑 `[파일 확인]`.

## 🔁 Roll-forward 공식 (원본 10장)

```
기초 AC
+ 취득 (현금유출, 투자활동 총액)
- 처분/만기상환 (현금유입, 투자활동 총액)
+ 현재가치할인할증차금 상각            ← 비현금 (이자수익)
- 손상차손                             ← 비현금
± 환율변동                             ← 비현금
= 기말 AC
```
