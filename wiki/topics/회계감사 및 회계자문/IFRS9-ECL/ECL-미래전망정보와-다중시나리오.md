# ECL의 미래전망정보(FLI)와 다중 시나리오

> [!info] 개요
> 전체 공정에서의 위치는 [[기대신용손실-ECL-계산구조]]. 모형 성능 검증과 모델 밖 조정은 [[ECL-모형검증과-오버레이]].

## 1. 먼저 결론

**FLI(Forward-Looking Information) = 과거 부도경험만 쓰지 않고, 앞으로 예상되는 경제상황을 ECL에 반영하는 것.**

그리고 반드시 함께 가는 원칙: **미래는 하나의 숫자로 확정되어 있지 않으므로, 여러 시나리오의 ECL을 각각 산출해 확률가중한다.**

FLI는 [[ECL-PD-부도확률]]·[[ECL-LGD-부도시손실률]] 산출보다 **주관성과 경영진 판단이 크게 개입되는 영역**이어서 감사 비중이 높다 `[강사 강조]`.

## 2. 왜 필요한가

PD·LGD 데이터는 기본적으로 **과거 경험**에 기초한다. 그런데 IFRS 9는 **기대손실**이다.

과거 5년 평균 부도율이 1%인데 다음 해에 경기침체·실업률 상승·금리 급등·부동산 가격 급락이 예상된다면, 과거 평균 1%를 그대로 쓰는 것은 현재의 기대손실을 나타내지 못할 수 있다.

```
Historical/Base PD → Forward-Looking Adjustment → 현재 기대경제상황을 반영한 PD
```

### 2-1. FLI는 충당금을 올리는 장치가 아니다

`[교육용 가상수치]` 기본 PD 2%:

| multiplier | 조정 PD |
|---:|---:|
| 1.20 | 2.4% |
| 1.25 | 2.5% |
| **0.90** | **1.8%** |

경제전망이 개선되면 이론적으로 **ECL이 감소할 수도 있다.** FLI 반영이 원칙적으로 충당금을 반드시 증가시키는 개념은 아니다.

## 3. 변수 선정 — 가장 중요한 감사 포인트

강의에서 예로 드는 후보 변수: GDP · 실업률 · 물가 · 금리 · 소비 · 부동산 관련 지표.

**그러나 거시변수를 많이 넣는 것이 좋은 모델이 아니다.** 회사는 통계적으로 "어떤 거시변수가 해당 포트폴리오의 PD·LGD와 관계가 있는가"를 찾는다.

### 3-1. 통계적 유의성 ≠ 경제적 타당성

원본이 반복해서 드는 사례: 어떤 가수의 **음반 판매량**(또는 아이스크림 판매량)과 기업 부도율 사이에 우연히 높은 상관관계가 나오고 p-value도 훌륭하다고 하자. 그렇다고 ECL 모델에 넣을 수는 없다.

```
Statistical significance  ≠  Economic validity
```

따라서 후보변수에는 **정성적 판단근거**가 필요하다. 교재의 정상적인 예:

- 회사채 금리 ↑ → 기업의 자금조달 부담 ↑ → PD 변화 가능
- 기업대출 연체율 ↑ → 기업 전반의 신용건전성 악화 → PD 상승 가능

감사인은 두 축을 함께 본다: **Quantitative(통계적으로 적절한가)** + **Qualitative(경제적으로 말이 되는가)**. 변수의 **방향성**과 정성적 판단근거가 문서화되어 있어야 한다.

### 3-2. 후보모형 선정 과정 — Management Bias

`[교육용 가상수치]` 변수 20개로 조합해 후보모형 100개 → 통계기준 통과 30개 → 상위 성능 10개 → 정성검토 후 3개 → 최종 1개.

감사인이 볼 것은 "최종모형의 R²가 얼마인가"가 아니다.

> [!note] 참고
> **100 → 30 → 10 → 3 → 1로 줄이는 과정에 사전에 정한 일관된 기준이 있었는가?**

만약 통계적으로 모두 통과한 최종 후보 중 **ECL이 가장 작게 나오는 모델**을 선택했다면, 통계적 통과 사실만으로 그 선택이 정당화되지 않는다 — **Management Bias** 이슈다 ([[IFRS9-ECL-03-Final-실전문제-감사실무]] 문제 15).

확인 항목: 사전 선정기준 · 경제적 설명가능성 · 변수 방향성 · 모델 안정성 · 최종선택 근거 · **충당금 결과가 선택에 영향을 주었는지**.

## 4. 다중 시나리오 — 왜 Base Case 하나로는 안 되는가

`[교육용 가상수치]` 내년 실업률 전망:

| 시나리오 | 실업률 | 확률 | ECL |
|---|---:|---:|---:|
| Upside | 4% | 33% | 75 |
| Base | 6% | 34% | 100 |
| Downside | 8% | 33% | 275 |

- 평균 실업률(약 6%) 하나를 모델에 넣으면 → ECL **100**
- 시나리오별 ECL을 확률가중하면 → 24.75 + 34 + 90.75 = **149.5 ≈ 150**

**100과 150. 50% 차이다.**

### 4-1. 이유는 비선형성

```
E[f(X)]  ≠  f(E[X])
```

주택가격 10% 하락 → ECL +1%라고 해서 20% 하락 → +2%가 되지 않는다. +10%가 될 수도 있다.

경제가 조금 나빠질 때는 부도가 약간 증가하지만, **일정 임계점을 넘으면** 담보가격 급락 · 기업 영업손실 · Refinancing 실패 · 연체 증가 · 담보회수율 감소가 동시에 발생한다. Downside에서는 **PD만이 아니라 LGD까지 함께 악화**되므로 ECL 곡선이 갑자기 위로 휜다 → [[ECL-LGD-부도시손실률]].

이 비선형성이 다중 시나리오의 논리적 근거다.

## 5. 시나리오 설계에서 감사인이 보는 세 질문

| # | 질문 | 초점 |
|---|---|---|
| 1 | **어떤 변수를 썼나** | 실업률·GDP·금리·부동산가격 중 무엇이며, 그것이 해당 포트폴리오 신용위험과 실제 관련 있는가 |
| 2 | **시나리오별 변수값은 어디서 왔나** | 4% / 6% / 8%의 Source(외부 경제전망·내부 경제연구소 등) |
| 3 | **확률은 어디서 왔나** | Upside 20 / Base 50 / Downside 30의 근거 — **가장 주관적** |

### 5-1. Weight 변경은 그 자체로 충당금을 바꾼다

`[교육용 가상수치]`

| | 전기 | 당기 |
|---|---|---|
| Upside | 30% | 20% |
| Base | 50% | 50% |
| Downside | **20%** | **30%** |

Downside ECL이 다른 시나리오보다 크다면, 다른 조건이 같아도 확률가중 ECL은 증가한다. 그래서 감사인은 **"Downside 확률을 10%p 높인 외부 경제근거가 무엇입니까?"**를 묻는다.

필요 증빙: 외부 경제전망 · 내부 경제연구소 전망 · 경영진 승인자료 · 과거 Weight 결정방식 · 당기 변경 근거.

> [!warning] 주의
> ⚠️ 반대 방향(Downside Weight를 근거 없이 **낮추는** 경우)은 RED FLAG다 → [[ECL-감사절차와-체크리스트]].

## 6. FLI vs Stress Test

혼동하기 쉬운 두 개념.

| | FLI / ECL Scenario | Stress Test |
|---|---|---|
| 목적 | 발생 가능한 **여러** 상황을 확률가중해 기대값 추정 | 매우 나쁜 환경에서 금융회사가 **버틸 수 있는가** |
| 구성 | Upside / Base / Downside | Baseline / Recession / Severe Recession |
| 성격 | 나쁜 시나리오만 쓰는 개념이 **아님** | 심각한 위기 상황 중심 |

다만 FY23 실무지침은 미래전망 반영 과정에서 **회사 자체 위기상황분석의 최악 시나리오를 반영**하도록 요구했고, 대내외 불확실성에 공감대가 형성되는 상황에서 **최악 시나리오를 원칙적으로 유의미한 수준인 20% 이상 반영**하되, 모형 민감도를 고려해 10%부터 적용한 뒤 점차 20% 이상으로 확대하는 방안도 언급한다.

> [!warning] 주의
> ⚠️ **이 20%/10%는 2023년 교재에 실린 당시 실무지침 내용이다.** 원본 저자는 이를 상당히 보수적인 감독기조로 해석하고 있다 `[강사견해]`. 현행 적용 여부는 반드시 별도 확인 `[현행 기준 확인 필요]`.

## 7. FLI와 Stage는 다른 축이다

경제가 나빠진다고 모든 차주를 Stage 2로 보내는 것이 아니다.

- **Stage 판단** = 최초 인식 이후 **해당 금융상품**의 신용위험 변화 → [[ECL-스테이지와-SICR]]
- **FLI** = 미래경제상황을 **ECL 측정**에 반영

Stage 1 차주의 12M PD도, Stage 2 차주의 Lifetime PD도 FLI 때문에 상승할 수 있다. 미래정보가 SICR 판단에 영향을 줄 수 있다는 점은 별개이므로 개념적 역할은 구분한다.

## 8. 실무 체크포인트

인터뷰 질문 ([[IFRS9-ECL-01-기초-완벽마스터]] PART 24):
- "현재 FLI 모델에 포함된 거시경제변수는 무엇입니까?"
- "해당 변수와 PD 또는 LGD 간 경제적 관계는 무엇입니까?"
- "Upside/Base/Downside 값은 어디에서 입수합니까?"
- "시나리오별 확률은 어떤 방식으로 결정합니까?"

조서 확인 시: FLI가 **어디에 반영되었는지**(PD에만? LGD에도?), 조서의 PD가 **단일 시나리오 값인지 확률가중 값인지**를 반드시 구분한다.

## 9. 핵심 정리

1. FLI는 과거 데이터 기반 RC를 현재 기대경제상황으로 보정하는 단계다.
2. FLI는 충당금을 올리는 장치가 아니다 — multiplier < 1도 가능하다.
3. 변수는 **통계적 유의성 + 경제적 설명가능성** 둘 다 필요하다.
4. ECL과 경제변수는 비선형이므로 **평균변수 단일 투입 ≠ 시나리오별 확률가중**이다.
5. 시나리오 **확률(Weight)**이 가장 주관적이며, 변경은 곧바로 충당금 변화로 이어진다.
6. 후보모형 축소 과정의 일관성 부재는 Management Bias 신호다.
