# 8년 자경농지·농지대토·공익사업용 토지 감면

> [!info] 개요
> 농지·수용 토지의 양도소득세 감면(조특법 §69·§70·§77)과 종합한도(§133), 농어촌특별세를 모은 정본이다. 비사업용토지 판정과의 구별은 [[비사업용토지]] 5-1b, 상속농지의 상속세 쪽 쟁점은 [[상속세-과세체계와-전략]], 이월과세 증여 토지의 수용은 [[양도소득세-이월과세와-부당행위계산]]에서 다룬다.

> [!caution] 검증 상태
> 첫 판은 [[삼일 Tax Agent]] 답([[2026-10-26-B10-양도소득세-감면(8년-자경농지-등)-소스요약]], 기준일 2026-10-26)을 정리한 것이다. 인용 번호 7건은 법제처 목록에서 실재를 확인했지만 조문 내용과 결론은 원문과 대조하지 않았다 `[원문 확인 필요]`. 2025년 공익사업 감면율·한도 개정과 2026년 대토 기한 개정의 경과조치는 삼일도 확정하지 못했다.

## 1. 먼저 결론

> [!summary] 핵심 요약
> 감면 종합한도를 모두 "1년 1억 원·5년 2억 원"으로 정리하면 틀린다. **자경농지**는 그 한도, **농지대토**는 5개 과세기간 1억 원의 별도 제한이 더 있고, **공익사업용 토지**는 연 2억 원·5개 과세기간 3억 원이다(§133).

| 구분 | 핵심 요건 | 감면율 | 종합한도 |
| --- | --- | --- | --- |
| 8년 자경농지(§69) | 재촌·직접 경작 8년 이상(소득기준 초과 연도 제외), 농지·지역 요건 | 100% | 연 1억 원, 농지 감면 합계 5년 2억 원 |
| 농지대토(§70) | 종전농지 재촌·자경 4년 이상, 대체 취득·경작 개시 기한, 면적·가액 요건, 신·구 농지 합계 8년 | 100% | 위 한도 + **대토 자체 5년 1억 원** |
| 공익사업용 토지(§77) | 사업인정고시일 등부터 소급해 2년 이전 취득, 적격 공익사업 양도·수용 | 현금 15%, 채권 20%, 만기보유 특약 35%·45% | 공익사업 감면 합계 연 2억 원, 5년 3억 원 |

- **3,700만 원은 근로소득만이 아니라 사업소득금액 + 총급여 합계 기준**이고, 사업소득 총수입금액 기준이 따로 있다(조특령 §66⑭).
- 농어촌특별세는 §69·§70은 비과세, §77은 원칙 20%지만 직접 경작한 토지는 별도 비과세 요건을 본다(농특세법 §4, 시행령 §4).

## 2. 8년 자경농지 감면(§69, 조특령 §66, 규칙 §27)

| 항목 | 기준 |
| --- | --- |
| 재촌 | 농지 소재 시·군·구, 연접 시·군·구, 또는 농지에서 **직선거리 30km 이내** |
| 거주자 | 양도일 현재 거주자(비거주자가 된 날부터 2년 이내 포함) |
| 직접 경작 | 경작에 **상시 종사**하거나 **농작업의 1/2 이상을 자기 노동력**으로 수행 |
| 기간 | 취득일~양도일 사이 적격 경작기간 8년 이상(소득기준 초과 과세기간 제외) |
| 농지 여부 | 지목이 아니라 실제 경작으로 판단, 원칙적으로 양도일 현재 농지 |
| 신청 | 예정·확정신고와 함께 세액감면신청서 |

보유기간·재촌기간·실제 자경기간을 구분한다. 오래 소유하고 근처에 살았다는 사정만으로 감면이 확정되지 않는다. 핵심은 **누가 어떤 농작업을 했는가**다.

### 2-1. 소득기준(조특령 §66⑭)

다음 중 하나에 해당하는 **과세기간 전체**를 경작기간에서 뺀다.

| 기준 | 내용 | 주의 |
| --- | --- | --- |
| 소득금액 | 사업소득금액 + 총급여 **3,700만 원 이상** | "초과"가 아니라 "이상". 사업소득금액이 음수면 0 |
| 사업 수입금액 | 사업소득 총수입금액이 업종별 금액 이상 | 도소매·부동산매매 등 3억 원, 제조·숙박음식·건설·운수·정보통신 등 1억5천만 원, 전문·교육·보건 등 7,500만 원(소득령 §208⑤2호) |
| 제외 소득 | 농업·임업소득, 소득세법 §45②의 부동산임대업소득, 농가부업소득 | |

- 소득기준에 안 걸린다고 자경이 인정되는 것이 아니다. 상시 종사·자기 노동력 요건은 따로 갖춰야 한다.
- 소득기준을 월할하지 않는다. 총급여 기준을 넘은 과세기간 전체를 뺐다(조심2025인4378, 2026.5.19., 대토 사후관리 사건). 2014.7.1. 이후 양도분부터 3,700만 원 기준이 적용된다는 회신이 있다(서면-2016-부동산-4266, 2016.7.21.).

### 2-2. 주거·상업·공업지역 편입과 환지

| 단계 | 내용 |
| --- | --- |
| 토지 자체 제외 | 일정 도시지역의 주거·상업·공업지역에 편입된 날부터 3년이 지난 농지는 원칙 제외 |
| 지역 예외 | 광역시의 군, 도농복합시·제주 행정시의 읍·면 등 |
| 개발사업 예외 | 대규모개발사업(토지소유자 1천 명 이상 또는 100만㎡, 택지·대지조성 10만㎡)의 단계적 시행·보상 지연, 사업시행자 책임의 지연 |
| 환지예정지 | 농지 외 토지로 환지예정지 지정일부터 3년이 지나면 원칙 제외(환지청산금 부분 예외) |
| 감면 소득 범위 | 적용되더라도 원칙적으로 **편입일·지정일까지 발생한 소득만** 감면 |

"편입 후 3년 안에 팔았으니 양도차익 전부 감면"은 틀릴 수 있다. 토지 적격성과 소득 안분을 따로 본다(§69① 단서, 조특령 §66④⑦).

### 2-3. 상속농지와 양도일 농지 판정 예외

- 상속인이 1년 이상 재촌·자경하면 피상속인의 경작기간을 통산한다. 상속인이 경작하지 않아도 상속일부터 3년 안에 팔거나, 기한 안에 사업지구 지정 후 협의매수·수용되면 별도 통산 특례를 본다.
- 매매계약 조건에 따라 매수자가 양도일 전에 형질변경·착공하면 매매계약일 현재 농지로 판정하는 예외가 있다.
- 농지이양은퇴보조금 대상 농지를 한국농어촌공사 등에 양도하면 자경기간이 3년으로 줄어드는 특례가 있고, 양도기한은 2026.12.31.이다. 일반 8년 자경감면 전체의 일몰로 오해하지 않는다.
- 피상속인의 과거 자경을 생활기록부상 부모 직업, 다른 소득 유무, 주민 확인 등으로 인정해 경정청구 거부를 취소한 결정이 있다(조심2025광3852, 2026.2.24.). 현재의 자기 노동력 요건을 가족 노동력으로 대체하는 근거는 아니다.

## 3. 농지대토 감면(§70, 조특령 §67)

경작상 필요에 따른 대토의 감면이지 단순 재투자 감면이 아니다.

| 항목 | 요건 |
| --- | --- |
| 종전농지 | 양도일 현재 4년 이상 거주, 4년 이상 재촌·경작 |
| 선양도·후취득 | 양도일부터 1년 안에 새 농지 취득(협의매수·수용 등 2년) |
| 선취득·후양도 | 취득일부터 1년 안에 종전농지 양도(수용 등 2년 특례, 2026.2.27. 표시) |
| 경작 개시 | 원칙적으로 1년 안에 새 농지 재촌·경작 |
| 대체 규모 | 새 농지 면적이 종전의 **2/3 이상** 또는 가액이 **1/2 이상** |
| 총 경작기간 | 신·구 농지 합계 8년 이상 |
| 취득 방식 | 상속·증여로 받은 새 농지 제외 |

- **사후관리**: 새 농지 경작 개시 후 합계 8년이 되기 전에 소득기준을 넘는 과세기간이 생기면 계속 경작하지 않은 것으로 보아 **추징**한다. 사유가 생긴 달 말일부터 2개월 안에 감면세액과 이자상당액을 낸다. §69에서 그해를 빼는 것과 효과가 다르다.
- 감면한도에 맞춰 일부 면적만 임의로 정해 대토를 주장한 것을 배척하고, 필지별로 요건을 갖춘 부분만 감면한 결정이 있다(조심2025광3999, 2026.4.29.).

## 4. 공익사업용 토지 감면(§77, 조특령 §72)

| 보상 | 감면율(2025.3.14. 각 5%p 상향) |
| --- | --- |
| 현금 | 15% |
| 법정 보상채권 | 20% |
| 3년 이상 만기보유 특약 | 35% |
| 5년 이상 만기보유 특약 | 45% |

- 사업인정고시일(그 전 양도는 양도일)부터 소급해 2년 이전 취득이어야 한다. 상속 토지와 이월과세 증여 토지는 피상속인·증여자 취득일을 쓴다. 양도기한은 2026.12.31.이다.
- 사업인정 전 협의취득은 뒤에 별도 사업인정고시가 없어도 §77①1호 감면 대상이라는 판결이 확정됐다(서울고법 2025누4120, 2026.2.6. → 대법원 2026두30681, 2026.9.3., 구법 사건).
- 한 양도에 감면이 둘 이상이면 하나를 고른다(§127). 일부 토지에 하나를 적용하고 나머지에 다른 감면을 적용할 수는 있지만 같은 부분의 중복 감면은 아니다. 감면율이 아니라 **감면세액·종합한도·농특세·추징 조건**을 함께 비교한다.

## 5. 종합한도와 농어촌특별세

| 감면군 | 연간 | 5개 과세기간(당해 + 직전 4개) |
| --- | --- | --- |
| §69 등 농지 감면 | 1억 원 | 합계 2억 원 |
| §70 농지대토 | 위 연간 한도 | **대토 자체 1억 원** + 농지 합계 2억 원 |
| §77·§77의2·§77의3 | 2억 원 | 합계 3억 원 |

- 감면세액은 양도 순서대로 합산한다. 분할한 토지·지분을 1년 안에 일부 팔고 그 뒤 2년 안에 나머지를 같은 사람이나 배우자에게 팔면 한 과세기간에 판 것으로 본다(§133③, 2023.12.31. 신설). 연도만 나눠서 연간 한도를 두 번 쓸 수 있다고 단정하지 않는다. 오래전부터 구분된 필지를 다른 매수인에게 따로 판 거래를 하나로 본 처분을 취소한 결정은 사실판단이다(조심2026전1426, 2026.6.18.).

| 감면 | 농어촌특별세 |
| --- | --- |
| §69 자경농지 | 비과세 |
| §70 농지대토 | 비과세 |
| §77 공익사업용 토지 | 원칙 감면세액의 20%. §69① 본문의 거주자가 **직접 경작한 토지**는 비과세 검토(8년 요건은 적용하지 않음) |

"수용 감면에는 항상 농특세가 붙는다"도, "농지면 모두 비과세"도 정확하지 않다.

## 6. 실무 체크포인트

1. 농지·재촌·자경을 따로 판정한다. 주민등록·농지대장과 실제 작업 수행 자료를 구분해 모은다.
2. 과세기간별 소득 판정표를 만든다(3,700만 원 합계 기준, 업종별 수입금액 기준).
3. 지역 편입일·환지예정지 지정일을 확인하고 토지 제외 여부와 감면소득 범위를 따로 본다.
4. 대토는 취득·양도·경작 개시·합계 8년 일정과 사후 소득기준을 관리한다.
5. 당해와 직전 4개 과세기간의 감면을 감면군별로 합산하고 분할·지분 합산 규정을 본다.
6. 중복 감면은 농특세까지 비교해 고른다. 공익사업 시행자의 확인자료와 채권 특약 자료도 챙긴다.
7. 2025년 공익사업 감면율·한도 개정 전 양도분에 현행 수치를 소급하지 않는다 `[원문 확인 필요]`.
