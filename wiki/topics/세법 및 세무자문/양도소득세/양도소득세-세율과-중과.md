# 양도소득세 세율과 중과

> 양도소득세 세율 구조와 세 가지 중과(단기보유·다주택·비사업용토지), 그리고 손피거래(매수자 부담 양도세)를 세무법인다솔 안수남 대표세무사 강의로 재구성했다.
> 전사 오류(중가세→중과세, 조종대상→조정대상, 늦은율/누율→누진율 등)는 교정했다.

---

## 1. 먼저 결론

양도소득세는 **재정 조달보다 부동산 가격 안정(자원배분)이 더 큰 목적인 '정책세목'**이다. 그래서 경기 조절용 카드로 **세율과 장기보유특별공제를 함께 움직인다.**

기본 세율 구조:
- **일반 부동산·권리**: 6~45% 누진세율.
- **단기보유**: 주택·입주권 1년 미만 **70%**, 2년 미만 **60%**(분양권은 2년 지나도 60%). 일반 부동산은 1년 미만 50%, 2년 미만 40%.
- **다주택 중과**: 2주택 +20%, 3주택 +30%(최고 82.5%까지). → **현재 유예 중.** [강의 시점 기준]
- **비사업용 토지**: +10%(장특공제는 적용). → [[비사업용토지]]
- **미등기 전매**: 70%.

중과 대상은 딱 세 가지 — **다주택자 · 비사업용 토지 · 단기보유**. 어떤 정부든 경기 조절에 쓸 수 있는 카드가 이 셋뿐이다.

---

## 2. 왜 중요한가

- 45% 최고세율에 30%를 더하면 75%, 지방소득세까지 하면 **82.5%**라는 "지구상에 없는 세율"이 나온다. 이런 징벌적 세율 때문에 현재 다주택 중과가 유예되고 있다.
- 강사의 핵심 주장: **양도(파는) 단계에 중과세를 하니 '매물 잠금 현상'이 온다.** 수요 억제책이라면 **취득 단계에 중과**해야 맞는데, 지금은 반대로 운영되어 공급이 줄고 가격이 급등한다. → [[세제-정책비판-강사견해]]
- 세율은 국회가 정한 법률로 부과해야 하는데(조세법률주의), **조정대상지역 지정만으로 중과가 발동**되고 지정 해제 요건이 없어 사실상 행정부가 세율을 좌우한다는 것이 문제라는 지적. → [[비사업용토지]] 동일 논리.

---

## 3. 기본 개념 — 정책세목의 3대 조절 카드

강사는 양도세를 경기 조절에 쓰는 방법을 셋으로 정리한다.

1. **중과세**(세율 + 장특공제 조절) — 대상: 다주택자, 비사업용 토지, 단기보유.
2. **비과세 요건 강화/완화** — 보유기간·거주기간 추가, 일시적 2주택 유예기간 단축/연장.
3. **공제·감면 조절** — 미분양 감면, 임대주택 장특공제 특례 등.

- 경기를 잡아야 할 때: 중과세(세율↑ + 장특공제 배제) 도입.
- 경기를 살려야 할 때: 감면·완화.

---

## 4. 판단 구조 — 어떤 세율이 적용되는가

```
1단계  자산 종류        → 부동산/권리, 주택/입주권, 분양권, 미등기
2단계  보유기간         → 1년 미만 / 2년 미만 / 2년 이상 (단기세율)
3단계  다주택 여부·지역  → 2주택 +20% / 3주택 +30% (조정지역) — 현재 유예
4단계  비사업용 토지 여부 → +10% (장특공제는 적용)
5단계  누진세율 적용     → 6~45%에 위 가산
```

## 5. 상세 설명

### 5-1. 단기보유 세율

- **주택·조합원입주권**: 1년 미만 70%, 2년 미만 60%. (2년 지나면 일반세율로 복귀.)
- **분양권**: 2년 지나도 60% 유지.
- **일반 부동산**: 1년 미만 50%, 2년 미만 40%.
- ⚠️ 강사는 단기세율(70/60%)이 과도해 완화가 필요한데 아직 개정이 안 됐다고 지적. [강의 시점 기준]
- ⚠️ **부수토지 단기중과 불합리**: 장기보유한 나대지에 건물을 9개월만 지어 팔면, 건물뿐 아니라 부수토지까지 단기 양도로 중과되는 불합리(강사가 위헌 소지로 지적). → [[장기보유특별공제]] 5-3.

### 5-2. 다주택 중과

- 2주택 +20%, 3주택 +30%. 45% + 30% + 지방소득세 = **최고 82.5%**.
- **현재 유예 중**이며(2026년 5월 9일까지 등), 강사는 유예가 계속 연장될 것으로 전망. [강의 시점 기준]
- 조정대상지역에 한해 중과되는 구조인데, 조정대상지역은 원래 **분양시장(청약) 규제**를 위한 것이지 양도세 중과 기준으로 쓸 성질이 아니라는 것이 강사 견해.
- **개선 제안**[강사견해]: 주택가격 급등지역을 객관적 요건(정부 평균 상승률 초과 등)으로 따로 지정하고, 중과는 3주택 이상에 +10% 정도로 하되 장특공제는 허용, 탄력세율(±5%)을 부여하자.

### 5-3. 비사업용 토지 중과

- 세율 +10%(기본지역). 조정지역 토지 중과(+20%)는 현재 없음. **장특공제는 적용**되어 상대적으로 견딜 만하다.
- 상세 판정은 [[비사업용토지]].

### 5-4. 손피거래 (매수자 부담 양도소득세)

"손피"는 매도자가 실제로 손에 쥐는 금액(net)을 정해 놓고, 그에 대한 양도세를 매수자가 부담하는 거래다.

- **원리**: 매수자가 양도세를 부담하면 그 부담액이 양도가액에 가산되고, 가산된 양도가액에 다시 세금이 붙는다(증여세에서 증여세를 대납하면 다시 증여세가 붙는 것과 같은 구조).
- **2024년 11월 7일부터**: 매수자가 부담하는 양도세 **전부를 양도가액에 합산**하도록 강화(기재부 해석이 "끝까지 간다"로 변경). 과거엔 1회만 가산했다.
- **방정식**: 순양도차익(피) P, 추가 양도세 X, 세율 t일 때
  ```
  (P + X) × t = X   →   X = P·t / (1 − t)
  ```
  예: P = 5,000만, t = 60% → X = 5,000 × 0.6 / 0.4 = 7,500만.
  (전사에서 "5천만 + X×60% = X → 7,500만"으로 설명. 검산: (5,000+7,500)×0.6 = 7,500 ✓)
- **실무 조언**: "한 번에 끊어라." 양도세까지 포함한 금액으로 거래가를 한 번에 정하고, **"양도소득세는 매수자가 부담한다"는 약정은 넣지 말 것**(넣으면 계속 재계산되어 눈덩이). 거래가에 포함해 한 번만 정리한다.
  - 분양권은 60%/70% 두 세율뿐이라 계산이 단순하나, 조합원입주권은 2년 이상 보유 시 누진세율이라 계산이 복잡해진다.
- 양도가액 포함/특약 문구 상세는 [[양도소득세-계산구조와-취득가액]] 5-1.

### 5-5. 미등기 전매

- 70% 세율.

## 6. 사례

**사례 A. 손피거래 방정식 (P=5천만, 세율 60%)**
- 상황: 매도자 순액 5,000만 원 확보, 세율 60%, 양도세를 매수자가 부담.
- 논리: (5,000 + X) × 0.6 = X → X = 7,500만.
- 판단: 매수자가 부담하는 양도세는 7,500만 원.
- 결과: 계약서에 금액 약정을 넣으면 계속 재계산되므로, 거래가에 포함해 한 번에 정리.
- 왜: 매수자 부담 양도세 전부가 양도가액에 합산되기 때문(2024.11.7~).

**사례 B. 82.5% 세율의 비현실성**
- 상황: 3주택 중과 + 지방소득세.
- 논리: 45% + 30% + (지방소득세 7.5%) = 82.5%.
- 판단·결과: 징벌적이라 시행 못 하고 유예. 매물 잠금 → 가격 급등의 역효과.
- 왜: 양도(공급) 단계 중과가 수요 억제가 아니라 공급 억제로 작동.

## 7. 헷갈리기 쉬운 부분

- **분양권은 2년 지나도 60%**(주택·입주권은 2년 후 일반세율).
- **비사업용 토지는 세율 +10%지만 장특공제는 됨**(다주택 중과는 장특공제 배제).
- **손피거래는 금액을 특약에 적지 말 것**: "매수자 부담"만 명시.
- **조정대상지역은 원래 청약 규제**: 양도 중과 기준으로 쓰는 것 자체가 강사의 비판점.

## 8. 실무상 체크포인트

1. **보유기간**(1년/2년 경계) 확인 — 단기세율 회피 가능한지.
2. **주택 수·지역** — 다주택 중과 유예 여부, 조정대상지역 여부.
3. **비사업용 토지 해당 여부** → [[비사업용토지]] 판정.
4. **손피거래라면** 방정식으로 부담액 산정, 특약 문구 정리(금액 미기재).
5. **부수토지 단기중과** 위험(신축 후 단기 양도) 확인.

## 9. 핵심 정리

- 양도세는 정책세목. 조절 카드 = 중과세 / 비과세 요건 / 공제·감면.
- 중과 대상 셋: **다주택 · 비사업용 토지 · 단기보유**.
- 단기: 주택·입주권 1년 미만 70% / 2년 미만 60%(분양권은 2년 후도 60%).
- 다주택: 2주택 +20% / 3주택 +30%(최고 82.5%) → 유예 중.
- 비사업용 토지: +10%(장특공제 적용).
- 손피거래: 매수자 부담 양도세 전부 합산(2024.11.7~), X = P·t/(1−t), 특약에 금액 미기재.
