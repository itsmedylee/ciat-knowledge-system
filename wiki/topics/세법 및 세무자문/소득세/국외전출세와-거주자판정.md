# 거주자 판정과 국외전출세

> [!info] 개요
> 국내법상 거주자 판정, 조세조약상 이중거주자 판정, 국외전출세, 비거주자의 국내 부동산 양도를 모은 정본이다. 해외금융계좌 신고는 [[해외금융계좌-신고제도]], 해외주식 양도세는 [[해외주식-양도소득세]], 1세대1주택 비과세 일반은 [[양도소득세-1세대1주택-비과세]], 비거주자 원천징수 세율은 [[원천징수-체계]]에서 다룬다.

> [!caution] 검증 상태
> 첫 판은 [[삼일 Tax Agent]] 답([[2026-10-26-B16-거주자-판정-국외전출세-소스요약]], 기준일 2026-10-26)을 정리한 것이다. 인용 번호 10건 중 9건은 법제처 목록에서 실재를 확인했고, **대법원 2026두30835(2026.9.23.)는 법제처에서 찾지 못했다**(최근 판결이라 미수록일 수 있음). 조문 내용과 결론은 원문과 대조하지 않았다 `[원문 확인 필요]`. 국외주식으로의 국외전출세 확대(2025.12.23.)의 적용 시기는 부칙을 확인하지 못했다.

## 1. 먼저 결론

> [!summary] 핵심 요약
> "183일 미만이면 비거주자"로 단순 판정하지 않는다. **국내 주소·거소, 조약상 거주지, 국외전출세, 주택 비과세**를 각각 따로 본다. 체류일수가 적어도 국내 생활관계로 거주자가 될 수 있고, 비거주자가 되면 국외전출세와 주택 비과세 제한이 함께 문제된다.

| 쟁점 | 결론 |
| --- | --- |
| 국내법상 거주자 | 국내에 **주소가 있거나** 183일 이상 거소가 있으면 거주자. 183일은 주소 판정과 별개(§1의2, 시행령 §2) |
| 거주기간 | 입국 다음 날~출국일. 2026년 소득분부터 **두 과세기간에 걸친 계속 183일**도 보고 2025년 거소기간이 들어갈 수 있다 |
| 조약상 이중거주자 | 양국 국내법 판정 후 조약의 순차 기준. 국내법상 거주자라는 결론만으로 끝내지 않는다 |
| 국외전출세 | 출국으로 비거주자가 되는지, 직전 10년 중 국내 5년 이상인지, 직전 연도 말 대주주인지가 출발점 |
| 납부유예 | 납세담보와 납세관리인 신고를 **모두** 갖춰야 하고, 신고의무는 유예되지 않는다 |
| 비거주자의 국내 주택 양도 | 1세대1주택 비과세 원칙 배제. 해외이주·취학·근무 세대전원 출국 특례는 따로 본다 |
| 부동산 원천징수 | 개인 양수자는 원천징수의무자가 아니다. 법인 양수자는 검토 |

## 2. 국내법상 거주자 판정

| 항목 | 확인 |
| --- | --- |
| 직업 | 계속 183일 이상 국내 거주가 통상 필요한 직업인지(시행령 §2③1호) |
| 가족·자산 | 국내 생계공동가족이 있고 직업·자산상 183일 이상 국내 거주가 예상되는지(2호) |
| 외국 국적·영주권 | 국적·영주권에 더해 국내 생계공동가족 부재, 국내 복귀 가능성까지 봐야 비거주자(§2④) |
| 해외 파견 | 거주자·내국법인의 국외사업장, 내국법인이 직간접 100% 출자한 해외현지법인 등에 파견된 임직원은 거주자로 본다(시행령 §3) |

| 거주기간 | 기준(시행령 §4, 시행규칙 §2) |
| --- | --- |
| 기본 | 입국 다음 날부터 출국일까지 |
| 한 과세기간 | 183일 이상 |
| 두 과세기간 | 중단 없이 계속 183일 이상(대통령령 제35349호, 2026.1.1. 이후 개시 과세기간 소득분부터, 2025년 기간 포함 가능: 서면-2025-법규국조-3904, 2026.6.9.) |
| 일시적 출국 | 명백히 일시적인 관광·치료·경조사·출장·연수 등이면 출국기간도 국내 거소기간에 포함 |
| 재외동포 일시 입국 | 사업과 무관한 관광·치료·병역·경조사로 증빙을 갖추면 거소기간 제외 |
| 거주자가 되는 날 | 국내 주소를 둔 날, 주소 간주사유 발생일, 거소 183일이 되는 날(시행령 §2의2) |
| 비거주자가 되는 날 | 주소·거소 국외 이전을 위한 출국일 다음 날 등 |

연말·연초에 걸친 체류를 연도별로 끊어 비거주자로 보지 않는다. 출입국 일수표와 국내 생활관계 검토표를 따로 만든다.

## 3. 조약상 이중거주자

OECD 모델 제4조의 공통 틀: ① 양국 국내법 판정 → ② 한쪽에만 항구적 주거 → ③ 양쪽에 있으면 중대한 이해관계의 중심지 → ④ 정할 수 없으면 일상적 거소 → ⑤ 국적 → ⑥ 상호합의.

- 항구적 주거는 소유주택에 한정되지 않는다. 회사 제공·임차주택도 계속 쓸 수 있으면 해당한다. 중심지는 가족·사회관계·직업·사업장소·재산 관리장소를 종합한다.
- 조약마다 문언이 다르다. 한미조세조약은 "과세상의 주소"와 가족과 함께 사는 장소라는 정의를 쓰고(조심2024서4670, 2026.1.23.), 한홍콩 조약은 국적 단계에 홍콩 거소 권한·한국 국민 여부를 쓴다(조심2024중0278, 2024.8.29.).
- 외국 거주자증명서가 있어도 판정이 끝나지 않는다.

| 구분 | 번호 | 요지 |
| --- | --- | --- |
| 유리 | 대법원 2018두60847(2019.3.14.) | 일본 구단 제공 주거도 항구적 주거, 직업·가족·경제활동을 종합해 일본 거주자(파기환송) |
| 유리 | 조심2024서4670(2026.1.23.) | 국내 주민등록·주택·송금이 있어도 가족의 미국 생활·활동·소득으로 미국 거주자, 부과 취소 |
| 불리 | 대법원 2026두30835(2026.9.23., 번호 미확인) | 일본 선수활동에도 국내 송금·소비, 부동산·임대·교육사업, 가족생활로 한국 거주자 |
| 불리 | 조심2024중0278(2024.8.29.) | 홍콩 근무·가족 거주·거주자증명서에도 국내 주거·임대소득·송금으로 한국 거주자 |

"해외 운동선수·해외 근무자는 비거주자" 같은 직업별 결론이 아니라 **개별 생활·경제관계**의 차이로 갈린다.

## 4. 국외전출세(§118의9~§118의17)

실제로 팔지 않아도 요건을 갖춘 국외전출자의 주식 등을 **출국일에 양도한 것으로 본다**. 단순 출국이 아니라 출국으로 비거주자가 되는 경우다(서면-2023-국제세원-4285, 2024.5.2.).

| 요건 | 내용 |
| --- | --- |
| 신분 전환 | 주소·거소 국외 이전을 위한 출국으로 비거주자가 됨 |
| 거주 이력 | 출국 전 10년 중 국내 주소·거소기간 합계 5년 이상 |
| 대주주 기준시점 | **출국연도 직전 연도 말** |
| 과세 자산·가액 | 출국 당시 보유, 출국일 시가 |

| 대주주(시행령 §157·§167의8) | 기준 |
| --- | --- |
| 상장 | 1% 이상 또는 50억 원 이상 |
| 코스닥 | 2% 이상 또는 50억 원 이상 |
| 코넥스 | 4% 이상 또는 50억 원 이상 |
| 비상장 | 4% 이상 또는 10억 원 이상(장외거래 벤처기업 주식은 40억 원) |

본인 명의만 보지 말고 최대주주·기타주주(배우자·직계존비속) 합산 규정을 확인한다. 상장·비상장 모두에 50억 원을 쓰지 않는다.

- **세액**: 출국일 시가 − 필요경비 − 연 250만 원, 국내주식 등은 3억 원 이하 20%, 초과분 25%. 비상장주식 시가가 어려우면 출국일 전후 3개월 매매사례가액, 기준시가 순서다(시행령 §178의9).

| 단계 | 기한 |
| --- | --- |
| 출국 전 신고 | **출국일 전날까지** 납세관리인과 주식 보유현황 신고(보유현황 누락 시 액면금액의 2% 가산) |
| 과세표준 신고·납부 | 출국월 말일부터 3개월 이내(납세관리인 신고 시 다음 해 5월 확정신고기간) |
| 납부유예 | 신고 때 신청. **납세담보 + 납세관리인** 모두 필요. 출국일부터 5년(유학 10년), 이자상당액 가산 |
| 실제 양도 | 양도월 말일부터 3개월 안 납부. 가액 하락 조정공제·외국납부세액공제 등은 실제 양도일부터 2년 안 경정청구 |
| 재전입·거주자 증여·상속 | 사유 발생일부터 1년 안 환급 신청 |

- 자진 수정신고 증액분은 유예할 수 있다는 기재부 해석(국제조세제도과-30, 2023.1.19.)과, 과세관청 증액경정의 추가납부세액은 유예할 수 없다는 회신(서면-2024-법규국조-2773, 2025.7.24.)은 사실관계가 다르다.
- 거주자에게 증여해 본세가 환급돼도 기존 무신고·납부불성실가산세는 환급되지 않는다(조심2020전8507, 2021.3.30.).
- **국외주식 확대**: 2025.12.23. 개정으로 국외주식등도 대상에 넣었고, 2026.2.27. 시행령에 국외주식 합계 5억 원 이하 등 적용 제외와 평가방법이 생겼다. 적용 시기는 개정안 설명자료상 2027.1.1. 이후 출국분이지만 부칙을 확인하지 못했다 `[원문 확인 필요]`. 지금은 국내주식 과세와 구분한다.
- 조문의 "신설" 표시가 처음 도입을 뜻하지 않는다. 10년 중 5년 요건과 신고·유예 규정은 2024.12.31. 정비 전부터 있었다.

## 5. 비거주자의 국내 부동산 양도

- 비거주자의 국내 부동산 양도소득은 거주자처럼 분류과세하지만 1세대1주택 비과세 등은 원칙적으로 빠진다(§121②). 예외(시행령 §180의2·§154):

| 특례 | 요건 |
| --- | --- |
| 해외이주 | 해외이주법상 해외이주로 세대전원 출국, 출국일 현재 1주택, 출국일부터 2년 안 양도 |
| 취학·근무 | 1년 이상 국외거주가 필요한 취학·근무로 세대전원 출국, 출국일 현재 1주택, 2년 안 양도 |
| 현지이주 출국일 | 영주권 등 장기체류 자격 취득일(시행규칙 §71) |

영주권 취득을 위해 잠깐 나갔다가 국내 생활을 계속한 사안에서 실제 세대전원 이주일을 출국일로 보아 비과세 특례를 인정한 결정이 있다(조심2026소1566, 2026.7.7.). 모든 현지이주 사건에 일반화하지 않는다.

| 원천징수와 신고 | 처리 |
| --- | --- |
| 개인 양수자 | §156①의 원천징수의무자에서 제외 |
| 법인 양수자 | 법정 요건에 따라 지급 때 원천징수 |
| 원천징수액 | 지급금액의 10%, 취득가액 등이 확인되면 10%와 양도차익 20% 중 적은 금액(소득세 기준) |
| 원천징수 생략 | 세무서장의 신고납부·비과세·과세미달 확인서를 지급자에게 제출(시행령 §207) |
| 양도자 신고 | 비거주자도 예정신고(양도월 말일부터 2개월) |

개인 매수자에게 원천징수의무가 없다고 양도자의 납세의무가 없는 것이 아니다. **비과세 판단, 양수자 원천징수, 양도자 신고**를 세 갈래로 나눈다.

## 6. 실무 체크포인트(출국 전 검토 파일)

- 거주자 전환 검토(주소·생계가족·직업·자산 → 일수 → 해외파견 특례 → 전환일)
- 직전 연도 말 대주주 판정과 출국일 보유·시가 자료를 따로 작성
- 출국일 전날까지 보유현황·납세관리인 신고, 납부유예 담보 준비
- 주택 특례 요건(세대전원 출국, 1주택, 2년 안 양도)과 현지이주 출국일 확인
