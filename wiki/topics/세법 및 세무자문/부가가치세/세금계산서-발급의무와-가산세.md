# 세금계산서 발급의무와 가산세

> [!info] 개요
> 세금계산서의 발급기한, 수정발급, 위수탁 발급, 전자발급 의무, 공급자·수취자 가산세, 매입자발행을 모은 정본이다. 부가가치세 과세체계 전반은 [[부가가치세-과세체계와-신고]], 매입세액 불공제 사유는 [[부가가치세-매입세액-공제와-불공제]], 영세율 세금계산서는 [[부가가치세-영세율]]에서 다룬다.

> [!caution] 검증 상태
> 첫 판은 [[삼일 Tax Agent]] 답([[2026-10-26-B02-세금계산서-발급의무와-가산세-소스요약]], 기준일 2026-10-26)을 정리한 것이다. 인용 번호 7건 중 6건은 법제처 목록에서 실재를 확인했고 1건(국세청 심사결정)은 법제처 미수록이다. 조문 내용과 결론은 원문과 대조하지 않았다 `[원문 확인 필요]`. 개정 조문의 최초 적용일(부칙)은 삼일도 확보하지 못했다.

## 1. 먼저 결론

> [!summary] 핵심 요약
> **발급기한·작성일자·국세청 전송기한을 따로 관리**한다. 공급시기 발급이 원칙이고, 월합계 등 법정 특례에 해당할 때만 다음 달 10일까지 발급할 수 있다. 전자세금계산서 전송기한은 원칙적으로 발급일 다음 날이다(부가세법 §34, 시행령 §68).

- 현행 조문상 가산세는 지연발급 1%, 미발급 2%, **가공 발급·수취 각 4%**, 위장 발급·수취 각 2%다(§60). 가공거래에 종전 3%를 일률 적용하지 않는다. 다만 4%로 바뀐 개정(2025.12.23.)의 최초 적용일은 부칙 확인이 필요하다.
- **매입세액 공제와 가산세는 따로 판단한다.** 늦게 받은 세금계산서도 요건에 따라 공제되지만 수취자에게 공급가액 0.5% 가산세가 붙을 수 있다(§39·§60, 시행령 §75·§108).
- "모든 거래는 다음 달 10일까지 발급하면 된다"는 안내는 틀린 단순화다.

## 2. 발급기한

### 2-1. 공급시기를 먼저 정한다

| 거래 | 공급시기 |
| --- | --- |
| 현금·외상·일반 할부판매 | 재화를 인도하거나 이용 가능하게 된 때(시행령 §28①) |
| 조건부 판매 | 조건 성취 또는 기한 경과로 판매가 확정된 때(§28②) |
| 장기할부판매 | 대가의 각 부분을 받기로 한 때. 2회 이상 분할 수령, 인도일 다음 날부터 최종 지급기일까지 1년 이상(§28③, 규칙 §17) |
| 완성도기준·중간지급조건부 재화·용역 | 각 부분의 대가를 받기로 한 때. 인도·완료 뒤에 받기로 한 부분은 인도·완료일(§28③·§29①) |
| 일반 용역 | 역무 제공 완료 또는 시설물·권리를 사용하는 때(법 §16) |
| 구획할 수 없는 계속적 공급 | 대가의 각 부분을 받기로 한 때 |
| 완료시점·약정 지급일을 공급시기로 볼 수 없는 용역 | 역무 제공이 완료되고 공급가액이 확정된 때(§29②1호) |

중간지급조건부는 "계약금·중도금·잔금"이라는 이름이 아니라, 계약금을 받기로 한 날 다음 날부터 인도·완료일까지 **6개월 이상**이고 그 사이 계약금 외 대가를 나눠 받는지로 판단한다(규칙 §18·§20).

### 2-2. 다음 달 10일 특례(§34)

| 구분 | 작성 연월일 | 발급기한 |
| --- | --- | --- |
| 거래처별 월합계 | 그달 말일 | 다음 달 10일 |
| 한 달 안 임의 기간 합계 | 그 기간 종료일 | 다음 달 10일 |
| 증명서류로 거래가 확인되는 건별 발급 | 실제 거래일 | 다음 달 10일 |

10일이 공휴일·토요일이면 다음 영업일이다. 다음 달 10일에 발급해도 **작성일자를 발급일로 바꾸지 않는다.**

### 2-3. 선발급 특례(§17)

공급시기 전이라도 ① 대가를 먼저 받고 그 금액으로 발급 ② 발급 후 7일 안에 대가 수령 ③ 계약서에 청구·지급시기를 정하고 그 사이가 30일 이내 ④ 실제 공급시기가 발급일이 속한 과세기간 안에 도래(조기환급을 받았으면 30일 이내)이면 발급 시점이 공급시기가 된다. 장기할부·계속적 공급의 별도 특례를 모든 중간지급조건부 거래로 넓히지 않는다(시행령 §30).

## 3. 위수탁 세금계산서(시행령 §69)

| 거래 | 처리 |
| --- | --- |
| 위탁판매·대리판매(수탁자가 인도) | **위탁자·본인 명의**로 발급하고 수탁자 등록번호를 덧붙인다 |
| 위탁자가 직접 인도 | 위탁자가 발급할 수 있다 |
| 위탁매입·대리매입 | 공급자가 **위탁자를 공급받는 자**로 발급하고 수탁자 등록번호를 덧붙인다 |
| 용역 주선·중개 | 위탁판매·매입 규정 준용 |

- 수탁자가 발급 업무를 해도 발급 가산세는 **위탁자·본인에게** 적용한다는 기본통칙(60-108…4)이 있다.
- 거래 실질과 위탁매매 여부가 어긋나도 거래사실 확인·당사자 신고납부 등 시행령 §75 9호 요건을 채우면 매입세액 공제 예외가 될 수 있다. 모든 명의 불일치를 구제하지는 않는다.
- 2025.2.28. 분할·분할합병일부터 등기일까지 승계법인의 발급·수취 허용, 2026.2.27. 전력 명의자·실사용자 특례 정비가 있었다(§69).

## 4. 수정세금계산서(시행령 §70①)

| 사유 | 작성일자·방식 | 제한 |
| --- | --- | --- |
| 재화 환입 | 환입일, 음(-) | 비고란에 당초 작성일 |
| 계약 해제 | **계약해제일**, 음(-) | 당초 작성일로 소급하지 않는다 |
| 공급가액 증감 | 증감 사유 발생일, 증액 양(+)·감액 음(-) | 대금 미수와 가격 감액을 구분 |
| 사후 내국신용장·구매확인서 | 당초 작성일로 영세율 양(+)·당초분 음(-) | 과세기간 종료 후 25일 이내 개설·발급 |
| 필요적 기재사항 착오 | 당초 음(-)·정정 양(+) | 경정을 미리 안 경우 제한 |
| 착오 외 기재오류 | 당초 음(-)·정정 양(+) | 확정신고기한 다음 날부터 1년 이내 |
| 전자 착오 이중발급 | 중복분 음(-) | |
| 면세 등 발급대상 아님 | 당초 음(-) | |
| 세율 오류 | 당초 음(-)·정정 양(+) | 경정을 미리 안 경우 제한 |

- 착오 정정·착오 외 정정·세율 오류는 세무조사 통지·현지확인·해명안내 이후 제한이 있다. 과세유형 전환 후 환입·해제·변동은 당초 작성일을 쓰는 별도 규정이 있다.
- **수정발급이 가능해도 이미 생긴 가산세는 없어지지 않는다.** 공급가액 증감에 따른 수정세금계산서 미발급에도 미발급가산세를 적용하는 집행기준(60-0-10)이 있다.
- 판결로 계약이 해제되면 판결 확정일을 해제 시점으로 수정발급할 수 있다는 회신이 있다(사전-2025-법규부가-0915, 2025.10.28.). 잔금 미지급만으로 바로 음(-) 수정발급하지 않는다.

## 5. 가산세와 매입세액 공제

### 5-1. 공급자·수취자 가산세(§60, 기준 공급가액)

| 유형 | 요건 | 세율 |
| --- | --- | --- |
| 지연발급 | 발급시기 후 그 과세기간 확정신고기한까지 발급 | 1% |
| 미발급 | 확정신고기한까지 미발급 | 2% |
| 전자의무자의 종이 발급 | 법정 발급시기에 종이로 발급 | 1% |
| 자기의 다른 사업장 명의 발급 | | 1% |
| 전자 지연전송 | 전송기한 후 확정신고기한까지 전송 | 0.3% |
| 전자 미전송 | 확정신고기한까지 미전송 | 0.5% |
| 필요적 기재사항 부실 | 착오·과실(거래사실 확인 예외) | 1% |
| 가공 발급·수취 | 공급 없이 발급·수취 | 각 4% |
| 위장 발급·수취 | 실제 공급은 있으나 명의 불일치 | 각 2% |
| 공급가액 과다기재 | 초과분 | 각 2% |
| 지연수취 등 공제 특례 | 시행령 §75 3·7·8호로 공제 | 0.5% |

세율을 단순 합산하지 않는다. 지연발급·미발급이 적용되는 부분에는 전송·기재불성실을 배제하고, 합계표 가산세와의 중복은 §60⑨로 판단한다.

### 5-2. 수취자의 공제(시행령 §75)

| 상황 | 공제 |
| --- | --- |
| 공급시기 후 확정신고기한까지 수취 | 공제 가능(3호) |
| 확정신고기한 후 수취 | 확정신고기한 다음 날부터 1년 안에 발급받아 수정신고·경정청구와 함께 내거나 과세관청이 결정·경정하는 등 요건 필요 |
| 전자 발급은 확인되나 미전송 | 발급사실이 확인되면 공제 |
| 전자의무자가 종이로 발급 | 확정신고기한까지 받고 거래사실이 확인되면 공제 |
| 일부 기재 착오 | 나머지로 거래사실이 확인되면 공제 |

원칙은 미수취·필요적 기재사항 오류면 불공제다(§39). 상세 불공제 사유는 [[부가가치세-매입세액-공제와-불공제]]에서 다룬다.

## 6. 전자세금계산서 의무(§32, 시행령 §68)

| 기간 | 개인사업자 기준(직전 연도 사업장별 공급가액, 면세 포함) |
| --- | --- |
| ~2023.6.30. | 2억 원 이상 |
| 2023.7.1.~2024.6.30. | 1억 원 이상 |
| 2024.7.1.~ | 8천만 원 이상 |

- 사업장별로 판단하고 면세공급가액도 넣는다. 의무자가 된 뒤 8천만 원 미만으로 줄어도 계속 의무자다. 매출이 줄었다고 종이 발급으로 돌아가라고 안내하지 않는다.
- 기준금액 이상인 해의 다음 해 제2기부터 의무가 생긴다. 수정신고·결정으로 기준을 넘으면 개시시점이 따로 있고, 개시 1개월 전까지 통지를 못 받았으면 통지 수령월의 다음다음 달 1일부터다.
- 법인은 §32②에 따라 의무자다. 2027년 이후 확대 일정은 [[2026-세제개편안-사업자]]·D04 정리를 함께 본다.

## 7. 매입자발행세금계산서(§34의2, 시행령 §71의2)

| 항목 | 내용 |
| --- | --- |
| 대상 | 발급의무 있는 공급자가 발급하지 않은 경우(부도·폐업, 계약 해제·변경에 따른 수정 미발급 포함) |
| 금액 | 거래건당 공급대가 5만 원 이상 |
| 신청기한 | 공급시기가 속한 **과세기간 종료일부터 1년 이내** |
| 신청 | 신청인 관할 세무서장에 거래사실확인신청서와 입증서류 제출(입증책임은 신청인) |
| 작성일자 | 세무서장이 확인한 거래일자 |
| 공제 | 예정·확정신고 또는 경정청구 때 매입자발행세금계산서합계표 제출, 공급 과세기간에서 공제 |

- **거래 뒤 폐업과 거래 당시 이미 휴·폐업을 구분**한다. 거래 당시 미등록·휴폐업자와 거래한 것이 명백하면 확인을 거부한다.
- 일반 지연수취 공제의 1년(확정신고기한 다음 날부터)과 매입자발행 신청 1년(과세기간 종료일부터)은 기산점이 다르다.
- 계약 해제 뒤에도 이미 진행된 공사가 확인되면 거래사실 확인 거부를 취소한 결정이 있다(조심2025전3947, 2025.12.19.).

## 9. 실무 체크포인트

- 발급: 공급시기와 월합계 특례를 구분하고 작성일자·발급일을 따로 확인한다.
- 전자: 발급 완료와 국세청 전송 완료를 따로 확인한다.
- 수정: 환입·해제·가격변동·당초 오류를 먼저 분류한다.
- 수취: 공제 여부와 수취자 0.5% 가산세를 따로 판단한다.
- 위수탁: 발급 명의·인도구조·수탁자 등록번호 표시를 계약서에 정한다.
