# 13. 오류 가능성 및 추가 확인 필요사항

## 13-1. 확정 오류

**현재 확정 오류로 단정할 수 있는 항목은 없다.**

최종 검증(기말현금 = 원장, D852 = True)이 통과하고 모든 소계행 N = 0이 확인되므로, **재무제표 숫자 자체는 정합성을 유지**하고 있다.

## 13-2. 오류 가능성 높음

### ① 검증식 S516의 기준 불일치 `[파일 확인]`

```
현재:  S516 = −전체표!D306 + S514 = 15,658,562
```

**원인**: 비교 대상 두 값의 기준이 다르다.
- `S514` (정산자료 합계) = S189를 **환산차대 포함 총액**(2,780,056,416)으로 담음
- `전체표!D306` = D349를 **환산차대 제외 순액**(2,764,397,854)으로 담음

**판단**: 재무제표는 정확하나(기말현금 일치 확인) **검증식이 서로 다른 기준을 비교**하고 있다.

**권고**: 검증식 자체를 정합화하거나, 이 차이가 구조적으로 발생함을 조서에 명시한다.
```
수정안: S516 = −전체표!D306 + S514 − 정산자료!U187 = 0
```

### ② 신탁계정미지급금 총액표시의 적정성 `[파일 확인]`

```
AC400 = 1,618,825,833,140,584  (약 1,619조)
AF400 = 1,617,890,520,292,069  (약 1,618조)
순액  =       935,312,848,515  (약 0.9조)
```

**쟁점**: 총자산 대비 비정상적으로 큰 총액이 재무활동에 표시된다. K-IFRS 1007호 문단 22는 **회전율이 높고 금액이 크며 만기가 짧은 항목**에 순액표시를 허용한다.

**판단**: 신탁계정미지급금은 순액표시 요건에 부합할 가능성이 높다. 총액표시 시 재무활동 총액이 1,619조로 표시되어 **정보 유용성이 현저히 저하**된다.

**권고**: 회사 회계정책 및 전기 공시와의 일관성을 확인한다. 전기에도 총액표시했다면 계속성을 유지하고, 그렇지 않다면 순액표시를 검토한다.

| 2 | **AI203 순확정급여자산** | BS 증감 1,081억 전액을 비현금 처리 | 퇴직급여 주석, **실제 기여금 납입액**(현금유출 여부) |

## 13-4. 정상 가능성 높음

| 항목 | 근거 |
|---|---|
| **명세행 N≠0 (52건)** | 인접 행 짝 상쇄 구조, 모든 소계행 N=0 확인 |
| **전체표 D349 = S189 − U187** | 환산차대는 OCI 항목으로 당기순이익에 없음. 이 처리 하에 기말현금이 원장과 정확히 일치 |
| **AO480 = −607,088** | 당기순이익 백만단위 반올림 보정. 삭제 시 기말현금 불일치 발생 |
| **파생 3분류** | 매매목적→영업, 공정가치위험회피→투자/재무, 현금흐름위험회피→재무. 회계기준 부합 |
| **FVPL 영업 / FVOCI·AC 투자** | 은행 CF 표준 분류 |
