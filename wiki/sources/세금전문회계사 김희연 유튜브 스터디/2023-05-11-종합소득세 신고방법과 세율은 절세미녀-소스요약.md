# 종합소득세 신고방법과 세율 — 소스요약

## 강의 개요

- **화자·분량**: [[김희연]] 회계사 · 2023-05-11 · 7분 11초.
- **성격**: 신고방법 선택(추계 vs 장부)과 세율 적용을 한 편에 묶은 구조 설명. 이 채널 종합소득세 시리즈의 골격에 해당한다.
- **식별자**: `Y4PN_9Zncyk` · [원본 영상](https://www.youtube.com/watch?v=Y4PN_9Zncyk)

## 다룬 주제

1. **신고방법은 추계와 기장 두 갈래**이고, 둘 중 유리한 쪽을 선택한다는 큰 틀 제시.
2. **추계**는 장부 없이 세법이 정한 산식으로 경비를 인정받는 방식. 적격증빙이 없어도 처리되는 편의가 있으나, 법에 열거된 소규모사업자를 제외하면 **무기장가산세 20%** 가 붙는다.
3. 추계는 다시 **단순경비율 / 기준경비율**로 갈리며, 판정은 **직전연도 총수입금액** 기준. 신규사업자는 직전연도 매출이 없으므로 당해 매출로 판단한다.
4. **추계는 구조적으로 결손이 나오지 않는다** — 항상 순이익이 산출되어 세금이 발생하므로, 창업 초기 결손 상황에서는 기장이 유리하다.
5. **기장**은 간편장부 / 복식부기로 갈린다. 간편장부는 가계부 수준이라 회계지식 없이 작성 가능, 복식부기는 전문성이 필요해 세무대리 위임을 권한다.
6. **간편장부 대상자가 복식부기로 신고하면 기장세액공제** — 세액의 20%, 한도 100만원 `[현행 기준 확인 필요]`.
7. 세율은 과세표준 구간별 누진. 예시로 순이익 6,000만원 → 24% 구간 → 누진공제 522만원 → 산출세액 918만원, 여기에 **지방소득세 10% 별도**, 실효세율 약 16%.
8. 신고 후 **11월 건강보험료 정산**으로 이어진다는 점을 마무리로 언급.

## ⚠️ 시점 주의

강의가 제시한 세율 구간(1,200만원 / 4,600만원)은 **2022년 귀속 기준**이며 현행이 아니다. 2023년 귀속부터 하위 구간이 1,400만원 / 5,000만원으로 개정되었다. 실제 적용 시 해당 귀속연도 구간을 확인한다. `[현행 기준 확인 필요]`
