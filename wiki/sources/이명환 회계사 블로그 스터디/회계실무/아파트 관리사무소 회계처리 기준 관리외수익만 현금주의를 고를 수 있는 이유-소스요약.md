# (소스요약) 아파트 관리사무소 회계처리 기준 — 관리외수익만 현금주의

## 강의 개요

- **블로그/필자**: 세무회계 환희 · [[이명환]] 회계사(taxdelight), 2026-10-10.
- **성격**: 새 회계담당자·입주자대표회의 감사 대상 해설. 국토부 고시 「공동주택 회계처리기준」 조문 인용과 분개 예시.

## 다룬 주제

1. **원칙 = 복식부기·발생주의**(기준 §4 본문). 12월 용역 대가를 1월에 지급해도 12월 비용.
2. **단서 = 관리외수익만 계정별로 발생주의/현금주의 선택**(중계기임대·주차·재활용품·알뜰시장·광고·이자수입 등), 고른 방식은 매년 계속 적용·주석 기재. 관리비용·관리수익·관리외비용은 선택 대상이 아니다 → 발생주의.
3. **장부상 차이 예시**: 12월분 재활용 36만·광고 24만원이 1월 입금 — 발생주의면 2026년 60만원(미수수익), 현금주의면 2027년, 혼합이면 36만/24만으로 갈린다. 두 해 합계는 같다.
4. **적용 대상**: 의무관리대상 공동주택(300세대↑, 150세대↑+승강기 또는 중앙집중·지역난방, 주상복합 주택 150세대↑, 동의로 지정). 회계연도 1.1~12.31, 결산서는 종료 후 **2개월 내** 입주자대표회의 제출, 감사는 **9개월 내**(서면동의 연도 예외 — 결산 의무는 그대로).
5. **감사 전 점검**: 연말 걸친 비용·수익의 발생주의 반영, 관리외수익 인식기준의 계속성·주석, **매월 재무제표 작성 + 매월 말 예금잔고증명 대조**(기준 §29, 2023.6 개정으로 감사도 대조 의무 — 관리비 횡령 방지 내부통제).
