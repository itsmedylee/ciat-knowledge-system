# (소스요약) 법인 폐업 후 통장 잔액 — 그냥 옮기면 안 되는 이유

## 강의 개요

- **블로그/필자**: 세무회계 환희 · [[이명환]] 회계사(taxdelight).
- **성격**: 부채 없이 예금만 남은 1인·소규모 주식회사(개인주주) 기준 단순화 설명(2026-10-07). 상담 유도형 FAQ 구성.

## 다룬 주제

1. **폐업신고 후에도 통장 돈은 법인 돈** — 청산 없이 개인 계좌로 옮기면 가지급금(인정이자) 또는 사외유출(상여) → 법인세·대표 세금 동반 증가.
2. **방치 시 의무**: 결손이어도 법인세 신고(§60③), 이사 임기·변경등기(과태료 500만원 이하), 휴면회사 의제해산·청산종결 의제는 등기부만 정리할 뿐.
3. **과세 구조**: 법인 단계 청산소득 + 주주 단계 의제배당(소득세법 §17②3호), 14% + 지방세 원천징수, 2천만원 기준.
4. **Case**: 자본금 5,000만·잉여금 1,500만·예금 6,500만 → 청산소득 0, 의제배당 1,500만, 원천징수 231만, 수령 6,269만원.
5. **청산 절차 5단계**: 특별결의 → 2주 내 해산·청산인 등기 → 채권신고 공고(2개월 이상) → 변제·분배 → 결산보고·청산종결등기.
