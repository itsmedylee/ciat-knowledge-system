# (소스요약) 매입자발행 세금계산서 — 거래처로부터 세금계산서를 받지 못했을 때

## 강의 개요

- **블로그/필자**: 세무회계 환희 · 이명환 회계사(taxdelight)
- **분량/성격**: 약 3.6천자, 매입자발행 세금계산서 제도 신청 실무 가이드(홈택스 화면 캡처 포함)
- **핵심 메시지**: 공급자가 세금계산서를 발급하지 않아 매입세액공제·비용인정을 못 받는 불합리함을 구제하기 위해, 공급받는 자가 관할세무서 확인을 거쳐 직접 세금계산서를 발행할 수 있다.

## 다룬 주제

1. **제도 취지**: 공급자 귀책으로 세금계산서 미발급 시 공급받는 자에게도 가산세·매입세액불공제·비용불인정 불이익이 발생하는 문제를 구제.
2. **신청요건 4가지**: ①공급자가 세금계산서 발급의무 있는 사업자 ②발급시기 미발급 또는 부도·폐업·계약해제·소재불명 등으로 수정세금계산서 미발급 ③건당 공급대가(부가세포함) 5만원 이상 ④공급시기가 속한 과세기간 종료일로부터 1년 이내 신청.
3. **신청 절차**: 거래사실 확인신청서(홈택스 또는 관할세무서) 제출 → 신청인 관할세무서 보정요구 가능(7일 이내) → 공급자 관할세무서로 송부(7일 이내) → 공급자 관할세무서 거래사실 확인(신청일 다음달 말일까지) → 통지 → 매입자가 세금계산서 발행. 양쪽 세무서 모두 확인 통지 시 발행 간주.
4. **효과**: 발행 완료 시 부가세 예정·확정신고 또는 경정청구로 매입세액공제 가능, 적격증빙으로 비용처리도 가능.
