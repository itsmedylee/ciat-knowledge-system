# (소스요약) 프리랜서 3.3% 종합소득세 환급검토 — 종합소득세 신고 가이드

## 강의 개요

- **블로그/필자**: 세무회계 환희 · 이명환 회계사(taxdelight)
- **분량/성격**: 약 6.6천자, 프리랜서 3.3% 원천징수 정산구조·경비율 선택·절세 항목 종합가이드(계산 사례 2건)
- **핵심 메시지**: 3.3%는 확정세금이 아닌 선납액이며, 직전연도 수입 3,600만원을 기준으로 단순경비율(높은 경비율, 무증빙)과 기준경비율(낮은 경비율, 주요경비 증빙+기장세액공제 검토)로 갈려 신고방식에 따라 환급 또는 추가납부가 결정된다.

## 다룬 주제

1. **3.3% 원천징수의 성격**(소득세법 §129①3호): 소득세3%+지방소득세0.3% 선납, 다음해 5월 종소세 신고로 정산(선납>실제세금=환급, 반대는 추가납부).
2. **신고 대상·기간**: 3.3% 원천징수 소득이 1원이라도 있으면 전원 대상, 2026.5.1~6.1(자동연장), 환급은 신고 후 1~2개월. 홈택스 원클릭 환급 서비스(최대 5년치 일괄확인).
3. **단순경비율 vs 기준경비율**: 적용대상(직전연도 수입 3,600만 미만/이상), 경비율(업종코드 940909 기준 기본64.1%·초과49.7% vs 기준17.3%+주요경비), 지출증빙 필요여부, 소득금액 계산식 — 직전연도 미달이어도 당해연도 1.5억 이상이면 단순경비율 배제.
4. **환급/추가납부 계산 사례**: (1)연수입2,400만 단순경비율 → 환급 약42만3천원, (2)연수입5,000만 기준경비율(주요경비500만) → 추가납부 약217만원.
5. **절세 체크리스트**: 사업용 신용카드 등록을 통한 경비증빙 정리, 기본공제·국민연금·건강보험료 소득공제, 표준세액공제7만, 결혼세액공제50만(2024~2026 신설), 수입 3,600만 초과 시 장부작성+기장세액공제(산출세액20%, 최대100만).
6. **무신고 가산세**: 무신고(일반)20%/(부정)40%, 납부지연 1일0.022% — 환급대상자도 신고해야 환급되며 최대 5년 경정청구 가능.
