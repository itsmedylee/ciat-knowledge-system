# (소스요약) 홈택스 세무대리인 수임동의·해임

## 강의 개요

- **블로그/필자**: 세무회계 환희 · [[이명환]] 회계사.
- **성격**: 납세자가 홈택스에서 세무대리인의 수임요청을 승인하거나 기존 대리관계를 해임하는 화면 절차 안내.
- **핵심 메시지**: 신고자료 조회·신고대행을 시작하기 전에 납세자 본인의 명시적 수임동의가 완료되어야 한다.

## 다룬 주제

1. 세무대리인이 수임등록 요청을 보내고 납세자가 홈택스에서 본인인증 후 동의하는 흐름을 설명한다.
2. 세무대리·납세관리 메뉴에서 요청 세무대리인의 상호·성명·관리번호를 확인하는 방법을 안내한다.
3. 기존 세무대리인을 변경할 때 해임 처리 후 신규 수임동의를 진행하는 순서를 제시한다.
4. 잘못된 대리인 승인, 미처리 요청, 사업자 여러 개의 수임상태를 각각 확인해야 한다고 주의한다.
