# (소스요약) 직원 4대보험 미가입의 소급부과 리스크

## 강의 개요

- **블로그/필자**: 세무회계 환희 · [[이명환]] 회계사.
- **성격**: 직원의 미가입 요청에도 사업주 의무가 사라지지 않는 이유와 소급부과·급여공제 문제를 설명한 노무·세무 경계 글.
- **핵심 메시지**: 가입의무는 당사자 합의로 배제할 수 없으며, 사후에 근로자 부담분까지 사업주에게 먼저 청구될 수 있다.

## 다룬 주제

1. 각서나 구두합의가 있어도 법정 가입대상이라면 사업주의 신고의무가 남는다고 설명한다.
2. 미가입이 확인되면 일정 기간 보험료와 과태료가 소급될 수 있고, 산재사고가 있으면 추가 부담이 커질 수 있다고 경고한다.
3. 사업주가 과거 근로자 부담분을 현재 급여에서 일방 공제하는 것은 임금 전액지급 원칙과 충돌할 수 있다고 본다.
4. 퇴직금·인건비 비용처리는 실제 근로와 지급증빙을 별도로 검토하며, 미가입 사실만으로 자동 부인되는 것은 아니라고 구분한다.
