# (소스요약) 상호 불균등 무상감자 — 순손실 주주에게도 증여이익이 계산되는 문제

## 강의 개요

- **블로그/필자**: 차누월드 ｜ 찬CPA · [[정찬우]] 회계사(jcw6014).
- **성격**: 불균등감자 증여세 계산 중 마주친 산식의 불합리를 숫자로 정리(2026-10-02). 입법·해석 공백 문제 제기.

## 다룬 주제

1. **과세요건과 위임**: 법은 "이익을 얻은 경우"를 요건으로 두고 계산방법만 시행령(§29의2)에 위임.
2. **사례**: 갑 1,200·을 500·병 300주, 하나의 결의로 갑 200·을 300주 무상소각, 1주 15,000원 → 소각분 750만원.
3. **산식 결과**: 갑 300만·을 40만·병 150만 = 490만원. 무상감자는 차액 100%라 기준금액 0.
4. ⭐ **통산하면**: 갑 +200만 · 을 −350만 · 병 +150만 — 실제 이전 350만원인데 과세 490만원, **순손실 주주 을에게도 40만원 증여이익**.
5. **불합리 3가지**: 순손실 주주 과세 / 반대 방향 증여 동시 계산 / 과세액 > 실제 이전 가치. 직접 다룬 판례·심판례·해석 없음 → 해석 또는 개정 필요.
