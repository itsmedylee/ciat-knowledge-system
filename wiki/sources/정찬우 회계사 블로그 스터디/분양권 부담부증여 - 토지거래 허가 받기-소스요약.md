# (소스요약) 분양권 부담부증여 ① 토지거래허가 받기

## 강의 개요

- **블로그/필자**: 차누월드 ｜ 찬CPA · [[정찬우]] 회계사(jcw6014). **본인 가족의 실제 실행 경험기**(직계존속 보유 분양권을 부담부증여). 규정 해설이 아니라 **관공서·은행·분양사무소를 통과한 절차 기록**이라는 점이 이 소스의 가치다.
- **성격**: 세법이 아니라 **행정절차** 문서. 세무 논점(부담부증여의 유상·무상 병존)은 짧게만 다룬다.
- **핵심 메시지**: **완전 무상증여는 토지거래허가 대상이 아니지만, 부담부증여는 "대가를 받고 이전하는" 유상거래 성질이 있어 허가 대상이 된다.** 규제지역 지정으로 잔금 납부가 막혀 증여로 방향을 틀 때 이 절차가 먼저 걸린다.

## 다룬 주제

1. **전체 절차 6단계**: 토지거래허가(구청) → 증여계약서 검인(구청) → 중도금 대출 **채무인수 동의 신청**(은행) → 분양계약서상 **권리의무승계**(분양사무소) → 채무인수 완료(은행) → **증여세·양도소득세 신고**(세무서).
2. **왜 허가 대상인가**: 부담부증여는 채무상당액만큼 유상양도 + 나머지 무상증여가 병존하므로 「부동산 거래신고 등에 관한 법률」 §11①의 "**대가를 받고 이전하거나 설정하는 경우**"에 해당한다. 허가 없이 체결한 계약은 **효력이 발생하지 않는다**(§11⑥).
3. **신청서 작성의 실제 함정 — 분양권은 사례가 없다**: 토지거래계약 허가신청서의 금액란을 담당자 답변대로 정리했다. (25) 면적 = 공급계약서상 **토지 면적** / (26) 단가 = 토지 ㎡당 **공시지가** / (27) 예정금액 = (25)×(26) / (30) 예정금액합계 = 공급계약서상 **분양가액 총액** / (29) 정착물 예정금액 = (30) − (27). 감정평가액이 아니라 **공시지가·분양가 기준**이라는 점이 핵심.
4. **토지취득자금 조달계획서**: 분양권은 취득시기마다 기납부액이 달라 헷갈리지만, **총 분양가액(전체 금액) 기준**으로 기재한다는 답변을 받았다.
5. ⚠️ **기존 주택 보유자의 규제와 분양권의 불합리**: 유주택자는 기존 주택을 팔아야 신규 취득을 허가받고 6개월의 쿠션 기간이 부여되는데, **분양권은 아직 집이 없는 상태라 "실거주" 취지와 정면 충돌**한다. 필자는 준공(잔금·입주지정일) 전 매도 약정서까지 썼으나 담당자가 반려했고, **반려가 아닌 공식 불허처분을 요구**하며 국민신문고 유권해석 신청과 행정심판을 준비하자 결국 **허가증을 수령**했다. 준비했던 이의신청 논거 4가지(투기 아닌 반강제적 선택 / 제도 취지 훼손 / 법 §2의 "부동산"과 "부동산등" 정의 구분 = 분양권의 특수성 / 6개월은 절대 기준이 아님)를 그대로 남겨 두었다. [강사견해]
6. 토지거래허가제의 합헌 논거로 헌재 1989.12.22. 88헌가1, 헌재 1997.6.26. 92헌바5를 인용한다. [원문 확인 필요]
