# (소스요약) 이미 근로소득으로 과세된 상황에서 법인세법상 상여 처분이 발생한 경우

## 강의 개요

- **블로그/필자**: 차누월드 ｜ 찬CPA · 정찬우 회계사(jcw6014)
- **분량/성격**: 매우 짧은 Q&A형 실무메모(약 0.5천자), 회계처리 분개 + 질의응답 1건
- **핵심 메시지**: 임원상여가 법인세법상 한도를 초과해 손금불산입·상여 소득처분되는 경우, 이미 근로소득으로 원천징수신고된 금액이라도 소득처분명세서(별지55호)의 ⑥신고여부란에 "여"로 표기해 신고하면 이중과세(소득금액변동통지 재발생) 없이 처리된다.

## 다룬 주제

1. **회계-세무 분개 비교**: Book(급여·상여100/현금100) vs Tax(사외유출100/현금100) → 세무조정 <손금불산입> 임원상여100 상여.
2. **의문 제기**: 이미 근로소득으로 원천징수신고한 금액인데, 손금불산입 상여처분 시 소득처분명세서에 기재되어 소득금액변동통지서를 다시 받으면 이중과세되는 것 아닌가.
3. **해결**: 소득처분명세서에는 기입하되 ⑥신고여부란에 "여"로 표기해 신고하면 기신고분으로 처리되어 별도 소득금액변동통지·추가 원천징수 없이 정리됨.

## ⚠️ 특이사항

원본이 매우 짧은 Q&A 메모로, 관련 법령조문·서식번호 외 상세 해설이 없다. 소득처분명세서 서식(별지55호) 작성 실무의 세부 절차는 원문에 없으므로 실제 적용 시 국세청 서식·작성요령을 별도 확인해야 한다. `[원문 확인 필요]`
