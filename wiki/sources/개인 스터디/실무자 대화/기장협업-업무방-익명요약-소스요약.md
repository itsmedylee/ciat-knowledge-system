# 직원 포함 기장 업무방 대화 익명 요약

## 강의 개요

- 강의가 아닌 담당 직원·세무 담당자·고객의 실무 대화다. 월별 인건비, 결산 자료, 수정 계산, 신고 완료·납부 안내를 포함한다.

- 익명 원천번호는 `CHAT-B`다. 원문은 위키 밖 `C:/dev/ciat-guide/.local/업무대화/2026-10-27/CHAT-B.txt`와 `전체색인.json`에 보존했다. 전체 날짜·행 범위는 위키 외부 `C:/dev/ciat-guide/_참고/업무대화-반영과-확인사항.md`에서 확인할 수 있다. 개인정보·고유 사건명·실제 금액은 이 요약에 옮기지 않았다.

## 다룬 주제

1. **직원 인계**: 자료·기장 소통을 업무방으로 옮기고 담당 직원을 소개한다. 기존 개인 대화에서 받은 자료·판단을 인계할 필요가 있다.
2. **원천세 반복**: 매월 납부서를 전달하고 기한을 안내한다. 특정 월만 지급액 변경을 요청한 뒤 다음 월 복귀를 명시한다. 적용 월·변경 기간·복귀를 함께 관리한다.
3. **종소세 일정**: 인건비 신고 기간과 결산 순서를 설명하고 고객 일정에 따라 조기 마감을 조정한다. 당시 소요 기간은 공통 처리 기간으로 채택하지 않았다.
4. **대납·카드 혜택**: 적용 대상과 제외 거래를 확인하고 추산액에 고객이 동의했지만, 뒤에 다른 매입이 섞인 사실을 확인해 수정본을 다시 보낸다. 최종액은 첨부 미확보로 미확인이다.
5. **결산 자료 보완**: 특정 카드 결제의 차량 대금 여부, 연말 사업용 계좌·차입금 잔액, 카드 개인 사용 표시, 차량 총주행거리를 요청한다. 고객 회신을 그대로 경비 인정으로 자동 전환하지 않는 검토 단계를 추가했다.
6. **결재 전후 수치**: 통화로 안내한 내용이 결재 때 바뀔 수 있음을 고지한다. 최종 결과 재안내와 수정 이력이 필요하다.
7. **완료·납부 안내**: 종소세의 국세·지방세 납부서와 조정료 청구서를 구분해 전달한다. 고객의 입금 회신은 세금 실제 납부의 증거로 단정하지 않았다.
8. **부가세**: 가계산 뒤 반기 임차료 증빙을 요청·수령하고 신고 완료와 개별 납기 연장을 안내한다. 사진 내용과 연장 근거·실제 납부는 별도 확인 대상이다.

## 정정과 한계

- 카드 혜택의 최초 추산은 수정됐으므로 확정 수익으로 쓰지 않는다. 계산 파일의 이름이 같아도 최종본을 확인한다.
- 인건비의 일시 변경과 다음 달 복귀 **예고**를 연결했지만, 이후 월의 실제 신고 완료를 추정하지 않았다.
- “고객이 개인 사용으로 표시한 것 외에는 전부 비용 처리”라는 회신은 포괄적인 세법 기준이 아니다. 실제 사업 관련성·증빙·적용 요건 검토를 절차에 보완했다 `[현행 기준 확인 필요]`.
- 개별 납기 연장을 일반 법정기한으로 옮기지 않았다. 수신 감사 회신과 실제 납부 확인도 구분했다.
