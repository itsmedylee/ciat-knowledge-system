# 유상사급 기말재고추정 로직중심 A-Z 학습노트 (소스요약)

> 원본은 특정 회사·실제 금액·실제 계정명을 배제하고 작성된 외부 LLM 학습노트다(약 17KB, 21개 절). 원본의 숫자는 전부 개념 설명용 예시이며 실제 수치가 아니다.
> 선행 소스 [[유상사급 관련 개념 및 회계처리-소스요약]]이 **"이 거래가 매출인가"(통제·수익인식)**를 다룬 데 비해, 이 자료는 **"기말에 농가에 남은 재고를 어떻게 추정하고 그 오류를 어떻게 평가하는가"**를 다룬다. 두 소스는 같은 거래를 다른 단계에서 본다.
> ⚠️ 감사 중요성·CTT 수치(중요성 50·수행중요성 40·CTT 2.5 등)는 원본의 설명용 예시이며 실제 기준이 아니다. 중요성 기준·용어 정의는 감사기준서 원문으로 대조한다. `[현행 기준 확인 필요]`

## 강의 개요

- 분량·성격: 약 17KB, 21개 절의 단계형 학습노트. 농가에 동물·사료를 공급하고 일정 시점에 회수·재매입하는 구조를 전제로 한다.
- 관점: 회계처리 판단(통제)보다 **측정·추정 로직과 감사상 오류평가**에 무게를 둔다. 재고가 여러 농가에 흩어져 물리적 실사가 어려운 상황을 출발점으로 삼는다.
- 도달점: 산식 오류 발견 → 실제 오류금액 산출 → 원인·반복가능성 평가 → 관련 계정·손익 전파 확인 → 중요성 평가의 순서를 세운다.

## 다룬 주제

1. **전산상 매출 ≠ 회계상 매출.** 농가 공급 시 `매출채권/매출`, 재매입 시 `재고/매입채무`가 기록되고 채권·채무가 상계되는 외형이 생기지만, 회사가 위험과 보상을 계속 부담하면 매출로 단정할 수 없다.
2. **기말재고 역산의 기본 아이디어.** 농가별 실제 보유량을 직접 확인할 수 없을 때, `농가에 공급한 금액 − 이미 회수된 금액 = 기말 미회수분`으로 추정하고, 그 안에 포함된 판매마진을 제거해 원가 수준으로 환산한다.
3. **매출총이익률과 원가가산율의 구별(이 자료의 핵심).** `매출총이익률 = 이익÷매출`, `원가가산율 = 이익÷원가`로 서로 다른 값이다(예: 판매가 100·원가 80 → 각각 20%·25%). 상호 환산식은 `원가가산율 = 매출총이익률 ÷ (1 − 매출총이익률)`이다.
4. **대표적 산식 오류.** 판매가에서 원가를 역산할 때 `판매가 ÷ (1 + 매출총이익률)`을 쓰면 100÷1.20=83.33이 되어 실제 원가 80과 어긋난다. 분모의 비율은 **원가가산율**이어야 한다(100÷1.25=80).
5. **추정재고 금액과 오류금액은 다르다.** 적정 추정액이 100이고 장부액이 98이면 오류는 100이 아니라 2다. 중요성 판단의 대상은 장부금액과 적정금액의 **차이**와 그 차이의 재무제표 영향이다.
6. **CTT·실제 오류금액·중요성의 3분.** CTT는 감사 수행상의 threshold이지 오류금액이 아니며, "추정금액이 CTT를 넘으니 오류"라거나 "산식이 틀렸으니 오류가 CTT 이상"이라는 추론은 모두 성립하지 않는다.
7. **금액이 작은 산식 오류의 질적 평가.** 단순 입력 실수인지, 담당자가 `매출총이익률 = 원가가산율`로 구조적으로 오해하는지에 따라 위험평가가 달라진다. 후자는 다른 기간·다른 계정으로의 확산 가능성을 검토해야 한다.
8. **오류의 전파 경로.** 유상사급 기말재고 추정 오류 → 농가 잔여재고 추정액 → 사료재고·생물자산 금액 → 생물자산 장부금액 → 공정가치와 장부금액의 차이 → 생물자산 평가손익 → 당기손익·이익잉여금.
9. **사료배부와 생물자산의 연결.** 기말 사료 관련 금액 100 중 40이 사료재고, 60이 사육 투입이면 생물자산에 배부된 사료원가가 60이다. 사료재고 추정이 바뀌면 생물자산 원가와 공정가치 평가차이까지 연동된다.
10. **매출원장 가공 5단계.** 매출차감(장려금·수수료) 분리 → 제품코드·거래처·출고구분으로 유상사급 식별 → 취소·상계 분개 확인 → 내부거래 구분 → `순수매출 + 유상사급 관련 + 매출차감 = 원장 총액` reconciliation. 매출원장에서 유상사급을 제거하는 작업과 기말재고를 추정하는 작업은 연결되지만 동일 절차가 아니다.
