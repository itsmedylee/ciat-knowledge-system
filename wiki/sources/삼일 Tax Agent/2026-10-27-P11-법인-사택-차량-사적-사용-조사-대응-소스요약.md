# (소스요약) 삼일 Tax Agent P11 — 법인 사택·차량 사적 사용 조사 대응

> [!caution] 검증 상태
> 삼일 Tax Agent(PwC 삼일 AI 세무 리서치)의 답을 요약했다. 위키 규칙상 **검토되지 않은 LLM 분석 결과**이므로 결론을 그대로 정본에 옮기지 않는다. 이번 배치(2026-10-27~29)는 답에 나온 판례·심판례·예규 번호의 실재 여부도 아직 확인하지 않았다 `[원문 확인 필요]`.

## 강의 개요

- **자료**: `raw/삼일 Tax Agent/2026-10-27-P11-법인-사택-차량-사적-사용-조사-대응.md` (질문 P11, 질문일 2026-10-27, 기준일 2026-10-27, 답 약 37KB). [[삼일 Tax Agent]] 컬렉션.
- **질문 요지**: 법인이 대표 가족 거주용 아파트를 사택으로 쓰고 고가 차량을 대표가 주말에 사용합니다. 세무조사에서 문제 되는 지점, 손금불산입·상여처분, 부가세 매입세액, 사전 정리 방법을 검토해 주세요.
- **성격**: 가상 사례(실제 고객 아님)의 쟁점별 결론·근거를 묻는 종합 검토형 질문이다.
- **답의 첫 결론**: 아파트는 대표의 주주 지위와 실제 사용관계, 차량은 보험·운행기록·실제 사적 사용분을 나누어 검토해야 합니다. 손금불산입된 금액을 모두 대표자 상여로 처리하거나, 아파트 취득대금 전액을 곧바로 대표자 가지급금으로 보는 것은 적절하지 않습니다.(법인세법 시행령 제50조, 법인세법 시행령 제106조, 대법원2014두43301, 2017.08.29, 서면-2025-법인-2790, 2025.08.26)
- **번호 확인**: 미실시(인용 번호 20개)

## 다룬 주제

1. **아파트 관련 법인세**: 대표가 소액주주가 아닌 출자임원이거나 그 친족이 사용하는 사택이면 유지·관리비 등의 손금불산입과 무상·저가 제공이익의 익금산입을 각각 검토합니다.(법인세법 시행령 제50조, 법인세법 시행령 제88조, 제도46013-537, 2000.11.28) 확인 불가
2. **아파트 취득자금**: 법인이 실제 취득한 사택이라면 가족 거주만으로 취득자금을 대표자 대여금으로 바꾸어 인정이자를 계산할 수는 없습니다.(대법원2014두43301, 2017.08.29, 대법원2017두56827, 2017.12.28) 확인 불가
3. **차량 관련 법인세**: 업무 외 사용금액, 보험 미가입, 요구되는 번호판 미부착, 감가상각비 한도초과를 구분해야 합니다.(법인세법 제27조의 2, 법인세법 시행령 제50조의 2) 확인 불가
4. **상여처분**: 대표에게 귀속되는 사적 사용이익은 상여 대상이지만, 실제 업무사용이 분명한 보험 미가입 비용이나 단순 한도초과액까지 모두 상여인 것은 아닙니다.(법인세법 시행령 제106조, 서면-2025-법인-2790, 2025.08.26, 조심2020중1868, 2021.04.13) 확인 불가
5. **부가가치세**: 일반적인 개별소비세 대상 승용차는 업무에 사용해도 구입·임차·유지 매입세액이 불공제됩니다. 사택 관련 업무무관 지출의 매입세액도 별도로 검토해야 합니다.(부가가치세법 제39조, 부가가치세법 시행령 제77조, 대법원2014두46430, 2016.03.24) 확인 불가
6. **사전 정리**: 과거 사용내역·귀속자·기신고 조정을 먼저 확인하고, 실제 회수와 수정신고의 요건을 검토해야 합니다. 조사통지 후 반환만으로 상여처분이 없어지지는 않습니다.(법인세법 시행령 제106조, 국세기본법 제45조) 확인 불가
