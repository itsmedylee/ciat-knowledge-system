# (소스요약) 삼일 Tax Agent V003 — 상생임대주택 3부(3부 중)

> [!caution] 검증 상태
> 삼일 Tax Agent(PwC 삼일 AI 세무 리서치)의 답을 요약했다. 위키 규칙상 **검토되지 않은 LLM 분석 결과**이므로 결론을 그대로 정본에 옮기지 않는다. 이번 배치(2026-10-27~29)는 답에 나온 판례·심판례·예규 번호의 실재 여부도 아직 확인하지 않았다 `[원문 확인 필요]`.

## 강의 개요

- **자료**: `raw/삼일 Tax Agent/2026-10-27-V003-상생임대주택-3부(3부-중).md` (질문 V003, 질문일 2026-10-27, 기준일 2026-10-27, 답 약 28KB). [[삼일 Tax Agent]] 컬렉션.
- **질문 요지**: 우리 사무소 정리 자료 「상생임대주택 (거주요건 면제, 5가지 판단, 실무사례)」의 서술 중 근거 확인이 필요한 부분입니다. 2026년 10월 현재 기준으로 검증해 주세요.
- **성격**: 위키 정본의 서술을 번호 붙은 명제로 주고 맞음·일부 수정·틀림·확인 불가를 판정받은 검증형 질문이다(2차, 3부작 포함).
- **답의 첫 결론**: 핵심 수정사항은 “예규 본문 확인 불가”라는 일괄 표시를 삭제하고, 문서별로 확인 결과를 반영하는 것입니다. 지정하신 예규들은 문서번호를 정규화하여 조회한 결과 모두 원문이 확인되었습니다. 특히 사전-2026-법규재산-0715는 2026.06.18.자 문서이며, 「2년(甲) → 1년(甲) → 2년(乙)」 사안이 아닙니다.(사전-2026-법규재산-0715, 2026.06.18, 서면-2025-부동산-0424, 2026.06.11)
- **판정 분포**: 일부 수정 4 · 틀림 2
- **번호 확인**: 미실시(인용 번호 15개)

## 다룬 주제

1. **1. 임대기간 종료일** (일부 수정): “제3호에 따른 임대기간”이라는 인용은 맞습니다. 실제 임대기간·묵시적 갱신·합산에 관한 예규는 확인됩니다. 다만 신설 양도기한의 기산일을 연장·갱신별로 직접 판단한 해석은 확인되지 않았습니다.(소득세법 시행령 제155조의 3, 서면-2023-법규재산-2729, 2024.04.25, 서면-2024-법규재산-0648, 2025.03.04)
2. **2. 임대 개시기한** (일부 수정): 조문 인용과 직접 해석 미확인이라는 취지는 유지하되, 체결과 임대 개시 모두 기한 내 이행하는 해석이 문언상 더 자연스럽다는 검토의견을 별도로 표시해야 합니다.(소득세법 시행령 제155조의 3)
3. **3. 개정 연혁에 따른 해석** (일부 수정): 제시한 개정 전후 문언 차이는 확인됩니다. 그러나 특정 회계사의 발언·자료 원문은 확인하지 못했으므로 인물에게 귀속시키는 서술과 법령에 기초한 자체 검토의견을 분리해야 합니다.(기획재정부 재산세제과-952, 2023.08.10)
4. **4. 예규 본문 자동 확인 불가** (틀림—현재 검증 상태로서): 이번 조회에서는 회신 본문이 확인되었습니다. 과거 특정 수집 방식의 장애 여부와 현재 원문 확인 여부는 구분해야 합니다.(서면-2024-법규재산-0648, 2025.03.04, 사전-2025-법규재산-0294, 2025.05.28, 서면-2025-부동산-0424, 2026.06.11)
5. **5. 0715·0424 혼동 정정** (일부 수정): 두 문서를 구분한 방향은 맞지만, 0715의 날짜·결론을 미확인으로 되돌릴 필요는 없습니다. 다만 제시한 국세청 페이지 ID와 문서번호의 연결은 이번에 직접 확인하지 못했습니다.(사전-2026-법규재산-0715, 2026.06.18, 서면-2025-부동산-0424, 2026.06.11)
6. **6. 나머지 예규 미확인 유지** (틀림—현재 검증 상태로서): 열거한 문서는 모두 문서번호·날짜·본문이 확인되었습니다. 아래 확인표로 대체할 수 있습니다.(기획재정부 재산세제과-952, 2023.08.10, 서면-2022-법규재산-4388, 2023.08.16, 서면-2024-법규재산-0980, 2025.11.28, 서면-2024-법규재산-0648, 2025.03.04, 사전-2025-법규재산-0294, 2025.05.28, 서면-2023-부동산-2302, 2024.0…
