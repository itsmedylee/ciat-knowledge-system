## 다룬 주제

1. **“2024년 1∼6월분에 어느 기준…[원문 확인 필요]”** (일부 수정): 1억400만원은 2023년 공급대가로 2024.7.1.∼2025.6.30.의 과세유형을 판정하는 경우부터 적용한다. 2024년 상반기 기존 사업자의 유형판정에 소급 적용하지 않는다. 신규·미등록 첫해 판정과는 구분한다.
2. **“첫해 판단도 환산액…[LLM 해석, 국세청 해석 미확인]”** (일부 수정): 미등록 첫해도 연환산 공급대가로 판단한다. 구법상 동일 구조의 회신이 확인되므로 ‘국세청 해석 미확인’은 삭제하되, 현행법 직접 회신은 아니라는 한계를 표시한다.
3. **“2023.7.∼12. 5,000만원 → 환산 1억원 → 일반과세”** (맞음): 예시 유지. 다만 간이과세 배제업종 여부와 별도로 미등록 첫해의 당시 기준 판정임을 명시한다.
4. **“첫해 판단 결과는 다음 해 6.30.까지…제61조⑥ 미등록자 적용 미확인”** (일부 수정): 통상 전환시점 설명은 유지하되, 최초부터 간이요건을 충족하지 못한 미등록자를 제61조 제6항만으로 간이로 볼 수 있다고 단정하지 않는다. 간이과세자로 결정·경정되더라도 제63조 제7항의 일반방식 세액계산을 별도 검토한다.
5. **“판매대금의 1.5%…국세청장 배제기준 미확인”** (일부 수정 / 확인 불가): 1.5%는 공제 전 금액이다. 도매업은 소매 겸영도 배제하되 재생용 재료수집·판매업은 예외다. 국세청장 고시별 해당 여부는 확인 불가다.
6. **“약 203만원 / 약 1,062만원”** (일부 수정): 아래 확인액만 유지하고 총액은 확정하지 않는다. ‘2년 뒤’만으로는 납부지연 일수를 정할 수 없다.
