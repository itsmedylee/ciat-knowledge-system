# (소스요약) 삼일 Tax Agent R11 — 심층 대조 — 장기보유공제의 거주기간 통산

> [!caution] 검증 상태
> 삼일 Tax Agent(PwC 삼일 AI 세무 리서치)의 답을 요약했다. 위키 규칙상 **검토되지 않은 LLM 분석 결과**이므로 결론을 그대로 정본에 옮기지 않는다. 이번 배치(2026-10-27~29)는 답에 나온 판례·심판례·예규 번호의 실재 여부도 아직 확인하지 않았다 `[원문 확인 필요]`.

- **성격**: 앞선 삼일 답의 단정 표현을 가상 사실로 다시 검토하게 한 재질문이다.
- **답의 첫 결론**: 비과세 기간통산을 표2의 공제율 계산에 그대로 적용할 수 없습니다. 표2 적용자격·보유분·거주분을 각각 판정해야 합니다.
- **번호 확인**: 미실시(인용 번호 9개)

## 다룬 주제

1. **① 동일주택 전입·전출 반복**: 소유가 계속되면 취득일부터 계산 보유 중 실제 거주한 각 구간 합산. 퇴거만으로 종전 거주가 소멸하지 않는다는 문언상 판단이며, 반복 전출 자체를 판단한 직접 판례는 확인 불가(소득세법 제95조, 서면-2020-법령해석재산-1806, 2020.06.08)
2. **② 배우자 증여**: 원칙은 증여일부터. 이월과세 적용 시 증여자 취득일부터 기산 동일세대였다는 이유만으로 증여 전 거주를 공제율에 합산하지 않음. 이월과세 적용 시 거주분의 별도 취급은 확인 불가(소득세법 제95조, 서면-2022-부동산-1727, 2022.11.02, 사전-2025-법규재산-0506, 2025.06.25)
3. **③ 상속**: 원칙은 상속개시일부터 상속 전 동일세대 거주도 공제율에는 합산 불가. 비과세는 상속개시 당시 동일세대라면 시행령 제154조 제8항 제3호에 따라 통산(소득세법 시행령 제154조, 대법원2025두34935, 2026.01.15)
4. **④ 재건축**: 법정 정비사업/임의재건축 구분 필요. 법정 사업은 기존자산분과 청산금납부분의 기산일이 다름 법정 사업의 통산 인정 사례가 있으나, 임의재건축 건물분은 신축 취득 이후만 계산. 비과세 통산과 다름(서면-2021-법규재산-4496, 2023.05.18, 서면-2021-법규재산-2385, 2023.06.28)
