## 이 컬렉션을 쓰는 법

- 각 소스요약은 답의 요약표(판정) 또는 쟁점 제목을 그대로 옮긴 처리 완료 마커다. 법리 상세는 관련 정본에만 둔다.
- A 묶음의 "일부 수정·틀림" 판정은 위키 정본의 오류 후보다. 정본의 「삼일 Tax Agent 교차검증」 절에서 반영 여부를 관리한다.
- 법제처에 없는 번호(국세청 심사·적부, 감사원, 지방세 해석, 일부 조세심판원 결정)는 국세법령정보시스템·조세심판원 사이트에서 직접 확인해야 한다.
