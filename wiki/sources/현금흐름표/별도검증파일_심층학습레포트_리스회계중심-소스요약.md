## 강의 개요

파일 위치는 `현금흐름표/` 폴더지만 **내용의 무게중심은 리스회계(K-IFRS 1116)** 다. 따라서 위키에서도 현금흐름표 클러스터에 밀어 넣지 않고 **별도 정본 [[리스회계-K-IFRS1116]]** 을 신설했다. 현금흐름표와의 접점만 [[CF계정-리스부채]] · [[CF-비현금거래]] 에 링크로 연결한다.

## 다룬 주제

### PART Ⅰ — "검증 파일"이라는 개념
- **정체 규정**: 이 파일은 "재무제표 작성 파일"이 아니라 **"검증 파일"** — 값을 만드는 로직보다 **TRUE/FALSE 판정 셀이 더 많다**
- **Single Source of Truth**: BS/PL/CE/CF 4표 + 주석 29개 전부가 단 하나의 원천(`지주정산표_2503`)에서 계정코드 VLOOKUP으로 파생. **주석에 손으로 친 숫자가 없다**
- **전기 DART 공시본을 파일 안에 통째로 붙여두기** — `=C27=전기DART_기말!B973` 같은 셀 대 셀 비교 가능. 원본이 "가장 저비용·고효과 기법"으로 평가
- **검증 아키텍처 6종**: 합계검증 / BS·PL Ref / **계정과목명 문자열 대사** / 주석 내 REF / 전기보고서 대사 / 차이 병기
- **단수조정(천원 환산) ±1 기법**: 큰 항목에 흡수, 항목 n개면 최대 ±n/2, 검증셀은 조정 후에도 TRUE 유지, **매 분기 재산정 필요**(하드코딩)
- **주석 자동화 4기법**: 취득원가 역산으로 표시 정합성 강제 / 명세 SUMIFS + `"<>소계"` 방어 / 대체의 부호 연동(제로섬) / **기초·기말은 TB, 중간 변동만 명세**(plug 금지)

### PART Ⅱ — 리스회계 심층 (이 소스의 본체)
- **5단 파이프라인**: 계약대장 → 월별 스케줄 → 결산분개 → TB → 주석 → CF
- **계약코드 체계** `10122201001` = 용도(사무실 10)·형태(혼합 12)·개시년월(2201)·일련(001)
- **계약대장 필수 컬럼**과 놓치기 쉬운 3개(최초임차개시일 vs 임차개시일 / VAT 별도 / 내부거래 플래그)
- **사용권자산 4구성요소 분해** — 리스부채분·선급리스료분·복구충당부채분·개설직접원가를 **계정 단위로 분리**, 관리는 세분·공시는 통합
- **임차보증금 현재가치평가 → 선급리스료 전환** (한국 실무 핵심 논점) + 세무상 유보 처리 차이
- **월별 결산분개 9종 세트** — 그대로 체크리스트로 사용 가능
- **개시·갱신·중도해지·만기해지·잔액정리 분개 패턴** 5종 (실제 금액 포함)
- **리스부채 총액 + 현재가치할인차금 차감계정** 구조와 그 장단점
- **만기구조 주석의 COUNTA 버킷팅 기법** — 월별 캘린더에 값을 채우고 `COUNTA(범위) × 월리스료`
- ⚠️ **미할인 리스료 총액 ≠ 리스부채 장부금액** — "가장 흔한 실수"
- **롤포워드 3중 tie-out**: 결산분개 셀 직접참조 → 롤포워드 → 만기구조표 총계
- **오류 수정의 추적성** — 2월 오류를 덮어쓰지 않고 3월에 수정분개 + 입력값/적정값/차액 셀 보존. 원본이 "파일 전체에서 가장 배울 만한 부분"으로 평가
- **연결 내부리스 제거** — 계정코드 첫 자리로 차·대 자동판정(`IF(LEFT=1 or 5, 대-차, 차-대)`), 이월이익잉여금 제거액이 등장하는 이유
- **리스 ↔ CF 연결고리 8항목 총정리표**
- **리스회계 실무 체크리스트 A~E** (계약대장·측정·결산분개·검증·공시)

### PART Ⅲ
- 감가상각비명세 설계(4,374행)와 **발견된 수식 이상**(`X4 = Q4-W4` → 장부가 음수)
- **K-IFRS 1007.44A 재무활동 부채 조정공시** 구조와 미해소 FALSE(361억 차이)
- 대손준비금 주석20 구성
- **리스 계정체계 부록**(별도 계정코드 ↔ 연결 COA 매핑) + ⚠️ 매핑 오류가 `IFERROR(...,0)`로 **조용히 0이 되는** 위험
