# 금융지주 연결현금흐름표 정산표 학습레포트 (소스 요약)

## 강의 개요

[[은행_현금흐름표_작성_실무가이드-소스요약]]이 **은행 별도 / 2026 2Q** 파일이라면, 이 소스는 **금융지주 연결 / FY25 1Q** 파일이다. 대상 실체·파일·기준일이 모두 다르므로 **같은 개념에 대한 독립적 제2 관측**이다. 위키에서는 기존 정본에 "🔷 금융지주 연결 사례" 절로 누적한다.

주목할 차이: 두 파일은 **정산표 열 배치가 다르다**(은행 별도는 J/K/M/P/S/U/W/Z/AC/AF/AI/AL·검증 N열, 금융지주 연결은 D/E/F/I/L/O/P/R/S/T/U/W/Y/AA/AC/AE/AG·검증 H열). → **열 문자를 외우면 안 되고, 열이 담는 "역할"을 외워야 한다**는 것을 두 사례가 함께 증명한다.

## 다룬 주제

- **파일 아키텍처 4계층**: 원천 TB(정산표) → 법인별 CF정산표 10개 + 펀드 → 연결정산표(493행) → CF공시용(2기 비교 + 수정전/후)
- **확장 가능 설계 5기법**: VLOOKUP 열번호의 셀 파라미터화(`B1=70`), `INDEX+MATCH`로 열번호 자동산출, 전기 TB 병존, 템플릿 동일화, 버전·기준일 파일명
- **지배 항등식** `H열 = SUM(I:AG) + F = 0` 과 그 해설("자산 증가는 현금 유출이므로 배분열 합 = −F")
- **K열·N열 트릭**: 계정코드 숫자가 SUM 범위에 섞여 다시 빼주는 구조 → 행 추가 시 범위 미확장으로 **검증이 소리 없이 깨지는** 위험
- **P열 = plug의 양면성**과 흡수 사례 3종(미지급금 계상 취득 / 유효이자 상각 / 리스개시 누락)
- **금융업 gross-up 구조**: 발생주의 이자수익·비용을 조정사항에서 전액 제거 → 현금기준 이자수취·지급을 별도 라인으로 재투입. **연결에서 역산하지 말고 자회사 산출값을 PBC로 받으라**는 실무 지침
- **비현금거래 실무 카탈로그 12유형** (유효이자 상각, 이연대출부대비용, 현재가치할인차금, 사할차, 리스 개시, 금융상품 재분류, 출자전환, OCI 평가, **미지급금 계상 취득 −433.27억**, 해외사업장환산, 연결범위 변동, 신종자본증권 상환손실 잉여금처분)
- **7단계 검증 맵** (행 → 열합계 → 총계 → 활동별 대사 → 최종 항등식 → 공시용 대사 → **기말현금 이중산출**)
- **PL Tie-out 문화**: 차이를 0으로 만들지 않고 **왜 다른지를 셀 옆에 문장으로** 남김 (4개 실사례)
- **계정과목명 문자열 대사**: 금액이 아니라 **계정명 텍스트**를 전기 공시본과 1:1 비교 → XBRL 태깅 오류 방지
- **환율변동효과의 논리검증**: `H426 = (H425 = I417) → TRUE` 로 차액이 설명 가능함을 증명
- **연결 특유**: `998:연결조정` 별도 트랙, `상세분석` 시트의 "원인(U열) = 차이(T열)" TRUE/FALSE 강제장치, 구조화기업(펀드) 33개 SUMIFS 집계 설계
- **대손준비금**: 이익잉여금 내 적립금 → **CF 영향 없음**, 자본변동표·주석만
- **실무 오류 패턴 카탈로그 8건** (수익증권 배당금은 IFRS9상 채권 → 배당 아님, 1 COA ≠ 1 성격 등)
- **자작성 절차 체크리스트 Phase 1~5**
- **리스크·개선 제안 8건** (수동 나열 검증식, plug 은닉, 외부파일 링크, 하드코딩 plug, 행 오프셋 불일치 등)

## 그대로 쓰면 안 되는 것

- 모든 셀 주소·금액은 **A금융지주 FY25 1Q 파일 고유값**이다. 개념 예시로만 사용.
- 금융지주회사감독규정 대손준비금 조문 — 원본이 `[조문번호·최신 개정 확인 필요]`로 표기.
- K-IFRS 1007.44A 재무활동 부채 조정공시 시트가 파일 내 **미확인** 상태로 기록됨.
