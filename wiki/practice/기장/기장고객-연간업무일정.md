# 기장고객 연간업무일정

이 문서는 계속적 기장수임에서 반복되는 신고·자료요청·검토 일정을 운영하기 위한 캘린더 MOC다. 법정기한의 근거와 세목별 판단은 관련 topic·workflow를 참조한다.

> ⚠️ 정확한 마감일은 토요일·공휴일·재난연장·세법개정에 따라 달라진다. 매년 12월에 다음 연도 국세청·지방자치단체·4대보험기관 캘린더로 확정한다.

## 매월 반복

- 급여 확정과 원천세·지방소득세 신고자료 마감
- 일용근로소득 지급명세서·간이지급명세서 대상 확인
- 일용근로자 근로내용확인신고
- 매출·매입·통장·카드 자료수취와 월마감
- 신규입사·퇴사·보수변경과 4대보험 신고

관련: [[지급명세서-제출의무와-가산세]] · [[급여와-4대보험-실무]]

## 분기·반기 반복

- 법인 부가가치세 예정·확정신고, 개인사업자 확정신고 및 예정고지 확인
- 원천세 반기납부자의 신고·신청·승인상태 확인
- 법인세·소득세 중간예납 또는 예정고지 확인

관련: [[부가가치세-신고자료-준비체크리스트]] · [[부가가치세-홈택스-신고절차]] · [[법인세-중간예납]]

## 연간 주요 구간

| 구간 | 핵심 업무 |
|---|---|
| 1월 | 하반기 부가세 확정, 원천세 반기납부, 연말정산 자료수취 |
| 2월 | 면세사업자 사업장현황신고, 연말정산, 하반기 근로소득 간이지급명세서 |
| 3월 | 연간 지급명세서, 12월말 법인 결산·법인세 |
| 4월 | 1기 부가세 예정, 법인지방소득세, 성실신고법인·연결납세 일정 |
| 5~6월 | 종합소득세·개인지방소득세, 성실신고확인, 해외금융계좌 |
| 7월 | 1기 부가세 확정, 원천세 반기납부, 상반기 근로소득 간이지급명세서 |
| 8월 | 12월말 법인 법인세 중간예납 |
| 9~10월 | 부가세 예정, 연말 결산 사전점검 |
| 11~12월 | 종합소득세 중간예납, 종합부동산세, 다음 연도 캘린더·원천세 반기납부 신청 |

## 운영 절차

1. 매년 12월 다음 연도 법정기한을 공식 캘린더로 확정한다.
2. 고객별 사업자유형·결산월·원천세 납부주기·성실신고·면세·해외계좌 여부를 태깅한다.
3. 법정기한에서 역산해 자료요청일·1차검토일·대표검토일·고객승인일을 배치한다.
4. 제출 후 접수증·납부서·오류내역을 보관하고 미납·반려 여부를 확인한다.
5. 월말에 다음 60일의 예외 일정과 담당자 용량을 재점검한다.
