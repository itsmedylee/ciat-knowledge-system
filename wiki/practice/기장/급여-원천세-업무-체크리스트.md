# 급여·원천세 업무 체크리스트

> [!info] 개요
> 월별 지급 자료와 고객의 최종 변경 요청을 신고에 연결한다. 가족·프리랜서 등 호칭이나 계약서 이름만으로 소득 구분과 세부담을 확정하지 않는다. 실제 지급 사실과 법정 제출 주기를 먼저 확인한다.

## 신고 전

- [ ] 지급 대상과 실제 근무·용역·지급 자료를 확인한다.
- [ ] 근로·사업·일용 등 소득 구분을 검토한다 → [[원천징수-체계]] · [[급여와-4대보험-실무]] · [[프리랜서-세무]].
- [ ] **귀속월 / 실제 지급일 / 신고 대상월**을 다른 필드에 적는다.
- [ ] 신규·종료·지급액 변경과 고객의 마지막 회신을 확인한다.
- [ ] 원천세 신고와 별도로 지급명세서 등의 제출 대상을 확인한다 → [[지급명세서-제출의무와-가산세]].

## 금액 변경 이력

| 필드 | 기록 기준 |
|---|---|
| 요청일·최종 회신 | 최초 요청과 뒤에 바뀐 요청을 모두 남긴다 |
| 종전액·요청액·확인액 | 실제 지급 근거와 대조한 적용액을 구분한다 |
| 적용 월·기간 | 한 달만 바뀌는지, 이후 계속 바뀌는지 확인한다 |
| 복귀 조건 | 일시 변경이면 다음 월 복귀를 다음 할 일로 등록한다 |
| 신고 반영 | 신고 결과·납부서와 대상 월·금액을 대조한다 |
| 변경 시점 | 신고 후 변경이면 정정 필요 여부를 검토 담당자에게 넘긴다 |

> [!warning] 주의
> 가족 인건비도 실제 용역·근무와 지급 증빙이 먼저다. 목표 소득률이나 절세 희망만으로 신고액을 정하지 않는다. 수령자의 다른 소득·공제·보험 영향은 별도 검토한다.

## 신고 후

1. 국세·지방소득세 신고 결과와 납부서를 구분해 확인한다.
2. 대상 기간·세목·납기를 적어 고객에게 전달한다.
3. 납부서 수신 확인과 실제 납부 확인을 별도 기록한다 → [[신고검토와-납부확인]].
4. 다음 달 복귀·추가 자료·미확인 지급 내역을 이월한다. 납부 기한은 [[기장고객-연간업무일정]]에서 해당 연도의 공식 일정과 대조한다.
