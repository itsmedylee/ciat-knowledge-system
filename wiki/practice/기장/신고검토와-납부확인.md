# 기장 신고 검토와 납부 확인

> [!info] 개요
> 신고 완료부터 고객의 실제 납부 확인까지 단계별로 남기는 공통 절차 초안이다. 고객별 신고 자료·납부 기록은 위키 밖에서 관리한다.

## 1. 가계산과 최종 신고를 구분한다

1. 계산의 기준일·대상 기간·자료 범위를 표시한다.
2. 미반영 임차료·카드·차량·공제와 미회신 질문을 적는다.
3. 수정본을 받으면 최종 적용본과 수치를 다시 확인한다. 고객의 최초 동의를 수정 후 최종 검토로 대신하지 않는다.
4. 검토 담당자가 공제·경비·누락·중복과 변경 내역을 확인한다.
5. 고객에게 미리 말한 수치가 결재 후 바뀌면 변경 내용과 최종 결과를 다시 안내한다.

## 2. 전달할 자료

| 자료 | 확인할 점 |
|---|---|
| 신고 요약·접수증 | 대상 기간, 최종 신고 결과, 접수 상태 |
| 납부서 | 세목·세액·납부기한, 국세·지방세 구분 |
| 개별 연장 안내 | 해당 고객·신고분에 실제 적용되는 근거와 변경 납기 |
| 조정료 등 청구서 | 세금과 별도 보수임을 구분 |

납부서 생성 자체가 필요한 업무는 [[홈택스-납부서-만들기]]를 따른다. 본 문서는 작성된 결과의 검토·전달·확인 절차를 소유한다.

## 3. 상태 관리

`최종 검토 → 신고 접수 확인 → 납부서 전달 → 고객 수신 확인 → 실제 납부 확인`

- 발송일·경로와 수신 회신을 적는다. 문자로 보낸 납부서를 고객이 업무방에서 찾으면 전달 경로를 알려주고 다시 확인한다.
- “받았습니다”, “납부하겠습니다”는 실제 납부 증빙이 아니다. 실제 납부 여부를 확인할 자료가 없으면 **미확인**으로 남긴다.
- 개별 납기 연장을 다른 고객에게 적용하지 않는다. 법정 일정은 [[기장고객-연간업무일정]]에서 공식 안내와 대조한다.
- 자료·수신·납부가 미확인인 항목에는 후속 연락 담당·다음 조치일을 지정한다. 사무소의 연락 횟수·기준일은 [[기장고객-소통과-담당자-인계]]에서 확정한다.

## 안내 문구

“현재 계산은 [기준일]까지 받은 자료를 반영한 예상입니다. [미반영 자료] 확인 후 달라질 수 있으며, 최종 검토가 끝나면 다시 안내드리겠습니다.”

“[대상 기간·세목] 신고 결과와 납부서를 전달드립니다. 납부서상 기한은 [날짜]입니다. 자료를 받으셨는지 회신 부탁드립니다.”
