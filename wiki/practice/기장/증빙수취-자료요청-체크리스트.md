# 증빙수취·자료요청 체크리스트

> [!info] 개요
> 기장고객에게 필요한 자료를 요청하고, 실제 파일 확보·내용 확인·장부 반영까지 추적하는 절차 초안이다. 고객별 원본과 진행표는 위키 밖의 업무시스템에서 관리한다.

## 1. 요청 전에 할 일

1. 대상 연도·반기·월과 이번 신고 범위를 먼저 정한다.
2. 이전 상담·개인 대화·직원 업무방에서 이미 받은 자료를 접수 목록에 연결한다.
3. 홈택스에서 확보 가능한 자료는 조회·수임 권한과 조회 결과를 먼저 확인한다. 누락·기간 차이·용도 불명확 항목만 추가 요청한다.
4. 자료마다 요청일·수신일·대상 기간·보관 위치·확인 담당·최종 버전·미해결 질문을 기록한다.

## 2. 수집 목록

| 구분 | 받을 자료·회신 | 확인할 점 |
|---|---|---|
| 임차료 | 해당 기간 종이 세금계산서 등 조회되지 않는 자료 | 월별 매수·공급기간·중복, 다음 반기 자료 혼입 |
| 카드·현금영수증 | 불명확 거래의 사용 용도와 개인 사용 표시 | 고객이 업무용이라고 답했어도 증빙·실제 사용과 공제 요건은 따로 검토 |
| 차량 | 등록·구입·취득 관련 증빙, 보험·금융·주행·업무 사용 자료 | 자산가액·비용·대출을 구분할 수 있도록 묶음 관리 |
| 결산 잔액 | 연말 사업용 계좌·차입금 잔액, 이자·보증료 등 | 기준일을 지정하고 장부와 대조 |
| 공제 | 연금·공제부금·기부·보험료 등 해당 증명 | 홈택스 확보 여부부터 확인, 실제 적용 판단은 별도 |
| 설립·변경 | 최종 등기부·정관·임대차·등록증·공과금 납부확인 | 최종 내용·기준일·서로 일치하는지 확인 |
| 상속 협업 | 최종 계약서·분할협의서와 필요한 재산·채무 자료 | 계약서 회수와 신고·등기 결과를 별도 추적 |

부가세 자료의 세부 항목은 [[부가가치세-신고자료-준비체크리스트]], 결산 자료는 [[종합소득세-결산-체크리스트]]를 따른다. 같은 요청표를 중복 운영하지 않는다.

## 3. 전송 표시와 실제 파일 확보를 구분한다

`요청함 → 전송 표시 확인 → 파일 확보 → 내용 확인 → 보완 필요 또는 장부 반영`

- TXT에 사진·파일 전송 표시만 있으면 **첨부 내용 미확인**이다. 파일명만으로 수치·작성 내용·승인 여부를 추정하지 않는다.
- 같은 이름의 파일이 재전송되면 수정 여부를 확인하고 이전본을 보존한다. 최종 적용본에는 확인일을 표시한다.
- 통화 요청과 삭제 메시지는 내용 확인 근거가 아니다. 통화 후 실제 확인한 사항만 별도 기록한다.
- 고객이 제출한 사실과 경비·공제 인정 판단을 구분한다 → [[사업소득-필요경비와-증빙]].

## 4. 대납금·카드 혜택 대사

1. 고객 대납액, 사무소 수수료, 카드 결제액, 혜택 수령액을 구분한다.
2. 혜택 적용 거래·제외 거래를 확인하고 실제 카드사 명세와 대조한다.
3. 요율을 곱한 예상액은 추산으로 표시한다. 고객이 처음 동의했어도 뒤에 계산 범위 오류·수정본이 오면 최종액을 다시 확인한다.
4. 수익 귀속과 계정 처리는 검토 담당자가 판단한다. 대화의 분개·과세 결론 자체는 현행 근거로 확정하지 않는다 `[현행 기준 확인 필요]`.

## 요청 문구 예시

“[대상 기간] 자료 중 [목록] 확인을 부탁드립니다. 카드 확인표에는 업무용 지출의 용도를 적고 개인 사용은 구분해 주세요. 이미 확보한 자료는 제외했습니다. 검토 후 추가 확인이 필요한 부분은 다시 안내드리겠습니다.”
