# 기장고객 종합소득세 결산 체크리스트

> [!info] 개요
> 계속 기장하는 개인사업자의 가결산·자료 보완·최종 검토·신고 안내를 잇는 초안이다. 세액 계산과 공제 판단의 정본은 [[종합소득세-과세체계와-신고]]다.

## 1. 가결산과 사전 안내

- [ ] 기준일, 반영 자료, 미반영 비용·공제를 예상세액과 함께 적는다.
- [ ] 연중 차량 취득·리모델링·자산 구입 등 큰 변동을 확인한다.
- [ ] 인건비·가족 지급액은 실제 지급·업무 내용에 맞춰 확인한다 → [[급여-원천세-업무-체크리스트]].
- [ ] 연금·기부·공제부금 등의 납입 자료와 적용 요건을 확인한다. 과거 상담의 한도·공제율을 현재 기준으로 사용하지 않는다.
- [ ] 고객이 조기 마감을 요청하면 자료 마감일·검토 순서·다음 안내일을 정한다. 과거 소요 기간을 모든 고객에게 약속하지 않는다.

## 2. 자료 보완과 대사

자료는 [[증빙수취-자료요청-체크리스트]]의 접수 목록 하나로 관리한다.

| 항목 | 결산 검토 |
|---|---|
| 사업용 계좌·차입금 | 연말 기준 잔액과 장부 잔액, 이자·보증료와 차입 목적 확인 |
| 카드·현금영수증 | 고객 회신의 실제 용도, 개인 사용, 비용·자산 구분 |
| 차량 | 취득·등록·보험·금융·주행 자료 확보, 취득 시점과 적용 기간 확인 |
| 대납·혜택 | 고객 대납금과 수수료·카드 혜택 구분, 수정본과 실제 수령 명세 대사 |
| 기타 비용 | 경조사·보험 등 실제 사업 관련성과 증빙 확인 |
| 공제 | 홈택스 확보 여부·미수집 증명·해당 연도 적용 요건 확인 |

차량의 세법 판단은 [[업무용승용차-사업용자동차-세무]], 경비·증빙은 [[사업소득-필요경비와-증빙]], 절세금융상품은 [[사업자-절세금융상품]]을 확인한다. 총주행거리 한 장을 받은 것만으로 업무 사용 요건을 충족한 것으로 처리하지 않는다.

## 3. 최종 검토와 안내

1. 미회신 질문·미확인 증빙·수정 계산 항목을 검토 담당자에게 넘긴다.
2. 통화로 말한 예상치와 최종 결재 수치를 구분한다. 수치가 바뀌면 고객에게 최종 결과를 다시 안내한다.
3. 신고 요약·소득세 및 지방소득세 납부서·조정료 청구서를 구분해 전달한다 → [[신고검토와-납부확인]].
4. 조정료 입금 회신을 세금 납부 완료로 기록하지 않는다.

## 가족 등 별도 신고 문의

신고도움자료를 받아 해당 연도의 다른 소득·경비·공제를 확인한다. 모두채움 안내를 받은 사실만으로 최적 신고라고 단정하거나, 전년도 판단을 다음 연도에 자동 적용하지 않는다.
