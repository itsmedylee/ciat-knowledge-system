# 법인설립 절차와 초기세팅

이 문서는 법인을 새로 세울 때의 **순서와, 나중에 되돌리기 어려운 결정들**을 정리한 절차서다. 개인사업자의 신규 개업은 [[신규사업자-개업세팅-체크리스트]]에서, **법인으로 전환할지 말지의 판단**은 [[개인사업자-법인전환-검토체크리스트]]에서 확인한다. 여기서는 **전환하기로 정한 뒤 또는 처음부터 법인으로 시작할 때** 무엇을 어떤 순서로 정하는지만 다룬다.

## 개인사업자와 결정적으로 다른 점

**법원 등기를 먼저 마쳐야 한다.** 법인등기부등본이 나와야 그것으로 사업자등록을 할 수 있다(개인의 주민등록등본에 해당하는 서류다). 직접 등기하는 것도 가능하지만, 실무에서는 법무사에게 맡기기를 권한다 `[강사견해]`.

```
① 등기 전 결정사항 확정 → ② 임대차계약(개인 명의) → ③ 법인 설립등기
   → ④ 임대차계약서 법인 명의 재작성 → ⑤ 인허가(필요 시) → ⑥ 사업자등록 → ⑦ 금융·세무 세팅
```

## 1. 소재지: 계약 전에 결정한다

- [ ] **수도권 과밀억제권역에 해당하는지 확인**한다: 대표자가 처음 창업하고 연령요건을 갖추면 감면 대상이 될 수 있으므로, 어느 주소지를 고르느냐에 따라 세부담이 크게 달라진다 → [[창업중소기업-세액감면]]
- [ ] ⚠️ **임대차계약 시점에는 아직 법인 등기가 없다.** 개인 명의로 먼저 계약하고, 등기 후 **법인 명의로 재작성**해야 한다.
- [ ] **임대인에게 이 사실을 미리 고지하고 특약사항에 명시**한다. 경험이 적은 임대인이 재작성을 거부해 사업자등록이 막히는 사례가 실제로 발생한다.
- [ ] 재작성에 동의하는 임대인과만 계약한다

## 2. 등기 전에 정해야 할 것

### 주주 구성

- [ ] **주주는 회사의 주인**이며 지분율에 따라 배당으로 이익을 나눠 받는다. 주주와 대표이사는 역할이 서로 다르다.
- [ ] **가족을 주주로 넣을지 설립 단계에서 결정**한다. 설립 시점에 자녀 등에게 지분을 배분해 두면 이후 이익을 배당으로 나눌 수 있다.
- [ ] ⚠️ 가족 주주는 **증여세와 실제 주주권 행사**가 전제되어야 한다. 명의만 빌리는 구조는 부인 위험이 있다 → [[법인활용-소득분산과-실질과세]]
- [ ] ⚠️ 법인이 **감면을 받으려면 대표자의 나이와 지역뿐 아니라 지분율까지 검토**해야 한다

### 임원 구성

- [ ] **대표이사**: 등기이사로서 법적 책임을 진다. 감면을 받으려면 **최초 창업자가 대표자**여야 한다.
- [ ] **감사 1인 지정**: 등기하려면 감사가 필요하다. 은퇴한 부모나 배우자 등이 맡는 경우가 많다. **감사로 등재했다고 해서 급여를 지급해야 하는 것은 아니다.**

### 목적사항(업종)

- [ ] ⚠️ **법인은 등기부등본에 적힌 목적사항 범위 안에서만 업종을 등록할 수 있다.** 앞으로 할 가능성이 있는 업종을 **설립할 때 모두 넣어 둔다.**
- [ ] 흔히 함께 넣는 업종은 부동산임대업, 부동산매매업, 경영컨설팅, 광고업, 전자상거래다
- [ ] 빠뜨린 업종은 나중에 추가할 수 있지만 **등기를 고치는 수수료가 든다**(사업자등록 정정과 달리 비용이 생긴다)
- [ ] ⚠️ **감면 측면에서는 나중에 업종을 추가하면 "사업의 확장"으로 판정될 위험**이 있다 → [[창업중소기업-세액감면]]

### 자본금

- [ ] 자본금은 **법인에서 마음대로 빼 쓸 수 없는 돈**이라는 점을 전제로 정한다
- [ ] 실무에서는 평균 **500만~1,000만원** 수준으로 정한다 `[강의 시점 기준]`
- [ ] 너무 낮으면(예: 100만원) **신용도에 문제**가 생기고, 너무 높으면 **등록면허세 등 설립 비용이 늘고 자금이 묶인다**

## 3. 설립등기 이후

- [ ] 임대차계약서를 **법인 명의로 다시 작성**한다
- [ ] 음식점·전자상거래 등은 **인허가를 받거나 통신판매업 신고**를 한다 (등기 후, 사업자등록 전)
- [ ] **사업자등록**을 신청한다
- [ ] 은행에서 법인 통장을 개설하고, 법인카드와 **공인인증서를 발급**받는다
- [ ] 홈택스에 사업용 계좌와 카드를 등록한다 → [[신규사업자-개업세팅-체크리스트]]

## 4. 대표이사 급여 설정

- [ ] 급여 수준은 **소득세와 법인세에 동시에 영향**을 주므로 신중히 결정한다 → [[법인-대표자보수와-자금인출]]
- [ ] **초기에는 무보수로 설정할 수 있다**: 아직 이익이 없거나 다른 소득이 있어 급여가 필요하지 않다면, **공단에 대표자 무보수 관련 서류를 제출**한다

## 5. 운영 단계에서 달라지는 점

- [ ] **법인은 세무기장이 사실상 필수**다. 기장료는 법인 기준으로 월 15만원부터 시작하며 부가세는 별도다 `[강의 시점 기준]`
- [ ] **통장 거래내역과 증빙을 철저히 일치**시켜야 한다. 개인사업자보다 요구되는 수준이 높다
- [ ] 법인에서는 **자금을 마음대로 인출할 수 없다**. 다만 대부분의 거래는 인출 없이 이루어지므로, 초기 세팅만 갖추면 운영은 단순해진다

## 강의상 단순화 주의

- "법인 전환하면 소득세와 건강보험료를 크게 줄인다"는 **결과가 보장된 것이 아니다.** 급여·배당 설계와 실제 자금 사용 계획에 따라 달라진다 → [[개인사업자-법인전환-검토체크리스트]]
- "절차가 생각보다 간단하다"는 **설립 절차**에 한정된 이야기다. 설립 이후의 증빙·자금관리 부담은 별개다.
