# 법인설립 절차와 초기세팅

이 문서는 법인을 새로 세울 때의 **순서와, 나중에 되돌리기 어려운 결정들**을 정리한 절차서다. 개인사업자의 신규 개업은 [[신규사업자-개업세팅-체크리스트]]에서, **법인으로 전환할지 말지의 판단**은 [[개인사업자-법인전환-검토체크리스트]]에서 확인한다. 여기서는 **전환하기로 정한 뒤 또는 처음부터 법인으로 시작할 때** 무엇을 어떤 순서로 정하는지만 다룬다.

## 개인사업자와 결정적으로 다른 점

통상 설립등기를 마치고 사업자등록을 진행하지만, 설립등기 전 등록을 예정한 규정도 있으므로 등기 완료를 절대적 선행요건으로 안내하지 않는다. 설립형태와 사업개시 일정에 맞춰 서류를 확인한다(부가가치세법 시행령 제11조).

```
① 등기 전 결정사항 확정 → ② 임대차계약(개인 명의) → ③ 법인 설립등기
   → ④ 임대차계약서 법인 명의 재작성 → ⑤ 인허가(필요 시) → ⑥ 사업자등록 → ⑦ 금융·세무 세팅
```

## 1. 소재지: 계약 전에 결정한다

- [ ] **수도권 과밀억제권역에 해당하는지 확인**한다: 대표자가 처음 창업하고 연령요건을 갖추면 감면 대상이 될 수 있으므로, 어느 주소지를 고르느냐에 따라 세부담이 크게 달라진다 → [[창업중소기업-세액감면]]
- [ ] ⚠️ **임대차계약 시점에는 아직 법인 등기가 없다.** 개인 명의로 먼저 계약하고, 등기 후 **법인 명의로 재작성**해야 한다.
- [ ] **임대인에게 이 사실을 미리 고지하고 특약사항에 명시**한다. 경험이 적은 임대인이 재작성을 거부해 사업자등록이 막히는 사례가 실제로 발생한다.
- [ ] 재작성에 동의하는 임대인과만 계약한다

## 2. 등기 전에 정해야 할 것

### 주주 구성

- [ ] **주주는 회사의 주인**이며 지분율에 따라 배당으로 이익을 나눠 받는다. 주주와 대표이사는 역할이 서로 다르다.
- [ ] **가족을 주주로 넣을지 설립 단계에서 결정**한다. 설립 시점에 자녀 등에게 지분을 배분해 두면 이후 이익을 배당으로 나눌 수 있다.
- [ ] ⚠️ 가족 주주는 **증여세와 실제 주주권 행사**가 전제되어야 한다. 명의만 빌리는 구조는 부인 위험이 있다 → [[법인활용-소득분산과-실질과세]]
- [ ] ⚠️ 법인이 **감면을 받으려면 대표자의 나이와 지역뿐 아니라 지분율까지 검토**해야 한다

### 임원 구성

- [ ] **대표이사**: 등기이사로서 법적 책임을 진다. 감면을 받으려면 **최초 창업자가 대표자**여야 한다.
- [ ] **감사 1인 지정**: 등기하려면 감사가 필요하다. 은퇴한 부모나 배우자 등이 맡는 경우가 많다. **감사로 등재했다고 해서 급여를 지급해야 하는 것은 아니다.**

### 목적사항(업종)

- [ ] ⚠️ **법인은 등기부등본에 적힌 목적사항 범위 안에서만 업종을 등록할 수 있다.** 앞으로 할 가능성이 있는 업종을 **설립할 때 모두 넣어 둔다.**
- [ ] 흔히 함께 넣는 업종은 부동산임대업, 부동산매매업, 경영컨설팅, 광고업, 전자상거래다
- [ ] 빠뜨린 업종은 나중에 추가할 수 있지만 **등기를 고치는 수수료가 든다**(사업자등록 정정과 달리 비용이 생긴다)
- [ ] ⚠️ **감면 측면에서는 나중에 업종을 추가하면 "사업의 확장"으로 판정될 위험**이 있다 → [[창업중소기업-세액감면]]

### 자본금

- [ ] 자본금은 **법인에서 마음대로 빼 쓸 수 없는 돈**이라는 점을 전제로 정한다
- [ ] 실무에서는 평균 **500만~1,000만원** 수준으로 정한다 `[강의 시점 기준]`
- [ ] 너무 낮으면(예: 100만원) **신용도에 문제**가 생기고, 너무 높으면 **등록면허세 등 설립 비용이 늘고 자금이 묶인다**

## 3. 설립등기 이후

- [ ] 임대차계약서를 **법인 명의로 다시 작성**한다
- [ ] 음식점·전자상거래 등은 **인허가를 받거나 통신판매업 신고**를 한다 (등기 후, 사업자등록 전)
- [ ] **사업자등록**을 신청한다
- [ ] 은행에서 법인 통장을 개설하고, 법인카드와 **공인인증서를 발급**받는다
- [ ] 홈택스에 사업용 계좌와 카드를 등록한다 → [[신규사업자-개업세팅-체크리스트]]

## 4. 대표이사 급여 설정

- [ ] 급여 수준은 **소득세와 법인세에 동시에 영향**을 주므로 신중히 결정한다 → [[법인-대표자보수와-자금인출]]
- [ ] **초기에는 무보수로 설정할 수 있다**: 아직 이익이 없거나 다른 소득이 있어 급여가 필요하지 않다면, **공단에 대표자 무보수 관련 서류를 제출**한다

## 5. 운영 단계에서 달라지는 점

- [ ] **법인은 세무기장이 사실상 필수**다. 기장료는 법인 기준으로 월 15만원부터 시작하며 부가세는 별도다 `[강의 시점 기준]`
- [ ] **통장 거래내역과 증빙을 철저히 일치**시켜야 한다. 개인사업자보다 요구되는 수준이 높다
- [ ] 법인에서는 **자금을 마음대로 인출할 수 없다**. 다만 대부분의 거래는 인출 없이 이루어지므로, 초기 세팅만 갖추면 운영은 단순해진다

## 6. 매출 없는 첫해: 장부·신고와 기장 시작 시점 (2026-11-13 추가)

매출이 없어도 법인은 **설립등기일부터 복식부기 장부**를 갖추고 신고해야 한다. 계약 시점("매출이 생기면 맡기겠다")과 장부 의무 시점은 별개다. ([[신설 법인 기장은 언제부터 매출 없는 첫해, 기장대리와 셀프기장-소스요약]])

- [ ] **첫해 신고 일정(12월 결산)**: 법인세 다음 해 3/31(소득이 없거나 결손이어도 신고, 재무제표·세무조정계산서 미첨부 시 신고로 보지 않음, 법인세법 §60③·⑤), 법인지방소득세 4/30, 부가세 확정신고(매출 0원이어도) 7/25·1/25, 예정신고·고지 4/25·10/25, 주민세 사업소분 8/31(7/1 현재 사업소).
- [ ] **무기장가산세 0원의 함정을 설명한다.** 무기장가산세는 max(산출세액 20%, 수입금액 1만분의 7)이라 매출·세액이 0인 첫해는 0원이다(§75의3). 그러나 신고하지 않아 추계로 결정되면 결손금도 0이 되어, **첫해 비용이 다음 해 이후 공제할 결손금으로 남지 않는다.** 가상 사례(첫해 비용 800만 원, 다음 해 소득 3,000만 원, 중소기업)에서 결손금 신고 여부에 따라 다음 해 법인세·지방소득세가 242만 원 vs 330만 원(88만 원 차이)이다. → [[이월결손금-공제]]
- [ ] 3만 원 초과 지출에 적격증빙이 없으면 산출세액이 없어도 증빙불비가산세(2%)가 붙는다.
- [ ] **기장 방식 판단**: 외부세무조정 대상이 아니면 월 기장·다음 해 3월 결산만·직접 신고 모두 가능하다. 대표 개인 결제가 섞이거나 매달 나가는 비용(임차료·구독료)이 있거나 다음 해 매출이 예정되면 **지금부터 월 기장**, 거래가 몇 건이고 법인 통장·카드로만 결제했다면 **3월 결산·세무조정만**으로도 충분하다는 것이 필자 견해다 `[강사견해]`.
- [ ] **설립 전후 지출**: 설립비용은 **정관에 기재된 것만** 손금(국세청 회신 `[원문 확인 필요]`). 사업자등록 전 매입세액은 공급시기가 속하는 과세기간 종료 후 **20일 이내 등록 신청** 시에만 공제되므로, 준비 단계의 큰 지출이 있으면 등록을 앞당긴다(설립등기 전에도 신청 가능). 대표 개인 결제분은 가수금으로, 가지급금은 첫해부터 0원으로 유지한다.
- [ ] **수임 시 받을 자료**: 정관(설립비용 조항), 등기사항전부증명서, 사업자등록증, 주주명부, 설립일부터의 법인 통장 전체 내역, 법인카드 내역, 설립등기 비용·등록면허세·법무사 세금계산서, 설립 전 지출 증빙과 결제 명의, 임대차계약서·보증금 이체 내역, 대표 개인 결제분 목록, 홈택스·위택스 수임 동의 → [[신규수임-온보딩-체크리스트]]
- [ ] **월 점검 숫자 5개**: 통장 잔액 = 장부 예금 잔액, 가수금 잔액과 영수증, 가지급금 0원, 결손금 누계, 3만 원 초과 적격증빙 미비 목록.

## 강의상 단순화 주의

- "법인 전환하면 소득세와 건강보험료를 크게 줄인다"는 **결과가 보장된 것이 아니다.** 급여·배당 설계와 실제 자금 사용 계획에 따라 달라진다 → [[개인사업자-법인전환-검토체크리스트]]
- "절차가 생각보다 간단하다"는 **설립 절차**에 한정된 이야기다. 설립 이후의 증빙·자금관리 부담은 별개다.

## 외부 등기 협업·변경 관리 (절차 보완)

> [!note] 참고
> [[기장협업-개별대화-익명요약-소스요약]]에서 일반화한 접수·서류·결과 확인 절차다. 상호·영문 표기·임원·결의·등기 요건을 현행 원문과 대조한 보완은 아니다. 기존 본문의 법률·세무 판단은 해당 정본과 전문가에게 별도 확인한다.

| 단계 | 확인할 일 |
|---|---|
| 소개·연락 | 연락 동의·가능일·첫 통화·다음 확인일 |
| 신청 전 | 상호·영문 병기·본점·자본금·주주 지분·임원·현재와 예정 목적의 최종 확인 |
| 서류 | 임대차 명의·날인·잔고 등 필요 자료 충족 여부를 등기 담당자가 확인 |
| 접수·보정 | 신청 내용·접수일·서류 미비·보정·후속 일정 기록 |
| 완료 | 최종 등기부·정관을 실제 확보하고 고객 전달·사업자등록 인계 확인 |
| 결산 인계 | 설립·이전 공과금의 납부처·납부확인서 회수 |

- 참고 회사의 목적을 복사하기 전에 실제 예정 사업과 인허가를 확인한다. 특이 상호·영문 병기는 현행 규정과 관할 확인 사항으로 남긴다.
- 본점 변경은 실제 이전인지 최초 기재 오류인지 구분하고 최종 등기·임대차·사업자등록 정정 내용을 대조한다.
- 공동대표·각자대표·이사 추가 중 최종 결정과 결과를 확인한다. 최초 상담명이 최종 등기 내용과 같다고 추정하지 않는다.
- 목적 추가·정관 정비의 결의·날인·첨부·등기 여부는 담당 전문가에게 확인한다. 설립 기본 정관과 추가 유료 정비 범위는 사전 안내한다.
- 서류·일정 지연과 차년도 연기는 보류 상태로 관리한다. 취급 범위·견적·보수 지원·증빙·완료 문서 회수의 운영 기준은 [[외부전문가-협업운영]]을 따른다.
