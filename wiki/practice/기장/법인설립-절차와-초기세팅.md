# 법인설립 절차와 초기세팅

법인을 새로 세울 때의 **순서와 되돌리기 어려운 결정들**을 정리한 절차서다. 개인사업자의 신규 개업은 [[신규사업자-개업세팅-체크리스트]], **전환할지 말지의 판단**은 [[개인사업자-법인전환-검토체크리스트]]를 본다. 여기서는 **전환하기로 정한 뒤 또는 처음부터 법인으로 시작할 때** 무엇을 어떤 순서로 정하는지만 다룬다.

## 개인사업자와 결정적으로 다른 점

**법원 등기가 선행되어야 한다.** 법인등기부등본이 나와야 그것으로 사업자등록을 할 수 있다(개인의 주민등록등본에 해당). 셀프 등기도 가능하나 실무상 법무사 위임을 권한다 `[강사견해]`.

```
① 등기 전 결정사항 확정 → ② 임대차계약(개인 명의) → ③ 법인 설립등기
   → ④ 임대차계약서 법인 명의 재작성 → ⑤ 인허가(필요 시) → ⑥ 사업자등록 → ⑦ 금융·세무 세팅
```

## 1. 소재지 — 계약 전에 결정한다

- [ ] **수도권 과밀억제권역 여부 확인** — 대표자가 최초 창업이고 연령요건을 갖추면 감면 대상이 되므로, 주소지 선택이 세부담을 크게 가른다 → [[창업중소기업-세액감면]]
- [ ] ⚠️ **임대차계약 시점에는 아직 법인 등기가 없다.** 개인 명의로 먼저 계약하고, 등기 후 **법인 명의로 재작성**해야 한다.
- [ ] **임대인에게 이 사실을 미리 고지하고 특약사항에 명시**한다. 경험이 적은 임대인이 재작성을 거부해 사업자등록이 막히는 사례가 실제로 발생한다.
- [ ] 재작성에 동의하는 곳에서만 계약한다

## 2. 등기 전에 정해야 할 것

### 주주 구성

- [ ] **주주는 회사의 주인**이며 지분율에 따라 배당으로 이익을 배분받는다. 대표이사와 역할이 분리된다.
- [ ] **가족을 주주로 넣을지 설립 단계에서 결정**한다 — 설립 시점에 자녀 등에게 지분을 배분해 두면 이후 이익을 배당으로 나눌 수 있다.
- [ ] ⚠️ 가족 주주는 **증여세와 실제 주주권 행사**가 전제되어야 한다. 명의만 빌리는 구조는 부인 위험이 있다 → [[법인활용-소득분산과-실질과세]]
- [ ] ⚠️ **감면을 받으려면 법인은 대표자 나이·지역뿐 아니라 지분율까지 검토**해야 한다

### 임원 구성

- [ ] **대표이사** — 등기이사로서 법적 책임을 진다. 감면을 받으려면 **최초 창업자가 대표자**여야 한다.
- [ ] **감사 1인 지정** — 등기상 필요. 은퇴한 부모나 배우자 등이 맡는 경우가 많다. **등재했다고 급여를 지급해야 하는 것은 아니다.**

### 목적사항(업종)

- [ ] ⚠️ **법인은 등기부등본의 목적사항 범위 내에서만 업종 등록이 가능하다.** 앞으로 할 가능성이 있는 업종을 **설립 시점에 모두 넣어둔다.**
- [ ] 흔히 함께 넣는 것 — 부동산임대업, 부동산매매업, 경영컨설팅, 광고업, 전자상거래
- [ ] 누락 시 나중에 추가할 수는 있으나 **등기 수정 수수료가 발생**한다(사업자등록 정정과 달리 비용이 든다)
- [ ] ⚠️ **감면 관점에서는 사후 업종 추가가 "사업의 확장"으로 판정될 위험**이 있다 → [[창업중소기업-세액감면]]

### 자본금

- [ ] **법인에서 임의로 뺄 수 없는 금액**임을 전제로 정한다
- [ ] 실무 평균 **500만~1,000만원** 수준 `[강의 시점 기준]`
- [ ] 너무 낮으면(예: 100만원) **신용도 문제**가 생기고, 너무 높으면 **등록면허세 등 설립 비용이 늘고 자금이 묶인다**

## 3. 설립등기 이후

- [ ] 임대차계약서를 **법인 명의로 재작성**
- [ ] 음식점·전자상거래 등 **인허가·통신판매업 신고** (등기 후, 사업자등록 전)
- [ ] **사업자등록** 신청
- [ ] 은행: 법인 통장 개설, 법인카드 발급, **공인인증서 발급**
- [ ] 홈택스 사업용 계좌·카드 등록 → [[신규사업자-개업세팅-체크리스트]]

## 4. 대표이사 급여 설정

- [ ] 급여 수준은 **소득세와 법인세에 동시에 영향**을 주므로 신중히 결정한다 → [[법인-대표자보수와-자금인출]]
- [ ] **초기 무보수 설정 가능** — 아직 이익이 없거나 다른 소득이 있어 급여가 불필요하면, **공단에 대표자 무보수 관련 서류를 제출**한다

## 5. 운영 단계에서 달라지는 점

- [ ] **법인은 세무기장이 사실상 필수**다. 기장료는 법인 기준 월 15만원부터 시작하며 부가세 별도 `[강의 시점 기준]`
- [ ] **통장 거래내역과 증빙을 철저히 일치**시켜야 한다 — 개인사업자보다 요구 수준이 높다
- [ ] **자금 인출이 제한적**이다. 다만 대부분의 거래는 인출 없이 이루어지므로 초기 세팅만 갖추면 운영은 단순해진다

## 강의상 단순화 주의

- "법인 전환하면 소득세와 건강보험료를 크게 줄인다"는 **결과가 보장된 것이 아니다.** 급여·배당 설계와 실제 자금 사용 계획에 따라 달라진다 → [[개인사업자-법인전환-검토체크리스트]]
- "절차가 생각보다 간단하다"는 **설립 절차**에 한정된 이야기다. 설립 이후의 증빙·자금관리 부담은 별개다.
