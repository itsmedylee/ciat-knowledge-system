# 신규사업자 개업세팅 체크리스트

신규 창업 고객을 수임할 때 **개업 시점에 한 번만 할 수 있는 결정**을 놓치지 않기 위한 절차서다. 법리·감면 요건의 근거는 여기에 두지 않고 정본 topic을 참조한다.

> **이 체크리스트의 존재 이유**: 개업 단계 항목의 상당수는 **사후 정정이 어렵거나 불가능**하다. 업종코드는 창업감면을, 과세유형 선택은 초기 시설투자 매입세액 환급을, 확정일자는 보증금 순위를 각각 되돌리기 어렵게 확정시킨다. 기장 수임 후 첫 마감에서 발견하면 이미 늦은 항목들이다.

## 진행 순서

```
장소 선정·임대차계약
   └→ ① 사업장 소재지 확인 (과밀억제권역 여부 = 감면율)
영업 인허가 (해당 업종만)
   └→ ② 인허가 취득 — 사업자등록보다 먼저
세무서·홈택스
   └→ ③ 업종코드 결정   ③-2 장부신고 방식   ④ 과세유형 선택   ⑤ 면허 신청   ⑥ 확정일자
은행·홈택스
   └→ ⑦ 사업용 계좌 개설·신고   ⑧ 사업용 카드 등록
직원 채용 시
   └→ ⑨ 4대보험 취득신고 · 원천세 · 근로계약서
```

> ⚠️ **사업자등록 시점을 오해하지 않는다.** 사업자는 원칙적으로 사업개시일부터 20일 이내 등록하며, 사업개시 전에도 신청할 수 있다. 개업 전 매입세액 공제에는 등록신청 기한·세금계산서 수취요건이 따르므로, 초기 인테리어·설비비 지출 전에 등록일정을 잡는다. "비용이 처음 발생한 날이 곧 법정 등록일"이라고 단정하지 않는다.

## 단계별 체크

### ① 사업장 소재지 — 계약 전에 확인
- [ ] **과밀억제권역 해당 여부** 확인. 같은 청년창업이라도 과밀억제권역이면 감면율이 절반으로 떨어진다 → [[창업중소기업-세액감면]]
- [ ] 2027년 이후 창업 예정이면 정부안의 **수도권 일반 / 비수도권 광역시·수도권 우대지역 / 기타 비수도권 / 비수도권 우대지역** 중 예상 구간을 판정하고, 우대지역은 시행령 확정 후 재확인한다.
- [ ] 2026년 창업과 2027년 창업의 감면율을 비교하되 **국회 통과 전 정부안**임을 고객에게 명시한다. 세금 외 사업 일정·계약·매출기회도 함께 기록한다.
- [ ] 임대차계약서상 **임대인 정보**를 사업자등록 신청서 기재용으로 확보
- ⚠️ 이 항목은 **계약 체결 전** 상담에서 다뤄야 실익이 있다. 계약 후에는 선택지가 없다.

### ② 영업 인허가 — 사업자등록보다 먼저
- [ ] 해당 업종의 인허가 필요 여부 확인
- [ ] **음식점(카페·주점·치킨집 포함)**: 구청 식품위생과 **영업신고증**. 구비서류 4종
  - [ ] 임대차계약서
  - [ ] 사업주 신분증
  - [ ] **건강진단결과서**(구 보건증)
  - [ ] **식품위생교육 수료증**
- [ ] 기존 동일업종 자리가 아니면(신축 건물·타 업종 전환) **현장 실사 소요기간**을 개업일정에 반영

### ③ 업종코드 — 감면 여부가 여기서 결정된다
- [ ] 국세청 업종코드(6자리) 확정. 근거는 [[창업중소기업-세액감면]]
- [ ] 실제 영위업종이 **감면 배제 업종에 해당하는지** 확인 — 음식점업 중 주점 및 비알코올 음료점업은 감면 대상에서 제외된다(조특법 §6③제7호, 2026-08-20 조문 대조). 업종코드는 실제 사업내용에 맞춘다.
- [ ] 겸업 업소(예: 베이커리 카페)는 **상호와 업종코드의 정합성** 확인. 상호가 업종 판단의 증거가 되므로 상호 확정 전에 상담하는 것이 유리
- [ ] 확장 예정 업종을 부업종으로 추가하려는 경우 → **조특법 §6⑩(사업확장·업종추가는 창업 아님)** 을 먼저 고지

### ③-2 장부신고 방식 — 2027년 추계과세 배제 대비
- [ ] 창업감면 적용 예정 사업자의 신고방식을 **장부에 따른 실제소득 신고 / 추계신고**로 구분한다.
- [ ] 2027-01-01 이후 개시 과세연도부터 추계과세 시 창업감면을 배제한다는 정부안을 설명하고, 확정 법률·시행령을 시행 전에 재확인한다 → [[창업중소기업-세액감면]].
- [ ] 장부를 직접 작성할지 기장대리를 맡길지 정하고, 증빙수취·계좌/카드 분리·월마감 일정을 설계한다.
- ⚠️ 정부안은 **유료 세무대리인 선임을 의무화한 것이 아니다.** 영상 제목의 “기장 대리 필수”는 영업적 표현이며, 핵심은 추계가 아닌 장부 기반 신고다. `[LLM 해석 — 확정 법률 확인 필요]`

### ④ 과세유형 — 간이 vs 일반
개업 시 판단이 필요한 **최소 실행 기준**만 둔다. 법정 적용·배제업종과 예상 공급대가, 포기신고의 구속기간, 초기 매입세액을 함께 본다. 계산구조는 [[부가가치세-과세체계와-신고]]를 참조한다.

| 판단요소 | 확인 | 결론 |
|---|---|---|
| 법정 간이과세 적용·배제 | [ ] 업종·지역·직전연도 환산 공급대가 확인 | 적용 가능 여부 우선 판정 |
| 초기 시설·인테리어·비품 **세금계산서 고액 수취** | [ ] 예상 공제세액·환급 가능성 산정 | 일반과세 선택 검토 |
| 예상 B2C 매출·매입률·거래처 요구 | [ ] 연간 세부담과 세금계산서 발급 필요 비교 | 간이·일반 손익 비교 |

- ⚠️ "고액 매입이 없고 상반기 개업이면 간이, 하반기면 일반"은 강의의 경험칙일 뿐 법정 판정기준이 아니다. 일반과세를 선택하면 일정 기간 간이과세로 돌아갈 수 없는 효과까지 포함해 비교한다.
- [ ] 경계 사례는 개별 계산 후 결정하고, 판단 근거를 수임 기록에 남긴다

### ⑤ 면허 신청 — 사업자등록 신청서에서 함께
- [ ] **주류 판매**: 음식점에서 술을 판매하면 사업자등록 신청서 면허란에 주류판매 면허 신청. 누락 시 사업자등록증에 주류판매 번호가 없어 **주류 도매 매입 자체가 불가**하고 세무서를 재방문해야 한다
  - 코드 `542`로 강의에서 청취됨 `[자동자막 오인식 가능 — 신청 시 원문 대조]`

### ⑥ 확정일자 — 임차보증금 보호
- [ ] 사업자등록과 **동시에** 세무서에서 확정일자 신청
- [ ] **임대차계약서 원본에 확정일자 도장** 날인 확인 (원본에 찍혀야 한다)
- [ ] 보증금 규모가 큰 경우 상가건물 임대차보호법 적용범위(보증금 환산액 한도) 별도 확인 `[현행 기준 확인 필요]`

### ⑦ 사업용 계좌
- [ ] 개인사업자는 사업과 개인 거래를 분리할 **전용 계좌**를 개설하도록 권고하고, 신고의무가 생기면 홈택스에 사업용계좌로 신고
- [ ] 기존 개인 명의 계좌를 사업용으로 신고하지 않도록 고지 — 사업과 무관한 개인 거래 내역까지 열람 범위에 들어간다 [강사견해]
- **법정 신고·사용의무는 복식부기의무자**에게 적용된다. 해당 과세기간 개시일부터 6개월 이내 신고하며, 사업개시와 동시에 복식부기의무자가 된 경우에는 다음 과세기간 개시일부터 6개월 이내다. 미사용액의 0.2%, 미신고 시 수입금액 기간안분액의 0.2%와 의무거래금액의 0.2% 중 큰 금액을 가산세로 본다. 전 사업자에 대한 계좌 분리는 법정의무가 아니라 내부통제 권고다.

### ⑧ 사업용 카드
- [ ] 홈택스에 사업용 카드 **등록**
- [ ] 신규 발급은 불필요하다고 안내 — 혜택 좋은 기존 개인카드를 등록해 사용해도 무방 [강사견해]
- 계좌는 신설 권장 / 카드는 등록만 — 이 비대칭을 고객에게 명확히 전달

### ⑨ 직원 채용 시 — 채용 시점에 함께 처리
- [ ] 4대보험 취득신고
- [ ] 원천세 신고 체계 수립
- [ ] 근로계약서 작성
- 미이행 리스크 2종: **인건비 비용처리 누락**(세무) · **노동청 진정·고발**(노무)
- 상시근로자 수에 따른 노동법 적용 차이 → [[5인미만-사업장-근로기준법-특례]]

### ⑩ 사업자등록 직후 세팅 — 여기서 감면이 갈린다

- [ ] **사업자 명의로 홈택스 회원가입**
- [ ] 은행에서 **사업자용 공인인증서** 발급 + 인터넷뱅킹 신청
- [ ] 전자세금계산서 발급에 사용할 인증수단 확인 — **전자세금용 인증서는 선택지 중 하나**이며, 홈택스가 지원하는 사업자 공동·금융인증서나 보안카드 등 사용 가능한 수단을 발급기관·홈택스에서 확인한다
- [ ] **현금영수증 가맹점 가입** — 소비자 상대 업종으로 직전 과세기간 수입금액 **2,400만원 이상**이면 의무. 의료업·수의업·약사업·변호사·회계사 등 시행령상 전문직·의무발행업종은 수입금액과 무관하게 가입대상이 될 수 있다
- ⚠️ **사업용계좌 미신고·현금영수증 미가맹은 [[창업중소기업-세액감면]]을 전액 배제시킨다.** 등록 직후에 함께 끝내는 것이 안전하다
- [ ] 카드결제를 받는다면 **카드단말기** 설치 (수수료·기능 비교)
- [ ] **가스·전기·인터넷·관리비 등 공과금을 사업자 명의로 전환**하고 세금계산서 발행 신청 — 사업용 카드로 결제 중이라면 별도 신청은 불필요
- [ ] **인테리어 세금계산서** 수취
- [ ] **권리금 지급 시 신고 여부 결정** — 원칙은 신고
- [ ] 직원이 있다면 **4대보험 사업장 성립신고**(사업장 자체 신고)와 **취득신고**(개인별)를 구분해 처리 → ⑨

### ⑪ 세금 자금 미리 떼어두기

- [ ] 고객에게 **부가가치세는 내 돈이 아님**을 초기에 각인시킨다 — 통장에 들어온 매출의 10%는 고객에게서 받아 잠시 보관하는 돈이다. 직장인 출신 창업자가 특히 혼동한다
- [ ] 적립 권고 수준: **매출의 10% 내외**를 별도 계좌에 파킹. 음식점 등 매입세액 공제가 제한적인 업종은 **부가세용으로만 매출의 4~5%** `[강사견해]`
- ⚠️ 갑자기 매출이 늘어난 해에 대비가 없으면 **세금을 낼 현금이 없어 체납자가 되고 금융활동이 제한**된다

## 수임 시 확보할 정보
- [ ] 개업예정일 · 사업장 소재지 · 상호(확정 여부)
- [ ] 2026년/2027년 창업·지정·확인·선정 예정일과 정부안 적용 여부
- [ ] 대표자 연령(청년창업 요건 판단용)
- [ ] 일반·청년·청년 신산업·벤처·에너지신기술·점프업 등 예상 감면유형
- [ ] 초기 투자 규모와 세금계산서 수취 예정 여부
- [ ] 장부작성 방식(직접기장/기장대리)과 추계신고 가능성
- [ ] 직원 채용 계획(인원·시기)
- [ ] 기존 사업 영위 이력(§6⑩ 창업 해당 여부 판단용)

> ⚠️ **정보보호**: 위 항목은 판단에 필요한 범위로만 수집하고, 신분증 사본·사업자등록증 사본·계좌 내역 등 식별정보와 원본 업무자료는 이 위키가 아니라 승인된 업무시스템에서 관리한다.
