# 사내근로복지기금 도입·운영 체크리스트

법리의 정본은 [[사내근로복지기금]]에서 확인한다.

## 도입 전

- [ ] 현재의 급여·상여·법정수당·복지제도를 구분하고, 기금으로 대체해서는 안 되는 항목을 표시한다
- [ ] 근로자 수를 따지기 전에 노사 대표를 구성할 수 있는지, 협의회를 운영할 수 있는지부터 확인한다
- [ ] 연간 복지수요, 회사의 출연 여력, 기본재산 사용한도, 5년 현금흐름을 계산한다
- [ ] 회사가 아끼는 세금만 보지 말고, 직원이 받는 혜택, 관리비, 해산할 때의 잔여재산까지 비교한다

## 설립

- [ ] 설립준비위원회와 복지기금협의회가 적법하게 구성되었는지 확인한다
- [ ] 정관·사업계획서·예산서·출연계획을 작성한다
- [ ] 고용노동부 인가 → 법인등기 → 고유번호 발급 → 계좌개설의 순서를 확인한다
- [ ] 출연하기 전에 손금·필요경비의 귀속시기와 증빙을 세무적으로 검토한다

## 운영

- [ ] 복지사업별 대상·금액·선정기준이 정관 및 협의회 의결과 일치하도록 한다
- [ ] 주택자금대부·학자금·의료비·선택적복지·회원권별로 법정 요건을 충족하는지 확인한다
- [ ] 특정인을 우대하거나, 대표자가 사적으로 이용하거나, 임금을 대체하거나, 회사가 돈을 환급받거나 되돌려받는 일을 차단한다
- [ ] 카드·포인트·현금 중 어떤 방식으로 지급하든 수혜자·목적·증빙·잔액을 추적한다
- [ ] 사업보고서·재무제표·감사보고서·회의록을 작성해 공개하고, 5년 동안 보관한다

## 연말·해산

- [ ] 출연금·기본재산·수익금·사업비 계정을 분리해 대사한다
- [ ] 사용한도와 미사용 재산의 차기 계획을 갱신한다
- [ ] 주된 사업이 종료되면 기금법인의 해산사유, 미지급 금품, 잔여재산의 귀속을 검토한다
- [ ] 잔여재산을 회사로 임의로 반환하거나 대표자에게 분배하지 않는다
