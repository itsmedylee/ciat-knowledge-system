# 사내근로복지기금 도입·운영 체크리스트

법리 정본은 [[사내근로복지기금]]을 참조한다.

## 도입 전

- [ ] 현행 급여·상여·법정수당·복지제도를 구분하고 대체 금지 항목 표시
- [ ] 근로자 수보다 먼저 노사 대표 구성과 협의회 운영 가능성 확인
- [ ] 연간 복지수요·출연여력·기본재산 사용한도·5년 현금흐름 계산
- [ ] 회사 절세액만이 아니라 직원 수혜, 관리비, 해산 시 잔여재산까지 비교

## 설립

- [ ] 설립준비위원회/복지기금협의회 구성 적법성
- [ ] 정관·사업계획서·예산서·출연계획 작성
- [ ] 고용노동부 인가 → 법인등기 → 고유번호 → 계좌개설 순서 확인
- [ ] 출연 전 손금·필요경비 귀속시기와 증빙을 세무 검토

## 운영

- [ ] 복지사업별 대상·금액·선정기준을 정관·협의회 의결과 일치
- [ ] 주택자금대부·학자금·의료비·선택적복지·회원권별 법정 요건 확인
- [ ] 특정인 우대·대표자 사적 이용·임금 대체·환급/되돌려받기 차단
- [ ] 카드·포인트·현금 지급 모두 수혜자·목적·증빙·잔액 추적
- [ ] 사업보고서·재무제표·감사보고서·회의록 작성, 공개, 5년 보관

## 연말·해산

- [ ] 출연금·기본재산·수익금·사업비 계정을 분리 대사
- [ ] 사용한도와 미사용 재산의 차기 계획 갱신
- [ ] 주된 사업 종료 시 기금법인 해산사유·미지급금품·잔여재산 귀속 검토
- [ ] 회사로 임의 반환하거나 대표자에게 분배하지 않음
