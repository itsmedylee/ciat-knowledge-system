# 유상사급 회계검토 체크리스트

법리·측정원칙은 정본 [[유상사급-수익인식과-생물자산-회계]]를 참조하고, 마진 역산 산식은 [[매출총이익률과-원가가산율]]을 참조한다. 이 문서는 자료수집·검증·결론화 순서만 관리한다.

## 0. 정보보호와 범위

- [ ] 작업본에서 회사명·농가명·개체번호·계좌정보 등 식별정보를 제거했다.
- [ ] 검토기간, 품종·제품군, 거래처 모집단, 중요성 기준을 확정했다.
- [ ] 외부매입·유상사급·무상사급·단순 위탁가공을 구분했다.

## 1. PBC 자료 요청

- [ ] 공급·사육/재배·재매입·정산 계약서와 변경합의서
- [ ] 거래처별 공급·재매입·상계 정산명세
- [ ] 개체·수량·중량·폐사·수확·이동 롤포워드
- [ ] 세금계산서·입출고증·검수증·운송장·보험·인허가 자료
- [ ] 기말 시세·평가기법·매각원가·공정가치 산출파일
- [ ] 계정별 원장, 매출채권·매입채무·재고·생물자산 보조부
- [ ] 기말 전후 공급·재매입·판매·폐사·수확 내역

## 2. 계약과 통제 매트릭스

거래유형별로 다음을 한 표에 기록한다.

- [ ] 사용·처분 지시권
- [ ] 강제 또는 선택 재매입권
- [ ] 공급·재매입 가격결정 방식
- [ ] 폐사·수율·시장가격 위험 부담자
- [ ] 제3자 판매 가능성
- [ ] 보험·담보·보관·품질관리 책임
- [ ] 계약 문구와 실제 운영의 차이

결론: `[통제 이전 / 통제 미이전 / 추가증거 필요]` 중 하나로 표시하고 근거 문서를 연결한다.

## 3. 회계처리 매핑

- [ ] 통제 이전 거래의 공급 매출과 후속 매입을 분리했다.
- [ ] 통제 미이전 거래의 중간 매출·매출채권·이익을 제거했다.
- [ ] 계속 통제한 재고·생물자산과 관련 원가를 복원했다.
- [ ] 사육·가공 보수의 자산원가/기간비용 분류를 검토했다.
- [ ] 순액 정산과 총액/순액 수익인식 판단을 혼동하지 않았다.

## 4. 생물자산·재고자산

- [ ] 살아 있는 동식물과 수확 후 생산물의 경계일을 정했다.
- [ ] IAS 41 적용대상·IAS 2 전환대상을 품목별로 구분했다.
- [ ] 공정가치-매각원가 산정의 시장·단위·수량·원가를 검증했다.
- [ ] 직접 원가와 공정가치 변동을 별도 계정·조정표로 추적했다.
- [ ] 기초+증가-감소=기말 수량 및 금액 롤포워드를 대사했다.

## 4b. 기말재고 추정 산식 검증

물리적 실사가 불가능해 회사가 내부자료로 기말재고를 추정한 경우에 적용한다. 개념은 [[유상사급-수익인식과-생물자산-회계]] 「기말재고 추정」 절에 있다.

- [ ] 추정의 필요성(직접 수량 파악이 불가능한 사유)을 문서화했다.
- [ ] 추정 기초자료(공급 채권·재매입 채무·출고·회수 내역)의 완전성을 확인했다.
- [ ] 상계 처리한 금액이 실제로 회수된 물량에 대응하는지 별도로 검토했다.
- [ ] 미회수분이 **판매가격 기준인지 원가 기준인지** 확정했다.
- [ ] 회사 산식의 비율이 **매출총이익률인지 원가가산율인지** 정의로 확인했다. → [[매출총이익률과-원가가산율]]
- [ ] 산식 형태와 비율 종류가 짝을 이루는지 대조했다. `× (1−GPM)` 또는 `÷ (1+원가가산율)`.
- [ ] `÷ (1 + 매출총이익률)` 형태의 오류가 없는지 확인했다(원가 과대계상 방향).
- [ ] 비율이 품목·사업부·기간별로 다른 경우 가중평균의 기준을 확인했다.
- [ ] 역방향 검증(산출 원가에 비율을 재적용해 판매가격 복원)을 수행했다.

## 4c. 오류금액 산출과 평가

- [ ] **적정 추정액 − 회사 장부액 = 오류금액**으로 산출했다(추정액 자체를 오류로 보지 않았다).
- [ ] 오류가 사료재고·사료배부·생물자산 원가·공정가치 평가손익·매출원가·관련 채권채무로 전파되는 경로를 추적했다.
- [ ] 최종 재무제표(당기손익·이익잉여금) 영향금액을 산출했다.
- [ ] **CTT·오류금액·중요성을 구분**해 적용했다(CTT 초과 사실만으로 오류로 결론하지 않았다).
- [ ] 오류 원인이 단순 실수인지 개념의 구조적 오해인지 평가했다.
- [ ] 개념 오해라면 다른 기간·다른 계정에 같은 산식이 쓰이는지 범위를 확인했다.
- [ ] 회사가 자체적으로 발견·수정할 수 있었는지(통제위험)를 평가했다.

## 4d. 매출원장 유상사급 분리

- [ ] 매출차감 항목(장려금·수수료 등)을 분리했다.
- [ ] 제품코드·거래처·출고구분·거래유형으로 유상사급 거래를 식별했다.
- [ ] 반대방향 취소·상계 분개를 함께 확인했다.
- [ ] 내부거래(내부매출)를 별도로 구분했다.
- [ ] `순수매출 + 유상사급 관련 + 매출차감 = 원장 총액` reconciliation을 수행했다.
- [ ] 매출원장 분리 작업과 기말재고 추정 작업을 **별개 절차로** 문서화했다.

## 5. 기말 cut-off

- [ ] 공급 완료·재매입 미완료 거래를 전수 추출했다.
- [ ] 기말 전후 거래의 입출고일·검수일·세금계산서일·장부일을 대사했다.
- [ ] 외부매입과 유상사급 회수 물량이 중복 또는 혼합되지 않았는지 확인했다.
- [ ] 미완료 순환거래의 매출 제거·자산 복원 조정분개를 재계산했다.
- [ ] 후속 재매입·판매·현금정산으로 기말 추정의 완전성을 확인했다.

## 6. 결론 문서화

- [ ] 거래유형별 통제 결론과 반대 증거를 함께 기록했다.
- [ ] 미조정 왜곡표에 매출·채권·원가·생물자산·공정가치 효과를 분리했다.
- [ ] 기준서 원문과 회사 회계정책의 일치 여부를 확인했다.
- [ ] 경영진 판단·평가전문가 자료·법률검토가 필요한 항목을 표시했다.
- [ ] 검토자·검토일·후속조치 담당자와 완료기한을 남겼다.
