# 업무용승용차 리스 세무조정 체크리스트

리스차량의 법인세 세무조정을 자료 확보부터 이월액 사후관리까지 순서대로 수행하기 위한 절차다.

> **법리는 이 문서에 복제하지 않는다.** 한도 구조·계산식·소득처분·이월 규정의 근거는 [[업무용승용차-사업용자동차-세무]] 7-3이 소유한다. 결산·신고 전체 흐름은 [[법인세-결산신고-체크리스트]]를 따른다.
>
> ✅ **2026-08-23 조문 검증 완료** — 법 §27의2, 시행령 §50의2·§106, 시행규칙 §27의2를 법제처 원문으로 대조했다. 근거는 [[업무용승용차-사업용자동차-세무]] 7-3의 검증표 참조.

---

## 1. 적용 대상 판정

- [ ] 해당 차량이 **업무용승용차**에 해당하는가 (경차·화물차·운수업용 등 제외 대상 확인) → [[업무용승용차-사업용자동차-세무]] 1장
- [ ] 리스 상대방이 「여신전문금융업법」에 따라 **등록한 시설대여업자**인가
  - ⚠️ 등록 시설대여업자 리스와 렌터카는 감가상각비 상당액 계산식이 다르다(렌터카는 `임차료 × 70%`)
- [ ] 리스계약기간(개시일·종료일) 확인 — 사업연도 중 일부 기간만 임차했다면 **1,500만원·800만원 모두 월할**
- [ ] **부동산임대업 주업 법인 등 축소한도 대상**인가 → 해당 시 1,500만원 → 500만원, 800만원 → 400만원
  - [ ] 업종·수입금액·자산구성으로 판정

## 2. 손금 인정의 전제요건

- [ ] **업무전용자동차보험** 가입 여부 확인 ⚠️ 미가입 시 관련비용 전액 부인 가능
  - [ ] ✅ **일부 기간만 가입한 경우 0원이 아니라 일할 안분**이다(시행령 §50의2⑨) — `관련비용 × 업무사용비율 × (실제 가입일수 ÷ 의무 가입일수)`
  - [ ] ⚠️ **임대차 특약에 의한 간주는 「임차계약기간 30일 이내」 단기 임차에만 적용**된다(시행령 §50의2⑧ + 시행규칙 §27의2⑤, 연간 합계 30일 초과 시 제외). **장기 리스·장기 렌트는 실제로 보험에 가입해야 한다**
- [ ] 취득가액 기준 해당 시 **연두색 전용번호판** 부착 여부 → [[업무용승용차-사업용자동차-세무]] 7장
- [ ] **운행기록부** 작성 여부 확인
  - [ ] 작성 → 실제 업무사용비율 적용
  - [ ] 미작성 → 1,500만원 기준 적용

## 3. 자료 확보 (가장 자주 막히는 단계)

| 자료 | 확인사항 | 확보 |
|---|---|---|
| 리스계약서 | 월 리스료·계약기간·보험/자동차세/정비 포함 여부 | [ ] |
| 리스사 청구내역 | 실제 지급 리스료 | [ ] |
| **리스사 비용구분자료** | 보험료·자동차세·수선유지비의 연간 금액 | [ ] |
| 보험증권·보험내역 | 보험료 부담주체 및 금액 | [ ] |
| 자동차세 내역 | 리스료 포함 여부 | [ ] |
| 정비약정 | 정비 포함형 여부 | [ ] |
| 운행기록부 | 실제 업무사용비율 | [ ] |

⚠️ **실무상 리스계약서만으로는 구성금액이 구분되지 않는 경우가 많다.** 계약서에 구분이 없으면 리스사에 아래 문구로 요청하는 것이 가장 안전하다.

> "법인세 업무용승용차 관련비용 명세서 작성을 위한 **연간 리스료 중 보험료·자동차세·수선유지비 구분내역**"

## 4. 관련비용 집계 (①단계)

- [ ] 차량별로 다음을 합산
  - [ ] 리스료
  - [ ] 유류비
  - [ ] 보험료
  - [ ] 수선비
  - [ ] 자동차세
  - [ ] 통행료
  - [ ] **금융리스부채 이자비용**
- [ ] ⚠️ 차량이 여러 대면 **반드시 차량별로 분리 집계** (한도가 차량별로 적용된다)

## 5. 업무사용비율 결정 (②단계)

- [ ] 운행기록부 있음 → 실제 업무사용비율
- [ ] 운행기록부 없음 →
  - [ ] 관련비용 ≤ 1,500만원 → **100%**
  - [ ] 관련비용 > 1,500만원 → **1,500만원 ÷ 관련비용**
- [ ] 사업연도 중 일부 기간 임차 시 1,500만원 **월할** 적용

## 6. 감가상각비 상당액 산출 (④단계) — 가장 오류가 잦은 단계

- [ ] 기본 산식: **감가상각비 상당액 = 임차료 − 보험료 − 자동차세 − 수선유지비**
- [ ] 수선유지비를 **실제 금액으로 구분할 수 있는가?**
  - [ ] 구분 가능 → 실제 금액 차감
  - [ ] 구분 불가 → **7% 간주규정** 적용 가능 여부 판정
- [ ] ⚠️ **7% 간주규정의 요건은 「수선유지비를 별도로 구분하기 어려운 경우」 하나다**(시행규칙 §27의2⑥1호 단서)
  - → 해당 시 `수선유지비 = (임차료 − 보험료 − 자동차세) × 7%`
  - [ ] ⚠️ **"할 수 있다" — 임의규정이다.** 실제 금액을 구분할 수 있으면 그 금액을 차감하는 것이 원칙이고, 7%는 구분이 어려울 때의 대안이다
- [ ] ⚠️ **정비 미포함 금융리스인데 관행적으로 "리스료 × 93%"를 쓰지 않았는가** — 요건 미충족 시 7%를 기계적으로 차감하면 안 된다
- [ ] ⚠️ **보험료·자동차세·수선유지비를 관련비용 집계(4장)에서 빼지 않았는가** — 이들은 관련비용에 그대로 포함되며, 여기서는 800만원 한도 대상을 분리할 뿐이다 (이중 차감 주의)

## 7. 800만원 한도 적용 (⑤단계)

- [ ] 업무사용 감가상각비 상당액 = 감가상각비 상당액 × 업무사용비율
- [ ] 차량별 연 800만원(축소한도 대상은 400만원) 한도 적용
- [ ] 일부 기간 임차 시 **월할**
- [ ] 한도초과액 산출

## 8. 소득처분

- [ ] 감가상각비 상당액 한도초과액 → **손금불산입(기타사외유출)**
- [ ] ⚠️ **보유차량의 감가상각비 한도초과액과 혼동하지 않았는가** — 근거 조항(1호/2호)이 달라 처분이 갈린다 → [[업무용승용차-사업용자동차-세무]] 7-3(3)
- [ ] 업무무관 부인액(1,500만원 초과분)은 **성격이 다르다** — 법인은 대표이사 상여 처분 가능 → [[업무용승용차-사업용자동차-세무]] 3장

## 9. 이월액 추인

- [ ] 전기 이월액 존재 여부 확인
- [ ] 추인 한도 = **800만원 − 당기 업무사용 감가상각비 상당액**
- [ ] 당기 상당액이 이미 800만원 이상이면 **추인 불가**
- [ ] **리스 종료 차량**: 당기 상당액 0 → 연 800만원씩 잔액 소진 시까지 계속 추인
  - [ ] ⚠️ 리스가 끝났다고 이월액 관리를 종료하지 않았는가
  - [ ] ⚠️ "10년 지나면 잔액 전액 손금"으로 알고 있지 않은가 — ✅ **현행 시행령 §50의2⑪2호에 그런 단서가 없음을 원문으로 확인**했다(2026-08-23). 이월공제 자체는 유지되므로 잔액 소진까지 계속 관리한다

## 10. 차량 교체·인수 시

- [ ] **A차 반납 + B차 신규**: 이월액을 B차로 **승계하지 않았는가** — 차량별로 독립 관리하고 한도도 각각 적용한다
- [ ] **리스차량을 직접 인수**: 임차기간 중 이월액은 소멸하지 않는다 (`사전-2020-법령해석법인-0295`)
  - [ ] ⚠️ "신규 800 + 이월 800 = 연 1,600만원"으로 단순 계산하지 않았는가 — 금액이 크면 사전답변의 사실관계와 신고서 기재방법을 별도 검토

## 11. 명세서 작성과 사후관리

- [ ] 「업무용승용차 관련비용 명세서」에 차량별로 기재
  - [ ] 당기 감가상각비 또는 감가상각비 상당액
  - [ ] 당기 한도초과액
  - [ ] 전기 이월액
  - [ ] 한도초과액 누계
  - [ ] 손금추인액
  - [ ] 차기 이월액
- [ ] 차량별 이월액 관리대장을 **잔액 0이 될 때까지** 유지
- [ ] 다음 사업연도 결산 시 이 대장을 먼저 확인
- [ ] ✅ **해산·합병·분할로 법인이 소멸하는 경우 — 이월잔액을 해산등기일이 속하는 사업연도에 전액 손금산입**한다(시행규칙 §27의2⑧). 청산 실무에서 놓치기 쉽다 → [[법인-폐업해산청산-체크리스트]]

## 자주 나오는 오류 5가지

1. **1,500만원과 800만원을 택일로 이해** — 순서가 다른 별개 규정이다.
2. **"리스료 × 93%"의 무조건 적용** — 7% 간주규정의 요건을 확인하지 않은 경우.
3. **보험료·자동차세·수선유지비의 이중 차감** — 관련비용에서까지 빼버리는 오류.
4. **리스 종료 시 이월액 관리 종료** — 종료 후가 오히려 추인 여력이 가장 큰 시기다.
5. **차량 교체 시 이월액 승계 시도** — 차량별 독립 원칙 위반.
