# 가업승계 검토 체크리스트

> [!info] 개요
> **이 문서는 순서와 점검 항목만 소유한다.** 요건의 근거·조문·숫자 사례는 정본 [[가업상속공제]](5-2~5-8 · 5-7 증여특례)에 있다. 여기에 법리를 복제하지 않는다.
>
> 관련: 주식 평가 [[비상장주식-보충적평가방법]] · 사업무관자산 정비 [[가지급금]] · [[부동산임대법인-세무]] · 상속 절차 [[상속개시-후-절차-체크리스트]] · 상담 [[자산가-상속증여-상담-유형과-질문]]

## 0. 먼저 경로를 고른다 — 상속공제 vs 증여특례

- [ ] 부모 건강·연령상 **시기를 고를 수 있는가** → 고를 수 있으면 **증여특례(조특법 §30의6)** 부터 검토(정본 5-7)
- [ ] 두 제도는 **연결**된다 — 증여특례 주식도 상속개시일 현재 요건을 갖추면 가업상속공제 대상(5-7b ⑨항)
- [ ] **2026 세제개편안**(정부안) 일정 확인 — 증여 2027.7.1 이후·상속 2027.7.1 이후 상속개시분부터 강화(경영기간 20년/30년, 727개 업종, 사후관리 10년) → **2027.6.30 이전 실행 여부**를 먼저 판단(5-5·5-7) `[현행 기준 확인 필요]`

## 1. 회사 요건

- [ ] 중소기업(자산총액 5천억 미만 등) 또는 중견기업(직전 3개 연도 매출 평균 **5천억 미만**)
- [ ] 별표 업종을 **주된 사업**으로 영위 — 업종코드 확인. 카페(비알코올 음료점) ✗ / 제과점 ○ 등 함정(5-1). 개편안에서 빠지는 업종(병원·약국·마트·주차장 등) 해당 여부(5-8)
- [ ] **중견기업이면 납부능력요건** — 가업 외 상속재산 > 상속세액 × 200%면 배제(3-2 「조문상 보충」)

## 2. 부모(피상속인·증여자) 요건

- [ ] **10년 이상 계속 경영**(동일 대분류 내 업종 변경 기간 합산)
- [ ] 특수관계인 합산 지분 **40%(상장 20%) 이상을 10년 이상** 보유 + 최대주주등
- [ ] **대표이사 재직**: 영위기간 50% 이상 / 10년 이상(자녀가 승계해 계속 재직) / 상속개시 전 10년 중 5년 이상 — **하나 이상**(5-2)
- [ ] 증여특례면 부모 **60세 이상**

## 3. 자녀(상속인·수증자) 요건 — 가장 자주 걸린다

- [ ] 18세 이상
- [ ] **상속공제**: 상속개시 전 **2년 이상 직접 종사** — 급여·근무 실질 자료 확보(이름만 올린 근무는 부인 사례). 65세 이전 사망·부득이한 사망은 예외. 배우자가 갖추면 인정(5-3·5-3b)
- [ ] **상속공제**: 신고기한까지 임원 취임 → 그 후 2년 내 대표이사
- [ ] **증여특례**: 신고기한까지 가업 종사 → **증여일부터 3년 내 대표이사**(5-7)

## 4. 공제·과세 대상 금액 계산

- [ ] 주식 평가(상속개시일·증여일 기준) → [[비상장주식-보충적평가방법]]
- [ ] **사업무관자산 비율** 산출 — 임대 부동산·대여금(가지급금)·과다보유현금(5년 평균 200% 초과)·영업무관 금융상품 → **사전 정비 대상 목록화**(3-2)
- [ ] 한도: 경영기간 10/20/30년 → 300/400/600억(증여특례도 동일 구간)
- [ ] 증여특례: 10억 공제 후 10%(120억 초과 20%) — **증여재산공제·신고세액공제 없음**, 수증자 2인 이상이면 1인 의제(5-7)

## 5. 신고 절차

- [ ] 상속: 신고기한 내 **가업상속재산명세서 + 입증서류** 제출(영 §15㉒)
- [ ] 증여특례: 신고기한(말일부터 3개월) 내 **특례적용신청서** 제출 — 놓치면 일반 세율(5-7b)
- [ ] 조세포탈·회계부정 형 확정 이력(전 10년·후 5년) 확인(§18의2⑧, §30의6④)

## 6. 사후관리 캘린더 (상속공제 5년 · 증여특례 5년)

- [ ] **상속공제 4대 사유**: 가업용 자산 40% 이상 처분(처분비율만큼) / 대표 사임·대분류 밖 업종변경·1년 이상 휴폐업 / 지분 감소(조금이라도) / 정규직 수·총급여가 **둘 다** 직전 2년 평균 90% 미만 → 공제액 **100%** + 이자(5-4)
- [ ] **증여특례**: 5년 대표직 유지·휴폐업 금지·대분류 밖 업종변경 금지·지분 유지(고용요건 없음)(5-7b)
- [ ] 매년 정규직 수(매월 말 평균)·총급여·지분율·업종코드를 기록하는 **관리대장** 운영
- [ ] 증여특례 후 **상속개시일 현재** 지분 유지·종사 여부 — 5년이 끝나도 가업상속공제 연결을 위해 계속 관리(5-7b ⑨)
- [ ] 사유 발생 시 그 달 말일부터 **6개월 내** 자진신고·납부(§18의2⑨)

## 7. 납부재원

- [ ] 공제 후 남는 상속세·증여세(사업무관자산분·한도 초과분) 재원 — 연부연납(가업상속재산 특례 기간 확인) → [[상속세-과세체계와-전략]] 3-4 `[원문 확인 필요]`
- [ ] 자가 건물 사업장은 **자산은 크고 현금은 없다** — 매각 없이 낼 수 있는지(5-8)
