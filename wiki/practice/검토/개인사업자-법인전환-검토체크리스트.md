# 개인사업자 법인전환 검토 체크리스트

성실신고확인대상 진입이나 소득 증가를 이유로 법인전환을 검토할 때 **세율차만 보고 결론내리지 않기 위한 절차서**다. 제도와 법리의 정본은 [[성실신고확인제도]]와 [[법인활용-소득분산과-실질과세]]를 참조한다.

## 진행 순서

```
0. 업종상 법인전환 가능 여부
   → 1. 현재 개인사업 구조와 성실신고 판정
   → 2. 비교 시나리오 정의
   → 3. 반복 세부담·현금흐름 계산
   → 4. 전환 시 일회성 세금·비용 계산
   → 5. 자금인출·승계·재투자 설계
   → 6. 법인 실질과 관계회사 거래 검증
   → 7. 실행·보류·재검토 결론
```

## 0. 법인전환 가능 여부

- [ ] 업종별 설립·개설 주체 제한과 인허가를 소관 법령으로 확인
- [ ] 의원·약국·전문자격업·공중위생업 등은 영상 설명만으로 가능/불가를 단정하지 않고 관할기관·전문법령 검토
- [ ] 직접 전환이 어렵다면 별도법인/MSO가 수행할 수 있는 업무와 본업 고유업무의 경계를 문서화

## 1. 현재 구조와 성실신고 판정

- [ ] 주업종·부업종과 한국표준산업분류 확인
- [ ] 해당 과세기간 수입금액을 15억원·7억5천만원·5억원 기준과 비교 → [[성실신고확인제도]]
- [ ] 겸영·복수 사업장 환산식 적용
- [ ] 공동사업장은 전체 수입금액으로 별도 판정
- [ ] 사업용 유형자산 처분 수입금액 제외 여부 확인
- [ ] 최근 3개년 매출·매출총이익·영업이익·사업소득·대표자 생활인출액 정리

## 2. 비교 시나리오

- [ ] A안: 개인사업 유지
- [ ] B안: 기존 사업 전체 법인전환
- [ ] C안: 본업은 개인 유지 + 실질 있는 별도법인/MSO
- [ ] D안: 당장은 유지하고 기준일에 재검토
- [ ] 각 안의 사업범위·계약주체·자산소유·직원·계좌를 서로 겹치지 않게 정의

## 3. 반복 세부담과 현금흐름

- [ ] 개인 종합소득세·지방소득세·건강보험료 예상액
- [ ] 법인세·지방소득세 예상액
- [ ] 대표자 급여·상여·배당·퇴직금별 개인세와 4대보험 영향
- [ ] 법인 내부에 남길 재투자금과 매년 개인에게 필요한 생활자금 구분
- [ ] 기장·결산·세무조정·등기·급여·4대보험 등 연간 관리비 반영
- ⚠️ 개인 최고세율과 법인 최저세율만 비교하지 않는다. 법인자금 인출 단계까지 합산한 **총 현금유출**로 비교한다.

## 4. 전환 시 일회성 세금과 비용

- [ ] 전환 방식: 사업양수도 / 현물출자 / 기타 구조
- [ ] 영업권 평가와 대가 지급구조
- [ ] 재고·유형자산·차량·무형자산 이전의 세무처리
- [ ] 부동산 이전 시 양도소득세·법인세·부가가치세·취득세 및 이월과세 요건 → [[부동산-법인활용]]
- [ ] 계약 승계·인허가 재발급·금융기관 동의·담보 변경 비용
- [ ] 포괄양수도·현물출자·일부 자산양수도·신규법인 병행 중 실제 사업승계 범위에 맞는 방식을 선택
- [ ] 영업권은 “현금인출 수단”으로 먼저 정하지 않고 실재·평가·원천징수·상각·특수관계 거래를 독립 검토
- [ ] 기존 대출·담보·보증의 법인 승계 가능 여부를 금융기관에 서면 확인

## 5. 성실신고확인 3년과 장기계획

- [ ] 성실신고확인대상 개인사업자의 전환법인이 법인세법상 **전환 후 3년 이내 확인대상**인지 판정
- [ ] 자녀 승계·지분증여·투자유치·매각 계획 확인
- [ ] 법인 청산 또는 대표자 자금회수 시 세부담까지 검토
- [ ] 단순히 현재 연순이익이 1억5천만원을 넘었다는 이유만으로 전환하지 않음 `[강사경험칙]`

## 6. 별도법인·MSO 실질 검증

- [ ] 법인이 실제로 제공하는 경영지원·마케팅·구매·인력·시설관리 업무 정의
- [ ] 담당 직원·사무공간·장비·업무시스템 존재
- [ ] 계약서·업무일지·산출물·메신저·이메일·거래내역 보존
- [ ] 본업자와 법인 사이 수수료의 산정근거와 비교가능 가격 확보
- [ ] 법인 고유 고객·거래처와 사업상 설립목적 확인
- [ ] 가족 주주·급여·배당은 실제 역할·근무·의사결정과 일치
- ⚠️ 실질 없는 페이퍼컴퍼니나 개인소득의 단순 이전은 [[법인활용-소득분산과-실질과세]]에 따라 부인·가산세 위험이 있다.

## 7. 결론과 산출물

- [ ] 3개년 개인 유지 vs 법인전환 세후현금흐름 비교표
- [ ] 일회성 전환세금·비용 명세
- [ ] 자금인출·재투자·승계 계획
- [ ] 업종규제·인허가 검토 메모
- [ ] 성실신고확인 대상 및 3년 규정 판정 메모
- [ ] 법인 실질 확보계획
- [ ] 결론: 실행 / 보류 / 조건부 실행 / 재검토일 지정

## 강의상 위험한 단순화

- “성실신고 대상이 되기 전에 전환하면 조사위험을 피한다”는 보장은 없다. 전환 자체보다 신고내용과 거래 실질을 본다.
- 가족을 주주로 넣는 것만으로 적법한 소득분산·상속재원이 생기지 않는다. 주식 취득자금, 증여세, 실제 주주권, 배당결의가 필요하다.
- 건강보험료가 일정률만큼 자동 절감되거나, 영업권을 설정하면 항상 세후현금이 유리하다는 단정은 하지 않는다.
