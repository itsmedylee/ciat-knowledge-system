# 개인사업자 법인전환 검토 체크리스트

성실신고확인대상 진입이나 소득 증가를 이유로 법인전환을 검토할 때 **세율차만 보고 결론내리지 않기 위한 절차서**다. 제도와 법리의 정본은 [[성실신고확인제도]]와 [[법인활용-소득분산과-실질과세]]를 참조한다.

## 진행 순서

```
0. 업종상 법인전환 가능 여부
   → 1. 현재 개인사업 구조와 성실신고 판정
   → 2. 비교 시나리오 정의
   → 3. 반복 세부담·현금흐름 계산
   → 4. 전환 시 일회성 세금·비용 계산
   → 5. 자금인출·승계·재투자 설계
   → 6. 법인 실질과 관계회사 거래 검증
   → 7. 실행·보류·재검토 결론
```

## 0. 법인전환 가능 여부

- [ ] 업종별 설립·개설 주체 제한과 인허가를 소관 법령으로 확인
- [ ] 의원·약국·전문자격업·공중위생업 등은 영상 설명만으로 가능/불가를 단정하지 않고 관할기관·전문법령 검토
- [ ] 직접 전환이 어렵다면 별도법인/MSO가 수행할 수 있는 업무와 본업 고유업무의 경계를 문서화

## 1. 현재 구조와 성실신고 판정

- [ ] 주업종·부업종과 한국표준산업분류 확인
- [ ] 해당 과세기간 수입금액을 15억원·7억5천만원·5억원 기준과 비교 → [[성실신고확인제도]]
- [ ] 겸영·복수 사업장 환산식 적용
- [ ] 공동사업장은 전체 수입금액으로 별도 판정
- [ ] 사업용 유형자산 처분 수입금액 제외 여부 확인
- [ ] 최근 3개년 매출·매출총이익·영업이익·사업소득·대표자 생활인출액 정리
- [ ] **직전연도 과세공급가액이 10억원을 초과했는지** 확인 — 소비자상대업종 개인사업자라도 이 기준을 넘으면 부가가치세 **신용카드 등 발행세액공제** 대상에서 제외된다. 공제율·한도 특례는 **2026.12.31까지 1.3%, 연 1,000만원**이며 이후에는 추가 개정 여부를 확인한다. 카드·배달 매출 비중이 큰 업종에서는 전환 전후 현금흐름 비교에 반영한다 ([[2025-01-15-음식점 창업절차와 절세비법 이것만 기억하세요 절세미녀-소스요약]])
- [ ] **사업소득금액(순익)이 2~3억원 구간에 진입했는지** 확인 — 성실신고 기준과 별개의 검토 트리거다 ([[2026-05-26-종합소득세 많이 나왔다면 지금 무조건 보세요 세금 반토막 내는 법 (2026 종소세 절세 전략) 절세미녀-소스요약]])
- [ ] ⭐ **이월결손금 잔액과 잔여 공제기간을 계산** — 법인전환 시 **전액 소멸**한다. 공제기간은 발생 과세기간 종료일부터 **15년**이다(소득세법 §45③, 2020.12.29 개정. **종전 위키 서술의 "10년"은 오류였다**). 결손금이 남아 있다면 이를 소진할 때까지 전환을 늦추는 편이 유리한지 먼저 계산한다 → [[법인전환-절세가이드]]
- [ ] 절세상품(노란우산·연금계좌) 한도를 이미 소진했는지 확인 → [[사업자-절세금융상품]]. 한도가 남아 있으면 구조 변경보다 먼저 채운다
- [ ] 공동사업자 등록·가족 인건비로 해결 가능한 구간인지 먼저 검토 → [[사업소득-필요경비와-증빙]]. 법인전환은 되돌리기 비용이 크므로 **덜 무거운 수단을 먼저 소진**한다

## 1-2. ⭐ 전제 확인 — "법인이 유리하다"가 성립하는 조건

**세율만 비교하면 법인이 크게 유리해 보이지만, 그 이익은 "법인에 두고 쓰지 않을 때만" 실현된다.**

소득 2억원 기준 **원천 강의의 단순 예시**다. 비용·공제·대표자 보수·배당·4대보험 등 전제가 생략되어 있어 현행 비교표로 재사용하지 않는다:

| | 세금(지방세 포함) | 세후 잔액 |
|---|---|---|
| 개인 (38% 구간) | 약 6,100만원 | 약 1억 3,800만원 |
| 법인 | 약 1,080만원 | 약 1억 8,900만원 |
| **법인 → 개인 인출 후** | +약 5,300만원 | **약 1억 3,000만원** |

⚠️ **인출하는 순간 개인과 거의 같아진다.** 근로소득·퇴직소득·배당 어느 경로든 결국 소득세율이 적용되기 때문이다.

- [ ] **"당장 그 돈을 써야 하는가"** 를 먼저 묻는다 — 써야 한다면 법인의 이점은 없다
- [ ] 법인이 유리한 경우: **사업 확장·재투자·지분 매각·승계**를 계획하고 **자금을 유보**할 수 있을 때. 이점의 실체는 세율이 아니라 **시간**이다
- [ ] 개인이 유리한 경우: 벌어서 써야 하고, **개인 명의로 부동산·주식을 취득해 자금출처를 만들어야** 할 때
- [ ] ⚠️ **법인 자금은 대표 개인의 돈이 아니다.** 증빙 없이 인출하면 **횡령**이고 세무상으로는 [[가지급금]]이 된다
- [ ] **순서 설계**: 감면 대상 업종이면 **개인사업자로 창업해 5년간 [[창업중소기업-세액감면]]을 받으며 자금출처를 만든 뒤** 법인 전환을 검토하는 경로가 유효하다

## 2. 비교 시나리오

- [ ] A안: 개인사업 유지
- [ ] B안: 기존 사업 전체 법인전환
- [ ] C안: 본업은 개인 유지 + 실질 있는 별도법인/MSO
- [ ] D안: 당장은 유지하고 기준일에 재검토
- [ ] 각 안의 사업범위·계약주체·자산소유·직원·계좌를 서로 겹치지 않게 정의

## 3. 반복 세부담과 현금흐름

- [ ] 개인 종합소득세·지방소득세·건강보험료 예상액
- [ ] 법인세·지방소득세 예상액
- [ ] ⭐⭐ **전환법인이 「성실신고확인대상 소규모법인」에 해당하는지 먼저 판정한다.** 해당하면 법인세법 §55①**2호**에 따라 **과세표준 200억원 이하 전 구간에 20% 단일세율**이 적용되어 저율구간(2억 이하 10%)이 사라진다. 요건은 시행령 §42②의 ①지배주주등 지분 50% 초과 ②부동산임대업 주업 또는 임대·이자·배당이 매출의 50% 이상 ③상시근로자 5명 미만 — **셋을 모두** 갖춘 경우다. **"법인세 10%"를 전제로 시뮬레이션한 뒤 전환하면 세율이 2배가 된다** → [[부동산임대법인-세무]]
- [ ] 위에 해당하면 접대비 기본한도·업무용승용차 감가상각 한도 축소분도 함께 반영
- [ ] 대표자 급여·상여·배당·퇴직금별 개인세와 4대보험 영향
- [ ] 법인 내부에 남길 재투자금과 매년 개인에게 필요한 생활자금 구분
- [ ] 기장·결산·세무조정·등기·급여·4대보험 등 연간 관리비 반영
- ⚠️ 개인 최고세율과 법인 최저세율만 비교하지 않는다. 법인자금 인출 단계까지 합산한 **총 현금유출**로 비교한다.

## 4. 전환 시 일회성 세금과 비용

- [ ] 전환 방식: 사업양수도 / 현물출자 / 기타 구조
- [ ] ⭐ **사업양수도 방식이면 3개월 기한을 일정에 박아둔다** — 사업영위자가 **발기인이 되어** 순자산가액 이상을 출자해 법인을 설립하고, **법인설립일부터 3개월 이내**에 사업에 관한 모든 권리·의무를 포괄적으로 양도해야 이월과세가 적용된다(조특법 시행령 §29②)
- [ ] 이월과세 적용신청서를 **전환 사업연도 과세표준 신고 시 개인·법인이 공동 제출**(동 §29④) — 신청 자체가 요건이므로 누락하면 이월과세가 없다
- [ ] 업종이 **소비성서비스업**(호텔·여관업, 일반유흥·무도유흥·단란주점업 등, 동 §29③)에 해당하지 않는지 확인 — 해당하면 이월과세 배제
- [ ] 대상 자산에 **주택 또는 주택을 취득할 수 있는 권리**가 포함되어 있지 않은지 확인 — 포함분은 이월과세 제외(조특법 §32① 단서)
- [ ] 영업권 평가와 대가 지급구조
- [ ] 재고·유형자산·차량·무형자산 이전의 세무처리
- [ ] 부동산 이전 시 양도소득세·법인세·부가가치세·취득세 및 이월과세 요건 → [[부동산-법인활용]]
- [ ] **취득세 감면율은 50%다**(지방세특례제한법 §57의2④, 2027.12.31까지). 종전 위키·강의 서술의 "75%"는 개정 전 기준이다
- [ ] ⚠️ **부동산 임대 및 공급업은 취득세 감면 대상에서 제외**된다(같은 항). 임대목적 법인전환이면 감면을 계산에 넣지 않는다
- [ ] 계약 승계·인허가 재발급·금융기관 동의·담보 변경 비용
- [ ] 포괄양수도·현물출자·일부 자산양수도·신규법인 병행 중 실제 사업승계 범위에 맞는 방식을 선택
- [ ] 영업권은 “현금인출 수단”으로 먼저 정하지 않고 실재·평가·원천징수·상각·특수관계 거래를 독립 검토
- [ ] 기존 대출·담보·보증의 법인 승계 가능 여부를 금융기관에 서면 확인

## 5. 성실신고확인 3년과 장기계획

- [ ] 성실신고확인대상 개인사업자의 전환법인이 법인세법상 **전환 후 3년 이내 확인대상**인지 판정(법인세법 §60의2①2호)
- [ ] ⚠️ **법인을 한 번 더 갈아타는 우회는 막혀 있다** — 같은 항 **3호**는 그 전환법인의 사업을 인수한 **다른 내국법인**까지 전환일부터 3년간 대상으로 삼는다
- [ ] ⭐ **이월과세 5년 사후관리 캘린더를 만든다**(조특법 §32⑤) — **설립등기일**부터 5년. 위반 시 사유발생일이 속하는 달의 말일부터 **2개월 이내** 납부
- [ ] **"폐업"의 범위를 넓게 본다** — 전환법인이 승계한 **사업용고정자산의 1/2 이상을 처분하거나 사업에 사용하지 않으면 사업 폐지로 간주**된다(시행령 §29⑥). 자산 구조조정 계획이 있으면 5년 안에 이 선을 넘지 않는지 확인
- [ ] ⭐⭐ **"주식 처분"에 증여·감자가 포함된다**(시행령 §29⑦) — 유상이전·무상이전·유상감자·무상감자 모두 처분이다(균등소각 제외). **자녀 증여 플랜이 5년 내 50%를 넘으면 이월과세가 추징된다.** 가업승계 증여특례(조특법 §30의6)를 적용받으면 예외이나, 이때는 **수증자가 기간을 통산**한다(동 §29⑧) → [[가족법인-자산승계]]
- [ ] 자녀 승계·지분증여·투자유치·매각 계획 확인
- [ ] 법인 청산 또는 대표자 자금회수 시 세부담까지 검토
- [ ] 단순히 현재 연순이익이 1억5천만원을 넘었다는 이유만으로 전환하지 않음 `[강사경험칙]`

## 6. 별도법인·MSO 실질 검증

- [ ] 법인이 실제로 제공하는 경영지원·마케팅·구매·인력·시설관리 업무 정의
- [ ] 담당 직원·사무공간·장비·업무시스템 존재
- [ ] 계약서·업무일지·산출물·메신저·이메일·거래내역 보존
- [ ] 본업자와 법인 사이 수수료의 산정근거와 비교가능 가격 확보
- [ ] 법인 고유 고객·거래처와 사업상 설립목적 확인
- [ ] 가족 주주·급여·배당은 실제 역할·근무·의사결정과 일치

## 강의상 위험한 단순화

- “성실신고 대상이 되기 전에 전환하면 조사위험을 피한다”는 보장은 없다. 전환 자체보다 신고내용과 거래 실질을 본다.
- 가족을 주주로 넣는 것만으로 적법한 소득분산·상속재원이 생기지 않는다. 주식 취득자금, 증여세, 실제 주주권, 배당결의가 필요하다.
- 건강보험료가 일정률만큼 자동 절감되거나, 영업권을 설정하면 항상 세후현금이 유리하다는 단정은 하지 않는다.
