# 주식·풋옵션 결합금융상품 검토 체크리스트

> [!info] 개요
> 법리와 회계원칙은 [[주식-풋옵션-결합금융상품-회계]]가 정본이다. 이 문서는 검토 순서와 증빙만 다룬다.

## 1. 계약 구조

- [ ] 주식매매계약과 모든 변경계약을 확보했다.
- [ ] 기초자산, 취득대금, 지분율, 투자목적을 확인했다.
- [ ] 풋·콜옵션의 보유자, 의무자, 행사기간과 행사가격 산식을 확인했다.
- [ ] CPI 등 지수의 정의, 적용기간, 단리·복리와 지급일을 확인했다.
- [ ] 양도제한, 재매입약정, 담보, 수익보장 조항을 확인했다.

## 2. 분류와 회계단위

- [ ] 주식, 채무상품, 별도 파생상품, 결합계약 중 회계단위를 문서화했다.
- [ ] 채무상품 주장 시 사업모형과 SPPI 근거를 확보했다.
- [ ] 지분상품의 FVPL 원칙과 최초인식 FVOCI 선택 여부를 확인했다.
- [ ] 내재파생상품을 분리하거나 분리하지 않는 기준서 근거를 확인했다.
- [ ] `풋옵션 존재=대여금`이라는 결론에 의존하지 않았다.

## 3. 공정가치

- [ ] 각 보고기간 말 평가자료가 존재한다.
- [ ] 주식가치와 풋옵션 가치를 중복 또는 누락 없이 반영했다.
- [ ] 행사가격·만기·변동성·상대방 신용위험·양도제한을 반영했다.
- [ ] BPS·평균금리 사용 시 대용치 적합성을 설명했다.
- [ ] 평가기준일과 현금흐름일을 맞추고 할인기간을 검산했다.
- [ ] 외부평가보고서 사용 시 [[DCF-가치평가-및-평가보고서-검토-실무]]로 교차검토했다.

## 4. Roll-forward와 손익

- [ ] 취득일부터 회수일까지 연도별 기초·공정가치·평가손익·회수·기말 장부금액을 연결했다.
- [ ] 평가손익과 제거손익을 직전 장부금액 기준으로 구분했다.
- [ ] 회수액과 최초원가의 차액 전부를 처분이익 또는 이자수익으로 처리하지 않았다.
- [ ] 금융자산 제거일과 현금 회수일의 차이를 확인했다.

## 5. 제거와 오류수정

- [ ] 계약상 권리 소멸 또는 양도 사실을 확인했다.
- [ ] 위험·보상과 통제 판단을 최초 분류와 분리했다.
- [ ] 과거 각 보고기간 말 공정가치를 재구성했다.
- [ ] 과거 누락액의 중요성과 비교표시 재작성 필요성을 검토했다.
- [ ] 결론·판단·평가 입력값·검토자 승인 흔적을 조서에 남겼다.
