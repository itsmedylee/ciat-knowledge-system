# 해외사업장 순투자·순투자위험회피 검토 체크리스트

> 법리와 회계원칙은 [[해외사업장-순투자와-순투자위험회피]]가 정본이다. 이 문서는 결산·감사 검토 순서와 요청자료를 다룬다.

## 1. 사실관계와 기능통화

- [ ] 대여계약 원본·변경계약, 최초 대여일, 통화, 만기, 금리와 상환조건을 확보했다.
- [ ] 대여자와 차입자의 기능통화 판단 memo를 확보했다.
- [ ] 과거 원리금 상환·만기연장 이력과 연장 사유를 확인했다.
- [ ] 향후 상환계획, 자회사 지급능력, 그룹 자금계획과 승인자료를 확보했다.

## 2. 순투자의 일부 판단

- [ ] 가까운 미래에 결제할 **계획이 없음**을 입증했다.
- [ ] 가까운 미래에 결제될 **가능성이 낮음**을 별도로 입증했다.
- [ ] 경영진 의도만이 아니라 객관적 자료로 결론을 뒷받침했다.
- [ ] 매출채권·매입채무 등 정상 영업항목과 구분했다.
- [ ] 순투자 판단을 선택적 `지정`으로 표현하지 않았다.

## 3. 별도·연결 처리

- [ ] 별도 FS의 외화대여금 재측정과 P/L 인식을 확인했다.
- [ ] 자회사 기능통화와 차입통화를 비교해 환율차이 발생 주체를 확인했다.
- [ ] 연결에서 내부 원금을 제거했다.
- [ ] 환율차이가 일반대여금이면 P/L, 순투자의 일부이면 OCI인지 확인했다.
- [ ] 관련 표시·공시와 [[CF-환율변동효과]]·[[CF-연결-특수사항]] 처리가 정합한지 확인했다.

## 4. 위험회피회계

- [ ] 위험회피수단의 거래상대방이 연결실체 외부임을 확인했다.
- [ ] 개시일의 지정문서 원본과 위험관리 목적·전략을 확보했다.
- [ ] 위험회피대상·수단·위험·hedge ratio가 명확하다.
- [ ] 적격 외화위험과 지정가능 순투자 금액 한도를 확인했다.
- [ ] 경제적 관계, 신용위험 및 유효·비유효부분 산식을 검토했다.
- [ ] IFRS 7/K-IFRS 1107 위험회피 공시 초안을 확인했다.

## 5. FCTR와 종료 사건

- [ ] 해외사업장별 FCTR을 환산·순투자 대여금·위험회피의 세 원천으로 roll-forward했다.
- [ ] 환율 근거, NCI 배분과 처분 재분류 산식을 확보했다.
- [ ] 위험회피수단 종료, 내부대여금 상환, 해외사업장 처분을 서로 구분했다.
- [ ] OCI 재분류의 사건·원천·기준서 근거를 문서화했다.
- [ ] 해석상 다툼이 있는 부분은 회계정책과 최신 원문 확인 결과를 남겼다.

## 6. 세무 교차검토

- [ ] 외화 화폐성 자산 평가방법 신고 현황을 확인했다. `[현행 조문 확인 필요]`
- [ ] 국외특수관계자 대여의 정상이자율·이전가격을 검토했다.
- [ ] 무이자·저리 대여의 부당행위계산부인 위험을 검토했다.
- [ ] 회계상 장기 미상환 근거와 세무 포지션이 모순되지 않는지 확인했다.
