# 법인대출 준비와 재무정보 체크리스트

법인대출은 담보·보증·신용·정책자금으로 나뉘며, 금융기관마다 한도·금리·서류가 다르다. 재무제표는 대출을 위해 꾸미는 자료가 아니라 **실제 사업상태를 일관되게 설명하는 자료**여야 한다.

## 사전 진단

- [ ] 자금 목적·필요액·집행일·상환재원·만기 구조 명확화
- [ ] 담보여력, 대표자·법인 신용, 국세·지방세·4대보험 체납 확인
- [ ] 은행 신용대출 / 담보대출 / 신보·기보·지역신보 보증 / 중진공 등 정책자금 비교
- [ ] 대표자 연대보증 여부는 기관·상품·시점별로 서면 확인

## 재무정보

- [ ] 최근 3개년 재무제표와 부가가치세 과세표준증명 대사
- [ ] 매출·영업이익·현금흐름·부채비율·유동비율의 변동 원인 설명
- [ ] 재고·개발비·매출채권·특수관계인 채권의 회수가능성과 평가근거
- [ ] 차입금·담보·보증·리스·우발채무 전체 목록
- [ ] 사업계획의 매출 가정과 기존 실적 간 연결성

## 금지선

- 비용 누락, 재고 부풀리기, 실질 없는 개발비 자산화 등으로 이익을 만드는 행위 금지
- 대출기관용 숫자와 세무신고 숫자를 다르게 관리하지 않음
- 자료 삭제·소급 계약·허위 매출·가공 거래 금지

강의는 결산 때 비용·재고·개발비를 “조정”해 재무상태를 좋게 보이는 방법을 제안하지만, 경제적 실질과 회계기준에 맞지 않는 조정은 분식·대출사기·세무 문제로 이어질 수 있어 정본에서 배제한다.
