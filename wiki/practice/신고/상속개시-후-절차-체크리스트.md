# 상속개시 후 절차 체크리스트

상속이 개시된 시점부터 신고·납부 완료까지의 **수행 순서**다.

> **법리는 이 문서에 복제하지 않는다.** 세액 계산·공제 요건·평가 기준은 [[상속세-과세체계와-전략]], 상속포기·한정승인의 법률 요건은 [[상속승인과-포기]], 재산분할의 세목별 영향은 [[상속재산-협의분할-세금검토-체크리스트]], 조사 대비는 [[상속세-세무조사-대비-체크리스트]]가 소유한다.
>
> ⚠️ **근거는 자동자막 소스 3건이다.** 아래의 모든 기한·금액은 `[현행 기준 확인 필요]`이며, 실제 사건에 적용하기 전에 법령으로 대조한다.

---

## 0. 기한 지도 (먼저 확인)

| 항목 | 기한 | 기산점 |
|---|---|---|
| 상속포기·한정승인 | **3개월** | 상속개시를 **안 날**부터 |
| 상속세 신고·납부 | **6개월** | 상속개시일이 **속하는 달의 말일**부터 |
| 상속세 신고 (해외 관련) | **9개월** | 피상속인 **또는** 상속인 중 1인이 해외 주소 |
| 취득세 신고·납부 | **6개월** | 상속개시일 (⚠️ 연장은 **상속인**이 해외 주소인 경우만 9개월) |
| 부동산 등기 | 6개월 권장 | 지연해도 과태료·가산세는 없음 |
| 차량 명의변경·폐차 | 1·3·6개월 차등 | 처리 방식에 따라 다름 |

⚠️ **상속세와 취득세의 기한연장 요건이 다르다.** 상속세는 피상속인의 해외 주소도 연장 사유가 되지만, **취득세는 상속인의 요건만 본다.**

## 1. 1개월 이내 — 파악과 보전

### 1-1. 절대 하면 안 되는 것 (가장 먼저 확인)

- [ ] ⚠️ **피상속인 계좌·카드를 개인 목적으로 사용하지 않는다.** 재산보다 채무가 많은 것으로 밝혀졌을 때 **단순승인으로 간주**되어 상속포기·한정승인이 봉쇄될 수 있다.
- [ ] 다만 **장례비·미납 카드대금·통신비 등 고인의 채무 변제**는 무방하다.
- [ ] 급하지 않다면 상속인 대표가 **본인 카드·이체로 선지출**하고 기록을 모아 협의분할 후 정산한다.

### 1-2. 증빙 확보

- [ ] **병원비 영수증** — ⚠️ 결제는 반드시 **피상속인 계좌·카드**로. 자녀가 결제하면 공제되지 않는다. 미청구분은 사망 후 정산해 피상속인 자산으로 처리
- [ ] **장례비 영수증** — 증빙 없어도 기본 공제분이 있으나, 추가 공제를 받으려면 증빙 필수. ⚠️ 자연장지·봉안시설 계약서는 **시설이용료와 유지관리비를 구분**해 기재되어야 한다(관리비는 공제 대상 아님)
- [ ] ⚠️ **상조회사 지원금 확인** — 지원받은 금액은 상속재산에 가산되므로 실질 공제효과가 줄어든다
- [ ] **간병비 정황증거** — 간병인 인적사항·신분증 사본, 문자 기록, 업체 계약서. 현금 지급이 많아 증빙이 없으면 조사에서 사전증여로 의심받는다

### 1-3. 재산·채무 파악

- [ ] 사망신고와 **동시에 「안심상속 원스톱 서비스」 신청** (정부24 온라인 또는 주민센터) → 2~3주 뒤 부동산·금융자산·연금·세금·차량 내역 열람
- [ ] ⚠️ 조회 결과는 **참고용**이며 결과값이 아니다
- [ ] ⚠️ **사인 간 채권채무는 포착되지 않는다** — 생전에 확인하지 못했다면 유품·계약서·통장 메모로 별도 추적
- [ ] 은행: 상속개시일 기준 **잔액증명서·대출잔액증명서·과거 10년 거래내역**
- [ ] ⚠️ **말소된 계좌도 거래내역이 있으면 전부** 확보
- [ ] 보험사: 보험금 청구 및 영수증. ⚠️ 계약자·수익자·**실제 납입자**를 함께 확인
- [ ] 누락 빈발 항목 별도 점검: **보험금·퇴직금·해외 부동산·해외 금융계좌·친지 간 채권채무**

## 2. 3개월 이내 — 승인 여부 결정 (골든타임)

- [ ] 재산 > 채무 확인 → 단순승인으로 진행
- [ ] 채무 > 재산 또는 불분명 → **상속포기 / 한정승인** 결정. 법률 요건은 [[상속승인과-포기]] 참조
- [ ] ⚠️ **상속포기는 후순위 상속인에게 권리가 이전된다.** 자녀가 여럿이면 **일부는 포기 + 1인은 한정승인**으로 절차를 종료하는 조합이 실무상 일반적
- [ ] 3개월을 놓쳤다면 **특별한정승인** 검토 — 채무를 **안 날부터 3개월**, 단 몰랐던 데 **중대한 과실이 없어야** 인정
- [ ] 상속인 확정: 가족관계증명서로 대습상속·혼외자·이복형제 등 확인

## 3. 6개월 이내 — 평가·분할·신고

### 3-1. 재산 평가

- [ ] **부동산**: 유사매매사례가액 조회(전후 6개월·동일 단지·공동주택가격 5% 이내) 또는 **감정평가** 중 선택
- [ ] ⚠️ 평가액 선택은 **상속세만이 아니라 향후 양도세까지** 함께 계산해 결정한다 → [[감정평가-이슈]]
- [ ] **예금**: 상속개시일 잔액 + 미수이자
- [ ] **상장주식**: 상속개시일 **전후 각 2개월(총 4개월) 종가 평균**
- [ ] 비상장주식·해외자산은 별도 평가 절차

### 3-2. 재산 분할

- [ ] 순위 확인: ① 유언 → ② 협의분할 → ③ 법정지분
- [ ] ⚠️ **협의분할은 상속인 전원 동의 필수** (1인이라도 거부하면 무효)
- [ ] 세목별 영향 검토 → [[상속재산-협의분할-세금검토-체크리스트]]
- [ ] ⚠️ **협의가 안 되면 법정지분 비율로 일단 신고한다.** 하루만 늦어도 무신고가산세가 발생한다

### 3-3. 취득세·등기

- [ ] 부동산 취득세 신고·납부 (⚠️ **6개월 초과 시 가산세**)
- [ ] 지분 분쟁 중이라면 **취득세를 먼저 납부하고 등기는 나중에** 하는 방법 검토
- [ ] 차량 명의변경 또는 폐차

### 3-4. 신고 요부 판정과 신고

- [ ] 상속재산 vs 상속공제 비교 → 신고 의무 판정
- [ ] ⚠️ **과거 10년 내 사전증여가 있으면 재산이 없어도 신고 대상**이다. 상속인이 여럿이면 **다른 형제의 증여 사실**을 반드시 확인
- [ ] 공제 한도에 여유가 있으면 **감정평가로 가액을 높여 신고**하는 전략 검토(향후 양도세 절감)
- [ ] 배우자 상속공제를 받으려면 **실제 분할·이전 완료**. 확정 못하면 **신고기한 + 9개월 내 「상속재산 미분할 신고서」 제출** ⚠️ 미제출 시 공제 상실

### 3-5. 납부방법 결정

- [ ] **일시납 / 분납(2회) / 연부연납(최대 10년) / 물납** 중 선택
- [ ] 연부연납: 납부세액 2천만원 초과 + 매년 1천만원 초과 + **납세담보 제공** + 가산이자
- [ ] ⚠️ **공동상속 부동산을 담보로 제공하려면 다른 상속인 동의가 필요**하다. 본인 고유재산으로 담보를 제공하면 동의 없이 개별 신청 가능
- [ ] 물납: 부동산·유가증권 비율 50% 초과 + 납부세액 > 금융재산가액. ⚠️ **해외 부동산·상장주식 제외**
- [ ] **연대납세의무 활용** 검토 — 배우자가 자녀의 상속세를 대납하면 증여세 문제가 발생하지 않는다

## 4. 사업 승계가 있는 경우 (추가)

- [ ] 6개월 내 **사업자등록 정정**
- [ ] 피상속인의 **종합소득세 신고**
- [ ] 정규 기한에 맞춰 **부가가치세 신고** 후 승계 영위

## 5. 실무 주의사항

- ⚠️ **상속세는 신고로 끝나지 않는다.** 전건 검증 대상이므로 신고 단계에서 조사 대응까지 염두에 두고 자료를 구축한다 → [[상속세-세무조사-대비-체크리스트]]
- ⚠️ **상속개시 전 자문이 가장 효과적이다.** 개시 후라면 **사망신고 전에** 상담받는 것이 권장된다(전략 선택지가 남아 있는 시점).
- ⚠️ **상속 직전 예금 인출·증여를 하지 않는다.** 상속공제 한도 차감 + 금융재산 상속공제 상실 + 추정상속재산 소명의무의 삼중 불이익이 발생한다.
