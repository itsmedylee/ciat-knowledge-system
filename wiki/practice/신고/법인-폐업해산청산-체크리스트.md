# 법인 폐업·해산·청산 체크리스트

**사업자등록 폐업, 상법상 해산, 청산종결은 서로 다른 절차**다. 폐업신고만 하면 법인격과 등기의무가 자동으로 끝나는 것이 아니다.

관련 판단 기준: [[법인사업자-세금-신고구조]] · [[부가가치세-과세체계와-신고]] · [[가지급금]] · [[법인-대표자보수와-자금인출]]

## 1. 종료 방식 확정

- [ ] 사업만 중단하고 법인을 유지할지, 해산·청산까지 할지 결정
- [ ] 지급불능·채무초과이면 일반 청산이 가능한지 법률전문가와 회생·파산 절차 검토
- [ ] 인허가·임대차·직원·거래처·금융기관 종료 일정 작성

## 2. 폐업 전 자산·부채 정리

- [ ] 현금·예금·매출채권·재고·유형자산·부동산·차량·지식재산 목록화
- [ ] 대표자 가지급금·가수금과 특수관계인 채권·채무의 실재·회수·상환 증빙 확인
- [ ] 미지급 급여·퇴직금·세금·공과금·보증·소송·계약상 책임 확인
- [ ] 자산의 대표자·주주 이전은 시가, 부가가치세, 법인세, 증여·상여처분을 사전 검토

## 3. 세무 신고

- [ ] 폐업일이 속하는 과세기간의 부가가치세와 잔존재화 검토
- [ ] 원천세·지급명세서·4대보험 정산
- [ ] 해산등기일과 청산 중 사업연도별 법인세 신고 일정 확인
- [ ] 잔여재산 확정·분배와 주주의 의제배당 여부 계산

## 4. 법무·행정

- [ ] 주주총회 해산결의, 청산인 선임·등기, 채권자 보호절차
- [ ] 채권 추심·채무 변제·잔여재산 분배
- [ ] 청산종결 등기와 장부·세무서류 보존책임
- [ ] 휴면회사 직권해산·계속등기 규정에 기대어 방치하지 않음

## 강의 주장 교정

- 장부상 이익잉여금이 있다는 이유만으로 폐업 시 그 전액이 자동 의제배당되는 것은 아니다. 실제 잔여재산 분배액과 주식 취득가액 등으로 판단한다.
- 가지급금이 남았다고 즉시 전액 대표자 상여가 되는 것도 아니다. 회수 가능성·채권포기·소득처분의 사실관계를 본다.
- “채무가 있으면 청산할 수 없다”는 단정도 부정확하다. 지급불능·채무초과이면 도산절차 검토가 필요하다는 뜻으로 읽어야 한다.
