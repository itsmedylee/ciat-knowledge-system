# 법인 폐업·해산·청산 체크리스트

**사업자등록상 폐업, 상법상 해산, 청산종결은 서로 다른 절차**다. 폐업신고만 한다고 해서 법인격과 등기의무가 자동으로 사라지지 않는다.

관련 판단 기준: [[법인-해산청산-세무]](의제사업연도·청산소득·의제배당 정본) · [[법인사업자-세금-신고구조]] · [[부가가치세-과세체계와-신고]] · [[가지급금]] · [[법인-대표자보수와-자금인출]]

## 1. 종료 방식 확정

- [ ] 사업만 중단하고 법인은 유지할지, 해산·청산까지 진행할지 결정한다
- [ ] 지급불능이나 채무초과 상태라면 일반 청산이 가능한지, 회생·파산 절차가 필요한지 법률전문가와 함께 검토한다
- [ ] 인허가·임대차·직원·거래처·금융기관과의 관계를 정리하는 일정을 만든다

## 2. 폐업 전 자산·부채 정리

- [ ] 현금·예금·매출채권·재고·유형자산·부동산·차량·지식재산의 목록을 만든다
- [ ] 대표자 가지급금·가수금과 특수관계인 채권·채무가 실재하는지, 회수·상환한 증빙이 있는지 확인한다
- [ ] 미지급 급여·퇴직금·세금·공과금과 보증·소송·계약상 책임이 남아 있는지 확인한다
- [ ] 자산을 대표자나 주주에게 이전할 때에는 시가, 부가가치세, 법인세, 증여·상여처분 문제를 미리 검토한다

## 3. 세무 신고

- [ ] 폐업일이 속하는 과세기간의 부가가치세를 신고하고, 남아 있는 재화(잔존재화)에 과세되는지 검토한다
- [ ] 원천세·지급명세서·4대보험을 정산한다
- [ ] 해산등기일과 청산 중의 사업연도별 법인세 신고 일정을 확인한다: 해산등기일 / 잔여재산가액 확정일 / 중간신고 사유 → [[법인-해산청산-세무]] 2절
- [ ] 해산등기일 현재의 이월결손금과, 2년 안에 잉여금을 자본에 전입했는지를 확인한다(청산소득이 커질 수 있다)
- [ ] 잔여재산을 확정해 분배하고, 주주에게 의제배당이 생기는지 계산한다

## 4. 법무·행정

- [ ] 주주총회에서 해산을 결의하고, 청산인을 선임해 등기하며, 채권자 보호절차를 밟는다
- [ ] 채권을 추심하고, 채무를 변제하고, 잔여재산을 분배한다
- [ ] 청산종결 등기를 마치고, 장부와 세무서류를 보존할 책임을 이행한다
- [ ] 휴면회사 직권해산이나 계속등기 규정에 기대어 법인을 방치하지 않는다
- [ ] ⚠️ 청산하기 전에 법인 통장의 잔액을 대표자 개인 계좌로 옮기지 않는다. 가지급금이나 상여로 처분될 위험이 있다([[법인 폐업 후 통장 잔액 그냥 옮기면 안 되는 이유-소스요약]])

## 강의 주장 교정

- 장부에 이익잉여금이 있다는 이유만으로 폐업할 때 그 전액이 자동으로 의제배당되는 것은 아니다. 실제로 분배한 잔여재산과 주식 취득가액 등을 기준으로 판단한다.
- 가지급금이 남아 있다고 해서 곧바로 전액이 대표자 상여가 되는 것도 아니다. 회수 가능성, 채권포기 여부, 소득처분에 관한 사실관계를 본다.
- “채무가 있으면 청산할 수 없다”는 단정도 정확하지 않다. 지급불능이나 채무초과 상태라면 도산절차를 검토해야 한다는 뜻으로 읽어야 한다.
