# 법인세 결산·신고 체크리스트

이 문서는 법인세 신고를 위해 자료를 모으고 결산을 검토하는 절차를 정리한다. 법인 세금 신고의 전체 구조는 [[법인사업자-세금-신고구조]]에서 확인한다.

## 1. 일정과 대상

- [ ] 사업연도 종료일과 일반 신고기한을 확인한다(12월 말 결산법인은 통상 다음 해 3월 31일까지)
- [ ] 성실신고확인, 연결납세, 외부감사 미종결 등으로 기한이 달라지는지 확인한다
- [ ] 법인지방소득세의 신고 일정을 따로 등록한다
- [ ] 중간예납·원천세·부가가치세로 이미 낸 세액을 대사한다

## 2. 장부 마감

- [ ] 법인계좌·카드·현금·매출채권·매입채무를 대사한다
- [ ] 재고를 실사하고 평가하며, 유형자산의 취득·처분·감가상각을 확인한다
- [ ] 대출잔액·이자·보증수수료를 금융기관 증명서와 대사한다
- [ ] 보험료·공과금·지방세 납부 증빙과 이자의 원천징수영수증을 받는다
- [ ] 대표자 가지급금·가수금과 특수관계인 거래에 대해 계약·이자·상환계획을 확인한다

## 3. 인건비·자본거래

- [ ] 급여대장·원천세·4대보험·지급명세서가 서로 일치하는지 확인한다
- [ ] 임원 상여와 퇴직금이 정관, 주주총회·이사회 결의, 보수규정에 근거하는지 확인한다 → [[법인-대표자보수와-자금인출]]
- [ ] 배당의 결의·지급·원천징수와 미처분이익잉여금의 변동을 확인한다
- [ ] 주식변동상황명세서와 실제 주주명부가 일치하는지 확인한다

## 4. 세무조정·공제감면

- [ ] 손금불산입·익금산입 항목과 귀속자에 대한 소득처분을 검토한다
- [ ] 업무용승용차·기업업무추진비·업무무관자산의 한도를 검토한다
- [ ] 이월결손금·세액공제·감면의 요건을 확인하고, 중복지원 여부와 사후관리도 확인한다
- [ ] 공제감면은 해당 사업연도의 법령과 증빙으로 확정하고, 자동자막에서 나온 숫자를 그대로 쓰지 않는다

## 5. 산출물

- [ ] 신고서·재무제표·세무조정계산서를 서로 대사한다
- [ ] 납부서, 분납 여부, 환급계좌를 확인한다
- [ ] 주요 추정·쟁점·다음 해로 넘어가는 사항을 결산 메모로 남긴다
- [ ] 반복해서 발생한 오류를 다음 사업연도의 월마감 체크리스트에 반영한다
