# 법인세 결산·신고 체크리스트

법인세 신고를 위한 자료수집과 결산 검토 절차다. 제도 지도는 [[법인사업자-세금-신고구조]]를 참조한다.

## 1. 일정과 대상

- [ ] 사업연도 종료일과 일반 신고기한 확인(12월 말 법인은 통상 다음 해 3월 31일)
- [ ] 성실신고확인·연결납세·외부감사 미종결 등 별도 기한 여부 확인
- [ ] 법인지방소득세의 별도 신고 일정 등록
- [ ] 중간예납·원천세·부가가치세 기납부액 대사

## 2. 장부 마감

- [ ] 법인계좌·카드·현금·매출채권·매입채무 대사
- [ ] 재고 실사와 평가, 유형자산 취득·처분·감가상각 확인
- [ ] 대출잔액·이자·보증수수료와 금융기관 증명서 대사
- [ ] 보험료·공과금·지방세·이자 원천징수영수증 수취
- [ ] 대표자 가지급금·가수금과 특수관계인 거래의 계약·이자·상환계획 확인

## 3. 인건비·자본거래

- [ ] 급여대장·원천세·4대보험·지급명세서 일치
- [ ] 임원 상여·퇴직금의 정관·주주총회/이사회·보수규정 확인 → [[법인-대표자보수와-자금인출]]
- [ ] 배당 결의·지급·원천징수와 미처분이익잉여금 변동 확인
- [ ] 주식변동상황명세서와 실제 주주명부 일치

## 4. 세무조정·공제감면

- [ ] 손금불산입·익금산입 항목과 귀속자 소득처분 검토
- [ ] 업무용승용차·기업업무추진비·업무무관자산 한도 검토
- [ ] 이월결손금·세액공제·감면의 요건, 중복지원·사후관리 확인
- [ ] 공제감면은 해당 사업연도 법령과 증빙으로 확정하고 자동자막 숫자를 사용하지 않음

## 5. 산출물

- [ ] 신고서·재무제표·세무조정계산서 상호 대사
- [ ] 납부서·분납·환급계좌 확인
- [ ] 주요 추정·쟁점·차기 이월사항을 결산 메모로 남김
- [ ] 다음 사업연도 월마감 체크리스트에 반복 오류 반영
