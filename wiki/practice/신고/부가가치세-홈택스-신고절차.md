# 부가가치세 홈택스 신고절차

홈택스에서 직접 부가가치세를 신고할 때의 **순서와 함정**을 정리한 절차서다. 제도·법리의 정본은 [[부가가치세-과세체계와-신고]]와 [[부가가치세-매입세액-공제와-불공제]]를 참조한다. 여기서는 **언제 시작할지, 어떤 서식을 켤지, 무엇을 빠뜨리기 쉬운지**만 다룬다.

## 0. 신고 시작 시점 — 자료가 다 모인 뒤에 시작한다

국세청 자료는 한꺼번에 열리지 않는다. 일찍 시작하면 **매출·매입이 누락된 채로 신고**된다.

| 자료 | 제공 시점 예시 (원천 강의의 1월 신고 기준) |
|---|---|
| 전자세금계산서·계산서 매출·매입 | 1.12 |
| 신용카드 매출 | 1.13 |
| 영세율(내국신용장·구매확인서) | 1.15 |
| 전자상거래 결제자료 (쿠팡·네이버·배민·요기요 등) | 1.16 |

- [ ] 해당 연도 홈택스의 **자료 제공 일정표**를 확인
- [ ] 신용카드·현금영수증 자료가 있으면 해당 자료가 열린 뒤 조회
- [ ] 온라인 판매가 있으면 각 플랫폼 정산자료까지 확보한 뒤 시작

⚠️ 날짜는 연도별로 바뀌므로 **해당 연도 홈택스 안내사항을 확인**한다. `[강의 시점 기준]`

## 1. 진입과 기본정보

- [ ] 홈택스 로그인 (인증서 로그인 권장 — 어차피 중간에 인증이 필요하다)
- [ ] 세금신고 → 부가가치세 → **정기신고(확정)**
- [ ] 사업자등록번호 입력 후 확인 → 사업자 세부사항 확인
- [ ] 과세기간 확인 — **일반과세자 2기는 7~12월, 간이과세자는 1~12월**

### ⚠️ 무실적 신고를 함부로 누르지 않는다

- [ ] **매출이 0원이어도 매입이 있으면 무실적 신고 금지**

예컨대 과세사업에 사용할 인테리어를 공급받고 적격 세금계산서를 수취했다면 매입세액이 환급 대상이 될 수 있다. 무실적 신고를 누르면 그 내용을 반영하지 못한다. 면세사업 관련·사업무관 지출 등은 공제되지 않는다.

## 2. 켜야 할 서식 선택

해당하는 것만 체크한다.

**매출 쪽**
- [ ] 매출처별 세금계산서합계표 — 세금계산서를 발행한 경우
- [ ] 신용카드매출전표등 발행금액집계표 — 카드·현금영수증 매출이 있는 경우
- [ ] 기타매출 — 순수 현금매출, 온라인 매출
- [ ] 과세표준명세 — 업종별 매출 구분 (대부분 작성)
- [ ] **부동산임대공급가액명세서** — ⚠️ **임대업은 미작성 시 가산세 대상**

**매입 쪽**
- [ ] 매입처별 세금계산서합계표
- [ ] 신용카드매출전표등 수취명세서 — 카드·현금영수증으로 지출한 분
- [ ] **건물등 감가상각자산 취득명세서** — 건물·차량·비품(노트북·책상·가구 등) 취득이 있는 경우
- [ ] **공제받지못할매입세액명세서** — ⚠️ 차량 렌트료 등 세법상 불공제 항목. **리스는 계산서(면세)라 해당 없음**

**기타**
- [ ] 매출/매입처별 계산서합계표 — 세금계산서가 아닌 계산서가 있는 경우
- [ ] 영세율매출명세서·영세율첨부서류제출명세서·수출실적명세서 — 수출, 해외 플랫폼 수입(유튜버·아마존 등)

## 3. 매출 입력

- [ ] 전자세금계산서 **불러오기** 실행
- [ ] **수기(종이) 세금계산서**가 있으면 하단에 직접 입력 후 「입력내용 추가」
- [ ] 신용카드·현금영수증 매출은 **발행내역 조회** 후 금액 반영
- [ ] **순수 현금매출**은 조회되지 않으므로 직접 입력

⚠️ **국세청에 조회되는 매출이 전부가 아니다.** 구매대행, 여러 오픈마켓 등은 정확히 집계되지 않으므로 **각 사이트에서 매출을 직접 확인해 합산**해야 한다.

## 4. 매입 입력과 공제 판정

- [ ] 전자세금계산서 불러오기
- [ ] 사업용 신용카드 내역 조회 후 반영
- [ ] ⚠️ **사전에 공제/불공제를 분류해 두어야 한다** — 홈택스가 자동으로 갈라주지 않는다 → [[부가가치세-매입세액-공제와-불공제]]

## 5. 세액공제·기납부 반영

- [ ] **전자신고 세액공제** — 홈택스로 직접 신고하면 적용된다
- [ ] **예정고지 납부분** 체크 — 10월(또는 4월)에 고지서로 납부한 금액
- [ ] 전자세금계산서 발급 세액공제 — 해당 시

## 6. 간이과세자 특칙

- [ ] 업종 선택 — **업종에 따라 부가가치율이 달라져 세액이 크게 바뀐다.** 가장 중요한 선택이다
- [ ] 매출은 신용카드·현금영수증·기타로 구분 입력
- [ ] 매입세금계산서합계표 반영
- [ ] 신용카드·현금영수증 발행세액공제 대상 여부와 자동 반영액 확인 — 현행 특례는 **2026.12.31까지 발급·결제금액의 1.3%, 연 1,000만원 한도**이며, 업종·사업자 유형·직전연도 공급가액 등 적용요건이 있다
- [ ] 해당 과세기간의 공급대가가 **4,800만원 미만**이면 원칙적으로 납부의무가 면제되지만, 신고의무가 없어지는 것은 아니다. 사업자등록 미이행 등에 따른 가산세 등 법 제69조 단서·예외도 확인한다
- [ ] 납부면제가 예상돼도 매출과 법정 제출명세를 사실대로 입력한다. **카드매입을 일괄 생략한다는 원천 강의의 처리법은 일반 원칙으로 사용하지 않는다**

## 7. 임대업 특칙

- [ ] 과세표준에 **임대료(월세) + 간주임대료** 를 모두 포함 → [[부가가치세-과세체계와-신고]]
- [ ] 간주임대료는 **매출세액 기타분**에 공급가액·세액 기재
- [ ] 과세표준명세에는 간주임대료를 **수입금액 제외**로 입력
- [ ] ⚠️ **부동산임대공급가액명세서** 작성 (미작성 시 가산세)
- [ ] 매입은 **건물관리비·수리비 등 부동산 관련분만** 반영. 소모품비·식대 등 일반 경비를 넣으면 소명 요구를 받기 쉽다

## 8. 마감

- [ ] 신고서 입력 완료 → 제출
- [ ] 납부서 확인 (홈택스 → 세금신고 → 전자신고 결과조회)
- [ ] 납부 — 현금·카드·기한연장 → [[부가가치세-과세체계와-신고]]

## 자주 나오는 실수

| 실수 | 결과 |
|---|---|
| 자료 제공 전에 신고 | 매출·매입 누락 |
| 매입만 있는데 무실적 신고 | 환급 기회 상실 |
| 임대업 명세서 미작성 | 가산세 |
| 카드 내역 전액 공제 처리 | 불공제 항목 부인·추징 |
| 온라인 매출 미집계 | 매출 누락 |
| 예정고지 납부분 미반영 | 이중 납부 |
