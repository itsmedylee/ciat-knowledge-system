# 현금영수증 환불·취소 처리 절차

> [!caution] 검증 상태
> 과거 상담에서 도출한 접수·결과 확인 체크리스트다. 발급 채널별 취소 가능 기간·ARS 메뉴·정정의 세무 효과는 사용 시점의 공식 안내로 확인한다 `[현행 기준 확인 필요]`. 과거 메뉴 순서를 현행 매뉴얼로 고정하지 않는다.

## 확인 순서

1. 원거래일·승인번호·원금액·발급 채널을 확인한다.
2. 소득공제용·지출증빙용·자진발급 여부, 실제 환불일·환불액을 확인한다.
3. 실제 거래에 맞는 전액 취소·부분 취소 방법과 현재 가능한 경로를 원발급 채널 또는 공식 상담으로 확인한다. 취소·재발급으로 중복·누락되지 않는지도 점검한다.
4. 인증·비밀번호 설정은 고객이 직접 하게 한다. 인증값을 업무 대화나 진행표에 저장하지 않는다.
5. 처리 결과의 원승인 연결·취소 금액·처리일과 환불 증빙을 확인한다.
6. 장부·신고 반영과 정정 필요 여부를 검토 담당자에게 넘긴다. 방법 안내와 실제 취소 완료를 구분한다.
