# 14. 현금흐름표 검토 체크리스트

## 14-1. 최우선 검증 (이것부터 확인)

- [ ] **기초현금 + 영업CF + 투자CF + 재무CF + 환율효과 = 기말현금(원장)**이 성립하는가
- [ ] 대차 검증(자산 = 부채 + 자본) 결과가 True인가
- [ ] 모든 소계행의 검증열(N) = 0인가
- [ ] 당기순이익이 손익계산서와 일치하는가

## 14-2. 계정별 체크포인트

### 대출채권
- [ ] 대손 제각(상각)액을 비현금으로 복원했는가
- [ ] 대손충당금 증감을 조정했는가
- [ ] 외화대출 환율변동을 분리했는가
- [ ] 현재가치할인차금 상각을 조정했는가

### 예수부채
- [ ] 외화예금 환율변동을 분리했는가
- [ ] 미지급이자를 조정했는가
- [ ] 순액표시 근거가 있는가

### 유가증권 (FVPL / FVOCI / AC)
- [ ] FVPL 평가손익을 손익조정에서 제거했는가
- [ ] **FVOCI 평가손익(OCI)을 손익조정에 넣지 않았는가** (넣으면 이중조정)
- [ ] FVOCI·AC 취득/처분을 총액으로 파악했는가
- [ ] 현재가치할인할증차금 상각을 조정했는가
- [ ] 처분 시 재분류조정(recycling) 처리가 맞는가

### 파생상품
- [ ] 매매목적 / 공정가치위험회피 / 현금흐름위험회피를 정확히 구분했는가
- [ ] 각 유형이 올바른 활동(영업/투자/재무)으로 분류되었는가
- [ ] 평가손익과 자산증감의 짝이 맞는가
- [ ] 해외사업환산차대를 손익조정에서 제외했는가

### 유형·무형·사용권자산
- [ ] 감가상각비·상각비를 전액 가산했는가
- [ ] 취득/처분을 총액으로 표시했는가
- [ ] 건설중자산 대체를 취득으로 이중계상하지 않았는가
- [ ] 처분손익과 처분가액을 구분했는가

### 리스
- [ ] **신규 리스 인식을 비현금으로 처리했는가** (가장 흔한 오류)
- [ ] 신규 리스 인식을 주석에 공시했는가
- [ ] 리스료 지급액이 M시트와 일치하는가
- [ ] 소액·단기리스 면제분을 구분했는가

### 발행금융채권·사채
- [ ] 할인발행차금 상각을 비현금으로 가산했는가
- [ ] 발행/상환을 총액으로 표시했는가
- [ ] 외화채권 환율변동을 분리했는가

### 환율
- [ ] 환율변동효과를 별도 라인(Ⅳ)으로 표시했는가
- [ ] 순증감 계산(Ⅴ)에서 환율효과를 **제외**했는가
- [ ] 외화환산손익(PL)과 해외사업환산차대(OCI)를 구분했는가

## 14-3. 비현금거래 체크포인트

- [ ] 신규 리스 인식을 반영했는가
- [ ] 계정 대체(건설중자산, 정상↔부실)를 반영했는가
- [ ] 현물 배당·출자전환을 반영했는가
- [ ] 비현금거래의 차변합계와 대변합계가 일치하는가
- [ ] 주석 공시 대상을 누락하지 않았는가

## 14-4. Key-in 체크포인트

- [ ] 모든 Key-in에 근거 조서가 있는가
- [ ] 전기 Key-in과 논리적 연속성이 있는가
- [ ] Key-in 입력 후 N열 = 0 재확인했는가
- [ ] **단수조정 셀을 임의로 삭제하지 않았는가**
- [ ] 하드코딩 셀이 시각적으로 구분되어 있는가

## 14-5. 분석적 검토 (Analytical Review)

- [ ] 영업활동 현금흐름 vs 당기순이익 비율이 합리적인가
- [ ] 전기 대비 각 활동별 현금흐름 변동이 설명 가능한가
- [ ] 환율효과 금액이 전기 대비 비정상적이지 않은가 (다른 오류가 흡수될 수 있음)
- [ ] 총액표시 금액이 비정상적으로 크지 않은가

## 🔷 14-6. 자작성 절차: Phase 1~5

> [!quote] 출처
> 출처: [[현금흐름표_정산표_학습레포트-소스요약]] (금융지주 연결 FY25 1Q). 14-1~14-5가 **완성된 CF를 검토**하는 순서라면, 이 절은 **처음부터 직접 작성**할 때의 순서다.
> 개념 근거는 [[CF-정산표-원리]] · [[CF-활동분류-논리]] · [[CF-검증체계와-단수조정]] 참조 (이 문서는 순서·주의점만 담는다).

### Phase 1. 준비
- [ ] 당기·전기 TB(정산표)를 **같은 파일에 배치**하고, 계정코드 체계가 일치하는지 확인한다
- [ ] (연결) 법인 열 구성을 확정한다: 신규 편입·제외 법인, **`998:연결조정` 열**
- [ ] VLOOKUP 열번호를 **파라미터 셀**로 관리하거나 `INDEX/MATCH`로 자동 산출하도록 구성한다
- [ ] **PBC를 발송**해 자회사에 다음 자료를 명시적으로 요구한다:
      **현금기준 이자수취·지급 / 배당수취 / 법인세납부 / 투자·재무 총액 유입·유출 / 비현금거래 명세**
      (⚠️ 이자 현금흐름은 **연결 레벨에서 역산하면 부정확**하다)

### Phase 2. 뼈대 구축
- [ ] BS의 모든 계정을 정산표 행에 나열하고, **자산 (+) / 부채·자본 부호반전**으로 부호를 통일한다
- [ ] **현금및현금성자산의 정의를 확정**하고, 3개월 초과 예치금과 사용이 제한된 예금을 **분리**한다 (가장 먼저 할 일)
- [ ] 활동구분(영업/투자/재무)을 **미리 확정해 문서로 남긴다**: 연도 간 일관성의 근거가 된다
- [ ] 검증식을 넣고, **코드열이 SUM 범위에 섞이지 않도록 물리적으로 분리**한다

### Phase 3. 배분
- [ ] 손익조정: PL 계정코드를 매핑한다. ⚠️ **1 계정 ≠ 1 성격**인 항목은 별도 명세를 확보한다
- [ ] 이자·배당·법인세: **자회사가 산출한 값을 쓰고, 역산하지 않는다**
- [ ] 투자·재무: **총액으로 표시**한다. 순액으로 표시하려면 1007.22~24 요건을 충족하는지 확인한다
- [ ] 비현금거래: **12유형을 빠짐없이 점검**하고([[CF-비현금거래]] §6-6), **차·대 합계 = 0**인지 확인한다
- [ ] 운전자본(plug)은 **마지막에** 산출한다: ⚠️ 다른 곳의 오류가 여기에 숨는다

### Phase 4. 검증
- [ ] **7단계 검증**이 전부 TRUE / 0인지 확인한다 ([[CF-검증체계와-단수조정]] §1)
- [ ] PL tie-out: 차이가 있으면 **사유를 문장으로 적는다**
- [ ] **기말현금을 두 가지 방법으로 산출해** 대사한다 (누적식 vs BS 직접 조회)
- [ ] 전기 공시 보고서와 **계정과목명 문자열을 대사**한다
- [ ] 단수차이에 **허용범위 정책**을 적용하고(예: ±10원), 범위를 넘으면 원인을 규명한다
- [ ] 수정전/수정후 비교열로 버전 간 변동을 확인한다

### Phase 5. 공시 연계
- [ ] **비현금거래를 주석 공시문으로 작성**한다 (1007.43)
- [ ] 사용이 제한된 현금을 주석에 공시한다 (1007.48)
- [ ] **재무활동 부채 조정표**를 작성한다 (1007.44A~44E): 기초 → 현금흐름 → 비현금 → 기말
- [ ] 단위를 환산할 때(원 → 천원/백만원) **소계를 다시 검증**하고, ±1 조정의 근거를 기록한다
- [ ] (연결) 내부거래·내부리스를 제거한 뒤의 잔액 기준인지 확인한다
