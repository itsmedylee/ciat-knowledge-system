# 국세기본법 1편 재작성 준비

준비일은 2026-11-10이다. 사용자가 다시 전달한 2026-09-21 게시본을 재작성 대상으로 삼는다. 이번 산출물은 자료와 구성안이며, 재작성 원고의 법률 검증·게시 판정은 아직 진행하지 않았다.

이후 사용자는 2편과 깊이·형태를 비슷하게 맞추려는 목적이라고 명확히 했다. 아래 최초 8개 절 구성안은 요약 중심이므로 그대로 적용하지 않았고, 2편과 비슷한 분량의 10개 절 초안을 `drafts/2026-11-10-납세의무-성립-확정-징수.md`에 작성했다. 현재 진행 상태는 해당 원고 머리말을 따른다.

## 1. 글의 목적과 독자

- 일반 납세자와 국세기본법을 공부하는 실무자가 성립·확정·징수를 구별하도록 돕는다.
- 독자의 중심 질문은 “세무서에서 통지서를 받았는데, 이미 세금이 정해졌다는 뜻인가요?”로 잡는다.
- 2편과 같은 정중한 경어체를 사용한다. 독자에게 명령하거나 공부 수준을 평가하는 표현은 쓰지 않는다.
- 한 편 안에서 기본 구조와 사례를 설명한다. 부과제척기간·징수권 소멸시효의 상세 내용은 2편으로 연결한다.
- 네이버용 본문을 먼저 준비하며, 홈페이지 정리본과 SVG 제작은 후속 작업으로 구분한다. 이전 2편의 배포 승인을 이번 1편의 게시 승인으로 확대하지 않는다.

## 2. 제목과 핵심 답변

추천 제목은 **[국세기본법] 세금은 언제 생기고, 어떻게 확정될까요?**이다.

부제는 “성립·확정·징수와 과세예고통지·납부고지의 차이”로 잡는다.

다른 제목 후보는 다음과 같다.

1. [국세기본법] 고지서가 와야 세금이 생기는 걸까요?
2. [국세기본법] 세금은 어떻게 정해지고 걷히게 될까요?

도입부에서 먼저 전달할 답은 다음과 같다.

- 세금은 고지서를 받았다는 이유로 처음 생기는 것이 아니라 세법상 과세요건에 따라 납세의무가 성립한다.
- 세액은 신고·정부의 결정·경정·성립과 동시 확정 등 세목과 경우에 맞는 방법으로 확정된다.
- 납부고지는 이미 확정된 세금을 걷는 경우와 결정·경정에 따른 부과 및 징수가 함께 나타나는 경우를 구별해야 한다.

## 3. 기존 글에서 정리할 부분

| 위치 | 재작성 방향 |
| --- | --- |
| 제목의 “국가가 세금을 만든다” | 세금의 법률상 성립과 세액 확정의 의미가 드러나는 제목으로 바꾼다. |
| 15개 절과 반복적인 정리 | 8개 절 안팎으로 묶고 설명·가상 사례·비교표의 역할을 나눈다. |
| 사례의 추가세액 500만 원과 2,000만 원 혼용 | 최초 신고 1,000만 원, 실제 본세 1,500만 원, 추가 과세분 500만 원으로 통일한다. |
| 제13·14절의 단일 흐름도 | 신고세액의 확정과 추가세액의 확정을 구별한다. 모든 세금이 확정 이후에 과세예고를 거치는 것처럼 연결하지 않는다. |
| 납부고지의 법적 기능 | 고지서 명칭보다 앞선 신고·확정 과정이 중요하다는 점을 두 사례로 설명한다. |
| 판례 번호 없는 “대법원도”, “법원 역시” | 실제 인용할 판결의 사건번호와 전문을 확인하거나, 법령으로 설명 가능한 문장으로 바꾼다. |
| 과세예고와 과세전적부심사의 예외 | 두 절차를 같은 것으로 취급하지 않는다. 2편에서 확인한 2023두51700의 적용 범위와 특별한 사정을 보존한다. |
| 마지막의 긴 공부 계획·자기평가 | 독자가 받은 문서를 어떻게 구별할지 정리하고 2편으로 연결한다. |

## 4. 목차안

1. **고지서를 받으면 그때 세금이 생기는 걸까요?** 통지서와 고지서의 차이에서 출발한다.
2. **성립·확정·징수는 무엇이 다를까요?** 세 용어를 한 문장씩 풀고 기본 구조를 보여 준다.
3. **부가가치세 1,000만 원을 신고하면 언제 확정될까요?** 신고 자체의 확정효와 납부의 구별을 설명한다.
4. **신고하지 않았거나 신고가 틀렸다면 어떻게 될까요?** 결정·경정과 추가 과세 사례를 설명한다. 신고 외의 확정방식도 짧은 표로 비교한다.
5. **과세예고통지서는 지금 돈을 내라는 뜻일까요?** 사전통지와 방어기회, 원칙적인 과세전적부심사 청구기간을 설명한다.
6. **납부고지서는 항상 세금을 새로 정하는 문서일까요?** 신고 후 미납세액의 징수와 추가 과세를 나눈다.
7. **세 가지 사례를 한눈에 비교해 볼까요?** 정상 납부·신고 후 미납·추가 과세를 별도 흐름으로 정리한다.
8. **통지서나 고지서를 받았다면 무엇부터 확인해야 할까요?** 문서 종류·대상 세액·신고 내역·송달일·대응기한을 확인하고 2편을 안내한다.

관련 법령·인용 판례·사무소 안내와 해시태그는 초안 README 규칙에 맞춰 후단에 둔다.

## 5. 가상 사례와 도식 설계

모든 사례는 가산세를 제외한 본세를 비교하는 설명용 가상 사례로 표시한다.

- 정상 납부는 `성립 → 신고로 1,000만 원 확정 → 납부`로 정리한다.
- 신고 후 미납은 `성립 → 신고로 1,000만 원 확정 → 미납 → 납부고지로 징수`로 정리한다.
- 추가 과세는 신고세액 1,000만 원이 이미 확정된 상태에서 누락 발견 후 추가 500만 원의 과세절차가 진행되는 것으로 설명한다. 법이 정한 경우의 조사 결과통지·과세예고와 사전구제, 결정·경정 및 부과·고지의 관계를 구별하며 실제 효력에는 적법한 송달도 확인한다.

도식은 개념도와 절차도를 구별한다. 모든 세목이 동일한 절차를 반드시 거치는 것처럼 표시하지 않는다. 결정·경정 후 내부 결재만으로 납세자에 대한 처분 효력이 완성되는 것처럼 단순화하지 않는다.

## 6. 이번 준비에서 확인한 조문

law-kr로 아래 현행 조문을 직접 조회했다.

| 근거 | 확인한 내용 |
| --- | --- |
| [국세기본법 제21조](https://www.law.go.kr/법령/국세기본법/제21조) | 과세요건 충족에 따른 성립, 세목별 성립시기와 원천징수·중간예납·예정신고 등의 예외 |
| [국세기본법 제22조](https://www.law.go.kr/법령/국세기본법/제22조) | 신고에 의한 확정, 정부의 결정·경정, 성립과 동시 확정 |
| [국세기본법 제81조의15](https://www.law.go.kr/법령/국세기본법/제81조의15) | 과세예고 대상, 납부고지 예정세액 100만 원 기준과 제외사유, 원칙적인 통지일부터 30일 이내 청구 및 적용 제외 |
| [국세징수법 제6조](https://www.law.go.kr/법령/국세징수법/제6조) | 납부고지서의 기재사항과 발급, 고지서 발급 예외 |

조회한 국세기본법은 MST 289999, 2026-10-02 시행본이며 국세징수법은 MST 290683, 2026-10-02 시행본이다. 성립과 확정이 항상 시간적으로 떨어진다고 단정하지 않는다. 국세기본법 제22조 제4항의 성립과 동시 확정 예외를 본문에 남긴다.

## 7. 초안 작성 때 추가로 확인할 근거

- 국세기본법 제12조의 송달 효력과 부가가치세의 결정·경정 근거를 관련 설명에 맞게 대조한다.
- [대법원 2004. 9. 3. 선고 2003두8180](https://www.law.go.kr/LSW/precInfoP.do?precSeq=83449)은 2편 판례 검증에서 신고확정세액의 징수처분을 설명하는 근거로 확인했다. 이번 1편에서 인용할 때에도 전문과 적용 사실관계를 다시 대조한다. 이 판결은 양도소득세 사건이므로 부가가치세 사건으로 소개하지 않는다.
- [대법원 2025. 2. 13. 선고 2023두51700](https://www.law.go.kr/LSW/precInfoP.do?precSeq=606537)은 2편에서 메인이 전문·주문·링크를 확인했다. 이번 글에서도 구법 사건이라는 점과 과세예고통지 생략에 관한 예외·증명책임을 유지한다.
- 기존 글의 불특정 “과세예고는 채무이행 요구가 아니다” 판결은 사건번호가 제시되지 않았다. 이를 임의 판결번호와 결합하지 않는다.
- 이번 준비는 다섯 검증자의 독립 검토를 실행한 결과가 아니다. 새 원고를 작성한 뒤 게시 전 법률 검증을 별도로 거친다.

## 8. 2편과 연결

1편에서는 세액이 언제 성립·확정되고 어떤 문서로 징수하는지를 이해한다. 이어서 “국가는 그 일을 언제까지 할 수 있을까요?”라는 질문으로 2편에 연결한다.

홈페이지에 공개된 2편은 [오래된 세금, 언제까지 매기고 걷을 수 있을까요?](https://ciatpartners.com/columns/tax-assessment-collection-limitation/)다. 네이버 2편의 게시 URL은 확인하지 않았으므로 임의 링크를 만들지 않는다.

예정 초안 파일은 `drafts/2026-11-10-납세의무-성립-확정-징수.md`다. 실제 초안 작성일이 달라지면 해당 작성일을 사용한다.
