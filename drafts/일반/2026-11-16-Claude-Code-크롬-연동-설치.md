# [생산성] 터미널을 처음 열어 본 사람의 Claude Code 크롬 연동 설치기 (Windows)

> **핵심 세 줄**
> 1. Claude Code를 크롬과 연결하면 Claude가 내 컴퓨터의 파일을 고치고, 크롬에서 결과를 확인하는 일까지 한 번에 합니다.
> 2. Windows에서는 PowerShell에 설치 명령 한 줄을 넣으면 되고, Node.js를 따로 설치할 필요가 없습니다. 연결에는 Claude 유료 구독 계정이 필요합니다.
> 3. Claude는 내가 로그인해 둔 사이트를 그대로 쓸 수 있습니다. 처음에는 읽기만 시키고, 허용 창을 읽은 뒤에 허용해야 합니다.

저는 개발자가 아닙니다. 며칠 전까지 터미널이 무엇인지도 정확히 몰랐습니다. 그런 상태에서 Claude Code를 설치하고 크롬 브라우저와 연결했습니다. 이 글은 그 과정에서 실제로 막혔던 곳을 순서대로 적은 기록입니다. Windows 기준이며, 명령어는 2026년 11월 16일에 Claude Code 공식 문서와 대조했습니다.

## 1. 왜 연결하나요

Claude를 쓰는 방법은 여러 가지이고, 방법마다 할 수 있는 일이 다릅니다.

| 구분 | 웹 claude.ai | Claude in Chrome 확장만 | VS Code의 Claude | Claude Code + 크롬 연동 |
| --- | --- | --- | --- | --- |
| 시키는 곳 | 웹 채팅창 | 크롬 옆 패널 | VS Code 편집기 | 터미널 |
| 내 컴퓨터 파일 수정 | 못 함 | 못 함 | 가능 | 가능 |
| 브라우저 조작 | 못 함 | 가능 | 연동하면 가능 | 가능 |
| 파일을 고치고 화면에서 확인 | 사람이 직접 | 파일 수정 불가 | 연동하면 가능 | 한 번에 가능 |

웹 Claude는 답을 알려 주고, 그 답을 파일에 옮기는 일은 사람이 합니다. 크롬 확장은 웹사이트를 대신 보고 누르지만 내 컴퓨터의 파일은 건드리지 못합니다. Claude Code를 크롬과 연결하면 두 가지를 함께 합니다.

## 2. 누구에게 필요한가요

필요한 경우와 필요 없는 경우가 분명히 나뉩니다.

- **필요한 경우:** 홈페이지 코드를 고친 뒤 브라우저에서 화면을 확인하는 일처럼 파일과 브라우저를 함께 쓰는 작업을 할 때입니다. 저는 사무소 홈페이지를 직접 관리하고 있어서 이 경우에 해당했습니다.
- **필요 없는 경우:** 블로그 글쓰기나 웹 관리자 화면처럼 웹사이트 안에서만 끝나는 작업입니다. 이런 일은 크롬 확장만으로 충분합니다.

터미널이 부담스럽다면 다른 방법도 있습니다. 공식 문서는 터미널 없이 쓰는 데스크톱 앱을 안내합니다. 이 글은 터미널로 설치하는 방법만 다룹니다.

## 5. 설치 순서

**1단계. 터미널 열기**

Windows 키를 누르고 `powershell`을 입력한 뒤 Enter를 누릅니다. 입력 줄이 `PS C:\`로 시작하면 PowerShell입니다.

**2단계. 설치 명령 넣기**

```
irm https://claude.ai/install.ps1 | iex
```

관리자 권한은 필요하지 않습니다. 설치하는 동안에는 화면에 진행 상황이 나오지 않습니다. 입력 줄이 다시 나타날 때까지 1~2분 기다립니다.

**3단계. 창을 닫고 새로 열기**

설치가 끝나면 PowerShell 창을 닫고 새로 엽니다. 그다음 설치를 확인합니다.

```
claude --version
```

`2.1.325` 같은 버전 숫자가 나오면 설치가 된 것입니다.

**4단계. 내 폴더로 이동한 뒤 크롬 연동으로 시작하기**

```
cd ~
claude --chrome
```

**5단계. 처음 화면과 로그인**

처음 실행하면 글자 색상 테마를 고르는 화면이 먼저 나옵니다. 로그인 화면이 아닙니다. 기본값에서 Enter를 누르면 됩니다. 이어서 브라우저가 열리면 Claude 구독 계정으로 로그인합니다.

**6단계. 연결 확인**

Claude Code 안에서 `/chrome`을 입력합니다. `Status: Enabled`와 `Extension: Installed`가 함께 보이면 연결된 것입니다.

**7단계. 읽기만 시켜 보기**

저는 처음에 이렇게 시켰습니다.

> 크롬에서 code.claude.com/docs/en/chrome 페이지를 열고, 제목이 뭔지 알려줘. 아무것도 수정하거나 제출하지 마.

Claude가 새 탭을 열어 페이지를 읽고 제목을 알려 주었습니다. 클릭이나 입력은 하지 않았습니다.

## 6. 제가 막혔던 곳 다섯 가지

**하나. `npm`을 인식하지 못한다는 오류가 났습니다.**
인터넷에는 `npm install -g @anthropic-ai/claude-code`로 설치하라는 안내가 많습니다. 이 방법은 Node.js가 설치된 컴퓨터에서만 됩니다. 제 컴퓨터에는 Node.js가 없어서 오류가 났습니다. 위 2단계의 설치 명령은 Node.js 없이 설치하는 공식 방법이고, 공식 문서도 이 방법을 권장합니다.

**둘. 설치 중에 아무 일도 일어나지 않는 것처럼 보였습니다.**
멈춘 것이 아니라 내려받는 중입니다. 공식 문서에도 설치 명령은 내려받는 동안 진행 상황을 보여 주지 않는다고 적혀 있습니다.

**셋. 설치했는데 `claude` 명령을 찾지 못했습니다.**
설치 직후의 창은 새 프로그램의 위치를 아직 모릅니다. 창을 닫고 새로 열면 됩니다.

**넷. 색상 선택 화면을 로그인 화면으로 착각했습니다.**
"Choose the text style"로 시작하는 화면은 테마 선택입니다. Enter를 누르면 다음으로 넘어갑니다.

**다섯. 작업 폴더가 `C:\Windows\System32`였습니다.**
PowerShell을 어떻게 열었는지에 따라 Windows 시스템 폴더에서 시작하는 경우가 있습니다. Claude Code는 시작한 폴더의 파일을 읽고 고칠 수 있으므로 시스템 폴더에서 실행하면 안 됩니다. `/exit`로 끝낸 뒤 `cd ~`로 내 폴더에 가서 다시 시작했습니다.

## 7. 쓰기 전에 알아 둘 주의사항

**로그인된 사이트를 그대로 씁니다.** 공식 문서에 따르면 Claude는 브라우저의 로그인 상태를 공유하므로 내가 이미 로그인한 사이트에 접근할 수 있습니다. 메일, 은행, 홈택스에 로그인해 둔 상태라면 그 화면도 대상이 됩니다. 로그인 화면이나 보안 문자가 나오면 Claude는 멈추고 사람에게 넘깁니다.

**허용 창을 읽고 허용합니다.** 브라우저 동작 전에 "Claude in Chrome wants to"로 시작하는 창이 뜹니다. 어느 사이트에서 무엇을 하려는지 읽은 뒤에 허용합니다. 사이트별 허용 범위는 크롬 확장 설정에서 관리합니다.

**처음에는 읽기만 시킵니다.** 지시문에 "수정하지 마", "제출하지 마"를 붙여 연습합니다. 익숙해지기 전에는 허락 없이 진행하는 자동 모드를 쓰지 않는 편이 안전합니다.

**고객 자료가 열린 화면에서는 쓰지 않습니다.** 이것은 공식 문서의 내용이 아니라 제 기준입니다. 저는 세무·회계 업무를 하므로 고객 자료가 보이는 탭이나 수임 고객의 홈택스 화면에서는 Claude에게 브라우저 작업을 시키지 않습니다. 업무용 브라우저와 연습용 브라우저를 나누는 방법도 있습니다.

**항상 켜 두면 사용량이 늘어납니다.** `/chrome`에서 "Enabled by default"를 켜면 `--chrome`을 매번 붙이지 않아도 됩니다. 다만 공식 문서는 이 설정이 브라우저 도구를 항상 불러와 컨텍스트 사용량을 늘린다고 안내합니다. 저는 필요할 때만 `--chrome`을 붙여 시작합니다.

## 8. 자주 쓰는 명령어

| 하고 싶은 일 | 입력 |
| --- | --- |
| 터미널 열기 | Windows 키 → `powershell` → Enter |
| 내 폴더로 이동 | `cd ~` |
| 크롬 연동으로 시작 | `claude --chrome` |
| 설치 확인 | `claude --version` |
| 연결 상태 확인(Claude Code 안에서) | `/chrome` |
| 종료 | `/exit` |
| 메뉴 닫기 | `Esc` |
| 실행 중인 작업 멈추기 | `Ctrl + C` |

연결이 끊기면 `/chrome`에서 "Reconnect extension"을 고릅니다. 그래도 안 되면 크롬과 Claude Code를 모두 껐다가 다시 켭니다.

## 9. 다음에 쓸 때의 순서

1. Windows 키 → `powershell` → Enter
2. `cd ~` (또는 작업할 폴더로 이동)
3. `claude --chrome`
4. 시킬 일을 한국어로 입력
5. 허용 창이 뜨면 읽고 허용
6. 끝나면 `/exit`
