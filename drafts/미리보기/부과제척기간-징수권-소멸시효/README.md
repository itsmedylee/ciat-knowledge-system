# 홈페이지 칼럼 HTML 미리보기

`index.html`을 Chrome·Edge 등 브라우저로 열면 볼 수 있습니다. 외부 파일·글꼴·이미지·서버 없이 동작하는 단일 HTML입니다.

- 상단의 데스크톱·모바일 버튼으로 화면 폭을 비교할 수 있습니다. 모바일 버튼은 좁은 화면의 배치를 살펴보는 미리보기이며 실제 기기 검증을 대신하지는 않습니다.
- 인쇄 버튼으로 인쇄하거나 브라우저의 PDF 저장 기능을 사용할 수 있습니다.
- 목차와 맨 위로 이동 버튼으로 본문을 탐색할 수 있습니다.
- 홈페이지 운영 배포는 하지 않았습니다. 실제 홈페이지의 공통 헤더·메뉴와 연결하기 전의 독립적인 디자인 시안입니다.

## 구성

- `index.html`은 원고 전문, SVG 5개, CSS, 미리보기 도구를 포함합니다.
- `build_preview.py`는 상위 초안 Markdown을 읽어 HTML을 다시 만듭니다. Python의 `markdown` 패키지가 필요합니다.
- `verification.json`은 본문 텍스트·숫자·근거 링크·소제목 보존, 내부용 메모 제외, SVG 문법 등의 검사 결과입니다.

원고를 수정한 뒤 이 폴더에서 아래 명령으로 다시 만들 수 있습니다.

```powershell
python .\build_preview.py
```

원고의 머리말과 내부용 검증 기록은 HTML에 넣지 않았습니다. 관련 법령·판례와 해시태그는 포함했습니다. SVG 도식은 원문을 돕는 요약이며, 구체적인 기산점과 적용 예외는 본문의 설명을 따릅니다.

## 확인 범위

HTML 구조·SVG XML 문법·원문 보존을 코드로 확인했습니다. 반응형 CSS와 인쇄 스타일을 작성했으나, 이번 세션에서는 브라우저 접속 호스트가 연결되지 않아 실제 브라우저 화면·모바일·인쇄 결과의 시각 검증은 하지 못했습니다.
