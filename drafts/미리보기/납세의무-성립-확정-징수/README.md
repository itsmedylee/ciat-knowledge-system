# 국세기본법 1편 홈페이지 미리보기

같은 폴더의 `index.html`을 브라우저로 열어 확인하시면 됩니다. 운영 홈페이지의 빌드 결과에서 본문과 CSS를 추출했으며, 인쇄/PDF 버튼을 제공합니다. SVG 도식은 3개입니다.

홈페이지 반영 코드는 `C:/dev/ciatpartners`에 준비되어 있습니다. 예정 경로는 `/columns/tax-obligation-assessment-collection/`입니다. 아직 커밋·푸시·운영배포하지 않았습니다.

빌드·TypeScript와 문서 구조 검사를 통과했습니다. 상세 결과는 `검증결과.json`과 홈페이지 저장소의 `docs/COLUMN-TAX-OBLIGATION-2026-11-10.md`에 있습니다. 브라우저 연결 제한으로 실제 화면의 육안 검사는 수행하지 못했습니다.
